Εισαγωγή: Τι είναι το Maxima;

Το Maxima είναι ένα Σύστημα Αλγεβρικής Επεξεργασίας (Computer Algebra System, CAS): ένα λογισμικό που εκτελεί μαθηματικές πράξεις συμβολικά, δηλαδή ακριβώς όπως ο άνθρωπος με χαρτί και μολύβι, χωρίς αποκοπή δεκαδικών.

Ενώ ένας επιστημονικός υπολογιστής (π.χ. Python/NumPy ή MATLAB) εργάζεται αριθμητικά — υπολογίζει $\sqrt{2}\approx 1.41421\ldots$ — το Maxima επιστρέφει ακριβώς sqrt(2), παραγοντοποιεί πολυώνυμα, ολοκληρώνει συναρτήσεις αναλυτικά και λύνει εξισώσεις σε κλειστή μορφή. Αυτή η ιδιότητα το καθιστά ιδιαίτερα χρήσιμο για:

  • Επαλήθευση χειρωνακτικών υπολογισμών — ανακαλύπτεις λάθη πριν την εξέταση.
  • Εξερεύνηση μαθηματικών εννοιών — π.χ. τι αλλάζει στη λύση μιας ΔΕ αν αλλάξει η αρχική συνθήκη;
  • Υπολογισμό ορίων, παραγώγων, ολοκληρωμάτων που είναι χρονοβόροι στο χέρι.
  • Γεωμετρική οπτικοποίηση με ενσωματωμένα γραφήματα 2D/3D.

Ιστορικό: Το Maxima κατάγεται από το Macsyma, το πρώτο CAS που αναπτύχθηκε στο MIT τη δεκαετία του 1960. Σήμερα διανέμεται ως ελεύθερο λογισμικό (GNU GPL) και αποτελεί μια από τις πιο ολοκληρωμένες ελεύθερες εναλλακτικές λύσεις έναντι εμπορικών συστημάτων όπως το Mathematica ή το Maple.

Για βαθύτερη μελέτη και εκτενή παρουσίαση των εντολών του Maxima βλ. .

💡 Maxima vs Python/NumPy — Πότε να χρησιμοποιώ τι;

  • Χρήση Maxima όταν: θέλεις ακριβή αναλυτική απάντηση, πρέπει να επαληθεύσεις θεωρητικό αποτέλεσμα, δουλεύεις με ορίσματα (π.χ. ολοκλήρωσε $\int x^n\,dx$ για γενικό $n$).
  • Χρήση Python/NumPy όταν: χρειάζεσαι αριθμητικό αποτέλεσμα για μεγάλο πίνακα, θέλεις να δημιουργήσεις γραφήματα υψηλής ποιότητας, η συνάρτηση δεν έχει κλειστή μορφή.
  • Ιδανικά: χρησιμοποιείς και τα δύο συμπληρωματικά!

Εισαγωγή στο Maxima

Το Maxima είναι ελεύθερο σύστημα αλγεβρικής επεξεργασίας (CAS — Computer Algebra System), διαθέσιμο για Windows, macOS και Linux. Αναπτύχθηκε από το MIT ως «Macsyma» τη δεκαετία του 1960 και σήμερα διατίθεται ως ανοιχτό λογισμικό. Το γραφικό του περιβάλλον, wxMaxima, προσφέρει φιλικό interface με αποτελέσματα σε μαθηματική σημειογραφία.

Εγκατάσταση

  1. Μεταβείτε στο https://wxmaxima-developers.github.io/wxmaxima/
  2. Κατεβάστε τον installer για το λειτουργικό σας σύστημα.
  3. Εγκαταστήστε — το Maxima συμπεριλαμβάνεται αυτόματα.

Βασικοί Κανόνες Σύνταξης

  • Κάθε εντολή τελειώνει με ερωτηματικό ; ή δολάριο $ (χωρίς εκτύπωση).
  • Σχόλια: /* κείμενο */
  • Ανάθεση τιμής: a : 5 (με άνω-κάτω τελεία)
  • Ορισμός συνάρτησης: f(x) := x^2 + 1
  • Το σύμβολο % αναφέρεται στο τελευταίο αποτέλεσμα.
  • Το float(…) μετατρέπει σε δεκαδικό αριθμό.
  • Εκτέλεση: Shift+Enter στο wxMaxima.

Πρώτες Εντολές στο Maxima

Εκφώνηση: Ανοίξτε το Maxima ή το wxMaxima και εκτελέστε τις ακόλουθες βασικές εντολές: (α) αριθμητικές πράξεις και αριθμητικές σταθερές ($\pi$, $e$), (β) υπολογισμό παραγόντων, ριζών και δυνάμεων, (γ) ορισμό μεταβλητής και συνάρτησης. Παρατηρήστε τη διαφορά μεταξύ συμβολικής και αριθμητικής αξιολόγησης.

Maxima
/* Αριθμητικές πραξεις */
2 + 3; /* 5 */
sqrt(2); /* sqrt(2) -- συμβολικο */
float(sqrt(2)); /* 1.41421356... */

/* Ορισμος συναρτησης */
f(x) := x^2 - 3*x + 2;
f(3); /* 2 */
f(a+1); /* (a+1)^2 - 3*(a+1) + 2 */

/* Σχολιο: το Maxima διατηρει ακριβη αποτελεσματα */
1/3 + 1/6; /* 1/2 */

Αλγεβρικές Πράξεις — Παραδείγματα

Εκφώνηση: Χρησιμοποιήστε το Maxima για αλγεβρικές πράξεις: (α) απλοποιήστε αλγεβρικές εκφράσεις με expand και factor, (β) λύστε εξισώσεις και ανισώσεις με solve, (γ) εκτελέστε παραγοντοποίηση πολυωνύμων. Συγκρίνετε τα αποτελέσματα με χειρωνακτικούς υπολογισμούς.

Maxima
/* Παραγοντοποιηση */
factor(x^3 - 3*x^2 + 3*x - 1); /* (x-1)^3 */

/* Απλοποιηση τριγωνομετρικης */
trigsimp(sin(x)^2 + cos(x)^2); /* 1 */

/* Λυση εξισωσης */
solve(x^2 - 5*x + 6 = 0, x); /* [x=2, x=3] */

/* Αντικατασταση */
f(x) := x^3 - 2*x;
ev(f(x), x = sqrt(2)); /* 0 */

Βασικές Πράξεις Πινάκων

Εκφώνηση: Χρησιμοποιήστε το Maxima για πράξεις πινάκων: (α) ορισμός πίνακα με matrix, (β) πολλαπλασιασμός πινάκων με . (τελεστής), (γ) υπολογισμός ορίζουσας με determinant και αντιστρόφου με invert. Επαληθεύστε ότι $A \cdot A^{-1} = I$.

Maxima
/* Ορισμος πινακων */
A: matrix([2, 1], [5, 3]);
B: matrix([3, -1], [-5, 2]);

/* Πολλαπλασιασμος */
A . B; /* matrix([1,0],[0,1]) -- αντιστροφος! */

/* Οριζουσα */
determinant(A); /* 1 */

/* Αντιστροφος */
invert(A); /* matrix([3,-1],[-5,2]) */

/* Επαληθευση: A * A^(-1) = I */
A . invert(A); /* ident(2) */

/* Αναστροφος */
C: matrix([1,2,3],[4,5,6]);
transpose(C); /* matrix([1,4],[2,5],[3,6]) */

Γραμμικό Σύστημα $3\times3$ με Maxima

Εκφώνηση: Χρησιμοποιήστε το Maxima για να επιλύσετε το γραμμικό σύστημα $3\times3$: ορίστε τον πίνακα συντελεστών $A$ και το διάνυσμα δεξιών μελών $\mathbf{b}$, και βρείτε τη λύση $\mathbf{x} = A^{-1}\mathbf{b}$ χρησιμοποιώντας linsolve. Επαληθεύστε την ορθότητα υπολογίζοντας $A \cdot \mathbf{x}$.

Maxima
load("linearalgebra");

/* Συστημα: x+2y-z=4, 2x-y+3z=1, 3x+y+2z=5 */
A: matrix([1, 2, -1], [2, -1, 3], [3, 1, 2]);
b: matrix([4], [1], [5]);

/* Μεθοδος 1: linsolve */
linsolve([x+2*y-z=4, 2*x-y+3*z=1, 3*x+y+2*z=5], [x,y,z]);
/* [x=2, y=1, z=0] */

/* Μεθοδος 2: αντιστροφος πινακας */
invert(A) . b;

/* Αναλυση: κλιμακωτη μορφη */
rref(addcol(A, b)); /* Επαυξημενος πινακας [A|b] */

/* Πυρηνας (ομογενες συστημα) */
nullspace(A);

Ιδιοτιμές και Ιδιοδιανύσματα

Εκφώνηση: Δίνεται ο πίνακας $A = \begin{pmatrix}4&1\\2&3\end{pmatrix}$. Χρησιμοποιήστε το Maxima για να: (α) υπολογίσετε το χαρακτηριστικό πολυώνυμο με charpoly, (β) βρείτε τις ιδιοτιμές με eigenvalues, (γ) υπολογίσετε τα ιδιοδιανύσματα με eigenvectors. Ερμηνεύστε τα αποτελέσματα.

Maxima
A: matrix([4, 1], [2, 3]);

/* Χαρακτηριστικο πολυωνυμο */
charpoly(A, lambda); /* lambda^2 - 7*lambda + 10 */

/* Ιδιοτιμες */
eigenvalues(A); /* [[2, 5], [1, 1]] => λ1=2 (πολλ.1), λ2=5 (πολλ.1) */

/* Ιδιοδιανυσματα */
eigenvectors(A);
/* Για λ=2: v=[-1,2], για λ=5: v=[1,1] */

/* Επαληθευση: A*v = λ*v */
v1: matrix([-1], [2]);
A . v1; /* 2 * v1 */

Παράγωγος, Όριο και Taylor

Εκφώνηση: Χρησιμοποιήστε το Maxima για συμβολικό διαφορικό λογισμό: (α) υπολογίστε παραγώγους διαφόρων τάξεων της $f(x) = x^3 e^{-x}$ με diff, (β) βρείτε όρια με limit, συμπεριλαμβανομένων ορίων στο άπειρο, (γ) αναπτύξτε σε σειρά Taylor γύρω από $x_0 = 0$ με taylor.

Maxima
/* Παραγωγος */
f(x) := x^2 * sin(x);
diff(f(x), x); /* 2*x*sin(x) + x^2*cos(x) */

/* Κανονας αλυσιδας */
g(x) := exp(x^2 + 1);
diff(g(x), x); /* 2*x*exp(x^2+1) */

/* 2η παραγωγος */
diff(f(x), x, 2);

/* Ορια */
limit(sin(x)/x, x, 0); /* 1 */
limit((1+1/n)^n, n, inf); /* %e */
limit(exp(-x), x, inf); /* 0 */

/* Κανονας L'Hopital */
limit((exp(x)-1)/x, x, 0); /* 1 */

/* Taylor γυρω απο x=0, ταξης 4 */
taylor(sin(x), x, 0, 5);
/* x - x^3/6 + x^5/120 + ... */

/* Αριθμητικη ριζα */
find_root(x^3 - 2, x, 1, 2); /* 1.259921... */

Αόριστο και Ορισμένο Ολοκλήρωμα

Εκφώνηση: Χρησιμοποιήστε το Maxima για υπολογισμό ολοκληρωμάτων: (α) αόριστα ολοκληρώματα σύνθετων συναρτήσεων με integrate, (β) ορισμένα ολοκληρώματα σε ένα διάστημα, (γ) ολοκληρώματα που εμπλέκουν τριγωνομετρικές και εκθετικές συναρτήσεις. Επαληθεύστε τα αποτελέσματα παραγωγίζοντας.

Maxima
/* Αοριστο ολοκληρωμα */
integrate(x^2, x); /* x^3/3 */
integrate(sin(x)*exp(x), x); /* exp(x)*(sin(x)-cos(x))/2 */
integrate(1/(x^2-1), x); /* log(x-1)/2 - log(x+1)/2 */

/* Ορισμενο ολοκληρωμα */
integrate(x^2, x, 0, 1); /* 1/3 */
integrate(sin(x), x, 0, %pi); /* 2 */

/* Γενικευμενο ολοκληρωμα */
integrate(exp(-x^2), x, 0, inf); /* sqrt(%pi)/2 */

/* Αριθμητικη ολοκληρωση (οταν δεν εχει κλειστη μορφη) */
romberg(exp(-x^2), x, 0, 1); /* 0.7468241... */

Διαφορικές Εξισώσεις — Χωριζόμενες και 2ης Τάξης

Εκφώνηση: Χρησιμοποιήστε το Maxima για να επιλύσετε διαφορικές εξισώσεις: (α) χωριζόμενη ΔΕ 1ης τάξης με ode2, (β) γραμμική ΔΕ 2ης τάξης με σταθερούς συντελεστές, (γ) αρχικό πρόβλημα με ic1 και ic2. Σχεδιάστε τη λύση με plot2d.

Maxima
/* ΔΕ 1ης ταξης: dy/dx = -y */
depends(y, x);
ode1: diff(y,x) + y = 0;
sol1: ode2(ode1, y, x); /* y = %c * exp(-x) */

/* Με αρχικη συνθηκη y(0)=2 */
ic1(sol1, x=0, y=2); /* y = 2*exp(-x) */

/* ΔΕ 2ης ταξης: y'' - 3y' + 2y = 0 */
ode2_eq: diff(y,x,2) - 3*diff(y,x) + 2*y = 0;
sol2: ode2(ode2_eq, y, x);
/* y = %k1*exp(x) + %k2*exp(2*x) */

/* Με αρχικες συνθηκες y(0)=1, y'(0)=0 */
ic2(sol2, x=0, y=1, diff(y,x)=0);
/* y = 2*exp(x) - exp(2*x) */

/* ΔΕ Bernoulli: y' + y/x = y^2 */
ode_bern: diff(y,x) + y/x = y^2;
ode2(ode_bern, y, x);

Σειρές και Ακολουθίες

Εκφώνηση: Χρησιμοποιήστε το Maxima για εργασία με ακολουθίες και σειρές: (α) ορισμός ακολουθίας και υπολογισμός πρώτων όρων, (β) σύγκλιση γεωμετρικής σειράς με sum, (γ) αθροίσματα σειρών inf (άπειρα) — π.χ. $\sum_{n=1}^{\infty} \frac{1}{n^2}$. Ερμηνεύστε τα αποτελέσματα.

Maxima
/* Αριθμητικη σειρα */
sum(1/k^2, k, 1, inf); /* %pi^2/6 */

/* x - x^3/6 + x^5/120 - x^7/5040 */

/* 1 + x + x^2/2 + x^3/6 + x^4/24 + x^5/120 */

/* Ακτινα συγκλισης με κριτηριο λογου */
f(n) := 1/n!;
float(limit(f(n+1)/f(n), n, inf)); /* 0 => ακτινα = +inf */

/* Σειρα δυναμεων */
powerseries(atan(x), x, 0);

/* Πίνακας ιδιοδιανυσμάτων P */
P : transpose(matrix(vecs[1][1][1], vecs[1][2][1]));

/* Έλεγχος: A = P * D * P^(-1) */
D : matrix([vals[1][1], 0], [0, vals[1][2]]);
print("Έλεγχος A = P*D*P^-1:", ratsimp(P . D . invert(P) - A));
