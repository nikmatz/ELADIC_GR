Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $a\lt b$, τότε $a+c\lt b+c$
    theorem add_c (a b c : ℝ) (h : a < b) : a + c < b + c
  • Αν $a\lt b$ και $c\gt 0$, τότε $ac\lt bc$
    theorem mul_c_pos (a b c : ℝ) (h : a < b) (hc : 0 < c) : a * c < b * c
  • Αν $a\lt b$ και $c\lt 0$, τότε $ac\gt bc$
    theorem mul_c_neg (a b c : ℝ) (h : a < b) (hc : c < 0) : a * c > b * c
  • Μεταβατικότητα: αν $a\lt b$ και $b\lt c$, τότε $a\lt c$
    theorem transitivity (a b c : ℝ) (h₁ : a < b) (h₂ : b < c) : a < c
  • Αν $0\lt a\lt b$, τότε $\dfrac{1}{a}\gt\dfrac{1}{b}$
    theorem inverse (a b : ℝ) (ha : 0 < a) (hab : a < b) : 1 / a > 1 / b

Κάθε υπόθεση έχει όνομα: π.χ. (h : a < b) σημαίνει «ξέρουμε ότι $a\lt b$ και αυτή τη γνώση τη λέμε h». Οι τέσσερις πρώτες ιδιότητες είναι έτοιμα θεωρήματα της Mathlib (add_lt_add_left, mul_lt_mul_of_pos_right, mul_lt_mul_of_neg_right, lt_trans)· την τελευταία την αποδεικνύουμε βήμα προς βήμα.

2. Βήμα προς βήμα: αν $0\lt a\lt b$, τότε $\frac{1}{a}\gt\frac{1}{b}$

Στο βιβλίο: $\dfrac{1}{a}-\dfrac{1}{b}$${}=\dfrac{b-a}{ab}\gt 0$, αφού $b-a\gt 0$ και $ab\gt 0$. Στον Lean:

Ο στόχος
a b : ℝ
ha : 0 < a
hab : a < b
⊢ 1 / a > 1 / b

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have hb : 0 < b := lt_trans ha hab

    Πρώτα σημειώνουμε ότι και $b\gt 0$, από τη μεταβατικότητα ($0\lt a$ και $a\lt b$). Το have προσθέτει ένα νέο γεγονός σε όσα ξέρουμε.

    Τι μένει να αποδειχθεί
    hb : 0 < b
⊢ 1 / a > 1 / b
  2. have key : 1 / a - 1 / b = (b - a) / (a * b) := by
  rw [div_sub_div _ _ ha.ne' hb.ne']
  ring

    Η ταυτότητα $\dfrac{1}{a}-\dfrac{1}{b}$${}=\dfrac{b-a}{ab}$: το div_sub_div φέρνει τα κλάσματα σε κοινό παρονομαστή (χρειάζεται $a\neq 0$ και $b\neq 0$) και το ring κάνει τις πράξεις στον αριθμητή.

    Τι μένει να αποδειχθεί
    key : 1 / a - 1 / b = (b - a) / (a * b)
⊢ 1 / a > 1 / b
  3. have pos : 0 < (b - a) / (a * b) := div_pos (sub_pos.mpr hab) (mul_pos ha hb)

    Το κλάσμα $\dfrac{b-a}{ab}$ είναι θετικό: θετικός αριθμητής (sub_pos: $b-a\gt 0$ αφού $a\lt b$) διά θετικό παρονομαστή (mul_pos: $ab\gt 0$).

    Τι μένει να αποδειχθεί
    pos : 0 < (b - a) / (a * b)
⊢ 1 / a > 1 / b
  4. linarith

    Από $\frac1a-\frac1b=\frac{b-a}{ab}$ και $\frac{b-a}{ab}\gt 0$ προκύπτει $\frac1a\gt\frac1b$. Αυτό είναι γραμμικός συνδυασμός όσων ξέρουμε, και τον βρίσκει η τακτική linarith.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: μεταβατικότητα

Απόδειξε ότι αν $a\lt b$ και $b\lt c$, τότε $a\lt c$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

import Mathlib

namespace Κεφ0.Anisotites

theorem add_c (a b c : ℝ) (h : a < b) : a + c < b + c :=
  add_lt_add_left h c

theorem mul_c_pos (a b c : ℝ) (h : a < b) (hc : 0 < c) : a * c < b * c :=
  mul_lt_mul_of_pos_right h hc

theorem mul_c_neg (a b c : ℝ) (h : a < b) (hc : c < 0) : a * c > b * c :=
  mul_lt_mul_of_neg_right h hc

theorem transitivity (a b c : ℝ) (h₁ : a < b) (h₂ : b < c) : a < c :=
  lt_trans h₁ h₂

theorem inverse (a b : ℝ) (ha : 0 < a) (hab : a < b) : 1 / a > 1 / b := by
  have hb : 0 < b := lt_trans ha hab
  have key : 1 / a - 1 / b = (b - a) / (a * b) := by
    rw [div_sub_div _ _ ha.ne' hb.ne']
    ring
  have pos : 0 < (b - a) / (a * b) := div_pos (sub_pos.mpr hab) (mul_pos ha hb)
  linarith

end Κεφ0.Anisotites
