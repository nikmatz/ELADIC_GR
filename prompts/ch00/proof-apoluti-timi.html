1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $|a|\ge 0$

  • $|a|=0\Leftrightarrow a=0$
    theorem eq_zero_iff (a : ℝ) : |a| = 0 ↔ a = 0
  • $|ab|=|a|\,|b|$
    theorem abs_product (a b : ℝ) : |a * b| = |a| * |b|
  • $\left|\dfrac{a}{b}\right|$${}=\dfrac{|a|}{|b|}$
    theorem abs_quotient (a b : ℝ) : |a / b| = |a| / |b|
  • $|a|\lt b\Leftrightarrow -b\lt a\lt b$
    theorem lt_iff (a b : ℝ) : |a| < b ↔ -b < a ∧ a < b
  • Τριγωνική ανισότητα: $|a+b|\le|a|+|b|$
    theorem triangle (a b : ℝ) : |a + b| ≤ |a| + |b|
  • Αντίστροφη τριγωνική: $\bigl||a|-|b|\bigr|\le|a-b|$

  • Το $|a-b|$ είναι η απόσταση των $a,b$

Το ↔ σημαίνει «αν και μόνο αν» και το ∧ «και». Δύο μικρές διαφορές από το βιβλίο: στον Lean ισχύει $\frac{a}{0}=0$, άρα ο τύπος για το $\left|\frac{a}{b}\right|$ ισχύει και χωρίς την υπόθεση $b\neq 0$· και η ισοδυναμία για το $|a|\lt b$ δεν χρειάζεται $b\gt 0$ (αν $b\le 0$, είναι ψευδή και τα δύο μέλη). Το dist a b είναι η απόσταση όπως ορίζεται στη Mathlib.

2. Βήμα προς βήμα: η τριγωνική ανισότητα

Στο βιβλίο: $-|a|\le a\le|a|$ και $-|b|\le b\le|b|$· προσθέτοντας, $-(|a|+|b|)\le a+b\le|a|+|b|$, δηλαδή $|a+b|\le|a|+|b|$. Στον Lean:

Ο στόχος
a b : ℝ
⊢ |a + b| ≤ |a| + |b|

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have ha₁ : -|a| ≤ a := neg_abs_le a
have ha₂ : a ≤ |a| := le_abs_self a
have hb₁ : -|b| ≤ b := neg_abs_le b
have hb₂ : b ≤ |b| := le_abs_self b

    Γράφουμε τις τέσσερις γνωστές ανισότητες: neg_abs_le είναι το $-|x|\le x$ και le_abs_self το $x\le|x|$.

    Τι μένει να αποδειχθεί
    ha₁ : -|a| ≤ a
ha₂ : a ≤ |a|
hb₁ : -|b| ≤ b
hb₂ : b ≤ |b|
⊢ |a + b| ≤ |a| + |b|
  2. rw [abs_le]

    Το abs_le λέει ότι $|x|\le y$ αν και μόνο αν $-y\le x\le y$. Ο στόχος γίνεται δύο ανισότητες.

    Τι μένει να αποδειχθεί
    ⊢ -(|a| + |b|) ≤ a + b ∧ a + b ≤ |a| + |b|
  3. constructor

    Χωρίζουμε τις δύο ανισότητες σε δύο στόχους.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος left
    ⊢ -(|a| + |b|) ≤ a + b
    σκέλος right
    ⊢ a + b ≤ |a| + |b|
  4. · linarith

    Η πρώτη, $-(|a|+|b|)\le a+b$, προκύπτει προσθέτοντας $-|a|\le a$ και $-|b|\le b$. Την πρόσθεση τη βρίσκει το linarith.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  5. · linarith

    Η δεύτερη, $a+b\le|a|+|b|$, προσθέτοντας $a\le|a|$ και $b\le|b|$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: η αντίστροφη τριγωνική ανισότητα

Απόδειξε ότι $\bigl||a|-|b|\bigr|\le|a-b|$, χρησιμοποιώντας την τριγωνική ανισότητα triangle. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Γράψε $a=(a-b)+b$ και εφάρμοσε την triangle: παίρνεις $|a|\le|a-b|+|b|$. Το ίδιο με $b=(b-a)+a$, όπου $|b-a|=|a-b|$ (abs_sub_comm). Μετά rw [abs_le], constructor και linarith.

Λύση
theorem reverse_triangle (a b : ℝ) : |(|a| - |b|)| ≤ |a - b| := by
  have h₁ : |a| ≤ |a - b| + |b| := by
    calc |a| = |a - b + b| := by rw [sub_add_cancel]
      _ ≤ |a - b| + |b| := triangle (a - b) b
  have h₂ : |b| ≤ |a - b| + |a| := by
    calc |b| = |b - a + a| := by rw [sub_add_cancel]
      _ ≤ |b - a| + |a| := triangle (b - a) a
      _ = |a - b| + |a| := by rw [abs_sub_comm]
  rw [abs_le]
  constructor
  · linarith
  · linarith
