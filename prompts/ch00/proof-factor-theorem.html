1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Διαίρεση με το $x-r$, με υπόλοιπο $P(r)$: $P(x)=(x-r)Q(x)+P(r)$
    theorem division (P : ℝ[X]) (r : ℝ) :
    P = (X - C r) * (P /ₘ (X - C r)) + C (P.eval r)
  • $P(r)=0\Leftrightarrow$ το $x-r$ διαιρεί το $P(x)$
    theorem factor (P : ℝ[X]) (r : ℝ) : P.eval r = 0 ↔ (X - C r) ∣ P
  • Το πηλίκο $Q$ έχει βαθμό $n-1$
    theorem quotient_degree (P : ℝ[X]) (r : ℝ) :
    (P /ₘ (X - C r)).natDegree = P.natDegree - 1

Το ℝ[X] είναι τα πολυώνυμα με πραγματικούς συντελεστές και X η μεταβλητή τους. Το C r είναι το σταθερό πολυώνυμο $r$, το P.eval r (ή eval r P) είναι η τιμή $P(r)$, το ∣ σημαίνει «διαιρεί» και το P /ₘ (X - C r) είναι το πηλίκο της διαίρεσης με το $x-r$. Το natDegree είναι ο βαθμός. Το πρώτο θεώρημα είναι η ταυτότητα της διαίρεσης που χρησιμοποιεί το βιβλίο.

2. Βήμα προς βήμα: $P(r)$${}=0\Leftrightarrow (x-r)\mid P(x)$

Στο βιβλίο: από την ταυτότητα $P(x)=(x-r)Q(x)+P(r)$. Αν $P(r)=0$, τότε $P(x)=(x-r)Q(x)$. Αντίστροφα, αν $P(x)=(x-r)Q(x)$, τότε $P(r)=0\cdot Q(r)=0$. Στον Lean:

Ο στόχος
P : ℝ[X]
r : ℝ
⊢ eval r P = 0 ↔ X - C r ∣ P

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. constructor

    Ένα «αν και μόνο αν» είναι δύο συνεπαγωγές· το constructor τις χωρίζει.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος mp
    ⊢ eval r P = 0 → X - C r ∣ P
    σκέλος mpr
    ⊢ X - C r ∣ P → eval r P = 0
  2. · intro h

    Πρώτη κατεύθυνση. Υποθέτουμε $P(r)=0$ (υπόθεση h).

    Τι μένει να αποδειχθεί
    h : eval r P = 0
⊢ X - C r ∣ P
  3. rw [division P r, h, C_0, add_zero]

    Γράφουμε το $P$ με την ταυτότητα της διαίρεσης, βάζουμε $P(r)=0$ και σβήνουμε το $+0$.

    Τι μένει να αποδειχθεί
    ⊢ X - C r ∣ (X - C r) * (P /ₘ (X - C r))
  4. exact dvd_mul_right (X - C r) _

    Το $x-r$ διαιρεί το $(x-r)Q(x)$ (dvd_mul_right: το $a$ διαιρεί το $a\cdot b$).

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  5. · intro h

    Αντίστροφη κατεύθυνση. Υποθέτουμε ότι το $x-r$ διαιρεί το $P$.

    Τι μένει να αποδειχθεί
    P : ℝ[X]
r : ℝ
h : X - C r ∣ P
⊢ eval r P = 0
  6. obtain ⟨Q, hQ⟩ := h

    «Διαιρεί» σημαίνει ότι υπάρχει $Q$ με $P=(x-r)Q$· το obtain μας δίνει αυτό το $Q$.

    Τι μένει να αποδειχθεί
    Q : ℝ[X]
hQ : P = (X - C r) * Q
⊢ eval r P = 0
  7. rw [hQ, eval_mul, eval_sub, eval_X, eval_C, sub_self, zero_mul]

    Υπολογίζουμε $P(r)=(r-r)\,Q(r)=0\cdot Q(r)=0$, κανόνα προς κανόνα: τιμή γινομένου, διαφοράς, του $x$ και της σταθεράς.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

Το θεώρημα natDegree_divByMonic λέει ότι ο βαθμός του πηλίκου είναι η διαφορά των βαθμών, όταν ο διαιρέτης έχει μεγιστοβάθμιο συντελεστή $1$, όπως το $x-r$ (monic_X_sub_C r). Μετά natDegree_X_sub_C: το $x-r$ έχει βαθμό $1$.

import Mathlib

namespace Κεφ0.Paragontas
open Polynomial

theorem division (P : ℝ[X]) (r : ℝ) :
    P = (X - C r) * (P /ₘ (X - C r)) + C (P.eval r) := by
  have h := modByMonic_add_div P (X - C r)
  rw [modByMonic_X_sub_C_eq_C_eval] at h
  rw [add_comm]
  exact h.symm

theorem factor (P : ℝ[X]) (r : ℝ) : P.eval r = 0 ↔ (X - C r) ∣ P := by
  constructor
  · intro h
    rw [division P r, h, C_0, add_zero]
    exact dvd_mul_right (X - C r) _
  · intro h
    obtain ⟨Q, hQ⟩ := h
    rw [hQ, eval_mul, eval_sub, eval_X, eval_C, sub_self, zero_mul]

theorem quotient_degree (P : ℝ[X]) (r : ℝ) :
    (P /ₘ (X - C r)).natDegree = P.natDegree - 1 := by
  rw [natDegree_divByMonic P (monic_X_sub_C r), natDegree_X_sub_C]

end Κεφ0.Paragontas
