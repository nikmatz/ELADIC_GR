Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει. Ορίζουμε πρώτα τη ρίζα z ρ φ n k $=\rho^{1/n}e^{i(\varphi+2k\pi)/n}$, όπως στο βιβλίο, και μετά αποδεικνύουμε τι ισχύει γι’ αυτήν.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Κάθε $z_k$${}=\rho^{1/n}e^{i(\varphi+2k\pi)/n}$ είναι $n$-στή ρίζα του $w=\rho e^{i\varphi}$
    theorem z_pow (ρ φ : ℝ) (hρ : 0 < ρ) (n k : ℕ) (hn : n ≠ 0) :
    z ρ φ n k ^ n = ρ * exp (φ * I)
  • Οι $z_0,\dots,z_{n-1}$ είναι διακεκριμένες
    theorem z_injective (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) {j k : ℕ}
    (hj : j < n) (hk : k < n) (h : z ρ φ n j = z ρ φ n k) : j = k
  • Κάθε $n$-στή ρίζα του $w$ είναι κάποια $z_k$ με $k\lt n$
    theorem all_roots (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) (x : ℂ)
    (hx : x ^ n = ρ * exp (φ * I)) : ∃ k < n, x = z ρ φ n k
  • Ένας μη μηδενικός μιγαδικός έχει ακριβώς $n$ διακεκριμένες $n$-στές ρίζες
    theorem exactly_n (n : ℕ) (hn : n ≠ 0) (w : ℂ) (hw : w ≠ 0) :
    (Polynomial.nthRoots n w).Nodup ∧ Multiset.card (Polynomial.nthRoots n w) = n

Το hρ : 0 < ρ λέει ότι το μέτρο είναι θετικό ($w\neq 0$) και το hn : n ≠ 0 ότι $n\ge 1$. Το ρ ^ (↑n)⁻¹ είναι το $\rho^{1/n}$. Στο τελευταίο θεώρημα το nthRoots n w είναι οι ρίζες του πολυωνύμου $x^n-w$ με πολλαπλότητες· το Nodup λέει ότι καμία δεν επαναλαμβάνεται και το card ότι είναι $n$. Η γεωμετρική εικόνα (κορυφές κανονικού $n$-γώνου) δεν τυποποιείται εδώ.

2. Βήμα προς βήμα: κάθε $z_k$ είναι ρίζα: $z_k^{\,n}=\rho e^{i\varphi}$

Στο βιβλίο: $z_k^{\,n}$${}=\left(\rho^{1/n}\right)^n e^{i(\varphi+2k\pi)}$${}=\rho\,e^{i\varphi}\,e^{2k\pi i}$${}=\rho\,e^{i\varphi}$, αφού $e^{2k\pi i}=1$. Στον Lean:

Ο στόχος

hρ : 0 < ρ
n k : ℕ
hn : n ≠ 0
⊢ z ρ φ n k ^ n = ↑ρ * cexp (↑φ * I)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

    Σημειώνουμε ότι $n\neq 0$ και ως μιγαδικός αριθμός· θα διαιρέσουμε με αυτόν.

    Τι μένει να αποδειχθεί

⊢ z ρ φ n k ^ n = ↑ρ * cexp (↑φ * I)
  2. unfold z

    Ανοίγουμε τον ορισμό του $z_k$.

    Τι μένει να αποδειχθεί
    ⊢ (↑(ρ ^ (↑n)⁻¹) * cexp ((↑φ + 2 * ↑k * ↑π) / ↑n * I)) ^ n = ↑ρ * cexp (↑φ * I)

    $(ab)^n=a^nb^n$, και $\left(\rho^{1/n}\right)^n=\rho$ για $\rho\ge 0$ (Real.rpow_inv_natCast_pow).

    Τι μένει να αποδειχθεί

    $\left(e^x\right)^n=e^{nx}$.

    Τι μένει να αποδειχθεί
    ⊢ ↑ρ * cexp (↑n * ((↑φ + 2 * ↑k * ↑π) / ↑n * I)) = ↑ρ * cexp (↑φ * I)

  calc (n : ℂ) * ((φ + 2 * k * π) / n * I) = (n / n) * ((φ + 2 * k * π) * I) := by ring

    Ο εκθέτης: $n\cdot\dfrac{\varphi+2k\pi}{n}\,i$${}=\varphi i+k\cdot 2\pi i$. Τον υπολογίζουμε με δύο ισότητες (calc), όπου $n/n=1$ αφού $n\neq 0$.

    Τι μένει να αποδειχθεί

⊢ ↑ρ * cexp (↑n * ((↑φ + 2 * ↑k * ↑π) / ↑n * I)) = ↑ρ * cexp (↑φ * I)

    $e^{\varphi i+k\cdot 2\pi i}$${}=e^{\varphi i}\,e^{2k\pi i}$${}=e^{\varphi i}\cdot 1$, αφού $e^{2k\pi i}=1$ (exp_nat_mul_two_pi_mul_I).

3. Στη Mathlib

Για τη διάκριση και την πληρότητα των ριζών χρησιμοποιήσαμε τις πρωταρχικές ρίζες της μονάδας της Mathlib: $z_k=z_0\cdot\zeta^k$ με $\zeta=e^{2\pi i/n}$ (θεώρημα z_eq).

  • Complex.isPrimitiveRoot_exp: το $e^{2\pi i/n}$ είναι πρωταρχική $n$-στή ρίζα της μονάδας.
  • IsPrimitiveRoot.nthRoots_eq: οι λύσεις της $x^n=w$ είναι οι $\zeta^k\alpha$, $k=0,\dots,n-1$.
  • IsPrimitiveRoot.nthRoots_nodup: είναι διακεκριμένες.
  • IsPrimitiveRoot.card_nthRoots: είναι ακριβώς $n$.

import Mathlib

namespace Κεφ0.NostesRizes
open Complex
open scoped Real

/-- Η ρίζα με δείκτη k: ρ^(1/n) · e^(i(φ + 2kπ)/n). -/
noncomputable def z (ρ φ : ℝ) (n k : ℕ) : ℂ :=
  ((ρ ^ ((n : ℝ)⁻¹) : ℝ) : ℂ) * exp ((φ + 2 * k * π) / n * I)

theorem z_pow (ρ φ : ℝ) (hρ : 0 < ρ) (n k : ℕ) (hn : n ≠ 0) :
    z ρ φ n k ^ n = ρ * exp (φ * I) := by
  have hn' : (n : ℂ) ≠ 0 := Nat.cast_ne_zero.mpr hn
  unfold z
  rw [mul_pow, ← ofReal_pow, Real.rpow_inv_natCast_pow hρ.le hn]
  rw [← exp_natCast_mul]
  have h : (n : ℂ) * ((φ + 2 * k * π) / n * I) = φ * I + k * (2 * π * I) := by
    calc (n : ℂ) * ((φ + 2 * k * π) / n * I) = (n / n) * ((φ + 2 * k * π) * I) := by ring
      _ = φ * I + k * (2 * π * I) := by rw [div_self hn', one_mul]; ring
  rw [h, exp_add, exp_nat_mul_two_pi_mul_I, mul_one]

theorem z_eq (ρ φ : ℝ) (n k : ℕ) :
    z ρ φ n k = z ρ φ n 0 * exp (2 * π * I / n) ^ k := by
  unfold z
  rw [← exp_natCast_mul, mul_assoc (((ρ ^ ((n : ℝ)⁻¹) : ℝ) : ℂ)), ← exp_add]
  congr 2
  push_cast
  ring

theorem z_injective (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) {j k : ℕ}
    (hj : j < n) (hk : k < n) (h : z ρ φ n j = z ρ φ n k) : j = k := by
  have h0 : z ρ φ n 0 ≠ 0 := by
    unfold z
    apply mul_ne_zero
    · exact_mod_cast (Real.rpow_pos_of_pos hρ _).ne'
    · exact exp_ne_zero _
  rw [z_eq ρ φ n j, z_eq ρ φ n k] at h
  have h' := mul_left_cancel₀ h0 h
  exact (isPrimitiveRoot_exp n hn).pow_inj hj hk h'

theorem exactly_n (n : ℕ) (hn : n ≠ 0) (w : ℂ) (hw : w ≠ 0) :
    (Polynomial.nthRoots n w).Nodup ∧ Multiset.card (Polynomial.nthRoots n w) = n := by
  have hζ := isPrimitiveRoot_exp n hn
  refine ⟨hζ.nthRoots_nodup hw, ?_⟩
  have hex : ∃ α, α ^ n = w := IsAlgClosed.exists_pow_nat_eq w (Nat.pos_of_ne_zero hn)
  rw [hζ.card_nthRoots]
  simp [hex]

theorem all_roots (ρ φ : ℝ) (hρ : 0 < ρ) (n : ℕ) (hn : n ≠ 0) (x : ℂ)
    (hx : x ^ n = ρ * exp (φ * I)) : ∃ k < n, x = z ρ φ n k := by
  have hζ := isPrimitiveRoot_exp n hn
  have hmem : x ∈ Polynomial.nthRoots n ((ρ : ℂ) * exp (φ * I)) :=
    (Polynomial.mem_nthRoots (Nat.pos_of_ne_zero hn)).mpr hx
  rw [hζ.nthRoots_eq (z_pow ρ φ hρ n 0 hn)] at hmem
  obtain ⟨k, hk, hkx⟩ := Multiset.mem_map.mp hmem
  refine ⟨k, Multiset.mem_range.mp hk, ?_⟩
  rw [← hkx, z_eq ρ φ n k, mul_comm]

end Κεφ0.NostesRizes
