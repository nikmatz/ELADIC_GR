Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει. Οι ευθείες είναι οι $y=m_1x+b_1$ και $y=m_2x+b_2$. «Παράλληλες και διακριτές» σημαίνει ότι δεν έχουν κοινό σημείο: δεν υπάρχει $x$ με $m_1x+b_1=m_2x+b_2$.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Παράλληλες και διακριτές $\Leftrightarrow m_1=m_2$ και $b_1\neq b_2$
    theorem parallel_iff (m₁ m₂ b₁ b₂ : ℝ) :
    (¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂) ↔ m₁ = m₂ ∧ b₁ ≠ b₂
  • Αν $m_1=m_2$ και $b_1=b_2$, ταυτίζονται
    theorem coincide (m b : ℝ) : ∀ x : ℝ, m * x + b = m * x + b
  • Κάθετες $\Leftrightarrow m_1m_2=-1$
    theorem perpendicular_iff (m₁ m₂ : ℝ) : (1 : ℝ) * 1 + m₁ * m₂ = 0 ↔ m₁ * m₂ = -1

Το ¬ ∃ x σημαίνει «δεν υπάρχει $x$». Για την καθετότητα: οι ευθείες έχουν διανύσματα κατεύθυνσης $(1,m_1)$ και $(1,m_2)$ και είναι κάθετες όταν το εσωτερικό τους γινόμενο $1\cdot 1+m_1m_2$ είναι $0$. Η απόδειξη του πρώτου θεωρήματος χρησιμοποιεί δύο βοηθητικά: no_common_point και common_point.

2. Βήμα προς βήμα: αν $m_1\neq m_2$, οι ευθείες τέμνονται

Αν $m_1\neq m_2$, η εξίσωση $m_1x+b_1=m_2x+b_2$ λύνεται: $x=\dfrac{b_2-b_1}{m_1-m_2}$. Άρα οι ευθείες έχουν κοινό σημείο και δεν είναι παράλληλες. Στον Lean:

Ο στόχος
m₁ m₂ b₁ b₂ : ℝ
hm : m₁ ≠ m₂
⊢ ∃ x, m₁ * x + b₁ = m₂ * x + b₂

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have hne : m₁ - m₂ ≠ 0 := sub_ne_zero.mpr hm

    Αφού $m_1\neq m_2$, ισχύει $m_1-m_2\neq 0$ (sub_ne_zero)· θα διαιρέσουμε με αυτό.

    Τι μένει να αποδειχθεί
    hne : m₁ - m₂ ≠ 0
⊢ ∃ x, m₁ * x + b₁ = m₂ * x + b₂
  2. refine ⟨(b₂ - b₁) / (m₁ - m₂), ?_⟩

    Δίνουμε το $x=\dfrac{b_2-b_1}{m_1-m_2}$. Μένει να ελέγξουμε ότι ικανοποιεί την εξίσωση.

    Τι μένει να αποδειχθεί
    ⊢ m₁ * ((b₂ - b₁) / (m₁ - m₂)) + b₁ = m₂ * ((b₂ - b₁) / (m₁ - m₂)) + b₂
  3. have key : (m₁ - m₂) * ((b₂ - b₁) / (m₁ - m₂)) = b₂ - b₁ := by
  rw [← mul_div_assoc, mul_div_cancel_left₀ _ hne]

    Το κλειδί: $(m_1-m_2)\cdot\dfrac{b_2-b_1}{m_1-m_2}$${}=b_2-b_1$, γιατί ο παρονομαστής δεν είναι $0$ (mul_div_cancel_left₀).

    Τι μένει να αποδειχθεί
    key : (m₁ - m₂) * ((b₂ - b₁) / (m₁ - m₂)) = b₂ - b₁
⊢ m₁ * ((b₂ - b₁) / (m₁ - m₂)) + b₁ = m₂ * ((b₂ - b₁) / (m₁ - m₂)) + b₂
  4. linear_combination key

    Η εξίσωση που θέλουμε διαφέρει από το key μόνο κατά αναδιάταξη όρων: $m_1x+b_1-(m_2x+b_2)$${}=(m_1-m_2)x-(b_2-b_1)$. Το linear_combination key το ελέγχει.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: αν $m_1=m_2$ και $b_1\neq b_2$, δεν υπάρχει κοινό σημείο

Απόδειξε την άλλη κατεύθυνση. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Ξεκίνα με rintro ⟨x, hx⟩: υπέθεσε ότι υπάρχει κοινό σημείο $x$ και φτάσε σε άτοπο. Με rw [hm] at hx βάλε $m_1=m_2$ στην εξίσωση· τότε το linarith δίνει $b_1=b_2$, που αντιφάσκει με το hb: exact hb (by linarith).

Λύση
theorem no_common_point (m₁ m₂ b₁ b₂ : ℝ) (hm : m₁ = m₂) (hb : b₁ ≠ b₂) :
    ¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂ := by
  rintro ⟨x, hx⟩
  rw [hm] at hx
  exact hb (by linarith)

theorem no_common_point (m₁ m₂ b₁ b₂ : ℝ) (hm : m₁ = m₂) (hb : b₁ ≠ b₂) :
    ¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂ := by
  rintro ⟨x, hx⟩
  rw [hm] at hx
  exact hb (by linarith)

theorem common_point (m₁ m₂ b₁ b₂ : ℝ) (hm : m₁ ≠ m₂) :
    ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂ := by
  have hne : m₁ - m₂ ≠ 0 := sub_ne_zero.mpr hm
  refine ⟨(b₂ - b₁) / (m₁ - m₂), ?_⟩
  have key : (m₁ - m₂) * ((b₂ - b₁) / (m₁ - m₂)) = b₂ - b₁ := by
    rw [← mul_div_assoc, mul_div_cancel_left₀ _ hne]
  linear_combination key

theorem parallel_iff (m₁ m₂ b₁ b₂ : ℝ) :
    (¬ ∃ x : ℝ, m₁ * x + b₁ = m₂ * x + b₂) ↔ m₁ = m₂ ∧ b₁ ≠ b₂ := by
  constructor
  · intro h
    by_cases hm : m₁ = m₂
    · refine ⟨hm, ?_⟩
      intro hb
      apply h
      exact ⟨0, by rw [hm, hb]⟩
    · exact absurd (common_point m₁ m₂ b₁ b₂ hm) h
  · rintro ⟨hm, hb⟩
    exact no_common_point m₁ m₂ b₁ b₂ hm hb

theorem coincide (m b : ℝ) : ∀ x : ℝ, m * x + b = m * x + b := fun _ => rfl

theorem perpendicular_iff (m₁ m₂ : ℝ) : (1 : ℝ) * 1 + m₁ * m₂ = 0 ↔ m₁ * m₂ = -1 := by
  constructor
  · intro h
    linarith
  · intro h
    linarith

end Κεφ0.Eutheies
