Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει. Γράφουμε κάθε τύπο για ημίτονο και συνημίτονο μαζί· για την εφαπτομένη οι τύποι προκύπτουν διαιρώντας, αφού $\tan\omega$${}=\dfrac{\sin\omega}{\cos\omega}$.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Γωνία $-\omega$: $\sin(-\omega)=-\sin\omega$, $\cos(-\omega)=\cos\omega$
    theorem neg_angle (ω : ℝ) : sin (-ω) = -sin ω ∧ cos (-ω) = cos ω
  • Γωνία $\frac{\pi}{2}-\omega$: ημίτονο $\cos\omega$, συνημίτονο $\sin\omega$
    theorem pi_div_two_sub (ω : ℝ) : sin (π / 2 - ω) = cos ω ∧ cos (π / 2 - ω) = sin ω
  • Γωνία $\frac{\pi}{2}+\omega$: ημίτονο $\cos\omega$, συνημίτονο $-\sin\omega$
    theorem pi_div_two_add (ω : ℝ) : sin (π / 2 + ω) = cos ω ∧ cos (π / 2 + ω) = -sin ω
  • Γωνία $\pi-\omega$: ημίτονο $\sin\omega$, συνημίτονο $-\cos\omega$
    theorem pi_sub (ω : ℝ) : sin (π - ω) = sin ω ∧ cos (π - ω) = -cos ω
  • Γωνία $\pi+\omega$: ημίτονο $-\sin\omega$, συνημίτονο $-\cos\omega$
    theorem pi_add (ω : ℝ) : sin (π + ω) = -sin ω ∧ cos (π + ω) = -cos ω
  • Γωνία $\frac{3\pi}{2}-\omega$: ημίτονο $-\cos\omega$, συνημίτονο $-\sin\omega$
    theorem three_pi_div_two_sub (ω : ℝ) :
    sin (3 * π / 2 - ω) = -cos ω ∧ cos (3 * π / 2 - ω) = -sin ω
  • Γωνία $\frac{3\pi}{2}+\omega$: ημίτονο $-\cos\omega$, συνημίτονο $\sin\omega$
    theorem three_pi_div_two_add (ω : ℝ) :
    sin (3 * π / 2 + ω) = -cos ω ∧ cos (3 * π / 2 + ω) = sin ω
  • Γωνία $2\pi-\omega$: ημίτονο $-\sin\omega$, συνημίτονο $\cos\omega$
    theorem two_pi_sub (ω : ℝ) : sin (2 * π - ω) = -sin ω ∧ cos (2 * π - ω) = cos ω

Το ∧ σημαίνει «και»: κάθε θεώρημα λέει δύο πράγματα, για το ημίτονο και για το συνημίτονο. Οι τύποι αποδεικνύονται για κάθε πραγματικό $\omega$, όχι μόνο για οξεία γωνία. Στη Mathlib οι τριγωνομετρικές συναρτήσεις ορίζονται με δυναμοσειρές, όχι από τον τριγωνομετρικό κύκλο· οι γνωστές τιμές, όπως $\sin\pi=0$ και $\cos\pi=-1$, είναι θεωρήματα της βιβλιοθήκης.

2. Βήμα προς βήμα: ο τύπος για τη γωνία $\pi-\omega$

Στο βιβλίο οι αναγωγικοί τύποι προκύπτουν από τους τύπους αθροίσματος και διαφοράς, π.χ. $\sin(\pi-\omega)$${}=\sin\pi\cos\omega-\cos\pi\sin\omega$${}=0-(-1)\sin\omega$${}=\sin\omega$. Ο Lean κάνει ακριβώς αυτό:

Ο στόχος
ω : ℝ
⊢ sin (π - ω) = sin ω ∧ cos (π - ω) = -cos ω

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. constructor

    Ο στόχος είναι δύο ισότητες ενωμένες με «και». Το constructor τον χωρίζει σε δύο στόχους, που αποδεικνύονται χωριστά.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος left
    ⊢ sin (π - ω) = sin ω
    σκέλος right
    ⊢ cos (π - ω) = -cos ω
  2. · rw [sin_sub, sin_pi, cos_pi]

    Πρώτο σκέλος. Ο τύπος διαφοράς sin_sub: $\sin(x-y)$${}=\sin x\cos y-\cos x\sin y$. Μετά βάζουμε τις τιμές $\sin\pi=0$ (sin_pi) και $\cos\pi=-1$ (cos_pi).

    Τι μένει να αποδειχθεί
    ⊢ 0 * cos ω - -1 * sin ω = sin ω
  3. ring

    Οι πράξεις $0\cdot\cos\omega-(-1)\sin\omega$${}=\sin\omega$ γίνονται με ring.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  4. · rw [cos_sub, sin_pi, cos_pi]

    Δεύτερο σκέλος, με τον τύπο cos_sub: $\cos(x-y)$${}=\cos x\cos y+\sin x\sin y$, και τις ίδιες τιμές.

    Τι μένει να αποδειχθεί
    ω : ℝ
⊢ -1 * cos ω + 0 * sin ω = -cos ω
  5. ring

    Πάλι πράξεις: $-1\cdot\cos\omega+0\cdot\sin\omega$${}=-\cos\omega$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: η γωνία $\pi+\omega$

Απόδειξε ότι $\sin(\pi+\omega)=-\sin\omega$ και $\cos(\pi+\omega)=-\cos\omega$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Όπως πριν, με constructor. Τώρα χρειάζεσαι τους τύπους αθροίσματος sin_add και cos_add, με τις ίδιες τιμές sin_pi, cos_pi, και στο τέλος ring.

Λύση
theorem pi_add (ω : ℝ) : sin (π + ω) = -sin ω ∧ cos (π + ω) = -cos ω := by
  constructor
  · rw [sin_add, sin_pi, cos_pi]
    ring
  · rw [cos_add, sin_pi, cos_pi]
    ring

theorem neg_angle (ω : ℝ) : sin (-ω) = -sin ω ∧ cos (-ω) = cos ω :=

theorem pi_div_two_sub (ω : ℝ) : sin (π / 2 - ω) = cos ω ∧ cos (π / 2 - ω) = sin ω :=
  ⟨sin_pi_div_two_sub ω, cos_pi_div_two_sub ω⟩

theorem pi_div_two_add (ω : ℝ) : sin (π / 2 + ω) = cos ω ∧ cos (π / 2 + ω) = -sin ω := by
  rw [add_comm]
  exact ⟨sin_add_pi_div_two ω, cos_add_pi_div_two ω⟩

theorem pi_sub (ω : ℝ) : sin (π - ω) = sin ω ∧ cos (π - ω) = -cos ω := by
  constructor
  · rw [sin_sub, sin_pi, cos_pi]
    ring
  · rw [cos_sub, sin_pi, cos_pi]
    ring

theorem pi_add (ω : ℝ) : sin (π + ω) = -sin ω ∧ cos (π + ω) = -cos ω := by
  constructor
  · rw [sin_add, sin_pi, cos_pi]
    ring
  · rw [cos_add, sin_pi, cos_pi]
    ring

theorem three_pi_div_two_sub (ω : ℝ) :
    sin (3 * π / 2 - ω) = -cos ω ∧ cos (3 * π / 2 - ω) = -sin ω := by
  have h : 3 * π / 2 - ω = (π / 2 - ω) + π := by ring
  rw [h, sin_add_pi, cos_add_pi, sin_pi_div_two_sub, cos_pi_div_two_sub]
  exact ⟨rfl, rfl⟩

theorem three_pi_div_two_add (ω : ℝ) :
    sin (3 * π / 2 + ω) = -cos ω ∧ cos (3 * π / 2 + ω) = sin ω := by
  have h : 3 * π / 2 + ω = (ω + π / 2) + π := by ring
  rw [h, sin_add_pi, cos_add_pi, sin_add_pi_div_two, cos_add_pi_div_two, neg_neg]
  exact ⟨rfl, rfl⟩

theorem two_pi_sub (ω : ℝ) : sin (2 * π - ω) = -sin ω ∧ cos (2 * π - ω) = cos ω :=
  ⟨sin_two_pi_sub ω, cos_two_pi_sub ω⟩
