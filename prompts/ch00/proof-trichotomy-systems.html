Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει. Ένα γραμμικό σύστημα γράφεται $A\vec x=\vec b$, με $A$ πίνακα $m\times n$. Το σύνολο των λύσεων είναι το {x | A *ᵥ x = b}.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Κάθε γραμμικό σύστημα έχει καμία λύση, ή μοναδική λύση, ή άπειρες λύσεις
    theorem trichotomy (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    {x | A *ᵥ x = b} = ∅ ∨ (∃ x, {x | A *ᵥ x = b} = {x}) ∨ {x | A *ᵥ x = b}.Infinite
  • Ακριβώς μία από τις τρεις: οι περιπτώσεις αποκλείουν η μία την άλλη
    theorem exclusive (S : Set (Fin n → ℝ)) :
    ¬ (S = ∅ ∧ ∃ x, S = {x}) ∧ ¬ (S = ∅ ∧ S.Infinite) ∧ ¬ ((∃ x, S = {x}) ∧ S.Infinite)
  • Το βασικό βήμα: αν $\vec x,\vec y$ είναι λύσεις, τότε και κάθε $\vec x+t(\vec y-\vec x)$ είναι λύση
    theorem line_of_solutions (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) (t : ℝ) : A *ᵥ (x + t • (y - x)) = b

Το A *ᵥ x είναι το γινόμενο του πίνακα $A$ με το διάνυσμα $\vec x$. Το ∅ είναι το κενό σύνολο, το {x} σύνολο με ένα μόνο στοιχείο και το .Infinite σημαίνει «άπειρο». Η γεωμετρική εικόνα για δύο εξισώσεις με δύο αγνώστους (ευθείες που τέμνονται, είναι παράλληλες ή ταυτίζονται) δεν τυποποιείται εδώ.

2. Βήμα προς βήμα: αν $\vec x,\vec y$ είναι λύσεις, τότε και το $\vec x+t(\vec y-\vec x)$

Αυτό είναι το κλειδί: αν το σύστημα έχει δύο διαφορετικές λύσεις, έχει μια ολόκληρη ευθεία λύσεων, άρα άπειρες. Στο βιβλίο: $A(\vec x+t(\vec y-\vec x))$${}=A\vec x+t(A\vec y-A\vec x)$${}=\vec b+t(\vec b-\vec b)$${}=\vec b$. Στον Lean:

Ο στόχος
m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
x y : Fin n → ℝ
hx : A *ᵥ x = b
hy : A *ᵥ y = b
t : ℝ
⊢ A *ᵥ (x + t • (y - x)) = b

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [mulVec_add]

    $A(\vec u+\vec v)=A\vec u+A\vec v$.

    Τι μένει να αποδειχθεί
    ⊢ A *ᵥ x + A *ᵥ t • (y - x) = b
  2. rw [mulVec_smul]

    $A(t\vec v)=t\,A\vec v$.

    Τι μένει να αποδειχθεί
    ⊢ A *ᵥ x + t • A *ᵥ (y - x) = b
  3. rw [difference A b x y hx hy]

    Από το βοηθητικό θεώρημα difference: $A(\vec y-\vec x)=\vec 0$, αφού $A\vec y=A\vec x=\vec b$.

    Τι μένει να αποδειχθεί
    ⊢ A *ᵥ x + t • 0 = b
  4. rw [smul_zero, add_zero, hx]

    $t\cdot\vec 0=\vec 0$, $A\vec x+\vec 0=A\vec x$ και $A\vec x=\vec b$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: η διαφορά δύο λύσεων

Απόδειξε ότι αν $A\vec x=\vec b$ και $A\vec y=\vec b$, τότε $A(\vec y-\vec x)=\vec 0$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Το rw [mulVec_sub] γράφει $A(\vec y-\vec x)=A\vec y-A\vec x$. Μετά βάλε τις υποθέσεις hx, hy και τελείωσε με sub_self ($\vec b-\vec b=\vec 0$).

theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (y - x) = 0 := by
  rw [mulVec_sub, hx, hy, sub_self]

import Mathlib

namespace Κεφ0.Trichotomia
open Matrix

variable {m n : ℕ}

theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (y - x) = 0 := by
  rw [mulVec_sub, hx, hy, sub_self]

theorem line_of_solutions (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) (t : ℝ) : A *ᵥ (x + t • (y - x)) = b := by
  rw [mulVec_add]
  rw [mulVec_smul]
  rw [difference A b x y hx hy]
  rw [smul_zero, add_zero, hx]

theorem trichotomy (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    {x | A *ᵥ x = b} = ∅ ∨ (∃ x, {x | A *ᵥ x = b} = {x}) ∨ {x | A *ᵥ x = b}.Infinite := by
  by_cases h0 : {x | A *ᵥ x = b}.Nonempty
  · right
    obtain ⟨x, hx⟩ := h0
    by_cases h1 : ∀ y, A *ᵥ y = b → y = x
    · left
      refine ⟨x, ?_⟩
      ext y
      constructor
      · intro hy
        exact h1 y hy
      · intro hy
        rw [Set.mem_singleton_iff] at hy
        rw [hy]
        exact hx
    · right
      push Not at h1
      obtain ⟨y, hy, hne⟩ := h1
      have hd : y - x ≠ 0 := sub_ne_zero.mpr hne
      apply Set.infinite_of_injective_forall_mem (f := fun t : ℝ => x + t • (y - x))
      · intro s t hst
        dsimp only at hst
        have h' : s • (y - x) = t • (y - x) := add_left_cancel hst
        exact smul_left_injective ℝ hd h'
      · intro t
        exact line_of_solutions A b x y hx hy t
  · left
    exact Set.not_nonempty_iff_eq_empty.mp h0

theorem exclusive (S : Set (Fin n → ℝ)) :
    ¬ (S = ∅ ∧ ∃ x, S = {x}) ∧ ¬ (S = ∅ ∧ S.Infinite) ∧ ¬ ((∃ x, S = {x}) ∧ S.Infinite) := by
  refine ⟨?_, ?_, ?_⟩
  · rintro ⟨h₁, x, h₂⟩
    rw [h₁] at h₂
    exact (Set.singleton_nonempty x).ne_empty h₂.symm
  · rintro ⟨h₁, h₂⟩
    rw [h₁] at h₂
    exact h₂ Set.finite_empty
  · rintro ⟨⟨x, h₁⟩, h₂⟩
    rw [h₁] at h₂
    exact h₂ (Set.finite_singleton x)

end Κεφ0.Trichotomia
