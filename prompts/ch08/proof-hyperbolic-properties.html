Οι συναρτήσεις είναι οι Real.cosh, Real.sinh και Real.tanh της Mathlib. Οι τύποι $\cosh x=\dfrac{e^x+e^{-x}}{2}$ και $\sinh x=\dfrac{e^x-e^{-x}}{2}$ είναι εκεί θεωρήματα (Real.cosh_eq, Real.sinh_eq), ενώ $\tanh x=\dfrac{\sinh x}{\cosh x}$. Στους στόχους η $e^x$ εμφανίζεται ως rexp x. Η StrictMono σημαίνει «γνησίως αύξουσα» σε όλο το $\mathbb{R}$. Για την $\tanh$ χρησιμοποιούμε την παράγωγό της, $\dfrac{1}{\cosh^2 x}\gt 0$, που την υπολογίζουμε με τον κανόνα του πηλίκου και την ταυτότητα $\cosh^2x-\sinh^2x=1$. Για την $\cosh$ χρησιμοποιούμε ότι $\cosh x\lt\cosh y$ ακριβώς όταν $|x|\lt|y|$.

2. Βήμα προς βήμα: $\cosh^2 x-\sinh^2 x=1$

Η ιδέα: με τους τύπους μέσω της $e^x$, η διαφορά $\cosh^2x-\sinh^2x$ γίνεται $e^x e^{-x}=e^{0}=1$. Ξεκινάμε από τον στόχο:

Ο στόχος
x : ℝ
⊢ cosh x ^ 2 - sinh x ^ 2 = 1

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [Real.cosh_eq, Real.sinh_eq]

    Αντικαθιστούμε $\cosh x=\dfrac{e^x+e^{-x}}{2}$ και $\sinh x=\dfrac{e^x-e^{-x}}{2}$.

    Τι μένει να αποδειχθεί
    ⊢ ((rexp x + rexp (-x)) / 2) ^ 2 - ((rexp x - rexp (-x)) / 2) ^ 2 = 1
  2. have h : exp x * exp (-x) = 1 := by

    Ενδιάμεσος ισχυρισμός: $e^x e^{-x}=1$.

    Τι μένει να αποδειχθεί
    ⊢ rexp x * rexp (-x) = 1
  3. rw [← Real.exp_add, add_neg_cancel, Real.exp_zero]

    $e^x e^{-x}=e^{x+(-x)}=e^{0}=1$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  4. linear_combination h

    Αν αναπτύξουμε τα τετράγωνα, η διαφορά γίνεται ακριβώς $e^x e^{-x}$, που είναι $1$ από την h. Τον υπολογισμό τον κάνει η linear_combination h.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: $\cosh 0=1$

Δείξε, από τον τύπο $\cosh x=\dfrac{e^x+e^{-x}}{2}$, ότι $\cosh 0=1$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

4. Στη Mathlib

Οι υπόλοιπες ιδιότητες υπάρχουν έτοιμες στη Mathlib:

  • Real.cosh_eq: $\cosh x=\dfrac{e^x+e^{-x}}{2}$.
  • Real.sinh_eq: $\sinh x=\dfrac{e^x-e^{-x}}{2}$.
  • Real.cosh_neg: $\cosh(-x)=\cosh x$.
  • Real.sinh_neg: $\sinh(-x)=-\sinh x$.
  • Real.tanh_neg: $\tanh(-x)=-\tanh x$.
  • Real.sinh_strictMono: η $\sinh$ είναι γνησίως αύξουσα.
  • Real.cosh_lt_cosh: $\cosh x\lt\cosh y\Leftrightarrow|x|\lt|y|$.
  • strictMono_of_deriv_pos: θετική παράγωγος παντού σημαίνει γνησίως αύξουσα συνάρτηση.
  • Real.sinh_add: ο τύπος για το $\sinh(x+y)$.
  • Real.cosh_add: ο τύπος για το $\cosh(x+y)$.

import Mathlib

namespace Κεφ8.YperbolikesIdiotites
open Real

theorem cosh_sq_minus_sinh_sq (x : ℝ) : cosh x ^ 2 - sinh x ^ 2 = 1 := by
  rw [Real.cosh_eq, Real.sinh_eq]
  have h : exp x * exp (-x) = 1 := by
    rw [← Real.exp_add, add_neg_cancel, Real.exp_zero]
  linear_combination h

theorem cosh_is_even (x : ℝ) : cosh (-x) = cosh x := Real.cosh_neg x

theorem sinh_is_odd (x : ℝ) : sinh (-x) = -sinh x := Real.sinh_neg x

theorem tanh_is_odd (x : ℝ) : tanh (-x) = -tanh x := Real.tanh_neg x

theorem sinh_strictly_increasing : StrictMono sinh := Real.sinh_strictMono

theorem tanh_has_deriv (x : ℝ) : HasDerivAt tanh (1 / cosh x ^ 2) x := by
  have h := (Real.hasDerivAt_sinh x).div (Real.hasDerivAt_cosh x) (Real.cosh_pos x).ne'
  have hfun : sinh / cosh = tanh := by
    funext y
    rw [Pi.div_apply, Real.tanh_eq_sinh_div_cosh]
  rw [hfun] at h
  convert h using 1
  rw [← cosh_sq_minus_sinh_sq x]
  ring

theorem tanh_strictly_increasing : StrictMono tanh :=
  strictMono_of_deriv_pos fun x => by
    rw [(tanh_has_deriv x).deriv]
    exact one_div_pos.mpr (pow_pos (Real.cosh_pos x) 2)

theorem cosh_decreasing_left (x y : ℝ) (hy : y ≤ 0) (hxy : x < y) : cosh y < cosh x := by
  rw [Real.cosh_lt_cosh, abs_of_nonpos hy, abs_of_nonpos (hxy.le.trans hy)]
  linarith

theorem cosh_increasing_right (x y : ℝ) (hx : 0 ≤ x) (hxy : x < y) : cosh x < cosh y := by
  rw [Real.cosh_lt_cosh, abs_of_nonneg hx, abs_of_nonneg (hx.trans hxy.le)]
  exact hxy

theorem cosh_at_zero : cosh 0 = 1 := by
  rw [Real.cosh_eq, neg_zero, Real.exp_zero]
  norm_num

theorem sinh_of_sum (x y : ℝ) : sinh (x + y) = sinh x * cosh y + cosh x * sinh y :=
  Real.sinh_add x y

theorem cosh_of_sum (x y : ℝ) : cosh (x + y) = cosh x * cosh y + sinh x * sinh y :=
  Real.cosh_add x y

end Κεφ8.YperbolikesIdiotites
