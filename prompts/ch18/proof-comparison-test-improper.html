Κριτήριο Σύγκρισης για Γενικευμένα Ολοκληρώματα

Κεφάλαιο 18 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΑν $0\le f(x)\le g(x)$ για $x\ge a$ και τα $f,g$ τοπικά ολοκληρώσιμα σε κάθε $[a,R]$: αν το $\int_a^{+\infty}g\,dx$ συγκλίνει τότε και το $\int_a^{+\infty}f\,dx$· αν το $\int_a^{+\infty}f\,dx$ αποκλίνει τότε και το $\int_a^{+\infty}g\,dx$.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $0\le f(x)\le g(x)$ για $x\ge a$ και το $\int_a^{+\infty}g\,dx$ συγκλίνει, τότε συγκλίνει και το $\int_a^{+\infty}f\,dx$
    theorem comparison (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hg : IntegrableOn g (Set.Ioi a)) : IntegrableOn f (Set.Ioi a)
  • Αν το $\int_a^{+\infty}f\,dx$ αποκλίνει, τότε αποκλίνει και το $\int_a^{+\infty}g\,dx$
    theorem comparison_diverges (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hdiv : ¬ IntegrableOn f (Set.Ioi a)) : ¬ IntegrableOn g (Set.Ioi a)
  • Σύνδεση με τον ορισμό του βιβλίου: για ολοκληρώσιμη $f$, $\int_a^R f\,dx\to\int_a^{+\infty}f\,dx$ καθώς $R\to+\infty$
    theorem limit_of_integrable (f : ℝ → ℝ) (a : ℝ) (hf : IntegrableOn f (Set.Ioi a)) :
    Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 (∫ x in Set.Ioi a, f x))
  • και αντίστροφα, για $f\ge 0$: αν το $\int_a^R f\,dx$ έχει όριο καθώς $R\to+\infty$, η $f$ είναι ολοκληρώσιμη στο $(a,+\infty)$
    theorem integrable_of_limit (f : ℝ → ℝ) (a L : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x)
    (hlim : Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 L)) : IntegrableOn f (Set.Ioi a)

Στη Mathlib, ότι το γενικευμένο ολοκλήρωμα $\int_a^{+\infty}f\,dx$ συγκλίνει γράφεται ως ολοκληρωσιμότητα στο $(a,+\infty)$: IntegrableOn f (Set.Ioi a). Για μη αρνητικές συναρτήσεις αυτό είναι ακριβώς η σύγκλιση του βιβλίου, όπως δείχνουν τα δύο τελευταία θεωρήματα: το $\int_a^R f\,dx$ έχει όριο καθώς $R\to+\infty$ ακριβώς όταν η $f$ είναι ολοκληρώσιμη. Για απλότητα υποθέτουμε την $f$ συνεχή για $x\ge a$, ώστε να είναι ολοκληρώσιμη σε κάθε $[a,R]$· το βιβλίο ζητά μόνο αυτή την ολοκληρωσιμότητα. Το σύνολο των $x\ge a$ γράφεται Set.Ici a και το $(a,+\infty)$ γράφεται Set.Ioi a.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • MeasureTheory.Integrable.mono': αν $|f|\le g$ και η $g$ είναι ολοκληρώσιμη, τότε και η $f$ είναι ολοκληρώσιμη.
  • ContinuousOn.aestronglyMeasurable: μια τεχνική συνθήκη μετρησιμότητας, που ισχύει για τις συνεχείς συναρτήσεις.
  • MeasureTheory.ae_restrict_of_forall_mem: ό,τι ισχύει σε κάθε σημείο ενός συνόλου, ισχύει και «σχεδόν παντού» σε αυτό.
  • MeasureTheory.intervalIntegral_tendsto_integral_Ioi: $\int_a^R f\,dx\to\int_a^{+\infty}f\,dx$ για ολοκληρώσιμη $f$.
  • MeasureTheory.integrableOn_Ioi_of_intervalIntegral_norm_tendsto: αν το $\int_a^R|f|\,dx$ έχει όριο, η $f$ είναι ολοκληρώσιμη στο $(a,+\infty)$.
  • intervalIntegral.integral_congr: συναρτήσεις ίσες στο διάστημα έχουν ίσα ολοκληρώματα.

import Mathlib

namespace Κεφ18.KritirioSygkrisis
open MeasureTheory Filter Topology

-- για μη αρνητική f, «το ολοκλήρωμα από a έως +∞ συγκλίνει» γράφεται IntegrableOn f (Set.Ioi a)
theorem comparison (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hg : IntegrableOn g (Set.Ioi a)) : IntegrableOn f (Set.Ioi a) := by
  refine Integrable.mono' hg ((hf.mono Set.Ioi_subset_Ici_self).aestronglyMeasurable measurableSet_Ioi)
    (ae_restrict_of_forall_mem measurableSet_Ioi fun x hx => ?_)
  rw [Real.norm_eq_abs, abs_of_nonneg (hf0 x (Set.Ioi_subset_Ici_self hx))]
  exact hfg x (Set.Ioi_subset_Ici_self hx)

theorem comparison_diverges (f g : ℝ → ℝ) (a : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x) (hfg : ∀ x ∈ Set.Ici a, f x ≤ g x)
    (hdiv : ¬ IntegrableOn f (Set.Ioi a)) : ¬ IntegrableOn g (Set.Ioi a) :=
  fun hg => hdiv (comparison f g a hf hf0 hfg hg)

-- σύνδεση με τον ορισμό του βιβλίου (1): τότε το ολοκλήρωμα από a έως R έχει όριο καθώς R → +∞
theorem limit_of_integrable (f : ℝ → ℝ) (a : ℝ) (hf : IntegrableOn f (Set.Ioi a)) :
    Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 (∫ x in Set.Ioi a, f x)) :=
  intervalIntegral_tendsto_integral_Ioi a hf tendsto_id

-- σύνδεση με τον ορισμό του βιβλίου (2): για μη αρνητική f ισχύει και το αντίστροφο
theorem integrable_of_limit (f : ℝ → ℝ) (a L : ℝ) (hf : ContinuousOn f (Set.Ici a))
    (hf0 : ∀ x ∈ Set.Ici a, 0 ≤ f x)
    (hlim : Tendsto (fun R => ∫ x in a..R, f x) atTop (𝓝 L)) : IntegrableOn f (Set.Ioi a) := by
  refine integrableOn_Ioi_of_intervalIntegral_norm_tendsto L a (fun R => ?_) tendsto_id ?_
  · exact ((hf.mono Set.Icc_subset_Ici_self).integrableOn_Icc).mono_set Set.Ioc_subset_Icc_self
  · refine hlim.congr' ((eventually_ge_atTop a).mono fun R hR => ?_)
    show ∫ x in a..R, f x = ∫ x in a..R, ‖f x‖
    refine intervalIntegral.integral_congr fun x hx => ?_
    rw [Set.uIcc_of_le hR] at hx
    simp only [Real.norm_eq_abs, abs_of_nonneg (hf0 x hx.1)]

end Κεφ18.KritirioSygkrisis
