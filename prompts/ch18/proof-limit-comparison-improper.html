Οριακό Κριτήριο Σύγκρισης (γενικευμένα ολοκληρώματα)

ΕκφώνησηΈστω $f(x)>0$, $g(x)>0$ για $x\ge a$, ολοκληρώσιμες σε κάθε $[a,R]$, με $\lim_{x\to+\infty}\dfrac{f(x)}{g(x)}$${}=L$ και $0<L<+\infty$. Τότε τα $\int_a^{+\infty}f(x)\,dx$ και $\int_a^{+\infty}g(x)\,dx$ συγκλίνουν ή αποκλίνουν ταυτόχρονα. Ανάλογο κριτήριο ισχύει για ολοκληρώματα 2ου είδους, με το όριο στο ιδιόμορφο σημείο.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $g(x)\gt 0$ για $x\ge a$ και $\lim_{x\to+\infty}\dfrac{f(x)}{g(x)}$${}=L$ με $0\lt L\lt+\infty$, τότε τα $\int_a^{+\infty}f\,dx$ και $\int_a^{+\infty}g\,dx$ συγκλίνουν ή αποκλίνουν ταυτόχρονα
    theorem limit_comparison (f g : ℝ → ℝ) (a L : ℝ) (hL : 0 < L)
    (hf : ContinuousOn f (Set.Ici a)) (hg : ContinuousOn g (Set.Ici a))
    (hg0 : ∀ x ∈ Set.Ici a, 0 < g x)
    (hlim : Tendsto (fun x => f x / g x) atTop (𝓝 L)) :
    IntegrableOn f (Set.Ici a) ↔ IntegrableOn g (Set.Ici a)

Η σύγκλιση του $\int_a^{+\infty}f\,dx$ γράφεται IntegrableOn f (Set.Ici a), όπως στο κριτήριο σύγκρισης· το αν θα πάρουμε το $[a,+\infty)$ ή το $(a,+\infty)$ δεν αλλάζει κάτι. Υποθέτουμε τις $f,g$ συνεχείς για $x\ge a$, ώστε να είναι ολοκληρώσιμες σε κάθε $[a,R]$. Η υπόθεση $f\gt 0$ του βιβλίου δεν χρειάζεται: από το $\dfrac{f}{g}\to L\gt 0$ προκύπτει ότι $f\gt 0$ για μεγάλα $x$. Η απόδειξη δείχνει ότι, για μεγάλα $x$, καθεμιά από τις δύο συναρτήσεις είναι φραγμένη από πολλαπλάσιο της άλλης (συμβολισμός f =O[atTop] g), και εφαρμόζει τη σύγκριση. Το ανάλογο κριτήριο για ολοκληρώματα 2ου είδους δεν διατυπώνεται εδώ.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Asymptotics.isBigO_of_div_tendsto_nhds: αν $\dfrac{f}{g}\to c$, τότε η $f$ είναι φραγμένη από πολλαπλάσιο της $g$ για μεγάλα $x$.
  • Filter.Tendsto.inv₀: αν $u\to L\neq 0$, τότε $\dfrac{1}{u}\to\dfrac{1}{L}$.
  • MeasureTheory.LocallyIntegrableOn.integrableOn_of_isBigO_atTop: η σύγκριση στο άπειρο για ολοκληρώματα.
  • ContinuousOn.locallyIntegrableOn: συνεχής συνάρτηση είναι ολοκληρώσιμη σε κάθε κλειστό διάστημα.
  • MeasureTheory.integrableAtFilter_atTop_iff: η ολοκληρωσιμότητα «στο άπειρο».

import Mathlib

namespace Κεφ18.OriakoKritirio
open MeasureTheory Filter Topology Asymptotics

theorem limit_comparison (f g : ℝ → ℝ) (a L : ℝ) (hL : 0 < L)
    (hf : ContinuousOn f (Set.Ici a)) (hg : ContinuousOn g (Set.Ici a))
    (hg0 : ∀ x ∈ Set.Ici a, 0 < g x)
    (hlim : Tendsto (fun x => f x / g x) atTop (𝓝 L)) :
    IntegrableOn f (Set.Ici a) ↔ IntegrableOn g (Set.Ici a) := by
  -- f = O(g) για x → +∞, γιατί f/g → L
  have hfg : f =O[atTop] g := by
    refine isBigO_of_div_tendsto_nhds ?_ L hlim
    filter_upwards [eventually_ge_atTop a] with x hx h0
    exact absurd h0 (hg0 x hx).ne'
  -- g = O(f) για x → +∞, γιατί g/f → 1/L
  have hgf : g =O[atTop] f := by
    have hinv : Tendsto (fun x => g x / f x) atTop (𝓝 L⁻¹) := by
      refine (hlim.inv₀ hL.ne').congr' ?_
      filter_upwards with x
      exact inv_div (f x) (g x)
    refine isBigO_of_div_tendsto_nhds ?_ L⁻¹ hinv
    filter_upwards [hlim.eventually (lt_mem_nhds hL)] with x hx h0
    rw [h0, zero_div] at hx
    exact absurd hx (lt_irrefl 0)
  -- σύγκριση στο άπειρο: οι συνεχείς f, g είναι ολοκληρώσιμες σε κάθε [a, R]
  constructor
  · intro hfi
    exact (hg.locallyIntegrableOn measurableSet_Ici).integrableOn_of_isBigO_atTop hgf
      (integrableAtFilter_atTop_iff.mpr ⟨a, hfi⟩)
  · intro hgi
    exact (hf.locallyIntegrableOn measurableSet_Ici).integrableOn_of_isBigO_atTop hfg
      (integrableAtFilter_atTop_iff.mpr ⟨a, hgi⟩)

end Κεφ18.OriakoKritirio
