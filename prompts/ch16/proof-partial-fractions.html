Κεφάλαιο 16 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΚάθε γνήσια ρητή συνάρτηση $\dfrac{P(x)}{Q(x)}$ (με $\deg P<\deg Q$) αναλύεται μονοσήμαντα σε άθροισμα απλών κλασμάτων: σε κάθε γραμμικό παράγοντα $(x-a)^k$ του $Q$ αντιστοιχούν οι όροι $\dfrac{A_1}{x-a}+\cdots+\dfrac{A_k}{(x-a)^k}$· σε κάθε ανάγωγο τετραγωνικό παράγοντα $(x^2+px+q)^m$ (με $p^2-4q<0$) αντιστοιχούν οι όροι $\dfrac{B_1x+\Gamma_1}{x^2+px+q}+\cdots+\dfrac{B_mx+\Gamma_m}{(x^2+px+q)^m}$. Η ολοκλήρωση δίνει λογαρίθμους και δυνάμεις (γραμμικοί όροι) ή λογαρίθμους και τόξα εφαπτομένης (ανάγωγοι τετραγωνικοί όροι).

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Ύπαρξη: για μονικά πολυώνυμα $g_i$, πρώτα μεταξύ τους ανά δύο, και εκθέτες $n_i$, κάθε πολυώνυμο $P$ γράφεται $P$${}=q\prod_i g_i^{n_i}+\sum_i\sum_{j\lt n_i} r_{ij}\,g_i^{\,j}\prod_{k\neq i}g_k^{n_k}$, με $\deg r_{ij}\lt\deg g_i$

    (hg : ∀ i ∈ s, (g i).Monic) (hcop : Set.Pairwise s fun i j => IsCoprime (g i) (g j))

      (∀ i ∈ s, ∀ j, (r i j).degree < (g i).degree) ∧
      P = q * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k

Η Mathlib διατυπώνει την ανάλυση σε μερικά κλάσματα για πολυώνυμα (ℝ[X]), χωρίς διαιρέσεις. Αν διαιρέσουμε και τα δύο μέλη με $Q=\prod_i g_i^{n_i}$, παίρνουμε $\dfrac{P}{Q}$${}=q+\sum_i\sum_{j}\dfrac{r_{ij}}{g_i^{\,n_i-j}}$, δηλαδή τη μορφή του βιβλίου, με παρονομαστές $g_i,g_i^2,\dots,g_i^{n_i}$. Για γραμμικό παράγοντα $g_i=x-a$ οι αριθμητές $r_{ij}$ έχουν βαθμό $0$, είναι δηλαδή σταθερές· για ανάγωγο τετραγωνικό παράγοντα έχουν βαθμό το πολύ $1$, είναι δηλαδή της μορφής $Bx+\Gamma$. Όταν $\deg P\lt\deg Q$, το πολυώνυμο $q$ είναι $0$. Η μοναδικότητα είναι το «μονοσήμαντα» του βιβλίου. Το παράδειγμα δείχνει την ανάλυση και την ολοκλήρωση σε μια συγκεκριμένη συνάρτηση. Στη Mathlib ο λογάριθμος Real.log ορίζεται και για αρνητικούς αριθμούς, ως $\ln|t|$, οπότε η απόλυτη τιμή φεύγει αμέσως (Real.log_abs).

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Polynomial.eq_quo_mul_prod_pow_add_sum_rem_mul_prod_pow: η ύπαρξη της ανάλυσης σε μερικά κλάσματα.
  • Polynomial.quo_mul_prod_pow_add_sum_rem_mul_prod_pow_unique: η μοναδικότητα της ανάλυσης.
  • Real.log_abs: $\ln|t|=\ln t$ στη Mathlib.
  • HasDerivAt.log: η παράγωγος της $\ln f(x)$.
  • HasDerivAt.const_mul: ο κανόνας για την $c\,f(x)$.
  • HasDerivAt.sub: ο κανόνας της διαφοράς.

import Mathlib

namespace Κεφ16.MerikaKlasmata
open Polynomial

-- ύπαρξη: P = q · ∏ gᵢ^nᵢ + Σᵢ Σⱼ rᵢⱼ · gᵢ^j · ∏ (k ≠ i) gₖ^nₖ, με deg rᵢⱼ < deg gᵢ
theorem decomposition (P : ℝ[X]) {ι : Type*} [DecidableEq ι] (s : Finset ι) (g : ι → ℝ[X])
    (hg : ∀ i ∈ s, (g i).Monic) (hcop : Set.Pairwise s fun i j => IsCoprime (g i) (g j))
    (n : ι → ℕ) :
    ∃ (q : ℝ[X]) (r : (i : ι) → Fin (n i) → ℝ[X]),
      (∀ i ∈ s, ∀ j, (r i j).degree < (g i).degree) ∧
      P = q * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k :=
  eq_quo_mul_prod_pow_add_sum_rem_mul_prod_pow P hg hcop n

-- μοναδικότητα: δύο τέτοιες αναλύσεις έχουν το ίδιο q και τα ίδια rᵢⱼ
theorem uniqueness {ι : Type*} [DecidableEq ι] (s : Finset ι) (g : ι → ℝ[X])
    (hg : ∀ i ∈ s, (g i).Monic) (hcop : Set.Pairwise s fun i j => IsCoprime (g i) (g j))
    (n : ι → ℕ) (q₁ q₂ : ℝ[X]) (r₁ r₂ : (i : ι) → Fin (n i) → ℝ[X])
    (hr₁ : ∀ i ∈ s, ∀ j, (r₁ i j).degree < (g i).degree)
    (hr₂ : ∀ i ∈ s, ∀ j, (r₂ i j).degree < (g i).degree)
    (h : q₁ * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r₁ i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k =
      q₂ * ∏ i ∈ s, g i ^ n i + ∑ i ∈ s, ∑ j, r₂ i j * g i ^ j.val * ∏ k ∈ s.erase i, g k ^ n k) :
    q₁ = q₂ ∧ ∀ i ∈ s, r₁ i = r₂ i :=
  quo_mul_prod_pow_add_sum_rem_mul_prod_pow_unique hg hcop hr₁ hr₂ h

-- παράδειγμα: 1/(x² - 1) = (1/2)/(x - 1) - (1/2)/(x + 1)
theorem example_decomposition (x : ℝ) (h1 : x ≠ 1) (h2 : x ≠ -1) :
    1 / (x ^ 2 - 1) = 1 / 2 / (x - 1) - 1 / 2 / (x + 1) := by
  have h1' : x - 1 ≠ 0 := sub_ne_zero.mpr h1
  have h2' : x + 1 ≠ 0 := fun h => h2 (by linarith)
  have h3 : x ^ 2 - 1 ≠ 0 := by
    rw [show x ^ 2 - 1 = (x - 1) * (x + 1) by ring]
    exact mul_ne_zero h1' h2'
  field_simp
  ring

-- και το ολοκλήρωμα: ∫ dx/(x² - 1) = (1/2) ln|x - 1| - (1/2) ln|x + 1| + C
theorem example_integral (x : ℝ) (h1 : x ≠ 1) (h2 : x ≠ -1) :
    HasDerivAt (fun x => 1 / 2 * Real.log |x - 1| - 1 / 2 * Real.log |x + 1|)
      (1 / (x ^ 2 - 1)) x := by
  simp only [Real.log_abs]
  have ha : HasDerivAt (fun x => Real.log (x - 1)) (1 / (x - 1)) x :=
    ((hasDerivAt_id' x).sub_const 1).log (sub_ne_zero.mpr h1)
  have hb : HasDerivAt (fun x => Real.log (x + 1)) (1 / (x + 1)) x :=
    ((hasDerivAt_id' x).add_const 1).log (fun h => h2 (by linarith))
  have h : HasDerivAt (fun x => 1 / 2 * Real.log (x - 1) - 1 / 2 * Real.log (x + 1))
      (1 / 2 * (1 / (x - 1)) - 1 / 2 * (1 / (x + 1))) x :=
    (ha.const_mul (1 / 2)).sub (hb.const_mul (1 / 2))
  convert h using 1
  rw [example_decomposition x h1 h2]
  ring

end Κεφ16.MerikaKlasmata
