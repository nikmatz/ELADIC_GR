ΘΕΩΡΗΜΑ: Αν ο παρονομαστής περιέχει τον παράγοντα $(x-a)^k$ με $k\ge 2$, η ανάλυση σε μερικά κλάσματα περιλαμβάνει $k$ όρους: $\dfrac{A_1}{x-a}+\dfrac{A_2}{(x-a)^2}+\dots+\dfrac{A_k}{(x-a)^k}$, με $\int\dfrac{A_1}{x-a}dx=A_1\ln|x-a|+C$ και $\int\dfrac{A_j}{(x-a)^j}dx=-\dfrac{A_j}{(j-1)(x-a)^{j-1}}+C$ για $j\ge 2$.

Οι απαντήσεις των μοντέλων μπορεί να έχουν λάθη. Για απόδειξη που έχει ελέγξει υπολογιστής βήμα προς βήμα, δες την καρτέλα Απόδειξη σε Lean.

Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $\int\dfrac{A}{x-a}\,dx=A\ln|x-a|+C$
    theorem int_first (A a x : ℝ) (hx : x ≠ a) :
    HasDerivAt (fun x => A * Real.log |x - a|) (A / (x - a)) x
  • $\int\dfrac{A}{(x-a)^j}\,dx$${}=-\dfrac{A}{(j-1)(x-a)^{j-1}}+C$ για $j\ge 2$, γραμμένο με $j=m+2$
    theorem int_power (A a x : ℝ) (m : ℕ) (hx : x ≠ a) :
    HasDerivAt (fun x => -A / ((m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x
  • Παράδειγμα: $\int\dfrac{3}{(x-1)^2}\,dx$${}=-\dfrac{3}{x-1}+C$
    theorem int_example (x : ℝ) (hx : x ≠ 1) :
    HasDerivAt (fun x => -3 / (x - 1)) (3 / (x - 1) ^ 2) x

Κάθε τύπος γράφεται ως «η δεξιά πλευρά έχει παράγωγο την ολοκληρωτέα συνάρτηση», σε κάθε $x\neq a$. Για να μη χρειαστεί η υπόθεση $j\ge 2$, γράφουμε $j=m+2$ με $m=0,1,2,\dots$· τότε $j-1=m+1$. Η ανάλυση $\dfrac{A_1}{x-a}+\dots+\dfrac{A_k}{(x-a)^k}$ είναι η περίπτωση του γραμμικού παράγοντα στην ανάλυση σε μερικά κλάσματα· εδώ ελέγχουμε τα ολοκληρώματα των όρων της. Στη Mathlib ο λογάριθμος Real.log ορίζεται και για αρνητικούς αριθμούς, ως $\ln|t|$, οπότε η απόλυτη τιμή φεύγει αμέσως (Real.log_abs).

2. Βήμα προς βήμα: $\int\dfrac{A}{(x-a)^{m+2}}\,dx$

Η ιδέα: παραγωγίζουμε την $-\dfrac{A}{(m+1)(x-a)^{m+1}}$ με τον κανόνα του πηλίκου. Ξεκινάμε από τον στόχο:

Ο στόχος
A a x : ℝ
m : ℕ
hx : x ≠ a
⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have hxa : x - a ≠ 0 := sub_ne_zero.mpr hx

    Αφού $x\neq a$, ισχύει $x-a\neq 0$.

    Τι μένει να αποδειχθεί

⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x
  2. -- ((x - a)^(m+1))' = (m + 1)(x - a)^m
have h1 : HasDerivAt (fun x => (x - a) ^ (m + 1)) ((m + 1) * (x - a) ^ m) x := by
  simpa using ((hasDerivAt_id' x).sub_const a).fun_pow (m + 1)

    Η $(x-a)^{m+1}$ έχει παράγωγο $(m+1)(x-a)^m$ (κανόνας της δύναμης). Το ↑m είναι ο φυσικός $m$ ως πραγματικός αριθμός.

have h2 := h1.const_mul ((m : ℝ) + 1)

    Πολλαπλασιάζουμε με τη σταθερά $m+1$.

    Τι μένει να αποδειχθεί

    Ο παρονομαστής $(m+1)(x-a)^{m+1}$ δεν μηδενίζεται.

⊢ HasDerivAt (fun x => -A / ((↑m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x

3. Δοκίμασε εσύ: $\int\dfrac{3}{(x-1)^2}\,dx$

Δείξε ότι η $-\dfrac{3}{x-1}$ έχει παράγωγο $\dfrac{3}{(x-1)^2}$, για $x\neq 1$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Εφάρμοσε τον τύπο με $A=3$, $a=1$ και $m=0$: have h := int_power 3 1 x 0 hx. Απλοποίησε τα $0+1$, $1\cdot$ και $(x-1)^1$ με simp only [Nat.cast_zero, zero_add, one_mul, pow_one] at h και τελείωσε με exact h.

Λύση
theorem int_example (x : ℝ) (hx : x ≠ 1) :
    HasDerivAt (fun x => -3 / (x - 1)) (3 / (x - 1) ^ 2) x := by
  have h := int_power 3 1 x 0 hx
  simp only [Nat.cast_zero, zero_add, one_mul, pow_one] at h
  exact h

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Real.log_abs: $\ln|t|=\ln t$ στη Mathlib.
  • HasDerivAt.log: η παράγωγος της $\ln f(x)$.
  • HasDerivAt.sub_const: η $f(x)-c$ έχει την ίδια παράγωγο με την $f$.
  • HasDerivAt.fun_pow: η παράγωγος της $f(x)^n$.
  • HasDerivAt.const_mul: ο κανόνας για την $c\,f(x)$.
  • hasDerivAt_const: η παράγωγος σταθεράς είναι $0$.
  • HasDerivAt.fun_div: ο κανόνας του πηλίκου.

import Mathlib

namespace Κεφ16.EpanalambanomenosParagontas

-- ο όρος A/(x - a): ∫ A/(x - a) dx = A ln|x - a| + C
theorem int_first (A a x : ℝ) (hx : x ≠ a) :
    HasDerivAt (fun x => A * Real.log |x - a|) (A / (x - a)) x := by
  simp only [Real.log_abs]
  have h : HasDerivAt (fun x => Real.log (x - a)) (1 / (x - a)) x :=
    ((hasDerivAt_id' x).sub_const a).log (sub_ne_zero.mpr hx)
  convert h.const_mul A using 1
  ring

-- οι όροι A/(x - a)^j με j ≥ 2, γραμμένο j = m + 2:
-- ∫ A/(x - a)^(m+2) dx = -A/((m + 1)(x - a)^(m+1)) + C
theorem int_power (A a x : ℝ) (m : ℕ) (hx : x ≠ a) :
    HasDerivAt (fun x => -A / ((m + 1) * (x - a) ^ (m + 1))) (A / (x - a) ^ (m + 2)) x := by
  have hxa : x - a ≠ 0 := sub_ne_zero.mpr hx
  -- ((x - a)^(m+1))' = (m + 1)(x - a)^m
  have h1 : HasDerivAt (fun x => (x - a) ^ (m + 1)) ((m + 1) * (x - a) ^ m) x := by
    simpa using ((hasDerivAt_id' x).sub_const a).fun_pow (m + 1)
  -- ((m + 1)(x - a)^(m+1))' = (m + 1)(m + 1)(x - a)^m
  have h2 := h1.const_mul ((m : ℝ) + 1)
  -- ο παρονομαστής δεν μηδενίζεται
  have hden : ((m : ℝ) + 1) * (x - a) ^ (m + 1) ≠ 0 :=
    mul_ne_zero (by positivity) (pow_ne_zero _ hxa)
  -- κανόνας του πηλίκου
  have h3 := (hasDerivAt_const x (-A)).fun_div h2 hden
  convert h3 using 1
  field_simp
  ring

theorem int_example (x : ℝ) (hx : x ≠ 1) :
    HasDerivAt (fun x => -3 / (x - 1)) (3 / (x - 1) ^ 2) x := by
  have h := int_power 3 1 x 0 hx
  simp only [Nat.cast_zero, zero_add, one_mul, pow_one] at h
  exact h

end Κεφ16.EpanalambanomenosParagontas
