ΕκφώνησηΈστω $x^2+bx+c$ ανάγωγο ($b^2-4c<0$). Με συμπλήρωση τετραγώνου $x^2+bx+c$${}=\left(x+\tfrac{b}{2}\right)^2+k^2$, $k=\sqrt{c-\tfrac{b^2}{4}}>0$, και το $\int\dfrac{Ax+B}{x^2+bx+c}dx$ αναλύεται σε λογαριθμικό μέρος (με αριθμητή την παράγωγο $2x+b$) και σε τόξο εφαπτομένης.

Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $b^2-4c\lt 0$ και $k=\sqrt{c-\tfrac{b^2}{4}}$, τότε $\int\dfrac{Ax+B}{x^2+bx+c}\,dx$${}=\dfrac{A}{2}\ln(x^2+bx+c)$ $+\,\dfrac{B-\tfrac{Ab}{2}}{k}\arctan\dfrac{x+\tfrac{b}{2}}{k}+C$
    theorem quadratic_factor (A B b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c) +
        (B - A * b / 2) / Real.sqrt (c - b ^ 2 / 4) *
          Real.arctan ((x + b / 2) / Real.sqrt (c - b ^ 2 / 4)))
      ((A * x + B) / (x ^ 2 + b * x + c)) x
  • Εφαρμογή: όταν ο αριθμητής είναι πολλαπλάσιο της $2x+b$, μένει μόνο το λογαριθμικό μέρος: $\int\dfrac{Ax+\tfrac{Ab}{2}}{x^2+bx+c}\,dx$${}=\dfrac{A}{2}\ln(x^2+bx+c)+C$
    theorem log_part (A b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c))
      ((A * x + A * b / 2) / (x ^ 2 + b * x + c)) x

Το αόριστο ολοκλήρωμα $\int f(x)\,dx=F(x)+C$ σημαίνει ότι η $F$ είναι αντιπαράγωγος της $f$, δηλαδή ότι η $F$ έχει παράγωγο $f$: γράφεται HasDerivAt F (f x) x. Η πρόταση του βιβλίου περιγράφει πώς αναλύεται το ολοκλήρωμα· εδώ διατυπώνουμε τον τύπο στον οποίο οδηγεί η ανάλυση και ελέγχουμε ότι η παράγωγος του δεξιού μέλους είναι η $\dfrac{Ax+B}{x^2+bx+c}$. Αφού $x^2+bx+c\gt 0$ για κάθε $x$, ο λογάριθμος δεν χρειάζεται απόλυτη τιμή. Η τετραγωνική ρίζα γράφεται Real.sqrt, και στις καταστάσεις του Lean εμφανίζεται ως √.

2. Βήμα προς βήμα: λογάριθμος και τόξο εφαπτομένης

Η ιδέα: $\dfrac{Ax+B}{x^2+bx+c}$${}=\dfrac{A}{2}\cdot\dfrac{2x+b}{x^2+bx+c}+\dfrac{B-\tfrac{Ab}{2}}{(x+\tfrac{b}{2})^2+k^2}$. Παραγωγίζουμε τα δύο μέρη του τύπου και ελέγχουμε ότι το άθροισμα των παραγώγων είναι η συνάρτηση που ολοκληρώνουμε. Ξεκινάμε από τον στόχο:

3. Δοκίμασε εσύ: μόνο λογάριθμος

Δείξε ότι η $\dfrac{A}{2}\ln(x^2+bx+c)$ έχει παράγωγο $\dfrac{Ax+\tfrac{Ab}{2}}{x^2+bx+c}$, όταν $b^2-4c\lt 0$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Εφάρμοσε τον τύπο με $B=\tfrac{Ab}{2}$: have h := quadratic_factor A (A * b / 2) b c hdisc x. Ο συντελεστής του τόξου εφαπτομένης γίνεται $0$· απλοποίησε με simp only [sub_self, zero_div, zero_mul, add_zero] at h και τελείωσε με exact h.

Λύση
theorem log_part (A b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c))
      ((A * x + A * b / 2) / (x ^ 2 + b * x + c)) x := by
  have h := quadratic_factor A (A * b / 2) b c hdisc x
  simp only [sub_self, zero_div, zero_mul, add_zero] at h
  exact h

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Real.sqrt_pos: $\sqrt{t}\gt 0$ ακριβώς όταν $t\gt 0$.
  • Real.sq_sqrt: $(\sqrt{t})^2=t$ για $t\ge 0$.
  • hasDerivAt_pow: η παράγωγος της $x^n$.
  • HasDerivAt.log: η παράγωγος της $\ln f(x)$.
  • HasDerivAt.arctan: η παράγωγος της $\arctan f(x)$.
  • HasDerivAt.div_const: η παράγωγος της $\dfrac{f(x)}{c}$.
  • HasDerivAt.const_mul: ο κανόνας για την $c\,f(x)$.
  • HasDerivAt.add: ο κανόνας του αθροίσματος.

theorem quadratic_factor (A B b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c) +
        (B - A * b / 2) / Real.sqrt (c - b ^ 2 / 4) *
          Real.arctan ((x + b / 2) / Real.sqrt (c - b ^ 2 / 4)))
      ((A * x + B) / (x ^ 2 + b * x + c)) x := by
  -- k = √(c - b²/4) > 0
  set k := Real.sqrt (c - b ^ 2 / 4) with hk_def
  have hk : 0 < k := Real.sqrt_pos.mpr (by linarith)
  have hk0 : k ≠ 0 := hk.ne'
  have hk2 : k ^ 2 = c - b ^ 2 / 4 := Real.sq_sqrt (by linarith)
  -- συμπλήρωση τετραγώνου: x² + bx + c = (x + b/2)² + k²
  have hsq : x ^ 2 + b * x + c = (x + b / 2) ^ 2 + k ^ 2 := by
    rw [hk2]
    ring
  have hpos : 0 < x ^ 2 + b * x + c := by
    rw [hsq]
    positivity
  -- λογαριθμικό μέρος: (ln(x² + bx + c))' = (2x + b)/(x² + bx + c)
  have h1 : HasDerivAt (fun x => x ^ 2 + b * x + c) (2 * x + b) x := by
    simpa using ((hasDerivAt_pow 2 x).add ((hasDerivAt_id' x).const_mul b)).add_const c
  have h2 := h1.log hpos.ne'
  -- τόξο εφαπτομένης: (arctan((x + b/2)/k))' = 1/(1 + ((x + b/2)/k)²) · 1/k
  have h3 : HasDerivAt (fun x => (x + b / 2) / k) (1 / k) x :=
    ((hasDerivAt_id' x).add_const (b / 2)).div_const k
  have h4 := h3.arctan
  -- συνδυάζουμε τα δύο μέρη
  have h5 : HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c) +
      (B - A * b / 2) / k * Real.arctan ((x + b / 2) / k))
      (A / 2 * ((2 * x + b) / (x ^ 2 + b * x + c)) +
        (B - A * b / 2) / k * (1 / (1 + ((x + b / 2) / k) ^ 2) * (1 / k))) x :=
    (h2.const_mul (A / 2)).add (h4.const_mul ((B - A * b / 2) / k))
  convert h5 using 1
  -- μένει μια αλγεβρική ταυτότητα
  have h6 : 1 + ((x + b / 2) / k) ^ 2 = ((x + b / 2) ^ 2 + k ^ 2) / k ^ 2 := by
    field_simp
    ring
  have hq : (x + b / 2) ^ 2 + k ^ 2 ≠ 0 := by
    rw [← hsq]
    exact hpos.ne'
  rw [h6, hsq]
  field_simp
  ring

theorem log_part (A b c : ℝ) (hdisc : b ^ 2 - 4 * c < 0) (x : ℝ) :
    HasDerivAt (fun x => A / 2 * Real.log (x ^ 2 + b * x + c))
      ((A * x + A * b / 2) / (x ^ 2 + b * x + c)) x := by
  have h := quadratic_factor A (A * b / 2) b c hdisc x
  simp only [sub_self, zero_div, zero_mul, add_zero] at h
  exact h
