Ολοκληρώματα με $\tan$ και $\sec$

Κεφάλαιο 16 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

Εκφώνηση$\int\tan x\,dx=\ln|\sec x|+C$ και $\int\sec x\,dx$${}=\ln|\sec x+\tan x|+C$, καθώς και $\int\sec^2x\,dx=\tan x+C$, $\int\sec x\tan x\,dx=\sec x+C$. Για $\int\tan^m x\sec^n x\,dx$: αν το $n$ είναι άρτιος με $n\ge 2$, κρατάμε έναν παράγοντα $\sec^2 x$ για το $du$ και θέτουμε $u=\tan x$· αν το $m$ είναι περιττός με $n\ge 1$, κρατάμε έναν παράγοντα $\sec x\tan x$ και θέτουμε $u=\sec x$· στις υπόλοιπες περιπτώσεις ($n=0$, ή $m$ άρτιος με $n$ περιττός) γράφουμε $\tan^2 x=\sec^2 x-1$ και καταφεύγουμε σε αναγωγικό τύπο, σε ολοκλήρωση κατά παράγοντες ή στον τύπο του $\int\sec x\,dx$.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $\int\sec^2x\,dx=\tan x+C$
    theorem int_sec_sq (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt Real.tan (1 / Real.cos x ^ 2) x
  • $\int\sec x\tan x\,dx=\sec x+C$
    theorem int_sec_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => 1 / Real.cos x) (1 / Real.cos x * Real.tan x) x
  • $\int\sec x\,dx$${}=\ln|\sec x+\tan x|+C$
    theorem int_sec (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x + Real.tan x|) (1 / Real.cos x) x
  • $\int\tan x\,dx=\ln|\sec x|+C$
    theorem int_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x|) (Real.tan x) x

Κάθε τύπος γράφεται ως «η δεξιά πλευρά έχει παράγωγο την ολοκληρωτέα συνάρτηση», σε κάθε $x$ με $\cos x\neq 0$. Η $\sec x$ γράφεται $\dfrac{1}{\cos x}$. Οι οδηγίες για το $\int\tan^m x\sec^n x\,dx$ λένε ποια αντικατάσταση να κάνουμε, δεν είναι θεωρήματα, γι’ αυτό δεν διατυπώνονται. Στη Mathlib ο λογάριθμος Real.log ορίζεται και για αρνητικούς αριθμούς, ως $\ln|t|$, οπότε η απόλυτη τιμή φεύγει αμέσως (Real.log_abs).

2. Βήμα προς βήμα: $\int\sec x\,dx$

Η ιδέα: παραγωγίζουμε την $\ln(\sec x+\tan x)$ και βρίσκουμε $\dfrac{\sec x\tan x+\sec^2x}{\sec x+\tan x}$${}=\sec x$. Ξεκινάμε από τον στόχο:

Ο στόχος
x : ℝ
hc : Real.cos x ≠ 0
⊢ HasDerivAt (fun x => Real.log |1 / Real.cos x + Real.tan x|) (1 / Real.cos x) x

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- στη Mathlib ισχύει ln|t| = ln t
simp only [Real.log_abs]

    Στη Mathlib $\ln|t|=\ln t$ (Real.log_abs), οπότε η απόλυτη τιμή φεύγει.

    Τι μένει να αποδειχθεί

have h1 : Real.sin x = -1 := by linarith
have h2 := Real.sin_sq_add_cos_sq x
rw [h1] at h2
have h3 : Real.cos x ^ 2 = 0 := by linarith

    Αν ήταν $1+\sin x=0$, τότε $\sin x=-1$, και από την $\sin^2x+\cos^2x=1$ θα είχαμε $\cos^2x=0$, άρα $\cos x=0$, που αντιφάσκει με την υπόθεση.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  4. -- sec x + tan x = (1 + sin x)/cos x ≠ 0
have hne : 1 / Real.cos x + Real.tan x ≠ 0 := by
  rw [Real.tan_eq_sin_div_cos, ← add_div]
  exact div_ne_zero hs hc

    Επομένως, $\sec x+\tan x$${}=\dfrac{1+\sin x}{\cos x}\neq 0$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  5. -- (sec x + tan x)' = sec x tan x + sec² x
have h1 : HasDerivAt (fun x => 1 / Real.cos x + Real.tan x)
    (1 / Real.cos x * Real.tan x + 1 / Real.cos x ^ 2) x :=
  (int_sec_tan x hc).add (int_sec_sq x hc)

    Η $\sec x+\tan x$ έχει παράγωγο $\sec x\tan x+\sec^2x$, από τους δύο προηγούμενους τύπους.

3. Δοκίμασε εσύ: $\int\tan x\,dx$

Δείξε ότι, όπου $\cos x\neq 0$, η $\ln|\sec x|$ έχει παράγωγο $\tan x$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Ξεκίνα με simp only [Real.log_abs]. Μετά εφάρμοσε τον κανόνα του λογαρίθμου στον τύπο για την $\sec x$: have h := (int_sec_tan x hc).log (one_div_ne_zero hc). Τέλος convert h using 1, rw [Real.tan_eq_sin_div_cos] και field_simp.

Λύση
theorem int_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x|) (Real.tan x) x := by
  simp only [Real.log_abs]
  have h := (int_sec_tan x hc).log (one_div_ne_zero hc)
  convert h using 1
  rw [Real.tan_eq_sin_div_cos]

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Real.hasDerivAt_tan: η παράγωγος της $\tan x$.
  • Real.hasDerivAt_cos: η παράγωγος του $\cos x$.
  • HasDerivAt.fun_div: ο κανόνας του πηλίκου.
  • Real.log_abs: $\ln|t|=\ln t$ στη Mathlib.
  • Real.sin_sq_add_cos_sq: $\sin^2x+\cos^2x=1$.
  • Real.tan_eq_sin_div_cos: $\tan x=\dfrac{\sin x}{\cos x}$.
  • HasDerivAt.add: ο κανόνας του αθροίσματος.
  • HasDerivAt.log: η παράγωγος της $\ln f(x)$.

import Mathlib

namespace Κεφ16.TanSec

-- γράφουμε sec x = 1/cos x

-- ∫ sec² x dx = tan x + C
theorem int_sec_sq (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt Real.tan (1 / Real.cos x ^ 2) x :=
  Real.hasDerivAt_tan hc

-- ∫ sec x tan x dx = sec x + C
theorem int_sec_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => 1 / Real.cos x) (1 / Real.cos x * Real.tan x) x := by
  have h := (hasDerivAt_const x (1 : ℝ)).fun_div (Real.hasDerivAt_cos x) hc
  convert h using 1
  rw [Real.tan_eq_sin_div_cos]
  field_simp
  ring

-- ∫ sec x dx = ln|sec x + tan x| + C
theorem int_sec (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x + Real.tan x|) (1 / Real.cos x) x := by
  -- στη Mathlib ισχύει ln|t| = ln t
  simp only [Real.log_abs]
  -- όταν cos x ≠ 0, τότε sin x ≠ -1
  have hs : 1 + Real.sin x ≠ 0 := by
    intro h
    have h1 : Real.sin x = -1 := by linarith
    have h2 := Real.sin_sq_add_cos_sq x
    rw [h1] at h2
    have h3 : Real.cos x ^ 2 = 0 := by linarith
    exact hc (pow_eq_zero_iff two_ne_zero |>.mp h3)
  -- sec x + tan x = (1 + sin x)/cos x ≠ 0
  have hne : 1 / Real.cos x + Real.tan x ≠ 0 := by
    rw [Real.tan_eq_sin_div_cos, ← add_div]
    exact div_ne_zero hs hc
  -- (sec x + tan x)' = sec x tan x + sec² x
  have h1 : HasDerivAt (fun x => 1 / Real.cos x + Real.tan x)
      (1 / Real.cos x * Real.tan x + 1 / Real.cos x ^ 2) x :=
    (int_sec_tan x hc).add (int_sec_sq x hc)
  -- κανόνας του λογαρίθμου
  have h2 := h1.log hne
  convert h2 using 1
  rw [Real.tan_eq_sin_div_cos]
  field_simp
  ring

theorem int_tan (x : ℝ) (hc : Real.cos x ≠ 0) :
    HasDerivAt (fun x => Real.log |1 / Real.cos x|) (Real.tan x) x := by
  simp only [Real.log_abs]
  have h := (int_sec_tan x hc).log (one_div_ne_zero hc)
  convert h using 1
  rw [Real.tan_eq_sin_div_cos]
  field_simp

end Κεφ16.TanSec
