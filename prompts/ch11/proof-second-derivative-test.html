Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $f'(x_0)=0$ και $f''(x_0)\gt 0$, η $f$ έχει τοπικό ελάχιστο στο $x_0$
    theorem second_deriv_min (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hpos : 0 < deriv (deriv f) x₀) : IsLocalMin f x₀
  • Αν $f'(x_0)=0$ και $f''(x_0)\lt 0$, η $f$ έχει τοπικό μέγιστο στο $x_0$
    theorem second_deriv_max (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hneg : deriv (deriv f) x₀ < 0) : IsLocalMax f x₀
  • Όταν $f''(x_0)=0$ μπορεί να υπάρχει ακρότατο: η $x^4$ έχει $f'(0)=f''(0)=0$ και ελάχιστο στο $0$
    theorem quartic : deriv (fun x : ℝ => x ^ 4) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 4)) 0 = 0 ∧
    IsLocalMin (fun x : ℝ => x ^ 4) 0
  • Μπορεί όμως και να μην υπάρχει: η $x^3$ έχει $f'(0)=f''(0)=0$ και κανένα ακρότατο στο $0$
    theorem cubic : deriv (fun x : ℝ => x ^ 3) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 3)) 0 = 0 ∧
    ¬ IsLocalExtr (fun x : ℝ => x ^ 3) 0

Η παράγωγος γράφεται deriv f x₀ και η δεύτερη παράγωγος deriv (deriv f) x₀. Το θεώρημα της Mathlib ζητά λιγότερα από το βιβλίο: μόνο τη συνέχεια της $f$ στο $x_0$ (ContinuousAt f x₀), όχι τη συνέχεια της $f''$ σε γειτονιά. Οι συναρτήσεις $x^4$ και $x^3$ δείχνουν γιατί το κριτήριο δεν αποφαίνεται όταν $f''(x_0)=0$: έχουν τις ίδιες τιμές $f'(0)=f''(0)=0$, αλλά η πρώτη έχει ελάχιστο και η δεύτερη κανένα ακρότατο. Το IsLocalExtr σημαίνει «τοπικό ακρότατο».

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • isLocalMin_of_deriv_deriv_pos: το κριτήριο δεύτερης παραγώγου για ελάχιστο.
  • isLocalMax_of_deriv_deriv_neg: το κριτήριο δεύτερης παραγώγου για μέγιστο.
  • deriv_pow_field: η παράγωγος της $x^n$ είναι $n\,x^{n-1}$.
  • deriv_const_mul: η παράγωγος της $c\,f(x)$ είναι $c\,f'(x)$.
  • Metric.eventually_nhds_iff: μια ιδιότητα ισχύει κοντά στο $x_0$ ακριβώς όταν ισχύει σε ένα διάστημα $(x_0-\varepsilon,x_0+\varepsilon)$.

theorem second_deriv_min (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hpos : 0 < deriv (deriv f) x₀) : IsLocalMin f x₀ :=
  isLocalMin_of_deriv_deriv_pos hpos hd hc

theorem second_deriv_max (f : ℝ → ℝ) (x₀ : ℝ) (hc : ContinuousAt f x₀) (hd : deriv f x₀ = 0)
    (hneg : deriv (deriv f) x₀ < 0) : IsLocalMax f x₀ :=
  isLocalMax_of_deriv_deriv_neg hneg hd hc

-- όταν f''(x₀) = 0 το κριτήριο δεν αποφαίνεται: η x⁴ έχει ελάχιστο στο 0, η x³ κανένα ακρότατο
theorem quartic : deriv (fun x : ℝ => x ^ 4) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 4)) 0 = 0 ∧
    IsLocalMin (fun x : ℝ => x ^ 4) 0 := by
  have h1 : deriv (fun x : ℝ => x ^ 4) = fun x => 4 * x ^ 3 := by
    funext x
    rw [deriv_pow_field]
    norm_num
  refine ⟨by rw [h1]; norm_num, ?_, ?_⟩
  · rw [h1, deriv_const_mul _ (differentiableAt_pow 3), deriv_pow_field]
    norm_num
  · exact Filter.Eventually.of_forall fun x => by
      show (0 : ℝ) ^ 4 ≤ x ^ 4
      rw [zero_pow (by norm_num)]
      positivity

theorem cubic : deriv (fun x : ℝ => x ^ 3) 0 = 0 ∧ deriv (deriv (fun x : ℝ => x ^ 3)) 0 = 0 ∧
    ¬ IsLocalExtr (fun x : ℝ => x ^ 3) 0 := by
  have h1 : deriv (fun x : ℝ => x ^ 3) = fun x => 3 * x ^ 2 := by
    funext x
    rw [deriv_pow_field]
    norm_num
  refine ⟨by rw [h1]; norm_num, ?_, ?_⟩
  · rw [h1, deriv_const_mul _ (differentiableAt_pow 2), deriv_pow_field]
    norm_num
  · have hpt : ∀ ε : ℝ, 0 < ε → dist (ε / 2) 0 < ε ∧ dist (-(ε / 2)) 0 < ε := by
      intro ε hε
      rw [Real.dist_eq, Real.dist_eq, sub_zero, sub_zero, abs_neg, abs_of_pos (half_pos hε)]
      constructor <;> linarith
    rintro (h | h)
    · obtain ⟨ε, hε, hball⟩ := Metric.eventually_nhds_iff.mp h
      have h2 : (0 : ℝ) ^ 3 ≤ (-(ε / 2)) ^ 3 := hball (hpt ε hε).2
      have h3 : 0 < (ε / 2) ^ 3 := pow_pos (half_pos hε) 3
      linarith
    · obtain ⟨ε, hε, hball⟩ := Metric.eventually_nhds_iff.mp h
      have h2 : (ε / 2) ^ 3 ≤ (0 : ℝ) ^ 3 := hball (hpt ε hε).1
      have h3 : 0 < (ε / 2) ^ 3 := pow_pos (half_pos hε) 3
      linarith
