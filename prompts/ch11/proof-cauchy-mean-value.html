    (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hgg' : ∀ x ∈ Set.Ioo a b, HasDerivAt g (g' x) x) :
    ∃ c ∈ Set.Ioo a b, (g b - g a) * f' c = (f b - f a) * g' c

Η συνέχεια στο $[a,b]$ γράφεται ContinuousOn f (Set.Icc a b). Για την παραγωγισιμότητα στο $(a,b)$ δίνουμε μια συνάρτηση f' για την παράγωγο: ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x. Το ίδιο για την $g$, με τη συνάρτηση g'. Η απόδειξη χρησιμοποιεί δύο φορές το θεώρημα Rolle (στη Mathlib exists_hasDerivAt_eq_zero): πρώτα για να δείξει ότι $g(b)\neq g(a)$ και μετά για τη βοηθητική συνάρτηση $h(x)$${}=[f(b)-f(a)]\,g(x)-[g(b)-g(a)]\,f(x)$. Η εντολή set δίνει όνομα σε μια παράσταση: γράφουμε $A$ αντί για $f(b)-f(a)$ και $B$ αντί για $g(b)-g(a)$.

2. Βήμα προς βήμα: το θεώρημα του Cauchy

Η ιδέα: η $h(x)=A\,g(x)-B\,f(x)$, με $A=f(b)-f(a)$ και $B=g(b)-g(a)$, παίρνει την ίδια τιμή στα άκρα, οπότε από το θεώρημα Rolle η $h'$ μηδενίζεται κάπου. Ξεκινάμε από τον στόχο:

Ο στόχος
f f' g g' : ℝ → ℝ
a b : ℝ
hab : a < b
hfc : ContinuousOn f (Set.Icc a b)
hgc : ContinuousOn g (Set.Icc a b)
hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x
hgg' : ∀ x ∈ Set.Ioo a b, HasDerivAt g (g' x) x
hg' : ∀ x ∈ Set.Ioo a b, g' x ≠ 0
⊢ ∃ c ∈ Set.Ioo a b, f' c / g' c = (f b - f a) / (g b - g a)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have hgab : g b - g a ≠ 0 := by

    Πρώτα δείχνουμε ότι $g(b)\neq g(a)$ (ισχυρισμός hgab).

    Τι μένει να αποδειχθεί
    ⊢ g b - g a ≠ 0
  2. intro h

    Με απαγωγή σε άτοπο: υποθέτουμε ότι $g(b)-g(a)=0$ και ψάχνουμε αντίφαση (False).

    Τι μένει να αποδειχθεί
    h : g b - g a = 0
⊢ False
  3. obtain ⟨c, hc, hc0⟩ := exists_hasDerivAt_eq_zero hab hgc (by linarith) hgg'

    Τότε $g(a)=g(b)$ και το θεώρημα Rolle δίνει $c\in(a,b)$ με $g'(c)=0$.

    Τι μένει να αποδειχθεί
    c : ℝ
hc : c ∈ Set.Ioo a b
hc0 : g' c = 0
⊢ False
  4. exact hg' c hc hc0

    Αυτό αντιφάσκει στην υπόθεση $g'(x)\neq 0$ στο $(a,b)$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  5. set A := f b - f a with hA

    Ονομάζουμε $A=f(b)-f(a)$.

    Ονομάζουμε $B=g(b)-g(a)$. Τώρα ο στόχος είναι $\dfrac{f'(c)}{g'(c)}=\dfrac{A}{B}$ και ξέρουμε ότι $B\neq 0$.

⊢ ∃ c ∈ Set.Ioo a b, f' c / g' c = A / B

    Η βοηθητική συνάρτηση $h(x)=A\,g(x)-B\,f(x)$ είναι συνεχής στο $[a,b]$ (hcont).

    Τι μένει να αποδειχθεί

⊢ ∃ c ∈ Set.Ioo a b, f' c / g' c = A / B

    HasDerivAt (fun x => A * g x - B * f x) (A * g' x - B * f' x) x := by

    Ισχυρισμός hderiv: στο $(a,b)$ η $h$ έχει παράγωγο $A\,g'(x)-B\,f'(x)$.

    Τι μένει να αποδειχθεί
    ⊢ ∀ x ∈ Set.Ioo a b, HasDerivAt (fun x => A * g x - B * f x) (A * g' x - B * f' x) x

exact ((hgg' x hx).const_mul A).sub ((hff' x hx).const_mul B)

    Κανόνες του σταθερού πολλαπλασίου και της διαφοράς.

3. Δοκίμασε εσύ: το θεώρημα μέσης τιμής ως ειδική περίπτωση

Με $g(x)=x$, οπότε $g'(x)=1$, δείξε ότι υπάρχει $c\in(a,b)$ με $f'(c)=\dfrac{f(b)-f(a)}{b-a}$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Εφάρμοσε το θεώρημα με (fun x => x) και (fun _ => 1): obtain ⟨c, hc, h⟩ := cauchy_mean_value f f' (fun x => x) (fun _ => 1) a b hab hfc continuousOn_id hff' (fun x _ => hasDerivAt_id' x) (fun _ _ => one_ne_zero). Τέλος exact ⟨c, hc, by simpa using h⟩: η simpa απλοποιεί το $\dfrac{f'(c)}{1}$.

Λύση
theorem lagrange_from_cauchy (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hfc : ContinuousOn f (Set.Icc a b)) (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) :
    ∃ c ∈ Set.Ioo a b, f' c = (f b - f a) / (b - a) := by
  obtain ⟨c, hc, h⟩ := cauchy_mean_value f f' (fun x => x) (fun _ => 1) a b hab hfc
    continuousOn_id hff' (fun x _ => hasDerivAt_id' x) (fun _ _ => one_ne_zero)
  exact ⟨c, hc, by simpa using h⟩

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • exists_hasDerivAt_eq_zero: το θεώρημα Rolle.
  • ContinuousOn.mul: το γινόμενο συνεχών συναρτήσεων είναι συνεχές.
  • ContinuousOn.sub: η διαφορά συνεχών συναρτήσεων είναι συνεχής.
  • HasDerivAt.const_mul: ο κανόνας για την $c\,f(x)$.
  • HasDerivAt.sub: ο κανόνας της διαφοράς.
  • div_eq_div_iff: $\dfrac{a}{b}=\dfrac{c}{d}$ ακριβώς όταν $ad=cb$, για $b,d\neq 0$.
  • exists_ratio_hasDerivAt_eq_ratio_slope: το θεώρημα του Cauchy στη Mathlib.

theorem cauchy_mean_value (f f' g g' : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hfc : ContinuousOn f (Set.Icc a b)) (hgc : ContinuousOn g (Set.Icc a b))
    (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hgg' : ∀ x ∈ Set.Ioo a b, HasDerivAt g (g' x) x)
    (hg' : ∀ x ∈ Set.Ioo a b, g' x ≠ 0) :
    ∃ c ∈ Set.Ioo a b, f' c / g' c = (f b - f a) / (g b - g a) := by
  have hgab : g b - g a ≠ 0 := by
    intro h
    obtain ⟨c, hc, hc0⟩ := exists_hasDerivAt_eq_zero hab hgc (by linarith) hgg'
    exact hg' c hc hc0
  set A := f b - f a with hA
  set B := g b - g a with hB
  have hcont : ContinuousOn (fun x => A * g x - B * f x) (Set.Icc a b) :=
    (continuousOn_const.mul hgc).sub (continuousOn_const.mul hfc)
  have hderiv : ∀ x ∈ Set.Ioo a b,
      HasDerivAt (fun x => A * g x - B * f x) (A * g' x - B * f' x) x := by
    intro x hx
    exact ((hgg' x hx).const_mul A).sub ((hff' x hx).const_mul B)
  have hends : A * g a - B * f a = A * g b - B * f b := by
    rw [hA, hB]
    ring
  obtain ⟨c, hc, hc0⟩ := exists_hasDerivAt_eq_zero hab hcont hends hderiv
  refine ⟨c, hc, ?_⟩
  rw [div_eq_div_iff (hg' c hc) hgab]
  linear_combination -hc0

theorem lagrange_from_cauchy (f f' : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hfc : ContinuousOn f (Set.Icc a b)) (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x) :
    ∃ c ∈ Set.Ioo a b, f' c = (f b - f a) / (b - a) := by
  obtain ⟨c, hc, h⟩ := cauchy_mean_value f f' (fun x => x) (fun _ => 1) a b hab hfc
    continuousOn_id hff' (fun x _ => hasDerivAt_id' x) (fun _ _ => one_ne_zero)
  exact ⟨c, hc, by simpa using h⟩

-- η μορφή της Mathlib, χωρίς διαίρεση
theorem cauchy_mathlib (f f' g g' : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hfc : ContinuousOn f (Set.Icc a b)) (hgc : ContinuousOn g (Set.Icc a b))
    (hff' : ∀ x ∈ Set.Ioo a b, HasDerivAt f (f' x) x)
    (hgg' : ∀ x ∈ Set.Ioo a b, HasDerivAt g (g' x) x) :
    ∃ c ∈ Set.Ioo a b, (g b - g a) * f' c = (f b - f a) * g' c :=
  exists_ratio_hasDerivAt_eq_ratio_slope f f' hab hfc hff' g g' hgc hgg'
