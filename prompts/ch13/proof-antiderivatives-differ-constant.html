Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $F'=G'=f$ στο $(a,b)$, υπάρχει σταθερά $C$ με $G(x)=F(x)+C$ για κάθε $x\in(a,b)$
    theorem antiderivatives_differ_const (F G f : ℝ → ℝ) (a b : ℝ)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x) :
    ∃ C, ∀ x ∈ Set.Ioo a b, G x = F x + C
  • Εφαρμογή: αν επιπλέον $G(x_0)=F(x_0)$ σε ένα σημείο, τότε $G=F$ σε όλο το $(a,b)$
    theorem same_value_same_function (F G f : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x)
    (h0 : G x₀ = F x₀) : ∀ x ∈ Set.Ioo a b, G x = F x

Το «η $F$ είναι αντιπαράγωγος της $f$ στο διάστημα» γράφεται ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x: σε κάθε σημείο του $(a,b)$ η $F$ έχει παράγωγο $f(x)$. Ως διάστημα $I$ παίρνουμε ένα ανοιχτό διάστημα $(a,b)$. Η απόδειξη χρησιμοποιεί το θεώρημα μέσης τιμής (exists_hasDerivAt_eq_slope): η $H=G-F$ έχει παράγωγο $0$, άρα παίρνει την ίδια τιμή σε όλα τα σημεία του διαστήματος. Η υπόθεση ότι το $I$ είναι διάστημα χρειάζεται, γιατί σε δύο ξένα διαστήματα οι σταθερές μπορεί να διαφέρουν.

2. Βήμα προς βήμα: $G=F+C$

Η ιδέα: η $H=G-F$ έχει παράγωγο $0$, οπότε από το θεώρημα μέσης τιμής είναι σταθερή· η σταθερά είναι η τιμή της στο μέσο του διαστήματος. Ξεκινάμε από τον στόχο:

Ο στόχος
F G f : ℝ → ℝ
a b : ℝ
hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x
hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x
⊢ ∃ C, ∀ x ∈ Set.Ioo a b, G x = F x + C

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- η διαφορά H = G - F έχει παράγωγο 0
have hH : ∀ x ∈ Set.Ioo a b, HasDerivAt (fun x => G x - F x) 0 x := by

    Ισχυρισμός hH: η διαφορά $H(x)=G(x)-F(x)$ έχει παράγωγο $0$ στο $(a,b)$.

    Τι μένει να αποδειχθεί
    ⊢ ∀ x ∈ Set.Ioo a b, HasDerivAt (fun x => G x - F x) 0 x
  2. intro x hx
have h := (hG x hx).sub (hF x hx)
rw [sub_self] at h
exact h

    Η παράγωγος της διαφοράς είναι $f(x)-f(x)=0$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  3. -- θεώρημα μέσης τιμής: η H παίρνει την ίδια τιμή σε δύο οποιαδήποτε σημεία
have hconst : ∀ x ∈ Set.Ioo a b, ∀ y ∈ Set.Ioo a b, x < y → G y - F y = G x - F x := by

    Ισχυρισμός hconst: για $x\lt y$ στο $(a,b)$ ισχύει $H(y)=H(x)$.

    Τι μένει να αποδειχθεί
    F G f : ℝ → ℝ
a b : ℝ
hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x
hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x
hH : ∀ x ∈ Set.Ioo a b, HasDerivAt (fun x => G x - F x) 0 x
⊢ ∀ x ∈ Set.Ioo a b, ∀ y ∈ Set.Ioo a b, x < y → G y - F y = G x - F x
  4. intro x hx y hy hxy

    Παίρνουμε $x\lt y$ στο $(a,b)$.

    Τι μένει να αποδειχθεί
    x : ℝ
hx : x ∈ Set.Ioo a b
y : ℝ
hy : y ∈ Set.Ioo a b
hxy : x < y
⊢ G y - F y = G x - F x
  5. have hcont : ContinuousOn (fun x => G x - F x) (Set.Icc x y) := fun z hz =>
  (hH z ⟨hx.1.trans_le hz.1, hz.2.trans_lt hy.2⟩).continuousAt.continuousWithinAt
obtain ⟨c, -, hc⟩ := exists_hasDerivAt_eq_slope (fun x => G x - F x) (fun _ => 0) hxy hcont
  (fun z hz => hH z ⟨hx.1.trans hz.1, hz.2.trans hy.2⟩)

    Θεώρημα μέσης τιμής για την $H$ στο $[x,y]$, όπου η $H$ είναι συνεχής (hcont): υπάρχει $c$ με $0=H'(c)=\dfrac{H(y)-H(x)}{y-x}$.

    Τι μένει να αποδειχθεί
    hcont : ContinuousOn (fun x => G x - F x) (Set.Icc x y)
c : ℝ
hc : 0 = (G y - F y - (G x - F x)) / (y - x)
⊢ G y - F y = G x - F x
  6. have h : (G y - F y - (G x - F x)) / (y - x) = 0 := hc.symm

    Γράφουμε την ισότητα ανάποδα: το κλάσμα είναι $0$.

    Τι μένει να αποδειχθεί
    h : (G y - F y - (G x - F x)) / (y - x) = 0
⊢ G y - F y = G x - F x
  7. rw [div_eq_zero_iff, sub_eq_zero] at h

    Ένα κλάσμα είναι $0$ ακριβώς όταν ο αριθμητής ή ο παρονομαστής είναι $0$: $H(y)=H(x)$ ή $y-x=0$.

    Τι μένει να αποδειχθεί
    h : G y - F y = G x - F x ∨ y - x = 0
⊢ G y - F y = G x - F x
  8. exact h.resolve_right (sub_ne_zero.mpr hxy.ne')

    Το $y-x=0$ αποκλείεται, γιατί $x\lt y$. Άρα $H(y)=H(x)$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  9. by_cases hab : a < b

    Δύο περιπτώσεις: το διάστημα $(a,b)$ είναι μη κενό ($a\lt b$) ή κενό.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος pos

  refine ⟨G ((a + b) / 2) - F ((a + b) / 2), fun x hx => ?_⟩

    Αν $a\lt b$, το μέσο $m=\dfrac{a+b}{2}$ ανήκει στο $(a,b)$. Διαλέγουμε $C=G(m)-F(m)$ και παίρνουμε τυχαίο $x\in(a,b)$.

    Τι μένει να αποδειχθεί

x : ℝ

⊢ G x = F x + (G ((a + b) / 2) - F ((a + b) / 2))

    Τρεις περιπτώσεις: $x\lt m$, $x=m$ ή $x\gt m$.

    Τι μένει να αποδειχθεί (3 στόχοι)σκέλος pos.inl

    Αν $x\lt m$: από την hconst, $H(m)=H(x)$, δηλαδή $G(x)=F(x)+C$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.

    Αν $x\gt m$: πάλι από την hconst, $H(x)=H(m)$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.

3. Δοκίμασε εσύ: ίδια τιμή σε ένα σημείο

Αν επιπλέον $G(x_0)=F(x_0)$ για κάποιο $x_0\in(a,b)$, δείξε ότι $G(x)=F(x)$ για κάθε $x\in(a,b)$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Πάρε τη σταθερά του θεωρήματος: obtain ⟨C, hC⟩ := antiderivatives_differ_const F G f a b hF hG. Στο $x_0$ η hC x₀ hx₀ δίνει $G(x_0)=F(x_0)+C$, οπότε με τη linarith βρίσκεις $C=0$. Τέλος intro x hx και rw [hC x hx, hC0, add_zero], όπου hC0 είναι το $C=0$.

Λύση
theorem same_value_same_function (F G f : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x)
    (h0 : G x₀ = F x₀) : ∀ x ∈ Set.Ioo a b, G x = F x := by
  obtain ⟨C, hC⟩ := antiderivatives_differ_const F G f a b hF hG
  have hC0 : C = 0 := by
    have h := hC x₀ hx₀
    linarith
  intro x hx
  rw [hC x hx, hC0, add_zero]

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • exists_hasDerivAt_eq_slope: το θεώρημα μέσης τιμής.
  • HasDerivAt.sub: ο κανόνας της διαφοράς.
  • HasDerivAt.continuousAt: παραγωγίσιμη συνάρτηση είναι συνεχής.
  • div_eq_zero_iff: $\dfrac{a}{b}=0$ ακριβώς όταν $a=0$ ή $b=0$.
  • lt_trichotomy: για δύο αριθμούς ισχύει $x\lt y$, $x=y$ ή $x\gt y$.

theorem antiderivatives_differ_const (F G f : ℝ → ℝ) (a b : ℝ)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x) :
    ∃ C, ∀ x ∈ Set.Ioo a b, G x = F x + C := by
  -- η διαφορά H = G - F έχει παράγωγο 0
  have hH : ∀ x ∈ Set.Ioo a b, HasDerivAt (fun x => G x - F x) 0 x := by
    intro x hx
    have h := (hG x hx).sub (hF x hx)
    rw [sub_self] at h
    exact h
  -- θεώρημα μέσης τιμής: η H παίρνει την ίδια τιμή σε δύο οποιαδήποτε σημεία
  have hconst : ∀ x ∈ Set.Ioo a b, ∀ y ∈ Set.Ioo a b, x < y → G y - F y = G x - F x := by
    intro x hx y hy hxy
    have hcont : ContinuousOn (fun x => G x - F x) (Set.Icc x y) := fun z hz =>
      (hH z ⟨hx.1.trans_le hz.1, hz.2.trans_lt hy.2⟩).continuousAt.continuousWithinAt
    obtain ⟨c, -, hc⟩ := exists_hasDerivAt_eq_slope (fun x => G x - F x) (fun _ => 0) hxy hcont
      (fun z hz => hH z ⟨hx.1.trans hz.1, hz.2.trans hy.2⟩)
    have h : (G y - F y - (G x - F x)) / (y - x) = 0 := hc.symm
    rw [div_eq_zero_iff, sub_eq_zero] at h
    exact h.resolve_right (sub_ne_zero.mpr hxy.ne')
  by_cases hab : a < b
  · have hm : (a + b) / 2 ∈ Set.Ioo a b := ⟨by linarith, by linarith⟩
    refine ⟨G ((a + b) / 2) - F ((a + b) / 2), fun x hx => ?_⟩
    rcases lt_trichotomy x ((a + b) / 2) with h | h | h
    · have := hconst x hx _ hm h
      linarith
    · rw [h]
      ring
    · have := hconst _ hm x hx h
      linarith
  · exact ⟨0, fun x hx => absurd (hx.1.trans hx.2) hab⟩

theorem same_value_same_function (F G f : ℝ → ℝ) (a b x₀ : ℝ) (hx₀ : x₀ ∈ Set.Ioo a b)
    (hF : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hG : ∀ x ∈ Set.Ioo a b, HasDerivAt G (f x) x)
    (h0 : G x₀ = F x₀) : ∀ x ∈ Set.Ioo a b, G x = F x := by
  obtain ⟨C, hC⟩ := antiderivatives_differ_const F G f a b hF hG
  have hC0 : C = 0 := by
    have h := hC x₀ hx₀
    linarith
  intro x hx
  rw [hC x hx, hC0, add_zero]
