ΕκφώνησηΈστω $f,g$ συναρτήσεις που έχουν αντιπαράγωγο σε διάστημα $I$ (π.χ. συνεχείς) και σταθερές $\lambda,\mu\in\mathbb{R}$. Τότε ισχύει η γραμμικότητα του αόριστου ολοκληρώματος: $\int\bigl(\lambda f(x)+\mu g(x)\bigr)\,dx$${}=\lambda\int f(x)\,dx+\mu\int g(x)\,dx$. Ειδικότερα, $\int \lambda f\,dx$${}=\lambda\int f\,dx$ και $\int (f\pm g)\,dx$${}=\int f\,dx\pm\int g\,dx$.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

    ∀ x ∈ I, HasDerivAt (fun x => F x - G x) (f x - g x) x

Το αόριστο ολοκλήρωμα $\int f(x)\,dx=F(x)+C$ σημαίνει ότι η $F$ είναι αντιπαράγωγος της $f$, δηλαδή ότι η $F$ έχει παράγωγο $f$: γράφεται HasDerivAt F (f x) x. Στο σύνολο $I$ γράφεται ∀ x ∈ I, HasDerivAt F (f x) x. Έτσι, η ισότητα $\int(c_1f+c_2g)\,dx$${}=c_1\int f\,dx+c_2\int g\,dx$ λέει ότι η $c_1F+c_2G$ είναι αντιπαράγωγος της $c_1f+c_2g$· η σταθερά $C$ απορροφά τις σταθερές των δύο ολοκληρωμάτων. Οι σταθερές $\lambda,\mu$ του βιβλίου γράφονται c₁ και c₂, γιατί το λ είναι δεσμευμένη λέξη του Lean.

2. Βήμα προς βήμα: η γραμμικότητα

Η ιδέα: οι κανόνες παραγώγισης για σταθερό πολλαπλάσιο και άθροισμα, διαβασμένοι ανάποδα. Ξεκινάμε από τον στόχο:

Ο στόχος
F G f g : ℝ → ℝ
c₁ c₂ : ℝ
I : Set ℝ
hF : ∀ x ∈ I, HasDerivAt F (f x) x
hG : ∀ x ∈ I, HasDerivAt G (g x) x
⊢ ∀ x ∈ I, HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. intro x hx

    Παίρνουμε τυχαίο $x\in I$.

    Τι μένει να αποδειχθεί
    x : ℝ
hx : x ∈ I
⊢ HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x
  2. have h1 : HasDerivAt (fun x => c₁ * F x) (c₁ * f x) x := (hF x hx).const_mul c₁

    Κανόνας σταθερού πολλαπλασίου: η $c_1F$ έχει παράγωγο $c_1f$.

    Τι μένει να αποδειχθεί
    h1 : HasDerivAt (fun x => c₁ * F x) (c₁ * f x) x
⊢ HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x
  3. have h2 : HasDerivAt (fun x => c₂ * G x) (c₂ * g x) x := (hG x hx).const_mul c₂

    Ομοίως, η $c_2G$ έχει παράγωγο $c_2g$.

    Τι μένει να αποδειχθεί
    h2 : HasDerivAt (fun x => c₂ * G x) (c₂ * g x) x
⊢ HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x
  4. exact h1.add h2

    Κανόνας αθροίσματος: η $c_1F+c_2G$ έχει παράγωγο $c_1f+c_2g$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: ο κανόνας της διαφοράς

Δείξε ότι $\int(f-g)\,dx$${}=\int f\,dx-\int g\,dx$, δηλαδή ότι η $F-G$ είναι αντιπαράγωγος της $f-g$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Πάρε τυχαίο $x\in I$ (intro x hx) και εφάρμοσε τον κανόνα της διαφοράς: exact (hF x hx).sub (hG x hx).

Λύση
theorem sub_rule (F G f g : ℝ → ℝ) (I : Set ℝ)
    (hF : ∀ x ∈ I, HasDerivAt F (f x) x) (hG : ∀ x ∈ I, HasDerivAt G (g x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => F x - G x) (f x - g x) x := by
  intro x hx
  exact (hF x hx).sub (hG x hx)

-- ∫ (c₁ f + c₂ g) dx = c₁ ∫ f dx + c₂ ∫ g dx, γραμμένο με αντιπαραγώγους
theorem linearity (F G f g : ℝ → ℝ) (c₁ c₂ : ℝ) (I : Set ℝ)
    (hF : ∀ x ∈ I, HasDerivAt F (f x) x) (hG : ∀ x ∈ I, HasDerivAt G (g x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => c₁ * F x + c₂ * G x) (c₁ * f x + c₂ * g x) x := by
  intro x hx
  have h1 : HasDerivAt (fun x => c₁ * F x) (c₁ * f x) x := (hF x hx).const_mul c₁
  have h2 : HasDerivAt (fun x => c₂ * G x) (c₂ * g x) x := (hG x hx).const_mul c₂
  exact h1.add h2

theorem const_mul_rule (F f : ℝ → ℝ) (c : ℝ) (I : Set ℝ) (hF : ∀ x ∈ I, HasDerivAt F (f x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => c * F x) (c * f x) x :=
  fun x hx => (hF x hx).const_mul c

theorem add_rule (F G f g : ℝ → ℝ) (I : Set ℝ)
    (hF : ∀ x ∈ I, HasDerivAt F (f x) x) (hG : ∀ x ∈ I, HasDerivAt G (g x) x) :
    ∀ x ∈ I, HasDerivAt (fun x => F x + G x) (f x + g x) x :=
  fun x hx => (hF x hx).add (hG x hx)
