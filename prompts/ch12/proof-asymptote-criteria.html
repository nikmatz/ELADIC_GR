Κριτήρια Ασυμπτώτων

Κεφάλαιο 12 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΓια ρητή συνάρτηση $f(x)=\dfrac{P(x)}{Q(x)}$ (με $P,Q$ χωρίς κοινό παράγοντα): (i) κατακόρυφη ασύμπτωτη $x=x_0$ σε κάθε ρίζα $x_0$ του $Q$· (ii) οριζόντια ασύμπτωτη αν $\deg P\le\deg Q$ — $y=0$ όταν $\deg P<\deg Q$, ή $y$ ίσο με τον λόγο των μεγιστοβάθμιων συντελεστών όταν $\deg P=\deg Q$· (iii) πλάγια ασύμπτωτη $y=\alpha x+\beta$ αν και μόνο αν $\deg P=\deg Q+1$, όπου $\alpha x+\beta$ είναι το πηλίκο της διαίρεσης $P/Q$. Γενικότερα (όχι μόνο για ρητές), η $y=\alpha x+\beta$ είναι πλάγια ασύμπτωτη της $f$ στο $\pm\infty$ αν και μόνο αν υπάρχουν τα πεπερασμένα όρια $\alpha$${}=\lim_{x\to\pm\infty}\dfrac{f(x)}{x}\ne 0$ και $\beta$${}=\lim_{x\to\pm\infty}\bigl(f(x)-\alpha x\bigr)$. Αν $\alpha=0$ και το $\beta$ υπάρχει, η ασύμπτωτη είναι οριζόντια.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • (i) Αν $q(x_0)=0$, $p(x_0)\neq 0$ και $q(x)\neq 0$ κοντά στο $x_0$, τότε $\left|\dfrac{p(x)}{q(x)}\right|\to+\infty$ όταν $x\to x_0$: κατακόρυφη ασύμπτωτη $x=x_0$
    theorem vertical_asymptote (p q : ℝ → ℝ) (x₀ : ℝ) (hp : ContinuousAt p x₀)
    (hq : ContinuousAt q x₀) (hq0 : q x₀ = 0) (hp0 : p x₀ ≠ 0)
    (hqne : ∀ᶠ x in 𝓝[≠] x₀, q x ≠ 0) :
    Tendsto (fun x => |p x / q x|) (𝓝[≠] x₀) atTop
  • (ii) Αν $\deg P\lt\deg Q$, τότε $\dfrac{P(x)}{Q(x)}\to 0$: οριζόντια ασύμπτωτη $y=0$
    theorem horizontal_zero (P Q : ℝ[X]) (hdeg : P.degree < Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 0)
  • (ii) Αν $\deg P=\deg Q$, η $\dfrac{P(x)}{Q(x)}$ τείνει στον λόγο των μεγιστοβάθμιων συντελεστών
    theorem horizontal_ratio (P Q : ℝ[X]) (hdeg : P.degree = Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 (P.leadingCoeff / Q.leadingCoeff))
  • (iii) Αν $S$ είναι το πηλίκο της διαίρεσης $P:Q$, τότε $\dfrac{P(x)}{Q(x)}-S(x)\to 0$· όταν $\deg P=\deg Q+1$, το $S(x)=\alpha x+\beta$ είναι η πλάγια ασύμπτωτη
    theorem minus_quotient (P Q : ℝ[X]) (hQ : Q ≠ 0) :
    Tendsto (fun x => P.eval x / Q.eval x - (P / Q).eval x) atTop (𝓝 0)
  • Γενικό κριτήριο: η $y=\alpha x+\beta$ είναι ασύμπτωτη στο $+\infty$ ακριβώς όταν $\dfrac{f(x)}{x}\to\alpha$ και $f(x)-\alpha x\to\beta$
    theorem oblique_iff (f : ℝ → ℝ) (α β : ℝ) :
    Tendsto (fun x => f x - (α * x + β)) atTop (𝓝 0) ↔
      Tendsto (fun x => f x / x) atTop (𝓝 α) ∧ Tendsto (fun x => f x - α * x) atTop (𝓝 β)

Το όριο γράφεται με την Tendsto: το Tendsto F atTop (𝓝 L) σημαίνει $F(x)\to L$ όταν $x\to+\infty$. Το 𝓝[≠] x₀ σημαίνει $x\to x_0$ με $x\neq x_0$, και το atTop στη θέση του ορίου σημαίνει $+\infty$. Τα πολυώνυμα είναι στοιχεία του ℝ[X]: η P.eval x είναι η τιμή $P(x)$, το P.degree ο βαθμός και το P.leadingCoeff ο μεγιστοβάθμιος συντελεστής. Το P / Q είναι το πηλίκο και το P % Q το υπόλοιπο της διαίρεσης. Για ρητή συνάρτηση χωρίς κοινό παράγοντα, σε κάθε ρίζα $x_0$ του $Q$ ισχύει $P(x_0)\neq 0$, και το $Q$ δεν έχει άλλες ρίζες κοντά στο $x_0$· έτσι εφαρμόζεται το (i). Η φράση «ασύμπτωτη $y=\alpha x+\beta$» σημαίνει $f(x)-(\alpha x+\beta)\to 0$, και για $\alpha=0$ η ασύμπτωτη είναι οριζόντια. Τα (ii) και (iii) διατυπώνονται για $x\to+\infty$· η περίπτωση $x\to-\infty$ είναι συμμετρική και δεν γράφεται εδώ χωριστά, όπως και η κατεύθυνση «μόνο αν» του (iii).

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Polynomial.div_tendsto_atTop_zero_of_degree_lt: $\dfrac{P(x)}{Q(x)}\to 0$ όταν $\deg P\lt\deg Q$.
  • Polynomial.div_tendsto_atTop_leadingCoeff_div_of_degree_eq: το όριο όταν $\deg P=\deg Q$.
  • Polynomial.degree_mod_lt: το υπόλοιπο έχει μικρότερο βαθμό από τον διαιρέτη.
  • EuclideanDomain.div_add_mod: η ταυτότητα της διαίρεσης $P=Q\,S+R$.
  • Polynomial.finite_setOfPred_isRoot: ένα μη μηδενικό πολυώνυμο έχει πεπερασμένες ρίζες.
  • Filter.Tendsto.pos_mul_atTop: αν $F\to C\gt 0$ και $G\to+\infty$, τότε $F\,G\to+\infty$.
  • tendsto_inv_nhdsGT_zero: $\dfrac{1}{t}\to+\infty$ όταν $t\to 0^+$.
  • Filter.Tendsto.div_atTop: αν $F\to L$ και $G\to+\infty$, τότε $\dfrac{F}{G}\to 0$.

import Mathlib

namespace Κεφ12.Asymptotes
open Filter Topology Polynomial

-- (i) κατακόρυφη ασύμπτωτη: στη ρίζα x₀ του παρονομαστή, με αριθμητή ≠ 0, |p/q| → +∞
theorem vertical_asymptote (p q : ℝ → ℝ) (x₀ : ℝ) (hp : ContinuousAt p x₀)
    (hq : ContinuousAt q x₀) (hq0 : q x₀ = 0) (hp0 : p x₀ ≠ 0)
    (hqne : ∀ᶠ x in 𝓝[≠] x₀, q x ≠ 0) :
    Tendsto (fun x => |p x / q x|) (𝓝[≠] x₀) atTop := by
  have h1 : Tendsto (fun x => |p x|) (𝓝[≠] x₀) (𝓝 |p x₀|) :=
    (hp.tendsto.abs).mono_left nhdsWithin_le_nhds
  have h2 : Tendsto (fun x => |q x|) (𝓝[≠] x₀) (𝓝[>] 0) := by
    apply tendsto_nhdsWithin_iff.mpr
    constructor
    · have h := (hq.tendsto.abs).mono_left (nhdsWithin_le_nhds (s := {x₀}ᶜ))
      rwa [hq0, abs_zero] at h
    · filter_upwards [hqne] with x hx
      exact abs_pos.mpr hx
  have h3 := h1.pos_mul_atTop (abs_pos.mpr hp0) (tendsto_inv_nhdsGT_zero.comp h2)
  refine h3.congr (fun x => ?_)
  simp [div_eq_mul_inv]

-- (ii) οριζόντια ασύμπτωτη y = 0 όταν deg P < deg Q
theorem horizontal_zero (P Q : ℝ[X]) (hdeg : P.degree < Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 0) :=
  Polynomial.div_tendsto_atTop_zero_of_degree_lt hdeg

-- (ii) όταν deg P = deg Q, η ασύμπτωτη είναι ο λόγος των μεγιστοβάθμιων συντελεστών
theorem horizontal_ratio (P Q : ℝ[X]) (hdeg : P.degree = Q.degree) :
    Tendsto (fun x => P.eval x / Q.eval x) atTop (𝓝 (P.leadingCoeff / Q.leadingCoeff)) :=
  Polynomial.div_tendsto_atTop_leadingCoeff_div_of_degree_eq hdeg

-- (iii) το πηλίκο S της διαίρεσης P / Q: η διαφορά P/Q - S τείνει στο 0
theorem minus_quotient (P Q : ℝ[X]) (hQ : Q ≠ 0) :
    Tendsto (fun x => P.eval x / Q.eval x - (P / Q).eval x) atTop (𝓝 0) := by
  have hR : Tendsto (fun x => (P % Q).eval x / Q.eval x) atTop (𝓝 0) :=
    Polynomial.div_tendsto_atTop_zero_of_degree_lt (Polynomial.degree_mod_lt P hQ)
  refine hR.congr' ?_
  have hfin : {x | Q.IsRoot x}.Finite := Polynomial.finite_setOfPred_isRoot hQ
  filter_upwards [Filter.atTop_le_cofinite hfin.compl_mem_cofinite] with x hx
  have hx' : Q.eval x ≠ 0 := hx
  have he : P.eval x = Q.eval x * (P / Q).eval x + (P % Q).eval x := by
    rw [← Polynomial.eval_mul, ← Polynomial.eval_add, EuclideanDomain.div_add_mod]
  rw [he, add_div, mul_div_cancel_left₀ _ hx']
  ring

-- γενικό κριτήριο: y = αx + β είναι ασύμπτωτη στο +∞ ακριβώς όταν f(x)/x → α και f(x) - αx → β
theorem oblique_iff (f : ℝ → ℝ) (α β : ℝ) :
    Tendsto (fun x => f x - (α * x + β)) atTop (𝓝 0) ↔
      Tendsto (fun x => f x / x) atTop (𝓝 α) ∧ Tendsto (fun x => f x - α * x) atTop (𝓝 β) := by
  constructor
  · intro h
    have h2 : Tendsto (fun x => f x - α * x) atTop (𝓝 β) := by
      have h' := h.add_const β
      rw [zero_add] at h'
      refine h'.congr (fun x => ?_)
      ring
    refine ⟨?_, h2⟩
    have h3 : Tendsto (fun x => (f x - α * x) / x) atTop (𝓝 0) := h2.div_atTop tendsto_id
    have h4 := h3.add_const α
    rw [zero_add] at h4
    refine h4.congr' ?_
    filter_upwards [eventually_ne_atTop 0] with x hx
    rw [sub_div, mul_div_assoc, div_self hx, mul_one, sub_add_cancel]
  · rintro ⟨_, h2⟩
    have h' := h2.sub_const β
    rw [sub_self] at h'
    refine h'.congr (fun x => ?_)
    ring

end Κεφ12.Asymptotes
