Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν η $f$ είναι συνεχής στο $[a,b]$, με $a\lt b$, υπάρχει $\xi\in[a,b]$ με $f(\xi)$${}=\dfrac{1}{b-a}\int_a^b f(x)\,dx$
    theorem integral_mean_value (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ x in a..b, f x
  • Εφαρμογή: αν επιπλέον $\int_a^b f(x)\,dx=0$, η $f$ έχει ρίζα στο $[a,b]$
    theorem root_of_zero_integral (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) (h0 : ∫ x in a..b, f x = 0) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 0

Το «υπάρχει $\xi\in[a,b]$» γράφεται ∃ ξ ∈ Set.Icc a b, και το ολοκλήρωμα $\int_a^b f(x)\,dx$ γράφεται ∫ x in a..b, f x. Υποθέτουμε $a\lt b$, ώστε να ορίζεται το κλάσμα $\dfrac{1}{b-a}$. Η απόδειξη ακολουθεί το βιβλίο: από το θεώρημα Weierstrass η $f$ έχει ελάχιστη τιμή $m$ και μέγιστη τιμή $M$, ολοκληρώνοντας την $m\le f(x)\le M$ βρίσκουμε ότι η μέση τιμή $\bar{f}$ είναι ανάμεσα στα $m$ και $M$, και το θεώρημα ενδιάμεσων τιμών δίνει το $\xi$. Η Mathlib έχει έτοιμη μια ισχυρότερη μορφή (exists_eq_interval_average), με το $\xi$ στο ανοιχτό διάστημα $(a,b)$.

2. Βήμα προς βήμα: $f(\xi)=\bar{f}$

Η ιδέα: η μέση τιμή $\bar{f}$ βρίσκεται ανάμεσα στην ελάχιστη και στη μέγιστη τιμή της $f$, οπότε από το θεώρημα ενδιάμεσων τιμών είναι τιμή της $f$. Ξεκινάμε από τον στόχο:

Ο στόχος
f : ℝ → ℝ
a b : ℝ
hab : a < b
hf : ContinuousOn f (Set.Icc a b)
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- Weierstrass: ελάχιστη τιμή m = f(x₁) και μέγιστη τιμή M = f(x₂) στο [a,b]
obtain ⟨x₁, hx₁, hmin⟩ := isCompact_Icc.exists_isMinOn (Set.nonempty_Icc.mpr hab.le) hf

    Θεώρημα Weierstrass (IsCompact.exists_isMinOn): η $f$ παίρνει ελάχιστη τιμή $m=f(x_1)$ σε κάποιο $x_1\in[a,b]$. Η hmin λέει ότι $f(x_1)\le f(x)$ για κάθε $x\in[a,b]$.

    Τι μένει να αποδειχθεί
    x₁ : ℝ
hx₁ : x₁ ∈ Set.Icc a b
hmin : IsMinOn f (Set.Icc a b) x₁
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x
  2. obtain ⟨x₂, hx₂, hmax⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab.le) hf

    Ομοίως, η $f$ παίρνει μέγιστη τιμή $M=f(x_2)$ σε κάποιο $x_2\in[a,b]$.

    Τι μένει να αποδειχθεί
    x₂ : ℝ
hx₂ : x₂ ∈ Set.Icc a b
hmax : IsMaxOn f (Set.Icc a b) x₂
⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x
  3. have hint : IntervalIntegrable f volume a b := hf.intervalIntegrable_of_Icc hab.le

    Η $f$ είναι συνεχής στο $[a,b]$, άρα ολοκληρώσιμη.

    Τι μένει να αποδειχθεί

⊢ ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ (x : ℝ) in a..b, f x
  4. -- m (b - a) ≤ ∫ f: ολοκληρώνουμε την m ≤ f(x)
have h1 : f x₁ * (b - a) ≤ ∫ x in a..b, f x := by

    Ισχυρισμός h1: $m\,(b-a)\le\int_a^b f(x)\,dx$.

    Τι μένει να αποδειχθεί
    ⊢ f x₁ * (b - a) ≤ ∫ (x : ℝ) in a..b, f x
  5. have h := intervalIntegral.integral_mono_on hab.le (intervalIntegrable_const (c := f x₁)) hint
  (fun x hx => isMinOn_iff.mp hmin x hx)

    Μονοτονία του ολοκληρώματος (intervalIntegral.integral_mono_on): ολοκληρώνουμε την $m\le f(x)$ στο $[a,b]$.

    Τι μένει να αποδειχθεί
    h : ∫ (u : ℝ) in a..b, f x₁ ≤ ∫ (u : ℝ) in a..b, f u
⊢ f x₁ * (b - a) ≤ ∫ (x : ℝ) in a..b, f x
  6. rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h

    Το ολοκλήρωμα της σταθεράς $m$ είναι $(b-a)\,m$.

    Τι μένει να αποδειχθεί
    h : f x₁ * (b - a) ≤ ∫ (u : ℝ) in a..b, f u
⊢ f x₁ * (b - a) ≤ ∫ (x : ℝ) in a..b, f x
  7. exact h

    Αυτό είναι ακριβώς ο ισχυρισμός h1.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  8. -- ∫ f ≤ M (b - a): ολοκληρώνουμε την f(x) ≤ M
have h2 : ∫ x in a..b, f x ≤ f x₂ * (b - a) := by
  have h := intervalIntegral.integral_mono_on hab.le hint (intervalIntegrable_const (c := f x₂))
    (fun x hx => isMaxOn_iff.mp hmax x hx)
  rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h
  exact h

    Με τον ίδιο τρόπο, ολοκληρώνοντας την $f(x)\le M$, παίρνουμε τον ισχυρισμό h2: $\int_a^b f(x)\,dx\le M\,(b-a)$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.

have hba : 0 < b - a := sub_pos.mpr hab

    Ισχύει $b-a\gt 0$, γιατί $a\lt b$.

    Ομοίως, ο ισχυρισμός h4: $\bar{f}\le M$, από την h2.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.

3. Δοκίμασε εσύ: ρίζα από μηδενικό ολοκλήρωμα

Αν η $f$ είναι συνεχής στο $[a,b]$, $a\lt b$, και $\int_a^b f(x)\,dx=0$, δείξε ότι η $f$ έχει ρίζα στο $[a,b]$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Πάρε το $\xi$ του θεωρήματος: obtain ⟨ξ, hξ, hfξ⟩ := integral_mean_value f a b hab hf. Στην hfξ αντικατάστησε το ολοκλήρωμα με $0$: rw [h0, mul_zero] at hfξ. Τέλος exact ⟨ξ, hξ, hfξ⟩.

Λύση
theorem root_of_zero_integral (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) (h0 : ∫ x in a..b, f x = 0) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 0 := by
  obtain ⟨ξ, hξ, hfξ⟩ := integral_mean_value f a b hab hf
  rw [h0, mul_zero] at hfξ
  exact ⟨ξ, hξ, hfξ⟩

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • IsCompact.exists_isMinOn: το θεώρημα Weierstrass για την ελάχιστη τιμή.
  • IsCompact.exists_isMaxOn: το θεώρημα Weierstrass για τη μέγιστη τιμή.
  • ContinuousOn.intervalIntegrable_of_Icc: συνεχής συνάρτηση στο $[a,b]$ είναι ολοκληρώσιμη.
  • intervalIntegral.integral_mono_on: η μονοτονία του ολοκληρώματος.
  • intervalIntegral.integral_const: $\int_a^b c\,dx=(b-a)\,c$.
  • le_div_iff₀: για $c\gt 0$: $a\le\dfrac{b}{c}$ ακριβώς όταν $a\,c\le b$.
  • div_le_iff₀: για $c\gt 0$: $\dfrac{a}{c}\le b$ ακριβώς όταν $a\le b\,c$.
  • intermediate_value_uIcc: το θεώρημα ενδιάμεσων τιμών.

import Mathlib

namespace Κεφ14.MesiTimi
open MeasureTheory

theorem integral_mean_value (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 1 / (b - a) * ∫ x in a..b, f x := by
  -- Weierstrass: ελάχιστη τιμή m = f(x₁) και μέγιστη τιμή M = f(x₂) στο [a,b]
  obtain ⟨x₁, hx₁, hmin⟩ := isCompact_Icc.exists_isMinOn (Set.nonempty_Icc.mpr hab.le) hf
  obtain ⟨x₂, hx₂, hmax⟩ := isCompact_Icc.exists_isMaxOn (Set.nonempty_Icc.mpr hab.le) hf
  have hint : IntervalIntegrable f volume a b := hf.intervalIntegrable_of_Icc hab.le
  -- m (b - a) ≤ ∫ f: ολοκληρώνουμε την m ≤ f(x)
  have h1 : f x₁ * (b - a) ≤ ∫ x in a..b, f x := by
    have h := intervalIntegral.integral_mono_on hab.le (intervalIntegrable_const (c := f x₁)) hint
      (fun x hx => isMinOn_iff.mp hmin x hx)
    rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h
    exact h
  -- ∫ f ≤ M (b - a): ολοκληρώνουμε την f(x) ≤ M
  have h2 : ∫ x in a..b, f x ≤ f x₂ * (b - a) := by
    have h := intervalIntegral.integral_mono_on hab.le hint (intervalIntegrable_const (c := f x₂))
      (fun x hx => isMaxOn_iff.mp hmax x hx)
    rw [intervalIntegral.integral_const, smul_eq_mul, mul_comm] at h
    exact h
  -- διαιρούμε με b - a > 0: m ≤ μέση τιμή ≤ M
  have hba : 0 < b - a := sub_pos.mpr hab
  have h3 : f x₁ ≤ 1 / (b - a) * ∫ x in a..b, f x := by
    rw [one_div_mul_eq_div, le_div_iff₀ hba]
    exact h1
  have h4 : 1 / (b - a) * ∫ x in a..b, f x ≤ f x₂ := by
    rw [one_div_mul_eq_div, div_le_iff₀ hba]
    exact h2
  -- θεώρημα ενδιάμεσων τιμών στο διάστημα με άκρα x₁ και x₂
  have hsub : Set.uIcc x₁ x₂ ⊆ Set.Icc a b := Set.uIcc_subset_Icc hx₁ hx₂
  obtain ⟨ξ, hξ, hfξ⟩ := intermediate_value_uIcc (hf.mono hsub) (Set.mem_uIcc_of_le h3 h4)
  exact ⟨ξ, hsub hξ, hfξ⟩

theorem root_of_zero_integral (f : ℝ → ℝ) (a b : ℝ) (hab : a < b)
    (hf : ContinuousOn f (Set.Icc a b)) (h0 : ∫ x in a..b, f x = 0) :
    ∃ ξ ∈ Set.Icc a b, f ξ = 0 := by
  obtain ⟨ξ, hξ, hfξ⟩ := integral_mean_value f a b hab hf
  rw [h0, mul_zero] at hfξ
  exact ⟨ξ, hξ, hfξ⟩
