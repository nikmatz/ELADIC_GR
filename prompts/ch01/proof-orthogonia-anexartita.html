1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Μη μηδενικά, ανά δύο ορθογώνια διανύσματα είναι γραμμικώς ανεξάρτητα
    theorem independent {k : ℕ} (v : Fin k → V) (hz : ∀ i, v i ≠ 0)
    (ho : ∀ i j, i ≠ j → ⟪v i, v j⟫_ℝ = 0) : LinearIndependent ℝ v
  • Ειδικά, τα ορθοκανονικά διανύσματα είναι γραμμικώς ανεξάρτητα
    theorem orthonormal_independent {k : ℕ} (v : Fin k → V) (hv : Orthonormal ℝ v) :
    LinearIndependent ℝ v

Τα διανύσματα είναι μια οικογένεια v : Fin k → V σε χώρο V με εσωτερικό γινόμενο. Η υπόθεση hz λέει ότι κανένα δεν είναι μηδενικό και η ho ότι $\langle v_i,v_j\rangle=0$ για $i\neq j$. Το Orthonormal ℝ v σημαίνει ότι έχουν μήκος $1$ και είναι ανά δύο ορθογώνια.

2. Βήμα προς βήμα: μη μηδενικά ορθογώνια διανύσματα είναι ανεξάρτητα

Η απόδειξη του βιβλίου: αν $\sum_i c_iv_i=0$, παίρνουμε εσωτερικό γινόμενο με το $v_j$ και όλοι οι όροι εκτός από έναν μηδενίζονται. Ξεκινάμε από τον στόχο:

Ο στόχος
V : Type u_1
inst✝¹ : NormedAddCommGroup V
inst✝ : InnerProductSpace ℝ V
k : ℕ
v : Fin k → V
hz : ∀ (i : Fin k), v i ≠ 0
ho : ∀ (i j : Fin k), i ≠ j → ⟪v i, v j⟫_ℝ = 0
⊢ LinearIndependent ℝ v

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [Fintype.linearIndependent_iff]

    Ο ορισμός της ανεξαρτησίας: αν $\sum_i c_iv_i=0$, τότε όλα τα $c_i$ είναι μηδέν.

    Τι μένει να αποδειχθεί
    ⊢ ∀ (g : Fin k → ℝ), ∑ i, g i • v i = 0 → ∀ (i : Fin k), g i = 0
  2. intro c hc j

    Παίρνουμε αριθμούς $c_i$ με $\sum_i c_iv_i=0$ (υπόθεση hc) και θα δείξουμε ότι $c_j=0$ για τυχαίο $j$.

    Τι μένει να αποδειχθεί
    c : Fin k → ℝ
hc : ∑ i, c i • v i = 0
j : Fin k
⊢ c j = 0
  3. have h1 : ⟪v j, ∑ i, c i • v i⟫_ℝ = 0 := by rw [hc, inner_zero_right]

    Παίρνουμε εσωτερικό γινόμενο με το $v_j$: $\langle v_j,\sum_i c_iv_i\rangle$${}=\langle v_j,\mathbf{0}\rangle$${}=0$.

    Τι μένει να αποδειχθεί
    h1 : ⟪v j, ∑ i, c i • v i⟫_ℝ = 0
⊢ c j = 0
  4. rw [inner_sum] at h1

    Το εσωτερικό γινόμενο μοιράζεται στο άθροισμα: $\sum_i\langle v_j,c_iv_i\rangle=0$.

    Τι μένει να αποδειχθεί
    h1 : ∑ i, ⟪v j, c i • v i⟫_ℝ = 0
⊢ c j = 0
  5. simp only [real_inner_smul_right] at h1

    Βγάζουμε τους αριθμούς έξω: $\sum_i c_i\langle v_j,v_i\rangle=0$.

    Τι μένει να αποδειχθεί
    h1 : ∑ x, c x * ⟪v j, v x⟫_ℝ = 0
⊢ c j = 0
  6. rw [Finset.sum_eq_single j] at h1

    Μένει μόνο ο όρος $i=j$: $c_j\langle v_j,v_j\rangle=0$. Το θεώρημα Finset.sum_eq_single αφήνει δύο υποχρεώσεις: ότι οι άλλοι όροι είναι μηδέν (h₀) και μια τεχνική συνθήκη (h₁).

    Τι μένει να αποδειχθεί (3 στόχοι)
    h1 : c j * ⟪v j, v j⟫_ℝ = 0
⊢ c j = 0
    σκέλος h₀
    ⊢ ∀ b ∈ Finset.univ, b ≠ j → c b * ⟪v j, v b⟫_ℝ = 0
    σκέλος h₁
    ⊢ j ∉ Finset.univ → c j * ⟪v j, v j⟫_ℝ = 0
  7. · have h2 : ⟪v j, v j⟫_ℝ ≠ 0 := inner_self_ne_zero.mpr (hz j)
  exact (mul_eq_zero.mp h1).resolve_right h2

    Επειδή $v_j\neq\mathbf{0}$, ισχύει $\langle v_j,v_j\rangle\neq 0$ (υπόθεση h2). Από $c_j\langle v_j,v_j\rangle=0$ μένει $c_j=0$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  8. · intro i _ hij
  rw [ho j i (Ne.symm hij), mul_zero]

    Οι άλλοι όροι: για $i\neq j$ ισχύει $\langle v_j,v_i\rangle=0$, άρα $c_i\cdot 0=0$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  9. · intro hj
  exact absurd (Finset.mem_univ j) hj

    Η τεχνική συνθήκη: το $j$ ανήκει στο σύνολο όλων των δεικτών, άρα η υπόθεση ότι δεν ανήκει είναι άτοπη.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: ορθοκανονικά διανύσματα είναι ανεξάρτητα

Συνέπεια του θεωρήματος: τα ορθοκανονικά διανύσματα έχουν μήκος $1$, άρα δεν είναι μηδενικά. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ξεκίνα με apply independent v. Μένουν δύο στόχοι. Για τον πρώτο: αν v i = 0, το hv.1 i, που λέει $\|v_i\|=1$, γίνεται $0=1$. Για τον δεύτερο: intro i j hij και exact hv.2 hij.

Λύση
theorem orthonormal_independent {k : ℕ} (v : Fin k → V) (hv : Orthonormal ℝ v) :
    LinearIndependent ℝ v := by
  apply independent v
  · intro i h
    have h1 := hv.1 i
    rw [h, norm_zero] at h1
    norm_num at h1
  · intro i j hij
    exact hv.2 hij

import Mathlib

namespace Κεφ1.OrthogoniaAnexartita
open scoped InnerProductSpace

variable {V : Type*} [NormedAddCommGroup V] [InnerProductSpace ℝ V]

theorem independent {k : ℕ} (v : Fin k → V) (hz : ∀ i, v i ≠ 0)
    (ho : ∀ i j, i ≠ j → ⟪v i, v j⟫_ℝ = 0) : LinearIndependent ℝ v := by
  rw [Fintype.linearIndependent_iff]
  intro c hc j
  have h1 : ⟪v j, ∑ i, c i • v i⟫_ℝ = 0 := by rw [hc, inner_zero_right]
  rw [inner_sum] at h1
  simp only [real_inner_smul_right] at h1
  rw [Finset.sum_eq_single j] at h1
  · have h2 : ⟪v j, v j⟫_ℝ ≠ 0 := inner_self_ne_zero.mpr (hz j)
    exact (mul_eq_zero.mp h1).resolve_right h2
  · intro i _ hij
    rw [ho j i (Ne.symm hij), mul_zero]
  · intro hj
    exact absurd (Finset.mem_univ j) hj

theorem orthonormal_independent {k : ℕ} (v : Fin k → V) (hv : Orthonormal ℝ v) :
    LinearIndependent ℝ v := by
  apply independent v
  · intro i h
    have h1 := hv.1 i
    rw [h, norm_zero] at h1
    norm_num at h1
  · intro i j hij
    exact hv.2 hij

end Κεφ1.OrthogoniaAnexartita
