Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Κάθε διάνυσμα γράφεται $v=\sum_i\langle v,e_i\rangle e_i$
    theorem expansion {n : ℕ} (b : OrthonormalBasis (Fin n) ℝ V) (v : V) :
    v = ∑ i, ⟪v, b i⟫_ℝ • b i
  • Οι συντεταγμένες είναι τα εσωτερικά γινόμενα: αν $v=\sum_i c_ie_i$, τότε $\langle v,e_j\rangle=c_j$
    theorem coordinate {n : ℕ} (b : OrthonormalBasis (Fin n) ℝ V) (c : Fin n → ℝ) (j : Fin n) :
    ⟪∑ i, c i • b i, b j⟫_ℝ = c j

Η ορθοκανονική βάση $\{e_1,\dots,e_n\}$ είναι το b : OrthonormalBasis (Fin n) ℝ V και το $e_i$ γράφεται b i. Τα b.orthonormal.1 j, που λέει $\|e_j\|=1$, και b.orthonormal.2, που λέει $\langle e_i,e_j\rangle=0$ για $i\neq j$, είναι οι δύο ιδιότητες της ορθοκανονικότητας.

2. Βήμα προς βήμα: η συντεταγμένη $c_j$ είναι το $\langle v,e_j\rangle$

Αν $v=\sum_i c_ie_i$, παίρνουμε εσωτερικό γινόμενο με το $e_j$ και βρίσκουμε $\langle v,e_j\rangle=c_j$. Αυτό δείχνει ότι οι συντεταγμένες είναι τα εσωτερικά γινόμενα. Ξεκινάμε από τον στόχο:

Ο στόχος
V : Type u_1
inst✝¹ : NormedAddCommGroup V
inst✝ : InnerProductSpace ℝ V
n : ℕ
b : OrthonormalBasis (Fin n) ℝ V
c : Fin n → ℝ
j : Fin n
⊢ ⟪∑ i, c i • b i, b j⟫_ℝ = c j

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [sum_inner]

    Το εσωτερικό γινόμενο μοιράζεται στο άθροισμα: $\sum_i\langle c_ie_i,e_j\rangle$.

    Τι μένει να αποδειχθεί
    ⊢ ∑ i, ⟪c i • b i, b j⟫_ℝ = c j
  2. simp only [real_inner_smul_left]

    Βγάζουμε τους αριθμούς $c_i$ έξω: $\sum_i c_i\langle e_i,e_j\rangle$. Ο Lean ονομάζει εδώ τον δείκτη x.

    Τι μένει να αποδειχθεί
    ⊢ ∑ x, c x * ⟪b x, b j⟫_ℝ = c j
  3. rw [Finset.sum_eq_single j]

    Μένει μόνο ο όρος $i=j$, γιατί $\langle e_i,e_j\rangle=0$ για $i\neq j$. Μένουν τρεις στόχοι: ο κύριος $c_j\langle e_j,e_j\rangle=c_j$, η υποχρέωση h₀ για τους άλλους όρους και η τεχνική συνθήκη h₁.

    Τι μένει να αποδειχθεί (3 στόχοι)
    ⊢ c j * ⟪b j, b j⟫_ℝ = c j
    σκέλος h₀
    ⊢ ∀ b_1 ∈ Finset.univ, b_1 ≠ j → c b_1 * ⟪b b_1, b j⟫_ℝ = 0
    σκέλος h₁
    ⊢ j ∉ Finset.univ → c j * ⟪b j, b j⟫_ℝ = 0
  4. · rw [real_inner_self_eq_norm_sq, b.orthonormal.1 j]

    Ισχύει $\langle e_j,e_j\rangle=\|e_j\|^2$ και $\|e_j\|=1$, γιατί η βάση είναι ορθοκανονική.

    Τι μένει να αποδειχθεί
    ⊢ c j * 1 ^ 2 = c j
  5. ring

    Είναι $c_j\cdot 1^2=c_j$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  6. · intro i _ hij
  rw [b.orthonormal.2 hij, mul_zero]

    Για $i\neq j$ ισχύει $\langle e_i,e_j\rangle=0$, άρα ο όρος είναι $0$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  7. · intro hj
  exact absurd (Finset.mem_univ j) hj

    Η τεχνική συνθήκη: το $j$ είναι ένας από τους δείκτες, άρα η υπόθεση ότι δεν είναι είναι άτοπη.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: ο τύπος $v=\sum_i\langle v,e_i\rangle e_i$

Δείξε ότι κάθε διάνυσμα γράφεται με συντεταγμένες τα εσωτερικά γινόμενα. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Η Mathlib έχει τον τύπο με τη σειρά $\langle e_i,v\rangle$, στο b.sum_repr' v. Γράψε conv_lhs => rw [← b.sum_repr' v], μετά refine Finset.sum_congr rfl (fun i _ => ?_) και τέλος rw [real_inner_comm] για τη συμμετρία του εσωτερικού γινομένου.

Λύση
theorem expansion {n : ℕ} (b : OrthonormalBasis (Fin n) ℝ V) (v : V) :
    v = ∑ i, ⟪v, b i⟫_ℝ • b i := by
  conv_lhs => rw [← b.sum_repr' v]
  refine Finset.sum_congr rfl (fun i _ => ?_)
  rw [real_inner_comm]

theorem coordinate {n : ℕ} (b : OrthonormalBasis (Fin n) ℝ V) (c : Fin n → ℝ) (j : Fin n) :
    ⟪∑ i, c i • b i, b j⟫_ℝ = c j := by
  rw [sum_inner]
  simp only [real_inner_smul_left]
  rw [Finset.sum_eq_single j]
  · rw [real_inner_self_eq_norm_sq, b.orthonormal.1 j]
    ring
  · intro i _ hij
    rw [b.orthonormal.2 hij, mul_zero]
  · intro hj
    exact absurd (Finset.mem_univ j) hj

theorem expansion {n : ℕ} (b : OrthonormalBasis (Fin n) ℝ V) (v : V) :
    v = ∑ i, ⟪v, b i⟫_ℝ • b i := by
  conv_lhs => rw [← b.sum_repr' v]
  refine Finset.sum_congr rfl (fun i _ => ?_)
  rw [real_inner_comm]
