1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Μη κενό $W\subseteq V$ είναι υπόχωρος $\Leftrightarrow$ για κάθε $u,v\in W$ και $\lambda,\mu\in\mathbb{R}$ ισχύει $\lambda u+\mu v\in W$
    theorem criterion (W : Set V) :
    (∃ S : Submodule ℝ V, (S : Set V) = W) ↔
      W.Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W
  • Αν το $W$ είναι μη κενό και κλειστό, τότε $\mathbf{0}\in W$

    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) : (0 : V) ∈ W
  • Αν το $W$ είναι κλειστό, τότε $u+v\in W$ για $u,v\in W$
    theorem add_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) {u v : V} (hu : u ∈ W) (hv : v ∈ W) :
    u + v ∈ W
  • Αν το $W$ είναι κλειστό, τότε $cu\in W$ για $u\in W$
    theorem smul_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) (c : ℝ) {u : V} (hu : u ∈ W) :
    c • u ∈ W
  • Κάθε υπόχωρος είναι μη κενός και κλειστός
    theorem closed (W : Submodule ℝ V) :
    (W : Set V).Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W

Ένας υπόχωρος στη Mathlib είναι ένα Submodule ℝ V: ένα σύνολο μαζί με τις αποδείξεις ότι περιέχει το $\mathbf{0}$ και είναι κλειστό ως προς την πρόσθεση και τον βαθμωτό πολλαπλασιασμό. Το ∃ S : Submodule ℝ V, (S : Set V) = W λέει ότι το $W$ είναι υπόχωρος. Ο ορισμός ofClosed στον κώδικα φτιάχνει τον υπόχωρο από τα τρία λήμματα. Το W.Nonempty σημαίνει ότι το $W$ είναι μη κενό. Στον Lean η συνθήκη αυτή μπαίνει στο δεξί μέλος της ισοδυναμίας, γιατί ένας υπόχωρος είναι πάντα μη κενός.

2. Βήμα προς βήμα: ένα μη κενό κλειστό σύνολο περιέχει το $\mathbf{0}$

Για να είναι το $W$ υπόχωρος χρειάζονται τρία πράγματα: $\mathbf{0}\in W$, κλειστότητα ως προς την πρόσθεση και κλειστότητα ως προς τον βαθμωτό πολλαπλασιασμό. Το πρώτο είναι το πιο ενδιαφέρον, γιατί μόνο εκεί χρειάζεται ότι το $W$ είναι μη κενό. Ξεκινάμε από τον στόχο:

Ο στόχος
V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
W : Set V
hne : W.Nonempty
h : ∀ u ∈ W, ∀ v ∈ W, ∀ (a b : ℝ), a • u + b • v ∈ W
⊢ 0 ∈ W

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. obtain ⟨w, hw⟩ := hne

    Το $W$ είναι μη κενό, άρα παίρνουμε ένα στοιχείο του, $w\in W$.

    Τι μένει να αποδειχθεί
    w : V
hw : w ∈ W
⊢ 0 ∈ W
  2. have h0 := h w hw w hw 0 0

    Εφαρμόζουμε την υπόθεση με $u=v=w$ και $\lambda=\mu=0$: $0w+0w\in W$.

    Τι μένει να αποδειχθεί
    h0 : 0 • w + 0 • w ∈ W
⊢ 0 ∈ W
  3. rw [zero_smul, zero_add] at h0

    Κάνουμε τις πράξεις: $0w=\mathbf{0}$ και $\mathbf{0}+\mathbf{0}=\mathbf{0}$.

    Τι μένει να αποδειχθεί
    h0 : 0 ∈ W
⊢ 0 ∈ W
  4. exact h0

    Αυτό ακριβώς ζητούσαμε.

3. Δοκίμασε εσύ: κλειστότητα ως προς την πρόσθεση

Δείξε ότι $u+v\in W$ για $u,v\in W$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

import Mathlib

namespace Κεφ1.KritirioYpoxorou

variable {V : Type*} [AddCommGroup V] [Module ℝ V]

theorem zero_mem_of_closed (W : Set V) (hne : W.Nonempty)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) : (0 : V) ∈ W := by
  obtain ⟨w, hw⟩ := hne
  have h0 := h w hw w hw 0 0
  rw [zero_smul, zero_add] at h0
  exact h0

theorem add_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) {u v : V} (hu : u ∈ W) (hv : v ∈ W) :
    u + v ∈ W := by
  have h1 := h u hu v hv 1 1
  rw [one_smul, one_smul] at h1
  exact h1

theorem smul_mem_of_closed (W : Set V)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) (c : ℝ) {u : V} (hu : u ∈ W) :
    c • u ∈ W := by
  have h2 := h u hu u hu c 0
  rw [zero_smul, add_zero] at h2
  exact h2

/-- Ο υπόχωρος με στοιχεία ακριβώς τα στοιχεία του W. -/
def ofClosed (W : Set V) (hne : W.Nonempty)
    (h : ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W) : Submodule ℝ V where
  carrier := W
  zero_mem' := zero_mem_of_closed W hne h
  add_mem' := add_mem_of_closed W h
  smul_mem' := smul_mem_of_closed W h

theorem closed (W : Submodule ℝ V) :
    (W : Set V).Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W := by
  refine ⟨⟨0, W.zero_mem⟩, ?_⟩
  intro u hu v hv a b
  exact W.add_mem (W.smul_mem a hu) (W.smul_mem b hv)

theorem criterion (W : Set V) :
    (∃ S : Submodule ℝ V, (S : Set V) = W) ↔
      W.Nonempty ∧ ∀ u ∈ W, ∀ v ∈ W, ∀ a b : ℝ, a • u + b • v ∈ W := by
  constructor
  · rintro ⟨S, rfl⟩
    exact closed S
  · rintro ⟨hne, h⟩
    exact ⟨ofClosed W hne h, rfl⟩
