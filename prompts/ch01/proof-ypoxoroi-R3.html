1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Κάθε υπόχωρος του $\mathbb{R}^3$ είναι το $\{\mathbf{0}\}$, ευθεία από την αρχή, επίπεδο από την αρχή ή ολόκληρος ο $\mathbb{R}^3$
    theorem classification (W : Submodule ℝ (Fin 3 → ℝ)) :
    W = ⊥ ∨ (∃ v ≠ 0, W = span ℝ {v}) ∨
      (∃ u v : Fin 3 → ℝ, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v])) ∨
        W = ⊤
  • $\dim W$${}=0\Leftrightarrow W$${}=\{\mathbf{0}\}$
    theorem dim_zero_iff (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W = 0 ↔ W = ⊥
  • $\dim W=1\Leftrightarrow W$ είναι ευθεία από την αρχή
    theorem dim_one_iff (W : Submodule ℝ (Fin 3 → ℝ)) :
    finrank ℝ W = 1 ↔ ∃ v ≠ 0, W = span ℝ {v}
  • $\dim W=2\Leftrightarrow W$ είναι επίπεδο από την αρχή
    theorem dim_two_iff (W : Submodule ℝ (Fin 3 → ℝ)) :
    finrank ℝ W = 2 ↔
      ∃ u v : Fin 3 → ℝ, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v])
  • $\dim W$${}=3\Leftrightarrow W$${}=\mathbb{R}^3$
    theorem dim_three_iff (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W = 3 ↔ W = ⊤

Ο $\mathbb{R}^3$ είναι το Fin 3 → ℝ και ένας υπόχωρος είναι ένα Submodule ℝ (Fin 3 → ℝ). Η διάσταση γράφεται finrank ℝ W. Το $\{\mathbf{0}\}$ είναι το ⊥ και ολόκληρος ο χώρος το ⊤. Η ευθεία $\{tv:t\in\mathbb{R}\}$ είναι το span ℝ {v}, που ο Lean εμφανίζει ως ℝ ∙ v, και το επίπεδο που παράγουν δύο ανεξάρτητα $u,v$ είναι το span ℝ (Set.range ![u, v]). Αντίστροφα, καθένα από αυτά είναι υπόχωρος, γιατί στον Lean είναι εξ ορισμού Submodule.

2. Βήμα προς βήμα: κάθε υπόχωρος του $\mathbb{R}^3$ είναι ένας από τους τέσσερις τύπους

Η ιδέα: η διάσταση ενός υποχώρου του $\mathbb{R}^3$ είναι $0$, $1$, $2$ ή $3$, και κάθε διάσταση δίνει έναν τύπο. Τα λήμματα για κάθε διάσταση είναι πιο πάνω στον κώδικα. Ξεκινάμε από τον στόχο:

Ο στόχος
W : Submodule ℝ (Fin 3 → ℝ)
⊢ W = ⊥ ∨ (∃ v, v ≠ 0 ∧ W = ℝ ∙ v) ∨ (∃ u v, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v])) ∨ W = ⊤

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

    finrank ℝ W = 0 ∨ finrank ℝ W = 1 ∨ finrank ℝ W = 2 ∨ finrank ℝ W = 3 := by
  have h := dim_le_three W

3. Δοκίμασε εσύ: υπόχωρος διάστασης $3$ είναι ολόκληρος ο $\mathbb{R}^3$

Δείξε ότι $\dim W$${}=3\Leftrightarrow W$${}=\mathbb{R}^3$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Χώρισε με constructor. Για το $\Rightarrow$: intro h, apply eq_top_of_finrank_eq και rw [h, Module.finrank_fin_fun]. Για το $\Leftarrow$: rintro rfl και rw [finrank_top, Module.finrank_fin_fun].

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Submodule.finrank_eq_zero: διάσταση $0$ ακριβώς για τον $\{\mathbf{0}\}$.
  • Submodule.eq_top_of_finrank_eq: υπόχωρος με τη διάσταση του χώρου είναι ολόκληρος ο χώρος.
  • finrank_eq_one_iff': χώρος διάστασης $1$ παράγεται από ένα μη μηδενικό διάνυσμα.
  • Module.finBasisOfFinrankEq: βάση με τόσα διανύσματα όσα η διάσταση.
  • finrank_span_eq_card: η διάσταση του χώρου που παράγουν ανεξάρτητα διανύσματα είναι το πλήθος τους.

import Mathlib

namespace Κεφ1.YpoxoroiR3
open Module Submodule

theorem dim_le_three (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W ≤ 3 := by
  have h := W.finrank_le
  rw [Module.finrank_fin_fun] at h
  exact h

theorem dim_zero_iff (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W = 0 ↔ W = ⊥ :=
  Submodule.finrank_eq_zero

theorem dim_three_iff (W : Submodule ℝ (Fin 3 → ℝ)) : finrank ℝ W = 3 ↔ W = ⊤ := by
  constructor
  · intro h
    apply eq_top_of_finrank_eq
    rw [h, Module.finrank_fin_fun]
  · rintro rfl
    rw [finrank_top, Module.finrank_fin_fun]

theorem dim_one_iff (W : Submodule ℝ (Fin 3 → ℝ)) :
    finrank ℝ W = 1 ↔ ∃ v ≠ 0, W = span ℝ {v} := by
  constructor
  · intro h
    obtain ⟨v, hv, hall⟩ := finrank_eq_one_iff'.mp h
    refine ⟨v, fun h0 => hv (Subtype.ext h0), ?_⟩
    apply le_antisymm
    · intro x hx
      obtain ⟨c, hc⟩ := hall ⟨x, hx⟩
      rw [mem_span_singleton]
      exact ⟨c, congrArg Subtype.val hc⟩
    · rw [span_le, Set.singleton_subset_iff]
      exact v.2
  · rintro ⟨v, hv, rfl⟩
    exact finrank_span_singleton hv

theorem dim_two_iff (W : Submodule ℝ (Fin 3 → ℝ)) :
    finrank ℝ W = 2 ↔
      ∃ u v : Fin 3 → ℝ, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v]) := by
  constructor
  · intro h
    let b := Module.finBasisOfFinrankEq ℝ W h
    have hf : (W.subtype ∘ b) = ![(b 0 : Fin 3 → ℝ), (b 1 : Fin 3 → ℝ)] := by
      funext i
      fin_cases i <;> rfl
    refine ⟨b 0, b 1, ?_, ?_⟩
    · rw [← hf]
      exact b.linearIndependent.map' W.subtype (ker_subtype W)
    · rw [← hf, Set.range_comp, ← map_span, b.span_eq, Submodule.map_top, Submodule.range_subtype]
  · rintro ⟨u, v, h, rfl⟩
    rw [finrank_span_eq_card h, Fintype.card_fin]

theorem classification (W : Submodule ℝ (Fin 3 → ℝ)) :
    W = ⊥ ∨ (∃ v ≠ 0, W = span ℝ {v}) ∨
      (∃ u v : Fin 3 → ℝ, LinearIndependent ℝ ![u, v] ∧ W = span ℝ (Set.range ![u, v])) ∨
        W = ⊤ := by
  obtain h0 | h1 | h2 | h3 :
      finrank ℝ W = 0 ∨ finrank ℝ W = 1 ∨ finrank ℝ W = 2 ∨ finrank ℝ W = 3 := by
    have h := dim_le_three W
    omega
  · exact Or.inl ((dim_zero_iff W).mp h0)
  · exact Or.inr (Or.inl ((dim_one_iff W).mp h1))
  · exact Or.inr (Or.inr (Or.inl ((dim_two_iff W).mp h2)))
  · exact Or.inr (Or.inr (Or.inr ((dim_three_iff W).mp h3)))

end Κεφ1.YpoxoroiR3
