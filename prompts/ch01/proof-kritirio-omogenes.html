Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Τα $v_1,\dots,v_k$ είναι γραμμικώς εξαρτημένα $\Leftrightarrow$ το σύστημα $x_1v_1+\dots+x_kv_k=0$ έχει μη μηδενική λύση
    theorem dependent_iff {k : ℕ} (v : Fin k → V) :
    ¬ LinearIndependent ℝ v ↔ ∃ x : Fin k → ℝ, x ≠ 0 ∧ ∑ i, x i • v i = 0
  • Συνέπεια: αν κάποιο $v_i$ είναι μηδέν, τα διανύσματα είναι εξαρτημένα
    theorem dependent_of_zero {k : ℕ} (v : Fin k → V) (i : Fin k) (h : v i = 0) :
    ¬ LinearIndependent ℝ v

Τα $v_1,\dots,v_k$ γράφονται ως οικογένεια v : Fin k → V: το v i είναι το $i$-οστό διάνυσμα, με $i=0,1,\dots,k-1$. Μια λύση του συστήματος είναι μια οικογένεια αριθμών x : Fin k → ℝ και το $x_1v_1+\dots+x_kv_k$ γράφεται ∑ i, x i • v i. Το x ≠ 0 σημαίνει ότι η λύση δεν είναι η μηδενική.

2. Βήμα προς βήμα: η ισοδυναμία με τη μη μηδενική λύση

Το σύστημα $x_1v_1+\dots+x_kv_k=0$ έχει πάντα τη μηδενική λύση. Τα διανύσματα είναι εξαρτημένα ακριβώς όταν έχει και άλλη. Ξεκινάμε από τον στόχο:

Ο στόχος
V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
k : ℕ
v : Fin k → V
⊢ ¬LinearIndependent ℝ v ↔ ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [Fintype.not_linearIndependent_iff]

    Η Mathlib περιγράφει την εξάρτηση έτσι: υπάρχουν αριθμοί $g_i$ με $\sum_i g_iv_i=0$ και κάποιο $g_i\neq 0$ (θεώρημα Fintype.not_linearIndependent_iff). Μένει να δούμε ότι αυτό λέει το ίδιο με τη μη μηδενική λύση $x$.

    Τι μένει να αποδειχθεί
    ⊢ (∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0) ↔ ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0
  2. constructor

    Μια ισοδυναμία αποδεικνύεται με δύο κατευθύνσεις: mp για το $\Rightarrow$ και mpr για το $\Leftarrow$.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος mp
    ⊢ (∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0) → ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0
    σκέλος mpr
    ⊢ (∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0) → ∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0
  3. · rintro ⟨g, hg, i, hi⟩

    Κατεύθυνση $\Rightarrow$: παίρνουμε τους αριθμούς $g$, τη σχέση hg και μια θέση $i$ με $g_i\neq 0$.

    Τι μένει να αποδειχθεί
    g : Fin k → ℝ
hg : ∑ i, g i • v i = 0
i : Fin k
hi : g i ≠ 0
⊢ ∃ x, x ≠ 0 ∧ ∑ i, x i • v i = 0
  4. exact ⟨g, fun h => hi (by simp [h]), hg⟩

    Η λύση είναι $x=g$. Δεν είναι η μηδενική, γιατί αν $g=0$, θα ήταν και $g_i=0$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  5. · rintro ⟨x, hx, hsum⟩

    Κατεύθυνση $\Leftarrow$: παίρνουμε μια μη μηδενική λύση $x$ με $\sum_i x_iv_i=0$.

    Τι μένει να αποδειχθεί
    V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
k : ℕ
v : Fin k → V
x : Fin k → ℝ
hx : x ≠ 0
hsum : ∑ i, x i • v i = 0
⊢ ∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0
  6. obtain ⟨i, hi⟩ := Function.ne_iff.mp hx

    Ένα διάνυσμα $x\neq 0$ έχει κάποια συντεταγμένη $x_i\neq 0$ (θεώρημα Function.ne_iff). Ο Lean γράφει x i ≠ 0 i, όπου το 0 i είναι η $i$-οστή συντεταγμένη του μηδενικού διανύσματος, δηλαδή το $0$.

    Τι μένει να αποδειχθεί
    i : Fin k
hi : x i ≠ 0 i
⊢ ∃ g, ∑ i, g i • v i = 0 ∧ ∃ i, g i ≠ 0
  7. exact ⟨x, hsum, i, hi⟩

    Οι αριθμοί $x$ δίνουν ακριβώς αυτό που ζητάει η Mathlib.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: αν κάποιο $v_i$ είναι μηδέν, τα διανύσματα είναι εξαρτημένα

Με το κριτήριο: η λύση με $x_i=1$ και όλα τα άλλα $0$ είναι μη μηδενική. Στον Lean υπάρχει και πιο σύντομος δρόμος. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Υπόθεσε ότι είναι ανεξάρτητα, με intro hli. Η Mathlib δίνει το hli.ne_zero i: σε ανεξάρτητη οικογένεια κάθε $v_i\neq 0$. Μαζί με το h δίνει άτοπο: exact hli.ne_zero i h.

Λύση
theorem dependent_of_zero {k : ℕ} (v : Fin k → V) (i : Fin k) (h : v i = 0) :
    ¬ LinearIndependent ℝ v := by
  intro hli
  exact hli.ne_zero i h

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Fintype.not_linearIndependent_iff: εξάρτηση $\Leftrightarrow$ υπάρχει μη τετριμμένος μηδενικός γραμμικός συνδυασμός.
  • LinearIndependent.ne_zero: σε ανεξάρτητη οικογένεια κανένα διάνυσμα δεν είναι μηδέν.

variable {V : Type*} [AddCommGroup V] [Module ℝ V]

theorem dependent_iff {k : ℕ} (v : Fin k → V) :
    ¬ LinearIndependent ℝ v ↔ ∃ x : Fin k → ℝ, x ≠ 0 ∧ ∑ i, x i • v i = 0 := by
  rw [Fintype.not_linearIndependent_iff]
  constructor
  · rintro ⟨g, hg, i, hi⟩
    exact ⟨g, fun h => hi (by simp [h]), hg⟩
  · rintro ⟨x, hx, hsum⟩
    obtain ⟨i, hi⟩ := Function.ne_iff.mp hx
    exact ⟨x, hsum, i, hi⟩

theorem dependent_of_zero {k : ℕ} (v : Fin k → V) (i : Fin k) (h : v i = 0) :
    ¬ LinearIndependent ℝ v := by
  intro hli
  exact hli.ne_zero i h
