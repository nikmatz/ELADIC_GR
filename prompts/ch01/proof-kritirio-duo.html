Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Τα $u,v$ είναι γραμμικώς εξαρτημένα $\Leftrightarrow$ το ένα είναι βαθμωτό πολλαπλάσιο του άλλου
    theorem dependent_iff (u v : V) :
    ¬ LinearIndependent ℝ ![u, v] ↔ (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u)
  • Εξαρτημένα $\Rightarrow$ $u=cv$ ή $v=cu$ για κάποιο $c$
    theorem multiple_of_dependent (u v : V) (h : ¬ LinearIndependent ℝ ![u, v]) :
    (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u)
  • Αν $u=cv$, τότε τα $u,v$ είναι εξαρτημένα
    theorem dependent_of_multiple (u v : V) (c : ℝ) (h : u = c • v) :
    ¬ LinearIndependent ℝ ![u, v]

Το ![u, v] είναι η οικογένεια των δύο διανυσμάτων και το LinearIndependent ℝ ![u, v] σημαίνει ότι είναι ανεξάρτητα. Με το ¬ μπροστά σημαίνει ότι είναι εξαρτημένα. Το c • v είναι το $cv$. Η φράση «το ένα είναι πολλαπλάσιο του άλλου» γράφεται «$u=cv$ για κάποιο $c$ ή $v=cu$ για κάποιο $c$». Χρειάζονται και οι δύο περιπτώσεις: αν $u\neq 0$ και $v=0$, τότε $v=0\cdot u$, ενώ το $u$ δεν είναι πολλαπλάσιο του $v$.

2. Βήμα προς βήμα: αν τα $u,v$ είναι εξαρτημένα, το ένα είναι πολλαπλάσιο του άλλου

Αυτή είναι η ουσιαστική κατεύθυνση. Η ιδέα: υπάρχουν $s,t$, όχι και τα δύο μηδέν, με $su+tv=0$. Λύνουμε ως προς το διάνυσμα που έχει μη μηδενικό συντελεστή. Ξεκινάμε από τον στόχο:

Ο στόχος
V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
u v : V
h : ¬LinearIndependent ℝ ![u, v]
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [LinearIndependent.pair_iff] at h

    Ξεδιπλώνουμε τον ορισμό: τα $u,v$ είναι ανεξάρτητα όταν από $su+tv=0$ έπεται $s=t=0$ (θεώρημα LinearIndependent.pair_iff). Η υπόθεση h λέει ότι αυτό δεν ισχύει.

    Τι μένει να αποδειχθεί
    h : ¬∀ (s t : ℝ), s • u + t • v = 0 → s = 0 ∧ t = 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  2. push Not at h

    Περνάμε την άρνηση προς τα μέσα: υπάρχουν $s,t$ με $su+tv=0$ που δεν είναι και τα δύο μηδέν. Ο Lean το γράφει «αν $s=0$, τότε $t\neq 0$».

    Τι μένει να αποδειχθεί
    h : ∃ s t, s • u + t • v = 0 ∧ (s = 0 → t ≠ 0)
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  3. obtain ⟨s, t, hst, hne⟩ := h

    Παίρνουμε αυτά τα $s,t$ μαζί με τις δύο ιδιότητές τους, τις hst και hne.

    Τι μένει να αποδειχθεί
    s t : ℝ
hst : s • u + t • v = 0
hne : s = 0 → t ≠ 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  4. by_cases hs : s = 0

    Δύο περιπτώσεις: $s=0$ (περίπτωση pos) ή $s\neq 0$ (περίπτωση neg).

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος pos
    hs : s = 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
    σκέλος neg
    hs : ¬s = 0
⊢ (∃ c, u = c • v) ∨ ∃ c, v = c • u
  5. · right
  refine ⟨0, ?_⟩

    Αν $s=0$, θα δείξουμε ότι το $v$ είναι πολλαπλάσιο του $u$, και μάλιστα $v=0\cdot u$. Διαλέγουμε το δεύτερο σκέλος του «ή» με το right και τον αριθμό $c=0$.

    Τι μένει να αποδειχθεί
    ⊢ v = 0 • u
  6. rw [hs, zero_smul, zero_add] at hst

    Με $s=0$ η σχέση $su+tv=0$ γίνεται $tv=0$.

    Τι μένει να αποδειχθεί
    hst : t • v = 0
⊢ v = 0 • u
  7. rw [zero_smul]
exact (smul_eq_zero.mp hst).resolve_left (hne hs)

    Αφού $t\neq 0$ (από την hne), η $tv=0$ δίνει $v=0$, δηλαδή $v=0\cdot u$. Η πρώτη περίπτωση τελείωσε.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  8. · left
  refine ⟨-t / s, ?_⟩

    Αν $s\neq 0$, λύνουμε ως προς $u$ και θα δείξουμε ότι $u=-\frac{t}{s}\,v$. Διαλέγουμε το πρώτο σκέλος του «ή» με το left.

    Τι μένει να αποδειχθεί
    V : Type u_1
inst✝¹ : AddCommGroup V
inst✝ : Module ℝ V
u v : V
s t : ℝ
hst : s • u + t • v = 0
hne : s = 0 → t ≠ 0
hs : ¬s = 0
⊢ u = (-t / s) • v
  9. have e : s • u = -(t • v) := eq_neg_of_add_eq_zero_left hst

    Από $su+tv=0$ παίρνουμε $su=-tv$.

    Τι μένει να αποδειχθεί
    e : s • u = -(t • v)
⊢ u = (-t / s) • v
  10. calc u = s⁻¹ • (s • u) := by rw [smul_smul, inv_mul_cancel₀ hs, one_smul]
  _ = s⁻¹ • -(t • v) := by rw [e]
  _ = (-t / s) • v := by rw [smul_neg, smul_smul, ← neg_smul]; congr 1; ring

    Πολλαπλασιάζουμε με $\frac{1}{s}$: $u$${}=\frac{1}{s}(su)$${}=\frac{1}{s}(-tv)$${}=-\frac{t}{s}\,v$. Η calc γράφει ακριβώς αυτή την αλυσίδα ισοτήτων και ο Lean ελέγχει κάθε κρίκο χωριστά.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: αν $u=cv$, τα $u,v$ είναι εξαρτημένα

Αυτή είναι η εύκολη κατεύθυνση: βρες συντελεστές, όχι και τους δύο μηδέν, που μηδενίζουν τον συνδυασμό. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ξεκίνα με rw [LinearIndependent.pair_iff] και intro hli. Αφού $1\cdot u+(-c)\cdot v=0$, γράψε have h1 := hli 1 (-c) (by rw [h]; module). Τώρα το h1 λέει ότι $1=0$, που είναι άτοπο: τελείωσε με norm_num at h1.

Λύση

  rw [LinearIndependent.pair_iff]
  intro hli

import Mathlib

namespace Κεφ1.KritirioDuo

variable {V : Type*} [AddCommGroup V] [Module ℝ V]

theorem dependent_of_multiple (u v : V) (c : ℝ) (h : u = c • v) :
    ¬ LinearIndependent ℝ ![u, v] := by
  rw [LinearIndependent.pair_iff]
  intro hli
  have h1 := hli 1 (-c) (by rw [h]; module)
  norm_num at h1

theorem dependent_of_multiple' (u v : V) (c : ℝ) (h : v = c • u) :
    ¬ LinearIndependent ℝ ![u, v] := by
  rw [LinearIndependent.pair_iff]
  intro hli
  have h1 := hli (-c) 1 (by rw [h]; module)
  norm_num at h1

theorem multiple_of_dependent (u v : V) (h : ¬ LinearIndependent ℝ ![u, v]) :
    (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u) := by
  rw [LinearIndependent.pair_iff] at h
  push Not at h
  obtain ⟨s, t, hst, hne⟩ := h
  by_cases hs : s = 0
  · right
    refine ⟨0, ?_⟩
    rw [hs, zero_smul, zero_add] at hst
    rw [zero_smul]
    exact (smul_eq_zero.mp hst).resolve_left (hne hs)
  · left
    refine ⟨-t / s, ?_⟩
    have e : s • u = -(t • v) := eq_neg_of_add_eq_zero_left hst
    calc u = s⁻¹ • (s • u) := by rw [smul_smul, inv_mul_cancel₀ hs, one_smul]
      _ = s⁻¹ • -(t • v) := by rw [e]
      _ = (-t / s) • v := by rw [smul_neg, smul_smul, ← neg_smul]; congr 1; ring

theorem dependent_iff (u v : V) :
    ¬ LinearIndependent ℝ ![u, v] ↔ (∃ c : ℝ, u = c • v) ∨ (∃ c : ℝ, v = c • u) := by
  constructor
  · exact multiple_of_dependent u v
  · rintro (⟨c, hc⟩ | ⟨c, hc⟩)
    · exact dependent_of_multiple u v c hc
    · exact dependent_of_multiple' u v c hc

end Κεφ1.KritirioDuo
