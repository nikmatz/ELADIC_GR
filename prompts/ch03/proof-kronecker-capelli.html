ΕκφώνησηΘεώρημα Kronecker–Capelli: το σύστημα $Ax=b$, με $\tilde{A}=[A\mid b]$ τον επαυξημένο πίνακα, είναι συμβατό $\Leftrightarrow\operatorname{rank}(A)$${}=\operatorname{rank}(\tilde{A})$. Τότε: αν $\operatorname{rank}(A)=n$ μοναδική λύση· αν $\operatorname{rank}(A)\lt n$ άπειρες λύσεις με $n-\operatorname{rank}(A)$ ελεύθερες παραμέτρους.

Τότε: αν $\operatorname{rank}(A)=n$ μοναδική λύση· αν $\operatorname{rank}(A)\lt n$ άπειρες λύσεις με $n-\operatorname{rank}(A)$ ελεύθερες παραμέτρους.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Το $Ax=b$ είναι συμβατό $\Leftrightarrow\operatorname{rank}(A)$${}=\operatorname{rank}(\tilde{A})$
    theorem compatible_iff (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    (∃ x, A *ᵥ x = b) ↔ A.rank = (augmented A b).rank
  • Αν $\operatorname{rank}(A)=n$, η λύση είναι μοναδική
    theorem unique_of_rank (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (h : A.rank = n)
    (x y : Fin n → ℝ) (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : x = y
  • Οι λύσεις του ομογενούς σχηματίζουν χώρο διάστασης $n-\operatorname{rank}(A)$: τόσες είναι οι ελεύθερες παράμετροι
    theorem dim_solutions (A : Matrix (Fin m) (Fin n) ℝ) :
    finrank ℝ (LinearMap.ker A.mulVecLin) = n - A.rank

Ο επαυξημένος πίνακας $\tilde{A}=[A\mid b]$ ορίζεται στον κώδικα ως augmented A b, πίνακας $m\times(n+1)$ με τελευταία στήλη το $b$. Οι στήλες ενός πίνακα γράφονται A.col και ο χώρος που παράγουν, ο χώρος στηλών $\mathcal{C}(A)$, γράφεται span ℝ (Set.range A.col). Για την περίπτωση $\operatorname{rank}(A)\lt n$: κάθε λύση είναι μια μερική λύση συν μια λύση του ομογενούς, και οι λύσεις του ομογενούς σχηματίζουν χώρο διάστασης $n-\operatorname{rank}(A)$.

2. Βήμα προς βήμα: συμβατό $\Leftrightarrow\operatorname{rank}(A)$${}=\operatorname{rank}(\tilde{A})$

Η ιδέα: ο βαθμός είναι η διάσταση του χώρου στηλών. Ο $\tilde{A}$ έχει μία στήλη παραπάνω, το $b$, και ο βαθμός μένει ίδιος ακριβώς όταν το $b$ ανήκει ήδη στον χώρο στηλών του $A$. Ξεκινάμε από τον στόχο:

Ο στόχος
m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
⊢ (∃ x, A *ᵥ x = b) ↔ A.rank = (augmented A b).rank

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [solvable_iff_mem]

    Το σύστημα έχει λύση ακριβώς όταν το $b$ είναι γραμμικός συνδυασμός των στηλών του $A$, δηλαδή $b\in\mathcal{C}(A)$ (λήμμα solvable_iff_mem, η άσκηση πιο κάτω).

    Τι μένει να αποδειχθεί
    ⊢ b ∈ span ℝ (Set.range A.col) ↔ A.rank = (augmented A b).rank
  2. rw [← finrank_span_range_col, ← finrank_span_range_col]

    Ο βαθμός ενός πίνακα είναι η διάσταση του χώρου που παράγουν οι στήλες του.

    Τι μένει να αποδειχθεί
    ⊢ b ∈ span ℝ (Set.range A.col) ↔
  finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (Set.range (augmented A b).col))
  3. rw [cols_augmented]

    Οι στήλες του $\tilde{A}$ είναι οι στήλες του $A$ και το $b$ (λήμμα cols_augmented).

    Τι μένει να αποδειχθεί
    ⊢ b ∈ span ℝ (Set.range A.col) ↔ finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (insert b (Set.range A.col)))
  4. constructor

    Δύο κατευθύνσεις: mp για το $\Rightarrow$ και mpr για το $\Leftarrow$.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος mp
    ⊢ b ∈ span ℝ (Set.range A.col) → finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (insert b (Set.range A.col)))
    σκέλος mpr
    ⊢ finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (insert b (Set.range A.col))) → b ∈ span ℝ (Set.range A.col)
  5. · intro hb

    Κατεύθυνση $\Rightarrow$: υποθέτουμε ότι $b\in\mathcal{C}(A)$.

    Τι μένει να αποδειχθεί
    hb : b ∈ span ℝ (Set.range A.col)
⊢ finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (insert b (Set.range A.col)))
  6. rw [span_insert_eq_span hb]

    Τότε η προσθήκη του $b$ δεν αλλάζει τον χώρο που παράγεται, άρα ούτε τη διάστασή του.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  7. · intro h

    Κατεύθυνση $\Leftarrow$: οι δύο χώροι έχουν την ίδια διάσταση.

    Τι μένει να αποδειχθεί
    m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
h : finrank ℝ ↥(span ℝ (Set.range A.col)) = finrank ℝ ↥(span ℝ (insert b (Set.range A.col)))
⊢ b ∈ span ℝ (Set.range A.col)
  8. have hle : span ℝ (Set.range A.col) ≤ span ℝ (insert b (Set.range A.col)) :=
  span_mono (Set.subset_insert b _)

    Ο $\mathcal{C}(A)$ περιέχεται στον χώρο που παράγουν οι στήλες του $A$ μαζί με το $b$.

    Τι μένει να αποδειχθεί
    hle : span ℝ (Set.range A.col) ≤ span ℝ (insert b (Set.range A.col))
⊢ b ∈ span ℝ (Set.range A.col)
  9. have heq := eq_of_le_of_finrank_eq hle h

    Ένας υπόχωρος που περιέχεται σε άλλον και έχει την ίδια διάσταση είναι ίσος με αυτόν (θεώρημα eq_of_le_of_finrank_eq).

    Τι μένει να αποδειχθεί
    heq : span ℝ (Set.range A.col) = span ℝ (insert b (Set.range A.col))
⊢ b ∈ span ℝ (Set.range A.col)
  10. rw [heq]

    Άρα αρκεί να δείξουμε ότι το $b$ ανήκει στον μεγαλύτερο χώρο.

    Τι μένει να αποδειχθεί
    ⊢ b ∈ span ℝ (insert b (Set.range A.col))
  11. exact subset_span (Set.mem_insert b _)

    Αυτό ισχύει, γιατί το $b$ είναι ένα από τα διανύσματα που τον παράγουν.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: λύση υπάρχει ακριβώς όταν $b\in\mathcal{C}(A)$

Το $A\mathbf{x}$ είναι γραμμικός συνδυασμός των στηλών του $A$ με συντελεστές τα $x_i$. Η Mathlib το λέει έτσι: η εικόνα της απεικόνισης $\mathbf{x}\mapsto A\mathbf{x}$ είναι ο χώρος που παράγουν οι στήλες. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Matrix.finrank_span_range_col: ο βαθμός είναι η διάσταση του χώρου στηλών.
  • Matrix.range_mulVecLin: η εικόνα της $\mathbf{x}\mapsto A\mathbf{x}$ είναι ο χώρος στηλών.
  • Submodule.span_insert_eq_span: η προσθήκη ενός διανύσματος του χώρου δεν αλλάζει τον χώρο που παράγεται.
  • Submodule.eq_of_le_of_finrank_eq: υπόχωρος μέσα σε άλλον με την ίδια διάσταση είναι ίσος με αυτόν.
  • LinearMap.finrank_range_add_finrank_ker: το θεώρημα τάξης-μηδενοχώρου.

import Mathlib

namespace Κεφ3.KroneckerCapelli
open Matrix Module Submodule

variable {m n : ℕ}

/-- Ο επαυξημένος πίνακας [A | b]: οι στήλες του A και, τελευταία, το b. -/
def augmented (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) : Matrix (Fin m) (Fin (n + 1)) ℝ :=
  Matrix.of fun i => Fin.snoc (A i) (b i)

theorem cols_augmented (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    Set.range (augmented A b).col = insert b (Set.range A.col) := by
  ext v
  simp only [Set.mem_range, Set.mem_insert_iff]
  constructor
  · rintro ⟨j, rfl⟩
    induction j using Fin.lastCases with
    | last => left; funext i; simp [augmented]
    | cast k => right; exact ⟨k, by funext i; simp [augmented]⟩
  · rintro (rfl | ⟨k, rfl⟩)
    · exact ⟨Fin.last n, by funext i; simp [augmented]⟩
    · exact ⟨k.castSucc, by funext i; simp [augmented]⟩

theorem solvable_iff_mem (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    (∃ x, A *ᵥ x = b) ↔ b ∈ span ℝ (Set.range A.col) := by
  rw [← range_mulVecLin, LinearMap.mem_range]
  rfl

theorem compatible_iff (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) :
    (∃ x, A *ᵥ x = b) ↔ A.rank = (augmented A b).rank := by
  rw [solvable_iff_mem]
  rw [← finrank_span_range_col, ← finrank_span_range_col]
  rw [cols_augmented]
  constructor
  · intro hb
    rw [span_insert_eq_span hb]
  · intro h
    have hle : span ℝ (Set.range A.col) ≤ span ℝ (insert b (Set.range A.col)) :=
      span_mono (Set.subset_insert b _)
    have heq := eq_of_le_of_finrank_eq hle h
    rw [heq]
    exact subset_span (Set.mem_insert b _)

theorem dim_solutions (A : Matrix (Fin m) (Fin n) ℝ) :
    finrank ℝ (LinearMap.ker A.mulVecLin) = n - A.rank := by
  have h := LinearMap.finrank_range_add_finrank_ker A.mulVecLin
  rw [finrank_range_mulVecLin, finrank_fin_fun] at h
  omega

theorem unique_of_rank (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (h : A.rank = n)
    (x y : Fin n → ℝ) (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : x = y := by
  have hk : LinearMap.ker A.mulVecLin = ⊥ := by
    rw [← Submodule.finrank_eq_zero, dim_solutions, h, Nat.sub_self]
  have hmem : x - y ∈ LinearMap.ker A.mulVecLin := by
    rw [LinearMap.mem_ker, mulVecLin_apply, mulVec_sub, hx, hy, sub_self]
  rw [hk, Submodule.mem_bot] at hmem
  exact sub_eq_zero.mp hmem

end Κεφ3.KroneckerCapelli
