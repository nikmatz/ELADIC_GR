Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Κάθε λύση γράφεται $\mathbf{x}$${}=\mathbf{x}_p+\mathbf{x}_h$ με $A\mathbf{x}_h=\mathbf{0}$, και αντίστροφα
    theorem general_solution (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (xp : Fin n → ℝ)
    (hp : A *ᵥ xp = b) (x : Fin n → ℝ) :
    A *ᵥ x = b ↔ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh
  • Η διαφορά δύο λύσεων είναι λύση του ομογενούς
    theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (x - y) = 0

Ο πίνακας είναι $m\times n$ (Matrix (Fin m) (Fin n) ℝ) και το $A\mathbf{x}$ γράφεται A *ᵥ x. Η μερική λύση $\mathbf{x}_p$ λέγεται xp και η υπόθεση hp λέει ότι $A\mathbf{x}_p=\mathbf{b}$. Το σύστημα είναι συμβιβαστό ακριβώς επειδή υπάρχει αυτή η μερική λύση.

2. Βήμα προς βήμα: κάθε λύση είναι $\mathbf{x}_p+\mathbf{x}_h$

Αποδεικνύουμε κάτι λίγο ισχυρότερο: το $\mathbf{x}$ είναι λύση ακριβώς όταν γράφεται $\mathbf{x}_p+\mathbf{x}_h$ με $\mathbf{x}_h$ λύση του ομογενούς. Ξεκινάμε από τον στόχο:

Ο στόχος
m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
xp : Fin n → ℝ
hp : A *ᵥ xp = b
x : Fin n → ℝ
⊢ A *ᵥ x = b ↔ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. constructor

    Δύο κατευθύνσεις: mp για το $\Rightarrow$ και mpr για το $\Leftarrow$.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος mp
    ⊢ A *ᵥ x = b → ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh
    σκέλος mpr
    ⊢ (∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh) → A *ᵥ x = b
  2. · intro hx

    Κατεύθυνση $\Rightarrow$: υποθέτουμε ότι το $\mathbf{x}$ είναι λύση (υπόθεση hx).

    Τι μένει να αποδειχθεί
    hx : A *ᵥ x = b
⊢ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh
  3. refine ⟨x - xp, ?_, ?_⟩

    Παίρνουμε $\mathbf{x}_h$${}=\mathbf{x}-\mathbf{x}_p$. Μένουν δύο στόχοι: ότι το $\mathbf{x}_h$ λύνει το ομογενές και ότι $\mathbf{x}$${}=\mathbf{x}_p+\mathbf{x}_h$.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος mp.refine_1
    ⊢ A *ᵥ (x - xp) = 0
    σκέλος mp.refine_2
    ⊢ x = xp + (x - xp)
  4. · rw [mulVec_sub, hx, hp, sub_self]

    $A(\mathbf{x}-\mathbf{x}_p)$${}=A\mathbf{x}-A\mathbf{x}_p$${}=\mathbf{b}-\mathbf{b}$${}=\mathbf{0}$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  5. · abel

    $\mathbf{x}_p+(\mathbf{x}-\mathbf{x}_p)$${}=\mathbf{x}$. Αυτές τις πράξεις πρόσθεσης τις κάνει η abel.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  6. · rintro ⟨xh, hh, rfl⟩

    Κατεύθυνση $\Leftarrow$: έχουμε $\mathbf{x}$${}=\mathbf{x}_p+\mathbf{x}_h$ με $A\mathbf{x}_h=\mathbf{0}$. Το rfl αντικαθιστά το $\mathbf{x}$ με το $\mathbf{x}_p+\mathbf{x}_h$.

    Τι μένει να αποδειχθεί
    m n : ℕ
A : Matrix (Fin m) (Fin n) ℝ
b : Fin m → ℝ
xp : Fin n → ℝ
hp : A *ᵥ xp = b
xh : Fin n → ℝ
hh : A *ᵥ xh = 0
⊢ A *ᵥ (xp + xh) = b
  7. rw [mulVec_add, hp, hh, add_zero]

    $A(\mathbf{x}_p+\mathbf{x}_h)$${}=A\mathbf{x}_p+A\mathbf{x}_h$${}=\mathbf{b}+\mathbf{0}$${}=\mathbf{b}$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: η διαφορά δύο λύσεων λύνει το ομογενές

Αν $A\mathbf{x}=\mathbf{b}$ και $A\mathbf{y}=\mathbf{b}$, δείξε ότι $A(\mathbf{x}-\mathbf{y})$${}=\mathbf{0}$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Αρκεί μόνο μία γραμμή: rw [mulVec_sub, hx, hy, sub_self].

Λύση
theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (x - y) = 0 := by
  rw [mulVec_sub, hx, hy, sub_self]

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Matrix.mulVec_sub: $A(\mathbf{x}-\mathbf{y})$${}=A\mathbf{x}-A\mathbf{y}$.
  • Matrix.mulVec_add: $A(\mathbf{x}+\mathbf{y})$${}=A\mathbf{x}+A\mathbf{y}$.

namespace Κεφ3.DomiLyseon
open Matrix

variable {m n : ℕ}

theorem general_solution (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (xp : Fin n → ℝ)
    (hp : A *ᵥ xp = b) (x : Fin n → ℝ) :
    A *ᵥ x = b ↔ ∃ xh, A *ᵥ xh = 0 ∧ x = xp + xh := by
  constructor
  · intro hx
    refine ⟨x - xp, ?_, ?_⟩
    · rw [mulVec_sub, hx, hp, sub_self]
    · abel
  · rintro ⟨xh, hh, rfl⟩
    rw [mulVec_add, hp, hh, add_zero]

theorem difference (A : Matrix (Fin m) (Fin n) ℝ) (b : Fin m → ℝ) (x y : Fin n → ℝ)
    (hx : A *ᵥ x = b) (hy : A *ᵥ y = b) : A *ᵥ (x - y) = 0 := by
  rw [mulVec_sub, hx, hy, sub_self]
