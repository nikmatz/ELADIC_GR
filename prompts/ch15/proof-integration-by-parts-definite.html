Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν οι $u,v$ έχουν συνεχείς παραγώγους στο $[a,b]$, τότε $\int_a^b u(x)v'(x)\,dx$${}=\bigl[u(x)v(x)\bigr]_a^b-\int_a^b u'(x)v(x)\,dx$
    theorem parts_definite (u v u' v' : ℝ → ℝ) (a b : ℝ)
    (hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x) (hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x)
    (hu' : ContinuousOn u' (Set.uIcc a b)) (hv' : ContinuousOn v' (Set.uIcc a b)) :
    ∫ x in a..b, u x * v' x = (u b * v b - u a * v a) - ∫ x in a..b, u' x * v x
  • Εφαρμογή: αν $u(a)v(a)=u(b)v(b)=0$, τότε $\int_a^b u v'\,dx$${}=-\int_a^b u' v\,dx$
    theorem parts_zero_boundary (u v u' v' : ℝ → ℝ) (a b : ℝ)
    (hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x) (hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x)
    (hu' : ContinuousOn u' (Set.uIcc a b)) (hv' : ContinuousOn v' (Set.uIcc a b))
    (ha : u a * v a = 0) (hb : u b * v b = 0) :
    ∫ x in a..b, u x * v' x = -∫ x in a..b, u' x * v x

Το «η $u$ έχει παράγωγο $u'$ στο $[a,b]$» γράφεται ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x, και η συνέχεια της παραγώγου γράφεται ContinuousOn u' (Set.uIcc a b). Το Set.uIcc a b είναι το διάστημα με άκρα $a$ και $b$, όποιο από τα δύο κι αν είναι μικρότερο· για $a\le b$ είναι το $[a,b]$. Η παράσταση $\bigl[u(x)v(x)\bigr]_a^b$ γράφεται u b * v b - u a * v a. Η Mathlib έχει έτοιμο το θεώρημα (intervalIntegral.integral_mul_deriv_eq_deriv_mul)· εδώ το αποδεικνύουμε από το θεμελιώδες θεώρημα, όπως στο βιβλίο.

2. Βήμα προς βήμα: κατά παράγοντες

Η ιδέα: ολοκληρώνουμε τον κανόνα του γινομένου $(uv)'=u'v+uv'$ από $a$ έως $b$ και χρησιμοποιούμε το θεμελιώδες θεώρημα. Ξεκινάμε από τον στόχο:

Ο στόχος
u v u' v' : ℝ → ℝ
a b : ℝ
hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x
hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x
hu' : ContinuousOn u' (Set.uIcc a b)
hv' : ContinuousOn v' (Set.uIcc a b)
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- κανόνας γινομένου: (u v)' = u' v + u v'
have hd : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => u x * v x) (u' x * v x + u x * v' x) x :=
  fun x hx => (hu x hx).mul (hv x hx)

    Κανόνας γινομένου: η $uv$ έχει παράγωγο $u'v+uv'$ σε κάθε σημείο του διαστήματος.

    Τι μένει να αποδειχθεί
    hd : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => u x * v x) (u' x * v x + u x * v' x) x
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  2. -- οι u, v είναι συνεχείς, άρα οι u' v και u v' είναι ολοκληρώσιμες
have huc : ContinuousOn u (Set.uIcc a b) := fun x hx => (hu x hx).continuousAt.continuousWithinAt
have hvc : ContinuousOn v (Set.uIcc a b) := fun x hx => (hv x hx).continuousAt.continuousWithinAt

    Οι $u$ και $v$ είναι παραγωγίσιμες, άρα συνεχείς.

    Τι μένει να αποδειχθεί
    huc : ContinuousOn u (Set.uIcc a b)
hvc : ContinuousOn v (Set.uIcc a b)
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  3. have h1 : IntervalIntegrable (fun x => u' x * v x) volume a b := (hu'.mul hvc).intervalIntegrable
have h2 : IntervalIntegrable (fun x => u x * v' x) volume a b := (huc.mul hv').intervalIntegrable

    Οι $u'v$ και $uv'$ είναι συνεχείς, ως γινόμενα συνεχών συναρτήσεων, άρα ολοκληρώσιμες.

    Τι μένει να αποδειχθεί
    h1 : IntervalIntegrable (fun x => u' x * v x) volume a b
h2 : IntervalIntegrable (fun x => u x * v' x) volume a b
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  4. -- θεμελιώδες θεώρημα για την u v
have hftc := intervalIntegral.integral_eq_sub_of_hasDerivAt hd (h1.add h2)

    Θεμελιώδες θεώρημα (intervalIntegral.integral_eq_sub_of_hasDerivAt): $\int_a^b (u'v+uv')\,dx$${}=u(b)v(b)-u(a)v(a)$.

    Τι μένει να αποδειχθεί
    hftc : ∫ (y : ℝ) in a..b, u' y * v y + u y * v' y = u b * v b - u a * v a
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  5. -- το ολοκλήρωμα του αθροίσματος σπάει σε δύο ολοκληρώματα
rw [intervalIntegral.integral_add h1 h2] at hftc

    Το ολοκλήρωμα του αθροίσματος σπάει σε δύο ολοκληρώματα (intervalIntegral.integral_add).

    Τι μένει να αποδειχθεί
    hftc : (∫ (x : ℝ) in a..b, u' x * v x) + ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a
⊢ ∫ (x : ℝ) in a..b, u x * v' x = u b * v b - u a * v a - ∫ (x : ℝ) in a..b, u' x * v x
  6. linarith

    Μεταφέρουμε το $\int_a^b u'v\,dx$ στο άλλο μέλος· αυτό το κάνει η linarith.

3. Δοκίμασε εσύ: μηδενικοί συνοριακοί όροι

Αν επιπλέον $u(a)v(a)=0$ και $u(b)v(b)=0$, δείξε ότι $\int_a^b u(x)v'(x)\,dx$${}=-\int_a^b u'(x)v(x)\,dx$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Γράψε το αριστερό μέλος με το θεώρημα και αντικατάστησε τους συνοριακούς όρους: rw [parts_definite u v u' v' a b hu hv hu' hv', ha, hb]. Μένει η ισότητα $0-0-I=-I$, που την ελέγχει η ring.

Λύση
theorem parts_zero_boundary (u v u' v' : ℝ → ℝ) (a b : ℝ)
    (hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x) (hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x)
    (hu' : ContinuousOn u' (Set.uIcc a b)) (hv' : ContinuousOn v' (Set.uIcc a b))
    (ha : u a * v a = 0) (hb : u b * v b = 0) :
    ∫ x in a..b, u x * v' x = -∫ x in a..b, u' x * v x := by
  rw [parts_definite u v u' v' a b hu hv hu' hv', ha, hb]
  ring

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • HasDerivAt.mul: ο κανόνας του γινομένου.
  • HasDerivAt.continuousAt: παραγωγίσιμη συνάρτηση είναι συνεχής.
  • ContinuousOn.mul: το γινόμενο συνεχών συναρτήσεων είναι συνεχές.
  • ContinuousOn.intervalIntegrable: συνεχής συνάρτηση σε κλειστό διάστημα είναι ολοκληρώσιμη.
  • intervalIntegral.integral_eq_sub_of_hasDerivAt: το θεμελιώδες θεώρημα του λογισμού.
  • intervalIntegral.integral_add: το ολοκλήρωμα του αθροίσματος.

open MeasureTheory

theorem parts_definite (u v u' v' : ℝ → ℝ) (a b : ℝ)
    (hu : ∀ x ∈ Set.uIcc a b, HasDerivAt u (u' x) x) (hv : ∀ x ∈ Set.uIcc a b, HasDerivAt v (v' x) x)
    (hu' : ContinuousOn u' (Set.uIcc a b)) (hv' : ContinuousOn v' (Set.uIcc a b)) :
    ∫ x in a..b, u x * v' x = (u b * v b - u a * v a) - ∫ x in a..b, u' x * v x := by
  -- κανόνας γινομένου: (u v)' = u' v + u v'
  have hd : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => u x * v x) (u' x * v x + u x * v' x) x :=
    fun x hx => (hu x hx).mul (hv x hx)
  -- οι u, v είναι συνεχείς, άρα οι u' v και u v' είναι ολοκληρώσιμες
  have huc : ContinuousOn u (Set.uIcc a b) := fun x hx => (hu x hx).continuousAt.continuousWithinAt
  have hvc : ContinuousOn v (Set.uIcc a b) := fun x hx => (hv x hx).continuousAt.continuousWithinAt
  have h1 : IntervalIntegrable (fun x => u' x * v x) volume a b := (hu'.mul hvc).intervalIntegrable
  have h2 : IntervalIntegrable (fun x => u x * v' x) volume a b := (huc.mul hv').intervalIntegrable
  -- θεμελιώδες θεώρημα για την u v
  have hftc := intervalIntegral.integral_eq_sub_of_hasDerivAt hd (h1.add h2)
  -- το ολοκλήρωμα του αθροίσματος σπάει σε δύο ολοκληρώματα
  rw [intervalIntegral.integral_add h1 h2] at hftc
  linarith

    (ha : u a * v a = 0) (hb : u b * v b = 0) :
    ∫ x in a..b, u x * v' x = -∫ x in a..b, u' x * v x := by
