1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν η $g$ έχει συνεχή παράγωγο στο $[a,b]$ και η $f$ είναι συνεχής, τότε $\int_a^b f\bigl(g(x)\bigr)g'(x)\,dx$${}=\int_{g(a)}^{g(b)}f(u)\,du$

    (hg : ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x) (hg' : ContinuousOn g' (Set.uIcc a b)) :
    ∫ x in a..b, f (g x) * g' x = ∫ u in g a..g b, f u
  • Εφαρμογή: $\int_a^b f(x+c)\,dx$${}=\int_{a+c}^{b+c}f(u)\,du$
    theorem shift (f : ℝ → ℝ) (a b c : ℝ) (hf : Continuous f) :
    ∫ x in a..b, f (x + c) = ∫ u in a + c..b + c, f u

Για απλότητα παίρνουμε την $f$ συνεχή σε όλο το $\mathbb{R}$, ενώ το βιβλίο ζητά συνέχεια μόνο στο σύνολο τιμών της $g$. Το «η $g$ έχει συνεχή παράγωγο στο $[a,b]$» γράφεται με δύο υποθέσεις: ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x και ContinuousOn g' (Set.uIcc a b). Το Set.uIcc a b είναι το διάστημα με άκρα $a$ και $b$. Η απόδειξη είναι αυτή του βιβλίου: αν η $F$ είναι αντιπαράγωγος της $f$, τότε η $F\bigl(g(x)\bigr)$ είναι αντιπαράγωγος της $f\bigl(g(x)\bigr)g'(x)$.

2. Βήμα προς βήμα: αλλαγή ορίων

Η ιδέα: με $F(u)=\int_{g(a)}^{u}f(t)\,dt$, η $F\bigl(g(x)\bigr)$ είναι αντιπαράγωγος της $f\bigl(g(x)\bigr)g'(x)$, και το θεμελιώδες θεώρημα δίνει το αποτέλεσμα. Ξεκινάμε από τον στόχο:

Ο στόχος
f g g' : ℝ → ℝ
a b : ℝ
hf : Continuous f
hg : ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x
hg' : ContinuousOn g' (Set.uIcc a b)
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- η F(u) = ∫ f(t) dt από g(a) έως u έχει παράγωγο f(u)
have hF : ∀ u, HasDerivAt (fun u => ∫ t in g a..u, f t) (f u) u :=
  fun u => (hf.integral_hasStrictDerivAt (g a) u).hasDerivAt

    Θεμελιώδες θεώρημα: η $F(u)=\int_{g(a)}^{u}f(t)\,dt$ έχει παράγωγο $f(u)$ σε κάθε $u$.

    Τι μένει να αποδειχθεί
    hF : ∀ (u : ℝ), HasDerivAt (fun u => ∫ (t : ℝ) in g a..u, f t) (f u) u
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u
  2. -- κανόνας αλυσίδας: (F(g(x)))' = f(g(x)) g'(x)
have hcomp : ∀ x ∈ Set.uIcc a b,
    HasDerivAt (fun x => ∫ t in g a..g x, f t) (f (g x) * g' x) x :=
  fun x hx => (hF (g x)).comp x (hg x hx)

    Κανόνας αλυσίδας: η $F\bigl(g(x)\bigr)$ έχει παράγωγο $f\bigl(g(x)\bigr)\,g'(x)$ σε κάθε $x$ του διαστήματος.

    Τι μένει να αποδειχθεί
    hcomp : ∀ x ∈ Set.uIcc a b, HasDerivAt (fun x => ∫ (t : ℝ) in g a..g x, f t) (f (g x) * g' x) x
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u
  3. -- η f(g(x)) g'(x) είναι συνεχής, άρα ολοκληρώσιμη
have hgc : ContinuousOn g (Set.uIcc a b) := fun x hx => (hg x hx).continuousAt.continuousWithinAt
have hint : IntervalIntegrable (fun x => f (g x) * g' x) volume a b :=
  ((hf.comp_continuousOn hgc).mul hg').intervalIntegrable

    Η $g$ είναι παραγωγίσιμη, άρα συνεχής, και η $f\bigl(g(x)\bigr)g'(x)$ είναι συνεχής, άρα ολοκληρώσιμη.

    Τι μένει να αποδειχθεί
    hgc : ContinuousOn g (Set.uIcc a b)
hint : IntervalIntegrable (fun x => f (g x) * g' x) volume a b
⊢ ∫ (x : ℝ) in a..b, f (g x) * g' x = ∫ (u : ℝ) in g a..g b, f u
  4. -- θεμελιώδες θεώρημα: το ολοκλήρωμα είναι F(g(b)) - F(g(a))
rw [intervalIntegral.integral_eq_sub_of_hasDerivAt hcomp hint]

    Θεμελιώδες θεώρημα για την $F\bigl(g(x)\bigr)$: το ολοκλήρωμα ισούται με $F\bigl(g(b)\bigr)-F\bigl(g(a)\bigr)$.

    Τι μένει να αποδειχθεί
    ⊢ (∫ (t : ℝ) in g a..g b, f t) - ∫ (t : ℝ) in g a..g a, f t = ∫ (u : ℝ) in g a..g b, f u
  5. -- F(g(a)) = 0, γιατί τα άκρα είναι ίσα
rw [intervalIntegral.integral_same, sub_zero]

    Το $F\bigl(g(a)\bigr)$${}=\int_{g(a)}^{g(a)}f(t)\,dt$ είναι $0$, γιατί τα άκρα είναι ίσα, και μένει $F\bigl(g(b)\bigr)$${}=\int_{g(a)}^{g(b)}f(u)\,du$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: μετατόπιση

Δείξε ότι $\int_a^b f(x+c)\,dx$${}=\int_{a+c}^{b+c}f(u)\,du$, για συνεχή $f$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Εφάρμοσε τον κανόνα με $g(x)=x+c$ και $g'(x)=1$: have h := subst_definite f (fun x => x + c) (fun _ => 1) a b hf (fun x _ => (hasDerivAt_id' x).add_const c) continuousOn_const. Στην h η ολοκληρωτέα συνάρτηση έχει τον παράγοντα $1$· σβήσε τον με simp only [mul_one] at h και τελείωσε με exact h.

Λύση
theorem shift (f : ℝ → ℝ) (a b c : ℝ) (hf : Continuous f) :
    ∫ x in a..b, f (x + c) = ∫ u in a + c..b + c, f u := by
  have h := subst_definite f (fun x => x + c) (fun _ => 1) a b hf
    (fun x _ => (hasDerivAt_id' x).add_const c) continuousOn_const
  simp only [mul_one] at h
  exact h

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Continuous.integral_hasStrictDerivAt: το θεμελιώδες θεώρημα: η $\int_{g(a)}^u f(t)\,dt$ έχει παράγωγο $f(u)$.
  • HasDerivAt.comp: ο κανόνας αλυσίδας.
  • HasDerivAt.continuousAt: παραγωγίσιμη συνάρτηση είναι συνεχής.
  • Continuous.comp_continuousOn: η σύνθεση συνεχών συναρτήσεων είναι συνεχής.
  • ContinuousOn.mul: το γινόμενο συνεχών συναρτήσεων είναι συνεχές.
  • ContinuousOn.intervalIntegrable: συνεχής συνάρτηση σε κλειστό διάστημα είναι ολοκληρώσιμη.
  • intervalIntegral.integral_eq_sub_of_hasDerivAt: το θεμελιώδες θεώρημα του λογισμού.
  • intervalIntegral.integral_same: $\int_a^a f=0$.

open MeasureTheory

theorem subst_definite (f g g' : ℝ → ℝ) (a b : ℝ) (hf : Continuous f)
    (hg : ∀ x ∈ Set.uIcc a b, HasDerivAt g (g' x) x) (hg' : ContinuousOn g' (Set.uIcc a b)) :
    ∫ x in a..b, f (g x) * g' x = ∫ u in g a..g b, f u := by
  -- η F(u) = ∫ f(t) dt από g(a) έως u έχει παράγωγο f(u)
  have hF : ∀ u, HasDerivAt (fun u => ∫ t in g a..u, f t) (f u) u :=
    fun u => (hf.integral_hasStrictDerivAt (g a) u).hasDerivAt
  -- κανόνας αλυσίδας: (F(g(x)))' = f(g(x)) g'(x)
  have hcomp : ∀ x ∈ Set.uIcc a b,
      HasDerivAt (fun x => ∫ t in g a..g x, f t) (f (g x) * g' x) x :=
    fun x hx => (hF (g x)).comp x (hg x hx)
  -- η f(g(x)) g'(x) είναι συνεχής, άρα ολοκληρώσιμη
  have hgc : ContinuousOn g (Set.uIcc a b) := fun x hx => (hg x hx).continuousAt.continuousWithinAt
  have hint : IntervalIntegrable (fun x => f (g x) * g' x) volume a b :=
    ((hf.comp_continuousOn hgc).mul hg').intervalIntegrable
  -- θεμελιώδες θεώρημα: το ολοκλήρωμα είναι F(g(b)) - F(g(a))
  rw [intervalIntegral.integral_eq_sub_of_hasDerivAt hcomp hint]
  -- F(g(a)) = 0, γιατί τα άκρα είναι ίσα
  rw [intervalIntegral.integral_same, sub_zero]

theorem shift (f : ℝ → ℝ) (a b c : ℝ) (hf : Continuous f) :
    ∫ x in a..b, f (x + c) = ∫ u in a + c..b + c, f u := by
  have h := subst_definite f (fun x => x + c) (fun _ => 1) a b hf
    (fun x _ => (hasDerivAt_id' x).add_const c) continuousOn_const
  simp only [mul_one] at h
  exact h
