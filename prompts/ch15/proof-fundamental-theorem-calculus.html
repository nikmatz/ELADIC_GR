Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Μέρος Α: αν η $f$ είναι συνεχής στο $[a,b]$, η $G(x)=\int_a^x f(t)\,dt$ έχει παράγωγο $f(x)$ σε κάθε $x\in(a,b)$
    theorem ftc_part_A (f : ℝ → ℝ) (a b : ℝ) (hf : ContinuousOn f (Set.Icc a b))
    (x : ℝ) (hx : x ∈ Set.Ioo a b) :
    HasDerivAt (fun u => ∫ t in a..u, f t) (f x) x
  • Μέρος Β (Newton–Leibniz): αν η $F$ είναι συνεχής στο $[a,b]$ με $F'=f$ στο $(a,b)$ και η $f$ είναι συνεχής στο $[a,b]$, τότε $\int_a^b f(x)\,dx=F(b)-F(a)$
    theorem ftc_part_B (f F : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hF : ContinuousOn F (Set.Icc a b))
    (hFf : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hf : ContinuousOn f (Set.Icc a b)) :
    ∫ x in a..b, f x = F b - F a

Η $G$ γράφεται fun u => ∫ t in a..u, f t, και η παράγωγος γράφεται με την HasDerivAt. Στο Μέρος Α δίνουμε την παράγωγο στα εσωτερικά σημεία του $[a,b]$· στα άκρα $a$ και $b$ η παράγωγος του βιβλίου είναι πλευρική. Στο Μέρος Β ζητάμε $F'(x)=f(x)$ μόνο στο ανοιχτό διάστημα $(a,b)$, μαζί με τη συνέχεια της $F$ στο $[a,b]$. Αυτή η υπόθεση είναι ασθενέστερη από την $F'=f$ σε όλο το $[a,b]$, άρα το αποτέλεσμα ισχύει και με τις υποθέσεις του βιβλίου. Και τα δύο μέρη υπάρχουν έτοιμα στη Mathlib.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • intervalIntegral.integral_hasDerivAt_right: η παράγωγος της $\int_a^x f(t)\,dt$ (Μέρος Α).
  • intervalIntegral.integral_eq_sub_of_hasDerivAt_of_le: ο τύπος Newton–Leibniz (Μέρος Β).
  • ContinuousOn.intervalIntegrable_of_Icc: συνεχής συνάρτηση στο $[a,b]$ είναι ολοκληρώσιμη.
  • ContinuousOn.stronglyMeasurableAtFilter: μια τεχνική συνθήκη μετρησιμότητας, που ισχύει για τις συνεχείς συναρτήσεις.
  • ContinuousOn.continuousAt: η $f$ είναι συνεχής σε κάθε εσωτερικό σημείο του $[a,b]$.

import Mathlib

namespace Κεφ15.ThemeliodesThewrima
open MeasureTheory

-- Μέρος Α: η G(x) = ∫ f(t) dt από a έως x έχει παράγωγο f(x) σε κάθε x ∈ (a, b)
theorem ftc_part_A (f : ℝ → ℝ) (a b : ℝ) (hf : ContinuousOn f (Set.Icc a b))
    (x : ℝ) (hx : x ∈ Set.Ioo a b) :
    HasDerivAt (fun u => ∫ t in a..u, f t) (f x) x := by
  have hint : IntervalIntegrable f volume a x :=
    (hf.mono (Set.Icc_subset_Icc le_rfl hx.2.le)).intervalIntegrable_of_Icc hx.1.le
  have hmeas : StronglyMeasurableAtFilter f (nhds x) volume :=
    (hf.mono Set.Ioo_subset_Icc_self).stronglyMeasurableAtFilter isOpen_Ioo x hx
  exact intervalIntegral.integral_hasDerivAt_right hint hmeas
    (hf.continuousAt (Icc_mem_nhds hx.1 hx.2))

-- Μέρος Β (Newton–Leibniz): αν F' = f, τότε το ολοκλήρωμα της f από a έως b είναι F(b) - F(a)
theorem ftc_part_B (f F : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b) (hF : ContinuousOn F (Set.Icc a b))
    (hFf : ∀ x ∈ Set.Ioo a b, HasDerivAt F (f x) x) (hf : ContinuousOn f (Set.Icc a b)) :
    ∫ x in a..b, f x = F b - F a :=
  intervalIntegral.integral_eq_sub_of_hasDerivAt_of_le hab hF hFf (hf.intervalIntegrable_of_Icc hab)

end Κεφ15.ThemeliodesThewrima
