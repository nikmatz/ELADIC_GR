1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν η $f$ είναι συνεχής και οι $a(x),b(x)$ παραγωγίσιμες, η $H(x)=\int_{a(x)}^{b(x)}f(t)\,dt$ έχει παράγωγο $H'(x)$${}=f\bigl(b(x)\bigr)b'(x)-f\bigl(a(x)\bigr)a'(x)$
    theorem leibniz (f a b a' b' : ℝ → ℝ) (hf : Continuous f)
    (ha : ∀ x, HasDerivAt a (a' x) x) (hb : ∀ x, HasDerivAt b (b' x) x) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x
  • Εφαρμογή: $\dfrac{d}{dx}\int_0^{x^2}f(t)\,dt$${}=f(x^2)\cdot 2x$
    theorem leibniz_square (f : ℝ → ℝ) (hf : Continuous f) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in (0 : ℝ)..x ^ 2, f t) (f (x ^ 2) * (2 * x)) x

Για απλότητα παίρνουμε την $f$ συνεχή σε όλο το $\mathbb{R}$, δηλαδή $I=\mathbb{R}$, και τις $a,b$ παραγωγίσιμες σε κάθε σημείο. Το ολοκλήρωμα με μεταβλητά άκρα γράφεται ∫ t in a x..b x, f t. Η απόδειξη είναι αυτή του βιβλίου: με $F(u)=\int_0^u f(t)\,dt$ ισχύει $H(x)$${}=F\bigl(b(x)\bigr)-F\bigl(a(x)\bigr)$, και ο κανόνας αλυσίδας δίνει την παράγωγο.

2. Βήμα προς βήμα: ο κανόνας Leibniz

Η ιδέα: γράφουμε την $H$ ως διαφορά δύο ολοκληρωμάτων με σταθερό κάτω άκρο $0$ και παραγωγίζουμε το καθένα με το θεμελιώδες θεώρημα και τον κανόνα αλυσίδας. Ξεκινάμε από τον στόχο:

Ο στόχος
f a b a' b' : ℝ → ℝ
hf : Continuous f
ha : ∀ (x : ℝ), HasDerivAt a (a' x) x
hb : ∀ (x : ℝ), HasDerivAt b (b' x) x
x : ℝ
⊢ HasDerivAt (fun x => ∫ (t : ℝ) in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- η F(u) = ∫ f(t) dt από 0 έως u έχει παράγωγο f(u) (θεμελιώδες θεώρημα)
have hF : ∀ u, HasDerivAt (fun u => ∫ t in (0 : ℝ)..u, f t) (f u) u :=
  fun u => (hf.integral_hasStrictDerivAt 0 u).hasDerivAt

    Θεμελιώδες θεώρημα (Continuous.integral_hasStrictDerivAt): η $F(u)=\int_0^u f(t)\,dt$ έχει παράγωγο $f(u)$ σε κάθε $u$.

    Τι μένει να αποδειχθεί
    hF : ∀ (u : ℝ), HasDerivAt (fun u => ∫ (t : ℝ) in 0..u, f t) (f u) u
⊢ HasDerivAt (fun x => ∫ (t : ℝ) in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x
  2. -- H(x) = F(b(x)) - F(a(x))
have hH : (fun x => ∫ t in a x..b x, f t) =
    fun x => (∫ t in (0 : ℝ)..b x, f t) - ∫ t in (0 : ℝ)..a x, f t := by

    Ισχυρισμός hH: $H(x)$${}=F\bigl(b(x)\bigr)-F\bigl(a(x)\bigr)$, δηλαδή οι δύο συναρτήσεις είναι ίσες.

    Τι μένει να αποδειχθεί
    ⊢ (fun x => ∫ (t : ℝ) in a x..b x, f t) = fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t
  3. funext y

    Δύο συναρτήσεις είναι ίσες όταν παίρνουν την ίδια τιμή σε κάθε σημείο $y$ (funext).

    Τι μένει να αποδειχθεί
    y : ℝ
⊢ ∫ (t : ℝ) in a y..b y, f t = (∫ (t : ℝ) in 0..b y, f t) - ∫ (t : ℝ) in 0..a y, f t
  4. rw [intervalIntegral.integral_interval_sub_left (hf.intervalIntegrable (μ := volume) 0 (b y))
  (hf.intervalIntegrable (μ := volume) 0 (a y))]

    Από την προσθετικότητα του ολοκληρώματος, $\int_0^{b(y)}f-\int_0^{a(y)}f$${}=\int_{a(y)}^{b(y)}f$ (intervalIntegral.integral_interval_sub_left). Η $f$ είναι συνεχής, άρα ολοκληρώσιμη σε κάθε διάστημα.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  5. rw [hH]

    Αντικαθιστούμε την $H$ με τη διαφορά $F\bigl(b(x)\bigr)-F\bigl(a(x)\bigr)$.

    Τι μένει να αποδειχθεί
    f a b a' b' : ℝ → ℝ
hf : Continuous f
ha : ∀ (x : ℝ), HasDerivAt a (a' x) x
hb : ∀ (x : ℝ), HasDerivAt b (b' x) x
x : ℝ
hF : ∀ (u : ℝ), HasDerivAt (fun u => ∫ (t : ℝ) in 0..u, f t) (f u) u
hH : (fun x => ∫ (t : ℝ) in a x..b x, f t) = fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t
⊢ HasDerivAt (fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t) (f (b x) * b' x - f (a x) * a' x) x
  6. -- κανόνας αλυσίδας για καθένα από τα δύο ολοκληρώματα
have h1 := (hF (b x)).comp x (hb x)

    Κανόνας αλυσίδας: η $F\bigl(b(x)\bigr)$ έχει παράγωγο $f\bigl(b(x)\bigr)\,b'(x)$. Η σύνθεση γράφεται με το σύμβολο ∘.

    Τι μένει να αποδειχθεί
    h1 : HasDerivAt ((fun u => ∫ (t : ℝ) in 0..u, f t) ∘ b) (f (b x) * b' x) x
⊢ HasDerivAt (fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t) (f (b x) * b' x - f (a x) * a' x) x
  7. have h2 := (hF (a x)).comp x (ha x)

    Ομοίως, η $F\bigl(a(x)\bigr)$ έχει παράγωγο $f\bigl(a(x)\bigr)\,a'(x)$.

    Τι μένει να αποδειχθεί
    h2 : HasDerivAt ((fun u => ∫ (t : ℝ) in 0..u, f t) ∘ a) (f (a x) * a' x) x
⊢ HasDerivAt (fun x => (∫ (t : ℝ) in 0..b x, f t) - ∫ (t : ℝ) in 0..a x, f t) (f (b x) * b' x - f (a x) * a' x) x
  8. exact h1.sub h2

    Κανόνας της διαφοράς: αφαιρούμε τις δύο παραγώγους.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: $\int_0^{x^2}f(t)\,dt$

Δείξε ότι η $H(x)=\int_0^{x^2}f(t)\,dt$ έχει παράγωγο $f(x^2)\cdot 2x$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Εφάρμοσε τον κανόνα με $a(x)=0$ και $b(x)=x^2$: have h := leibniz f (fun _ => 0) (fun x => x ^ 2) (fun _ => 0) (fun x => 2 * x) hf (fun x => hasDerivAt_const x 0) (fun x => by simpa using hasDerivAt_pow 2 x) x. Η h δίνει την παράγωγο $f(x^2)\cdot 2x-f(0)\cdot 0$· απλοποίησέ τη με simp only [mul_zero, sub_zero] at h και τελείωσε με exact h.

Λύση
theorem leibniz_square (f : ℝ → ℝ) (hf : Continuous f) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in (0 : ℝ)..x ^ 2, f t) (f (x ^ 2) * (2 * x)) x := by
  have h := leibniz f (fun _ => 0) (fun x => x ^ 2) (fun _ => 0) (fun x => 2 * x) hf
    (fun x => hasDerivAt_const x 0) (fun x => by simpa using hasDerivAt_pow 2 x) x
  simp only [mul_zero, sub_zero] at h
  exact h

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Continuous.integral_hasStrictDerivAt: το θεμελιώδες θεώρημα: η $\int_0^u f(t)\,dt$ έχει παράγωγο $f(u)$.
  • intervalIntegral.integral_interval_sub_left: $\int_0^{b}f-\int_0^{a}f=\int_a^b f$.
  • Continuous.intervalIntegrable: συνεχής συνάρτηση είναι ολοκληρώσιμη σε κάθε διάστημα.
  • HasDerivAt.comp: ο κανόνας αλυσίδας.
  • HasDerivAt.sub: ο κανόνας της διαφοράς.

import Mathlib

namespace Κεφ15.KanonasLeibniz
open MeasureTheory

theorem leibniz (f a b a' b' : ℝ → ℝ) (hf : Continuous f)
    (ha : ∀ x, HasDerivAt a (a' x) x) (hb : ∀ x, HasDerivAt b (b' x) x) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in a x..b x, f t) (f (b x) * b' x - f (a x) * a' x) x := by
  -- η F(u) = ∫ f(t) dt από 0 έως u έχει παράγωγο f(u) (θεμελιώδες θεώρημα)
  have hF : ∀ u, HasDerivAt (fun u => ∫ t in (0 : ℝ)..u, f t) (f u) u :=
    fun u => (hf.integral_hasStrictDerivAt 0 u).hasDerivAt
  -- H(x) = F(b(x)) - F(a(x))
  have hH : (fun x => ∫ t in a x..b x, f t) =
      fun x => (∫ t in (0 : ℝ)..b x, f t) - ∫ t in (0 : ℝ)..a x, f t := by
    funext y
    rw [intervalIntegral.integral_interval_sub_left (hf.intervalIntegrable (μ := volume) 0 (b y))
      (hf.intervalIntegrable (μ := volume) 0 (a y))]
  rw [hH]
  -- κανόνας αλυσίδας για καθένα από τα δύο ολοκληρώματα
  have h1 := (hF (b x)).comp x (hb x)
  have h2 := (hF (a x)).comp x (ha x)
  exact h1.sub h2

theorem leibniz_square (f : ℝ → ℝ) (hf : Continuous f) (x : ℝ) :
    HasDerivAt (fun x => ∫ t in (0 : ℝ)..x ^ 2, f t) (f (x ^ 2) * (2 * x)) x := by
  have h := leibniz f (fun _ => 0) (fun x => x ^ 2) (fun _ => 0) (fun x => 2 * x) hf
    (fun x => hasDerivAt_const x 0) (fun x => by simpa using hasDerivAt_pow 2 x) x
  simp only [mul_zero, sub_zero] at h
  exact h

end Κεφ15.KanonasLeibniz
