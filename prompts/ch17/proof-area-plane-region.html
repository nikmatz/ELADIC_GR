1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $f\ge g$ στο $[a,b]$, το εμβαδόν του χωρίου ανάμεσα στις $y=f(x)$ και $y=g(x)$ είναι $E$${}=\int_a^b\bigl[f(x)-g(x)\bigr]\,dx$
    theorem area_ordered (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b))
    (hgf : ∀ x ∈ Set.Icc a b, g x ≤ f x) :
    volume (regionBetween g f (Set.Icc a b)) = ENNReal.ofReal (∫ x in a..b, (f x - g x))
  • Αν οι καμπύλες αλλάζουν σχετική θέση, το εμβαδόν είναι $E$${}=\int_a^b\bigl|f(x)-g(x)\bigr|\,dx$, δηλαδή το άθροισμα των εμβαδών στα υποδιαστήματα
    theorem area_abs (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b)) :
    volume (regionBetween (fun x => min (f x) (g x)) (fun x => max (f x) (g x)) (Set.Icc a b)) =
      ENNReal.ofReal (∫ x in a..b, |f x - g x|)

Το εμβαδόν ενός χωρίου του επιπέδου είναι, στη Mathlib, το μέτρο Lebesgue του, volume. Το εμβαδόν είναι μη αρνητικός αριθμός ή $+\infty$ (τύπος ENNReal)· γι’ αυτό το ολοκλήρωμα γράφεται μέσα σε ENNReal.ofReal, που το μετατρέπει σε τέτοιον αριθμό. Όταν $f\ge g$, το χωρίο είναι το σύνολο regionBetween g f (Set.Icc a b) των σημείων $(x,y)$ με $x\in[a,b]$ και $g(x)\lt y\lt f(x)$. Όταν οι καμπύλες αλλάζουν σχετική θέση, το χωρίο βρίσκεται σε κάθε $x$ ανάμεσα στη μικρότερη και στη μεγαλύτερη από τις τιμές $f(x)$, $g(x)$, δηλαδή ανάμεσα στις $\min\{f(x),g(x)\}$ και $\max\{f(x),g(x)\}$. Επειδή $\max-\min=|f-g|$, το εμβαδόν είναι $\int_a^b|f-g|\,dx$· σε κάθε υποδιάστημα όπου οι καμπύλες δεν αλλάζουν θέση, αυτό είναι ακριβώς το ολοκλήρωμα του βιβλίου. Αν συμπεριλάβουμε και τις καμπύλες του συνόρου, το εμβαδόν δεν αλλάζει.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • volume_regionBetween_eq_integral: το εμβαδόν του χωρίου ανάμεσα σε δύο γραφικές παραστάσεις.
  • MeasureTheory.Measure.volume_eq_prod: το εμβαδόν στο επίπεδο είναι το γινόμενο των μέτρων μήκους στους δύο άξονες.
  • ContinuousOn.integrableOn_Icc: συνεχής συνάρτηση σε κλειστό διάστημα είναι ολοκληρώσιμη εκεί.
  • ContinuousOn.inf: η $\min\{f,g\}$ είναι συνεχής.
  • ContinuousOn.sup: η $\max\{f,g\}$ είναι συνεχής.
  • min_le_max: $\min\{u,v\}\le\max\{u,v\}$.
  • max_sub_min_eq_abs': $\max\{u,v\}-\min\{u,v\}=|u-v|$.
  • intervalIntegral.integral_of_le: για $a\le b$, το $\int_a^b$ είναι ολοκλήρωμα στο $(a,b]$.
  • MeasureTheory.integral_Icc_eq_integral_Ioc: τα ολοκληρώματα στα $[a,b]$ και $(a,b]$ είναι ίσα.

import Mathlib

namespace Κεφ17.EmvadonXwriou
open MeasureTheory

-- όταν f ≥ g: το εμβαδόν είναι το ολοκλήρωμα της f - g
theorem area_ordered (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b))
    (hgf : ∀ x ∈ Set.Icc a b, g x ≤ f x) :
    volume (regionBetween g f (Set.Icc a b)) = ENNReal.ofReal (∫ x in a..b, (f x - g x)) := by
  rw [Measure.volume_eq_prod, volume_regionBetween_eq_integral hg.integrableOn_Icc
    hf.integrableOn_Icc measurableSet_Icc hgf, intervalIntegral.integral_of_le hab,
    integral_Icc_eq_integral_Ioc]
  rfl

-- όταν οι καμπύλες αλλάζουν σχετική θέση: το εμβαδόν είναι το ολοκλήρωμα της |f - g|
theorem area_abs (f g : ℝ → ℝ) (a b : ℝ) (hab : a ≤ b)
    (hf : ContinuousOn f (Set.Icc a b)) (hg : ContinuousOn g (Set.Icc a b)) :
    volume (regionBetween (fun x => min (f x) (g x)) (fun x => max (f x) (g x)) (Set.Icc a b)) =
      ENNReal.ofReal (∫ x in a..b, |f x - g x|) := by
  rw [Measure.volume_eq_prod, volume_regionBetween_eq_integral (hf.inf hg).integrableOn_Icc
    (hf.sup hg).integrableOn_Icc measurableSet_Icc (fun x _ => min_le_max),
    intervalIntegral.integral_of_le hab, integral_Icc_eq_integral_Ioc]
  simp only [Pi.sub_apply, max_sub_min_eq_abs']

end Κεφ17.EmvadonXwriou
