1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Με $h=\dfrac{b-a}{n}$ και $x_i=a+ih$: $T_n$${}=\dfrac{h}{2}\bigl[f(x_0)$${}+2f(x_1)+\dots+2f(x_{n-1})$${}+f(x_n)\bigr]$
    theorem trapezoid_formula (f : ℝ → ℝ) (n : ℕ) (a b : ℝ) :
    trapezoidal_integral f n a b =
      (b - a) / n / 2 *
        (f a + 2 * ∑ k ∈ Finset.range (n - 1), f (a + (k + 1) * (b - a) / n) + f b)
  • $\Bigl|T_n-\int_a^b f(x)\,dx\Bigr|\le\dfrac{(b-a)^3}{12n^2}M_2$, όπου $|f''(x)|\le M_2$ στο $[a,b]$
    theorem trapezoid_error (f : ℝ → ℝ) (a b M : ℝ) (n : ℕ) (hn : 0 < n) (hab : a ≤ b)
    (hf : ContDiffOn ℝ 2 f (Set.Icc a b))
    (hM : ∀ x, |iteratedDerivWithin 2 f (Set.Icc a b) x| ≤ M) :
    |trapezoidal_integral f n a b - ∫ x in a..b, f x| ≤ (b - a) ^ 3 / (12 * n ^ 2) * M

Η Mathlib ορίζει τον κανόνα τραπεζίου ως trapezoidal_integral f n a b, με τη μορφή $T_n$${}=h\left[\dfrac{f(a)+f(b)}{2}+f(x_1)+\dots+f(x_{n-1})\right]$· το πρώτο θεώρημα δείχνει ότι αυτός είναι ο τύπος του βιβλίου. Στο άθροισμα ∑ k ∈ Finset.range (n - 1) το $k$ παίρνει τις τιμές $0,1,\dots,n-2$, και ο όρος $f\bigl(a+(k+1)\tfrac{b-a}{n}\bigr)$ είναι το $f(x_{k+1})$. Για το σφάλμα υποθέτουμε ότι η $f$ έχει συνεχή δεύτερη παράγωγο στο $[a,b]$ (ContDiffOn ℝ 2 f (Set.Icc a b)). Η δεύτερη παράγωγος υπολογίζεται μέσα στο διάστημα (iteratedDerivWithin 2 f (Set.Icc a b)), με πλευρικές παραγώγους στα άκρα, και το $M_2$ είναι άνω φράγμα της απόλυτης τιμής της. Η υπόθεση γράφεται για κάθε πραγματικό $x$, αλλά έξω από το $[a,b]$ αυτή η παράγωγος ορίζεται ίση με $0$, οπότε ουσιαστικά αφορά μόνο το $[a,b]$.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής από τη Mathlib:

  • trapezoidal_integral: ο ορισμός του $T_n$.
  • trapezoidal_error: ο ορισμός του σφάλματος $T_n-\int_a^b f(x)\,dx$.
  • trapezoidal_error_le_of_c2: το φράγμα του σφάλματος, για συνάρτηση με συνεχή δεύτερη παράγωγο.
  • Set.uIcc_of_le: για $a\le b$, το διάστημα με άκρα $a$ και $b$ είναι το $[a,b]$.

import Mathlib

namespace Κεφ17.KanonasTrapeziou

-- ο ορισμός της Mathlib, με h = (b - a)/n, γράφεται όπως στο βιβλίο:
-- T_n = (h/2) (f(x₀) + 2 f(x₁) + … + 2 f(x_{n-1}) + f(xₙ))
theorem trapezoid_formula (f : ℝ → ℝ) (n : ℕ) (a b : ℝ) :
    trapezoidal_integral f n a b =
      (b - a) / n / 2 *
        (f a + 2 * ∑ k ∈ Finset.range (n - 1), f (a + (k + 1) * (b - a) / n) + f b) := by
  unfold trapezoidal_integral
  ring

-- φράγμα του σφάλματος: |T_n - ∫ f| ≤ (b - a)³ M₂ / (12 n²)
theorem trapezoid_error (f : ℝ → ℝ) (a b M : ℝ) (n : ℕ) (hn : 0 < n) (hab : a ≤ b)
    (hf : ContDiffOn ℝ 2 f (Set.Icc a b))
    (hM : ∀ x, |iteratedDerivWithin 2 f (Set.Icc a b) x| ≤ M) :
    |trapezoidal_integral f n a b - ∫ x in a..b, f x| ≤ (b - a) ^ 3 / (12 * n ^ 2) * M := by
  rw [← Set.uIcc_of_le hab] at hf hM
  have h := trapezoidal_error_le_of_c2 hf hM hn
  rw [abs_of_nonneg (sub_nonneg.mpr hab)] at h
  unfold trapezoidal_error at h
  calc _ ≤ (b - a) ^ 3 * M / (12 * n ^ 2) := h
    _ = (b - a) ^ 3 / (12 * n ^ 2) * M := by ring

end Κεφ17.KanonasTrapeziou
