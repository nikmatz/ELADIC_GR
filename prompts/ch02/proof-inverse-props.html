1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $(A^{-1})^{-1}=A$
    theorem inv_of_inv (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) : A⁻¹⁻¹ = A
  • $(AB)^{-1}=B^{-1}A^{-1}$
    theorem inv_of_mul (A B : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (hB : B.det ≠ 0) :
    (A * B)⁻¹ = B⁻¹ * A⁻¹
  • $(A^{T})^{-1}=(A^{-1})^{T}$
    theorem inv_of_transpose (A : Matrix (Fin n) (Fin n) ℝ) : Aᵀ⁻¹ = A⁻¹ᵀ
  • $\det(A^{-1})=\dfrac{1}{\det(A)}$
    theorem det_of_inv (A : Matrix (Fin n) (Fin n) ℝ) : A⁻¹.det = 1 / A.det
  • $(\lambda A)^{-1}$${}=\dfrac{1}{\lambda}A^{-1}$
    theorem inv_of_smul (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (c : ℝ) (hc : c ≠ 0) :
    (c • A)⁻¹ = (1 / c) • A⁻¹
  • Αν ο $A$ είναι διαγώνιος με $a_{ii}\ne 0$, ο $A^{-1}$ είναι διαγώνιος με στοιχεία $\dfrac{1}{a_{ii}}$
    theorem inv_of_diagonal (d : Fin n → ℝ) (h : ∀ i, d i ≠ 0) :
    (diagonal d)⁻¹ = diagonal (fun i => 1 / d i)

Ο $A$ είναι αντιστρέψιμος όταν $\det A\neq 0$, και αυτή είναι η υπόθεση hA : A.det ≠ 0. Το hA.isUnit γράφει το $\det A\neq 0$ στη μορφή που ζητούν τα θεωρήματα της Mathlib. Ο αντίστροφος γράφεται A⁻¹ και ο ανάστροφος Aᵀ. Οι τύποι $(A^{T})^{-1}=(A^{-1})^{T}$ και $\det(A^{-1})=\frac{1}{\det(A)}$ ισχύουν στον Lean χωρίς υπόθεση: όταν $\det A=0$, η Mathlib ορίζει $A^{-1}=0$ και τα δύο μέλη συμπίπτουν.

2. Βήμα προς βήμα: $(AB)^{-1}=B^{-1}A^{-1}$

Όπως στο βιβλίο, όλες οι ιδιότητες βγαίνουν από τη μοναδικότητα του αντιστρόφου: για να δείξουμε ότι ένας πίνακας είναι ο αντίστροφος του $M$, αρκεί να δείξουμε ότι το γινόμενο του $M$ με αυτόν δίνει $I$. Ξεκινάμε από τον στόχο:

Ο στόχος
n : ℕ
A B : Matrix (Fin n) (Fin n) ℝ
hA : A.det ≠ 0
hB : B.det ≠ 0
⊢ (A * B)⁻¹ = B⁻¹ * A⁻¹

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. apply inv_eq_right_inv

    Αρκεί να δείξουμε ότι $(AB)(B^{-1}A^{-1})=I$: τότε ο $B^{-1}A^{-1}$ είναι ο αντίστροφος του $AB$ (θεώρημα Matrix.inv_eq_right_inv).

    Τι μένει να αποδειχθεί
    ⊢ A * B * (B⁻¹ * A⁻¹) = 1
  2. rw [Matrix.mul_assoc]

    Προσεταιριστική ιδιότητα: $(AB)(B^{-1}A^{-1})$${}=A\,\big(B\,(B^{-1}A^{-1})\big)$.

    Τι μένει να αποδειχθεί
    ⊢ A * (B * (B⁻¹ * A⁻¹)) = 1
  3. rw [← Matrix.mul_assoc B]

    Ξανά προσεταιριστική, μέσα στην παρένθεση: $B\,(B^{-1}A^{-1})$${}=(BB^{-1})\,A^{-1}$.

    Τι μένει να αποδειχθεί
    ⊢ A * (B * B⁻¹ * A⁻¹) = 1
  4. rw [mul_nonsing_inv B hB.isUnit]

    Αφού $\det B\neq 0$, ισχύει $BB^{-1}=I$.

    Τι μένει να αποδειχθεί
    ⊢ A * (1 * A⁻¹) = 1
  5. rw [Matrix.one_mul]

    Ισχύει $IA^{-1}=A^{-1}$.

    Τι μένει να αποδειχθεί
    ⊢ A * A⁻¹ = 1
  6. exact mul_nonsing_inv A hA.isUnit

    Αφού $\det A\neq 0$, ισχύει $AA^{-1}=I$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: $(A^{-1})^{-1}=A$

Με την ίδια μέθοδο: δείξε ότι ο $A$ είναι ο αντίστροφος του $A^{-1}$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ξεκίνα με apply inv_eq_right_inv. Ο στόχος γίνεται $A^{-1}A=I$, που είναι το nonsing_inv_mul A hA.isUnit.

Λύση
theorem inv_of_inv (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) : A⁻¹⁻¹ = A := by
  apply inv_eq_right_inv
  exact nonsing_inv_mul A hA.isUnit

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Matrix.inv_eq_right_inv: αν $AB=I$, τότε $A^{-1}=B$.
  • Matrix.mul_nonsing_inv: $AA^{-1}=I$ όταν $\det A\neq 0$.
  • Matrix.nonsing_inv_mul: $A^{-1}A=I$ όταν $\det A\neq 0$.
  • Matrix.transpose_nonsing_inv: $(A^{-1})^{T}=(A^{T})^{-1}$.
  • Matrix.det_nonsing_inv: η ορίζουσα του $A^{-1}$.

import Mathlib

namespace Κεφ2.IdiotitesAntistrofou
open Matrix

variable {n : ℕ}

theorem inv_of_inv (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) : A⁻¹⁻¹ = A := by
  apply inv_eq_right_inv
  exact nonsing_inv_mul A hA.isUnit

theorem inv_of_mul (A B : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (hB : B.det ≠ 0) :
    (A * B)⁻¹ = B⁻¹ * A⁻¹ := by
  apply inv_eq_right_inv
  rw [Matrix.mul_assoc]
  rw [← Matrix.mul_assoc B]
  rw [mul_nonsing_inv B hB.isUnit]
  rw [Matrix.one_mul]
  exact mul_nonsing_inv A hA.isUnit

theorem inv_of_transpose (A : Matrix (Fin n) (Fin n) ℝ) : Aᵀ⁻¹ = A⁻¹ᵀ :=
  (transpose_nonsing_inv A).symm

theorem det_of_inv (A : Matrix (Fin n) (Fin n) ℝ) : A⁻¹.det = 1 / A.det := by
  rw [det_nonsing_inv, Ring.inverse_eq_inv, one_div]

theorem inv_of_smul (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.det ≠ 0) (c : ℝ) (hc : c ≠ 0) :
    (c • A)⁻¹ = (1 / c) • A⁻¹ := by
  apply inv_eq_right_inv
  rw [Matrix.smul_mul, Matrix.mul_smul, smul_smul, one_div, mul_inv_cancel₀ hc, one_smul,
    mul_nonsing_inv A hA.isUnit]

theorem inv_of_diagonal (d : Fin n → ℝ) (h : ∀ i, d i ≠ 0) :
    (diagonal d)⁻¹ = diagonal (fun i => 1 / d i) := by
  apply inv_eq_right_inv
  rw [diagonal_mul_diagonal, ← diagonal_one]
  congr 1
  funext i
  rw [mul_one_div_cancel (h i)]

end Κεφ2.IdiotitesAntistrofou
