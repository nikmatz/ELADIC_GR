1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

    (C : Matrix (Fin p) (Fin q) ℝ) : (A * B) * C = A * (B * C)
  • $A(B+C)=AB+AC$

    A * (B + C) = A * B + A * C
  • $(A+B)C=AC+BC$

    (A + B) * C = A * C + B * C
  • $\lambda(AB)=(\lambda A)B$

    (A * B)ᵀ = Bᵀ * Aᵀ

Οι διαστάσεις είναι γενικές: ο A είναι $m\times n$, ο B είναι $n\times p$ και ο C είναι $p\times q$, ώστε να ορίζονται τα γινόμενα. Το στοιχείο $(MN)_{ij}$ γράφεται (M * N) i j και το $\sum_k$ γράφεται ∑ k. Ο μοναδιαίος πίνακας είναι το 1 και ο ανάστροφος το Aᵀ. Τις επιμεριστικές ιδιότητες και τις ιδιότητες του $I$ τις παίρνουμε έτοιμες από τη Mathlib.

2. Βήμα προς βήμα: $(AB)C=A(BC)$

Η προσεταιριστική ιδιότητα θέλει χειρισμό διπλών αθροισμάτων. Η ιδέα: και τα δύο μέλη δίνουν στη θέση $(i,l)$ το $\sum_j\sum_k a_{ij}b_{jk}c_{kl}$. Ξεκινάμε από τον στόχο:

Ο στόχος
m n p q : ℕ
A : Matrix (Fin m) (Fin n) ℝ
B : Matrix (Fin n) (Fin p) ℝ
C : Matrix (Fin p) (Fin q) ℝ
⊢ A * B * C = A * (B * C)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. ext i l

    Συγκρίνουμε τα στοιχεία στη θέση $(i,l)$.

    Τι μένει να αποδειχθεί
    i : Fin m
l : Fin q
⊢ (A * B * C) i l = (A * (B * C)) i l
  2. simp only [Matrix.mul_apply]

    Ο ορισμός του γινομένου: $(MN)_{ij}=\sum_k m_{ik}n_{kj}$. Αριστερά βγαίνει $\sum_k\big(\sum_j a_{ij}b_{jk}\big)c_{kl}$ και δεξιά $\sum_j a_{ij}\sum_k b_{jk}c_{kl}$. Ο Lean δίνει δικά του ονόματα στους δείκτες άθροισης.

    Τι μένει να αποδειχθεί
    ⊢ ∑ j, (∑ j_1, A i j_1 * B j_1 j) * C j l = ∑ j, A i j * ∑ j_1, B j j_1 * C j_1 l
  3. simp only [Finset.sum_mul, Finset.mul_sum]

    Βάζουμε τους πολλαπλασιαστές μέσα στα αθροίσματα (επιμεριστική ιδιότητα). Αριστερά: $\sum_k\sum_j a_{ij}b_{jk}c_{kl}$. Δεξιά: $\sum_j\sum_k a_{ij}(b_{jk}c_{kl})$.

    Τι μένει να αποδειχθεί
    ⊢ ∑ x, ∑ i_1, A i i_1 * B i_1 x * C x l = ∑ x, ∑ i_1, A i x * (B x i_1 * C i_1 l)
  4. rw [Finset.sum_comm]

    Αλλάζουμε τη σειρά των δύο αθροισμάτων στο αριστερό μέλος (θεώρημα Finset.sum_comm). Τώρα και τα δύο μέλη αθροίζουν πρώτα ως προς $j$ και μετά ως προς $k$.

    Τι μένει να αποδειχθεί
    ⊢ ∑ y, ∑ x, A i y * B y x * C x l = ∑ x, ∑ i_1, A i x * (B x i_1 * C i_1 l)
  5. refine Finset.sum_congr rfl (fun j _ => Finset.sum_congr rfl (fun k _ => ?_))

    Αρκεί οι όροι να είναι ίσοι ένας προς έναν, για κάθε $j$ και $k$ (θεώρημα Finset.sum_congr).

    Τι μένει να αποδειχθεί
    j : Fin n
x✝¹ : j ∈ Finset.univ
k : Fin p
x✝ : k ∈ Finset.univ
⊢ A i j * B j k * C k l = A i j * (B j k * C k l)
  6. ring

    Μένει η προσεταιριστική ιδιότητα των πραγματικών αριθμών.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: $(AB)^{T}=B^{T}A^{T}$

Η απόδειξη είναι στοιχείο προς στοιχείο, με τον ορισμό του γινομένου. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ξεκίνα με ext i j και ξεδίπλωσε τους ορισμούς με rw [Matrix.transpose_apply, Matrix.mul_apply, Matrix.mul_apply]. Δείξε ότι τα δύο αθροίσματα έχουν ίσους όρους με refine Finset.sum_congr rfl (fun k _ => ?_) και τελείωσε με rw [Matrix.transpose_apply, Matrix.transpose_apply, mul_comm].

Λύση
theorem transpose_of_mul (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ) :

  rw [Matrix.transpose_apply, Matrix.mul_apply, Matrix.mul_apply]

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Matrix.mul_apply: ο ορισμός του γινομένου: $(MN)_{ij}=\sum_k m_{ik}n_{kj}$.
  • Finset.sum_comm: αλλαγή της σειράς δύο αθροισμάτων.
  • Matrix.mul_assoc: η προσεταιριστική ιδιότητα, έτοιμη στη Mathlib.
  • Matrix.transpose_mul: $(AB)^{T}=B^{T}A^{T}$, έτοιμο στη Mathlib.

import Mathlib

namespace Κεφ2.GinomenoPinakon
open Matrix

variable {m n p q : ℕ}

theorem mul_associates (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ)
    (C : Matrix (Fin p) (Fin q) ℝ) : (A * B) * C = A * (B * C) := by
  ext i l
  simp only [Matrix.mul_apply]
  simp only [Finset.sum_mul, Finset.mul_sum]
  rw [Finset.sum_comm]
  refine Finset.sum_congr rfl (fun j _ => Finset.sum_congr rfl (fun k _ => ?_))
  ring

theorem mul_distrib_left (A : Matrix (Fin m) (Fin n) ℝ) (B C : Matrix (Fin n) (Fin p) ℝ) :
    A * (B + C) = A * B + A * C :=
  Matrix.mul_add A B C

theorem mul_distrib_right (A B : Matrix (Fin m) (Fin n) ℝ) (C : Matrix (Fin n) (Fin p) ℝ) :
    (A + B) * C = A * C + B * C :=
  Matrix.add_mul A B C

theorem smul_mul_left (c : ℝ) (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ) :
    c • (A * B) = (c • A) * B :=
  (Matrix.smul_mul c A B).symm

theorem smul_mul_right (c : ℝ) (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ) :
    c • (A * B) = A * (c • B) :=
  (Matrix.mul_smul A c B).symm

theorem mul_identity (A : Matrix (Fin m) (Fin n) ℝ) :
    A * (1 : Matrix (Fin n) (Fin n) ℝ) = A ∧ (1 : Matrix (Fin m) (Fin m) ℝ) * A = A :=
  ⟨Matrix.mul_one A, Matrix.one_mul A⟩

theorem transpose_of_mul (A : Matrix (Fin m) (Fin n) ℝ) (B : Matrix (Fin n) (Fin p) ℝ) :
    (A * B)ᵀ = Bᵀ * Aᵀ := by
  ext i j
  rw [Matrix.transpose_apply, Matrix.mul_apply, Matrix.mul_apply]
  refine Finset.sum_congr rfl (fun k _ => ?_)
  rw [Matrix.transpose_apply, Matrix.transpose_apply, mul_comm]

end Κεφ2.GinomenoPinakon
