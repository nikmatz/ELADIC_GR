Θεώρημα Rank–Nullity για Πίνακες

Κεφάλαιο 2 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΓια $A\in\mathcal{M}_{m\times n}(\mathbb{R})$ με $\operatorname{rank}(A)=r$: $\dim\mathcal{R}(A)$${}=\dim\mathcal{C}(A)$${}=r$, $\dim\mathcal{N}(A)=n-r$, $\dim\mathcal{N}(A^{T})=m-r$, και επομένως $\operatorname{rank}(A)+\dim\mathcal{N}(A)$${}=n$ και $\operatorname{rank}(A)+\dim\mathcal{N}(A^{T})$${}=m$. Επιπλέον $\mathcal{C}(A)\perp\mathcal{N}(A^{T})$ στο $\mathbb{R}^m$ και $\mathcal{R}(A)\perp\mathcal{N}(A)$ στο $\mathbb{R}^n$.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $\dim\mathcal{R}(A)$${}=\dim\mathcal{C}(A)$${}=r$: ο $A^{T}$ έχει τον ίδιο βαθμό με τον $A$
    theorem row_rank_eq_col_rank (A : Matrix (Fin m) (Fin n) ℝ) : Aᵀ.rank = A.rank
  • $\operatorname{rank}(A)+\dim\mathcal{N}(A)$${}=n$, άρα $\dim\mathcal{N}(A)=n-r$
    theorem rank_nullity (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n
  • $\operatorname{rank}(A)+\dim\mathcal{N}(A^{T})$${}=m$, άρα $\dim\mathcal{N}(A^{T})=m-r$
    theorem rank_nullity_transpose (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker Aᵀ.mulVecLin) = m
  • $\mathcal{C}(A)\perp\mathcal{N}(A^{T})$ στον $\mathbb{R}^m$
    theorem col_perp_null_transpose (A : Matrix (Fin m) (Fin n) ℝ) (v : Fin n → ℝ) (w : Fin m → ℝ)
    (hw : Aᵀ *ᵥ w = 0) : (A *ᵥ v) ⬝ᵥ w = 0
  • $\mathcal{R}(A)\perp\mathcal{N}(A)$ στον $\mathbb{R}^n$
    theorem row_perp_null (A : Matrix (Fin m) (Fin n) ℝ) (v : Fin n → ℝ) (w : Fin m → ℝ)
    (hv : A *ᵥ v = 0) : (Aᵀ *ᵥ w) ⬝ᵥ v = 0

Ο βαθμός γράφεται A.rank και στη Mathlib είναι η διάσταση του χώρου στηλών. Ο χώρος γραμμών του $A$ είναι ο χώρος στηλών του $A^{T}$, οπότε η ισότητα $\dim\mathcal{R}(A)$${}=\dim\mathcal{C}(A)$ είναι η Aᵀ.rank = A.rank. Ο μηδενοχώρος $\mathcal{N}(A)$ είναι ο πυρήνας της απεικόνισης $x\mapsto Ax$, το LinearMap.ker A.mulVecLin, και η διάστασή του γράφεται με το finrank ℝ. Για την καθετότητα: κάθε διάνυσμα του $\mathcal{C}(A)$ έχει τη μορφή $Av$, κάθε διάνυσμα του $\mathcal{R}(A)$ τη μορφή $A^{T}w$, και το εσωτερικό γινόμενο γράφεται ⬝ᵥ.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Matrix.rank_transpose: $\operatorname{rank}(A^{T})$${}=\operatorname{rank}(A)$.
  • Matrix.finrank_range_mulVecLin: ο βαθμός είναι η διάσταση της εικόνας της $x\mapsto Ax$.
  • LinearMap.finrank_range_add_finrank_ker: το θεώρημα τάξης-μηδενοχώρου.
  • Matrix.dotProduct_mulVec: $v\cdot(Aw)=(v^{T}A)\cdot w$.
  • Matrix.mulVec_transpose: $A^{T}x=x^{T}A$.

import Mathlib

namespace Κεφ2.TaksiMidenoxoros
open Matrix Module

variable {m n : ℕ}

theorem row_rank_eq_col_rank (A : Matrix (Fin m) (Fin n) ℝ) : Aᵀ.rank = A.rank :=
  rank_transpose A

theorem rank_nullity (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker A.mulVecLin) = n := by
  rw [← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker, finrank_fin_fun]

theorem rank_nullity_transpose (A : Matrix (Fin m) (Fin n) ℝ) :
    A.rank + finrank ℝ (LinearMap.ker Aᵀ.mulVecLin) = m := by
  rw [← rank_transpose A, ← finrank_range_mulVecLin, LinearMap.finrank_range_add_finrank_ker,
    finrank_fin_fun]

theorem col_perp_null_transpose (A : Matrix (Fin m) (Fin n) ℝ) (v : Fin n → ℝ) (w : Fin m → ℝ)
    (hw : Aᵀ *ᵥ w = 0) : (A *ᵥ v) ⬝ᵥ w = 0 := by
  rw [dotProduct_comm, dotProduct_mulVec, ← mulVec_transpose, hw, zero_dotProduct]

theorem row_perp_null (A : Matrix (Fin m) (Fin n) ℝ) (v : Fin n → ℝ) (w : Fin m → ℝ)
    (hv : A *ᵥ v = 0) : (Aᵀ *ᵥ w) ⬝ᵥ v = 0 := by
  rw [mulVec_transpose, ← dotProduct_mulVec, hv, dotProduct_zero]

end Κεφ2.TaksiMidenoxoros
