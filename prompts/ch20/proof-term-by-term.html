1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Για $|x-x_0|\lt R$ η παραγωγισμένη σειρά $\sum_{n=1}^{\infty}n\,c_n(x-x_0)^{n-1}$ συγκλίνει

    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    Summable (fun n => (n + 1) * c (n + 1) * (x - x₀) ^ n)
  • Για $|x-x_0|\lt R$: $f'(x)$${}=\sum_{n=1}^{\infty}n\,c_n(x-x_0)^{n-1}$

    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    HasDerivAt (fun y => ∑' n, c n * (y - x₀) ^ n)
      (∑' n, (n + 1) * c (n + 1) * (x - x₀) ^ n) x
  • Για $|x-x_0|\lt R$ η ολοκληρωμένη σειρά $\sum_{n=0}^{\infty}\dfrac{c_n}{n+1}(x-x_0)^{n+1}$ συγκλίνει απολύτως

    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    Summable (fun n => |c n / (n + 1) * (x - x₀) ^ (n + 1)|)
  • Για $|x-x_0|\lt R$ η $G(x)$${}=\sum_{n=0}^{\infty}\dfrac{c_n}{n+1}(x-x_0)^{n+1}$ έχει παράγωγο $f(x)$, δηλαδή $\int f(x)\,dx=C+G(x)$
    theorem integral_term_by_term (c : ℕ → ℝ) (x₀ x : ℝ)
    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    HasDerivAt (fun y => ∑' n, c n / (n + 1) * (y - x₀) ^ (n + 1))
      (∑' n, c n * (x - x₀) ^ n) x

Η σειρά δυνάμεων $\sum c_n y^n$ και η ακτίνα σύγκλισής της $R$ γράφονται όπως στον τύπο Cauchy–Hadamard: FormalMultilinearSeries.ofScalars ℝ c και .radius, με $y=x-x_0$ και το $|x-x_0|$ ως ‖x - x₀‖ₑ. Η $f(x)$${}=\sum_{n=0}^{\infty}c_n(x-x_0)^n$ γράφεται fun y => ∑' n, c n * (y - x₀) ^ n. Η παραγωγισμένη σειρά γράφεται με αρίθμηση από το $0$, ως $\sum_{n=0}^{\infty}(n+1)\,c_{n+1}(x-x_0)^n$, που είναι η $\sum_{n=1}^{\infty}n\,c_n(x-x_0)^{n-1}$ του βιβλίου. Το $\int f(x)\,dx=C+G(x)$ σημαίνει ότι η $G$ είναι αντιπαράγωγος της $f$, δηλαδή ότι $G'(x)=f(x)$, και έτσι διατυπώνεται. Η παραγώγιση χρησιμοποιεί το θεώρημα της Mathlib για σειρές δυνάμεων. Η ολοκλήρωση αποδεικνύεται με παραγώγιση όρο προς όρο στο διάστημα $|y-x_0|\lt r$, για κάποιο $r$ με $|x-x_0|\lt r\lt R$, όπου οι παράγωγοι των όρων φράσσονται από τους όρους $|c_n|\,r^n$ μιας συγκλίνουσας σειράς. Ότι οι δύο νέες σειρές συγκλίνουν για $|x-x_0|\lt R$ σημαίνει ότι η ακτίνα σύγκλισής τους είναι τουλάχιστον $R$· ότι είναι ακριβώς $R$, δηλαδή ότι αποκλίνουν για $|x-x_0|\gt R$, δεν διατυπώνεται εδώ.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • FormalMultilinearSeries.hasDerivAt_sum: η παράγωγος του αθροίσματος μιας σειράς δυνάμεων, όρο προς όρο.
  • FormalMultilinearSeries.derivSeries_coeff_one: οι συντελεστές της παραγωγισμένης σειράς είναι $(n+1)\,c_{n+1}$.
  • FormalMultilinearSeries.radius_le_radius_derivSeries: η παραγωγισμένη σειρά έχει ακτίνα τουλάχιστον $R$.
  • FormalMultilinearSeries.ofScalars_apply_eq: ο $n$-οστός όρος της σειράς είναι $c_n y^n$.
  • HasDerivAt.comp_sub_const: η μετατόπιση $y=x-x_0$ δεν αλλάζει την παράγωγο.
  • FormalMultilinearSeries.summable_norm_mul_pow: για $r\lt R$ η $\sum|c_n|\,r^n$ συγκλίνει.
  • ENNReal.lt_iff_exists_nnreal_btwn: ανάμεσα στο $|x-x_0|$ και στο $R$ υπάρχει πραγματικός $r$.
  • hasDerivAt_tsum_of_isPreconnected: παραγώγιση σειράς συναρτήσεων όρο προς όρο σε διάστημα, όταν οι παράγωγοι των όρων φράσσονται από τους όρους συγκλίνουσας σειράς.
  • hasDerivAt_pow: η παράγωγος του $y^{n+1}$ είναι $(n+1)\,y^n$.

import Mathlib

namespace Κεφ20.OroProsOro
open Filter Topology
open scoped NNReal ENNReal

-- f(x) = Σ cₙ (x - x₀)ⁿ, και R η ακτίνα σύγκλισης της σειράς δυνάμεων Σ cₙ yⁿ
-- η παραγωγισμένη σειρά Σ (n + 1) cₙ₊₁ (x - x₀)ⁿ, δηλαδή Σ n cₙ (x - x₀)ⁿ⁻¹, συγκλίνει
theorem deriv_series_summable (c : ℕ → ℝ) (x₀ x : ℝ)
    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    Summable (fun n => (n + 1) * c (n + 1) * (x - x₀) ^ n) := by
  set p := FormalMultilinearSeries.ofScalars ℝ c with hp
  have hs : Summable fun n => (x - x₀) ^ n • p.derivSeries.coeff n := by
    simpa using p.derivSeries.summable <|
      Metric.eball_subset_eball p.radius_le_radius_derivSeries <| by simpa using hx
  have h1 := (ContinuousLinearMap.apply ℝ ℝ (1 : ℝ)).summable hs
  simp only [ContinuousLinearMap.apply_apply, smul_apply,
    FormalMultilinearSeries.derivSeries_coeff_one, hp, FormalMultilinearSeries.coeff_ofScalars,
    smul_eq_mul, nsmul_eq_mul] at h1
  refine h1.congr fun n => ?_
  push_cast
  ring

-- παραγώγιση όρο προς όρο: f'(x) = Σ (n + 1) cₙ₊₁ (x - x₀)ⁿ
theorem deriv_term_by_term (c : ℕ → ℝ) (x₀ x : ℝ)
    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    HasDerivAt (fun y => ∑' n, c n * (y - x₀) ^ n)
      (∑' n, (n + 1) * c (n + 1) * (x - x₀) ^ n) x := by
  have h := (FormalMultilinearSeries.ofScalars ℝ c).hasDerivAt_sum hx
  -- το άθροισμα της σειράς δυνάμεων στο y είναι Σ cₙ yⁿ
  have hsum : (FormalMultilinearSeries.ofScalars ℝ c).sum = fun y => ∑' n, c n * y ^ n := by
    funext y
    simp only [FormalMultilinearSeries.sum, FormalMultilinearSeries.ofScalars_apply_eq, smul_eq_mul]
  rw [hsum] at h
  -- μετατόπιση: y = x - x₀
  have h2 := h.comp_sub_const x x₀
  convert h2 using 1
  refine tsum_congr fun n => ?_
  simp only [FormalMultilinearSeries.coeff_ofScalars, smul_eq_mul, nsmul_eq_mul]
  push_cast
  ring

-- η ολοκληρωμένη σειρά Σ cₙ/(n + 1) (x - x₀)ⁿ⁺¹ συγκλίνει απολύτως
theorem integral_series_summable (c : ℕ → ℝ) (x₀ x : ℝ)
    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    Summable (fun n => |c n / (n + 1) * (x - x₀) ^ (n + 1)|) := by
  have h := (FormalMultilinearSeries.ofScalars ℝ c).summable_norm_mul_pow hx
  simp only [FormalMultilinearSeries.ofScalars_norm, coe_nnNorm, Real.norm_eq_abs] at h
  refine Summable.of_nonneg_of_le (fun n => abs_nonneg _) (fun n => ?_) (h.mul_left |x - x₀|)
  -- |cₙ/(n + 1)| |x - x₀|ⁿ⁺¹ ≤ |x - x₀| · |cₙ| |x - x₀|ⁿ
  have h1 : |(n : ℝ) + 1| = (n : ℝ) + 1 := abs_of_pos (by positivity)
  have h2 : |c n| / ((n : ℝ) + 1) ≤ |c n| :=
    div_le_self (abs_nonneg _) (by linarith [(Nat.cast_nonneg n : (0 : ℝ) ≤ n)])
  rw [abs_mul, abs_div, abs_pow, h1, pow_succ]
  calc |c n| / ((n : ℝ) + 1) * (|x - x₀| ^ n * |x - x₀|)
      ≤ |c n| * (|x - x₀| ^ n * |x - x₀|) := mul_le_mul_of_nonneg_right h2 (by positivity)
    _ = |x - x₀| * (|c n| * |x - x₀| ^ n) := by ring

-- ολοκλήρωση όρο προς όρο: η G(x) = Σ cₙ/(n + 1) (x - x₀)ⁿ⁺¹ έχει παράγωγο f(x)
theorem integral_term_by_term (c : ℕ → ℝ) (x₀ x : ℝ)
    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    HasDerivAt (fun y => ∑' n, c n / (n + 1) * (y - x₀) ^ (n + 1))
      (∑' n, c n * (x - x₀) ^ n) x := by
  -- διαλέγουμε r με |x - x₀| < r < R
  obtain ⟨r, hr1, hr2⟩ := ENNReal.lt_iff_exists_nnreal_btwn.mp hx
  have hxr : |x - x₀| < r := by
    have h : ‖x - x₀‖₊ < r := ENNReal.coe_lt_coe.mp hr1
    rw [← Real.norm_eq_abs, ← coe_nnNorm]
    exact_mod_cast h
  -- η σειρά Σ |cₙ| rⁿ συγκλίνει, γιατί r < R
  have hu : Summable (fun n => |c n| * (r : ℝ) ^ n) := by
    have h := (FormalMultilinearSeries.ofScalars ℝ c).summable_norm_mul_pow hr2
    simpa using h
  -- παραγωγίζουμε όρο προς όρο στο διάστημα |y - x₀| < r
  refine hasDerivAt_tsum_of_isPreconnected (g := fun n y => c n / (n + 1) * (y - x₀) ^ (n + 1))
    (g' := fun n y => c n * (y - x₀) ^ n) hu Metric.isOpen_ball
    (convex_ball x₀ r).isPreconnected (fun n y _ => ?_) (fun n y hy => ?_)
    (Metric.mem_ball_self (lt_of_le_of_lt (abs_nonneg _) hxr)) ?_ ?_
  · -- κάθε όρος cₙ/(n + 1) (y - x₀)ⁿ⁺¹ έχει παράγωγο cₙ (y - x₀)ⁿ
    have h := ((hasDerivAt_pow (n + 1) (y - x₀)).comp_sub_const y x₀).const_mul (c n / (n + 1))
    convert h using 1
    rw [Nat.add_sub_cancel, Nat.cast_add, Nat.cast_one, ← mul_assoc,
      div_mul_cancel₀ _ (by positivity : (n : ℝ) + 1 ≠ 0)]
  · -- φράγμα στο διάστημα: |cₙ (y - x₀)ⁿ| ≤ |cₙ| rⁿ
    rw [Metric.mem_ball, Real.dist_eq] at hy
    rw [Real.norm_eq_abs, abs_mul, abs_pow]
    exact mul_le_mul_of_nonneg_left (pow_le_pow_left₀ (abs_nonneg _) hy.le n) (abs_nonneg _)
  · -- στο κέντρο x₀ όλοι οι όροι είναι 0
    simp
  · rw [Metric.mem_ball, Real.dist_eq]
    exact hxr

end Κεφ20.OroProsOro
