Σειρά Taylor και Maclaurin

Κεφάλαιο 20 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΈστω $f$ με παραγώγους κάθε τάξης σε ανοικτό διάστημα που περιέχει το $x_0$. Η ισότητα $f(x)$${}=\sum_{n=0}^{\infty}\dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n$ ισχύει αν και μόνο αν $\lim_{n\to\infty}R_n(x)=0$, όπου $R_n(x)$${}=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$ (υπόλοιπο Lagrange, με $\xi$ μεταξύ $x_0$ και $x$). Για $x_0=0$ προκύπτει η σειρά Maclaurin.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Το πολυώνυμο Taylor $T_n(x)$${}=\sum_{k=0}^{n}\dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k$ είναι το μερικό άθροισμα της σειράς Taylor
    theorem taylor_partial_sum (f : ℝ → ℝ) (n : ℕ) (s : Set ℝ) (x₀ x : ℝ) :
    taylorWithinEval f n s x₀ x =
      ∑ k ∈ Finset.range (n + 1), iteratedDerivWithin k f s x₀ / k ! * (x - x₀) ^ k
  • $f(x)$${}=\sum_{n=0}^{\infty}\dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n$ αν και μόνο αν $R_n(x)=f(x)-T_n(x)\to 0$
    theorem taylor_series_iff (f : ℝ → ℝ) (s : Set ℝ) (x₀ x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)
  • Για $x_0=0$: η σειρά Maclaurin
    theorem maclaurin_iff (f : ℝ → ℝ) (s : Set ℝ) (x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s 0 x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s 0 x) atTop (𝓝 0)
  • Υπόλοιπο Lagrange: $R_n(x)$${}=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$ για κάποιο $\xi$ μεταξύ $x_0$ και $x$
    theorem lagrange_remainder (f : ℝ → ℝ) (n : ℕ) (x₀ x : ℝ) (hx : x₀ ≠ x)
    (hf : ContDiffOn ℝ n f (Set.uIcc x₀ x))
    (hf' : DifferentiableOn ℝ (iteratedDerivWithin n f (Set.uIcc x₀ x)) (Set.uIoo x₀ x)) :
    ∃ ξ ∈ Set.uIoo x₀ x, f x - taylorWithinEval f n (Set.uIcc x₀ x) x₀ x =
      iteratedDerivWithin (n + 1) f (Set.uIcc x₀ x) ξ * (x - x₀) ^ (n + 1) / (n + 1)!
  • Στο κέντρο $x_0$ η σειρά Taylor συγκλίνει πάντα στο $f(x_0)$
    theorem taylor_at_center (f : ℝ → ℝ) (s : Set ℝ) (x₀ : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x₀) atTop (𝓝 (f x₀))

Το πολυώνυμο Taylor είναι στη Mathlib η taylorWithinEval f n s x₀ x, όπου οι παράγωγοι υπολογίζονται μέσα σε ένα σύνολο $s$, όπως στο Κεφάλαιο 11. Η ισότητα $f(x)$${}=\sum_{n=0}^{\infty}\dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n$ σημαίνει ότι τα μερικά αθροίσματα $T_n(x)$ τείνουν στο $f(x)$. Η ισοδυναμία με το $R_n(x)\to 0$ είναι θέμα ορίων και ισχύει χωρίς υποθέσεις για την $f$· οι υποθέσεις παραγωγισιμότητας χρειάζονται για να έχουν νόημα οι συντελεστές και για τη μορφή Lagrange του υπολοίπου, που δίνεται όπως στο Κεφάλαιο 11. Η σειρά Maclaurin είναι η ειδική περίπτωση $x_0=0$.

2. Βήμα προς βήμα: $T_n(x)\to f(x)$ $\Leftrightarrow$ $R_n(x)\to 0$

Η ιδέα: $R_n(x)=f(x)-T_n(x)$, άρα αρκούν οι ιδιότητες των ορίων. Ξεκινάμε από τον στόχο:

Ο στόχος
f : ℝ → ℝ
s : Set ℝ
x₀ x : ℝ
⊢ Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x)) ↔
    Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. constructor

    Μια ισοδυναμία αποδεικνύεται με δύο κατευθύνσεις· η constructor δίνει δύο στόχους.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος mp
    ⊢ Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x)) →
    Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)
    σκέλος mpr
    ⊢ Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0) →
    Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x))
  2. · -- (⇒) αν T_n(x) → f(x), τότε f(x) - T_n(x) → f(x) - f(x) = 0
  intro h

    ($\Rightarrow$) Υποθέτουμε ότι $T_n(x)\to f(x)$ (υπόθεση h).

    Τι μένει να αποδειχθεί
    h : Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x))
⊢ Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)
  3. have h1 := (tendsto_const_nhds (x := f x)).sub h

    Η σταθερή ακολουθία $f(x)$ τείνει στο $f(x)$, άρα από τις ιδιότητες των ορίων $f(x)-T_n(x)\to f(x)-f(x)$.

    Τι μένει να αποδειχθεί
    h1 : Tendsto (fun x_1 => f x - taylorWithinEval f x_1 s x₀ x) atTop (𝓝 (f x - f x))
⊢ Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)
  4. rw [sub_self] at h1

    Ισχύει $f(x)-f(x)=0$, άρα το h1 είναι ακριβώς ο στόχος.

    Τι μένει να αποδειχθεί
    h1 : Tendsto (fun x_1 => f x - taylorWithinEval f x_1 s x₀ x) atTop (𝓝 0)
⊢ Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)
  5.   exact h1
· -- (⇐) αν R_n(x) → 0, τότε T_n(x) = f(x) - R_n(x) → f(x) - 0 = f(x)
  intro h

    ($\Leftarrow$) Υποθέτουμε ότι $R_n(x)=f(x)-T_n(x)\to 0$.

    Τι μένει να αποδειχθεί
    h : Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0)
⊢ Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x))
  6. have h1 := (tendsto_const_nhds (x := f x)).sub h

    Πάλι από τις ιδιότητες των ορίων: $f(x)-\bigl(f(x)-T_n(x)\bigr)\to f(x)-0$.

    Τι μένει να αποδειχθεί
    h1 : Tendsto (fun x_1 => f x - (f x - taylorWithinEval f x_1 s x₀ x)) atTop (𝓝 (f x - 0))
⊢ Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x))
  7. rw [sub_zero] at h1

    Ισχύει $f(x)-0=f(x)$.

    Τι μένει να αποδειχθεί
    h1 : Tendsto (fun x_1 => f x - (f x - taylorWithinEval f x_1 s x₀ x)) atTop (𝓝 (f x))
⊢ Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x))
  8. have h2 : (fun n => f x - (f x - taylorWithinEval f n s x₀ x)) =
    fun n => taylorWithinEval f n s x₀ x := by
  funext n
  ring
rw [h2] at h1

    Επειδή $f(x)-\bigl(f(x)-T_n(x)\bigr)$${}=T_n(x)$, όπως ελέγχει η ring στο h2, το h1 λέει ότι $T_n(x)\to f(x)$, που είναι ο στόχος.

h2 : (fun n => f x - (f x - taylorWithinEval f n s x₀ x)) = fun n => taylorWithinEval f n s x₀ x
⊢ Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x))

3. Δοκίμασε εσύ: Η σειρά στο κέντρο

Δείξε ότι για $x=x_0$ η σειρά Taylor συγκλίνει πάντα στο $f(x_0)$, για κάθε $f$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Όλα τα πολυώνυμα Taylor έχουν τιμή $f(x_0)$ στο $x_0$ (taylorWithinEval_self), άρα η ακολουθία είναι σταθερή: simp only [taylorWithinEval_self] και μετά exact tendsto_const_nhds.

theorem taylor_at_center (f : ℝ → ℝ) (s : Set ℝ) (x₀ : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x₀) atTop (𝓝 (f x₀)) := by
  simp only [taylorWithinEval_self]
  exact tendsto_const_nhds

import Mathlib

namespace Κεφ20.SeiraTaylor
open Filter Topology
open scoped Nat

-- T_n(x) = Σ από k = 0 έως n των f^(k)(x₀)/k! · (x - x₀)^k, με παραγώγους μέσα στο σύνολο s
theorem taylor_partial_sum (f : ℝ → ℝ) (n : ℕ) (s : Set ℝ) (x₀ x : ℝ) :
    taylorWithinEval f n s x₀ x =
      ∑ k ∈ Finset.range (n + 1), iteratedDerivWithin k f s x₀ / k ! * (x - x₀) ^ k := by
  rw [taylor_within_apply]
  refine Finset.sum_congr rfl (fun k _ => ?_)
  rw [smul_eq_mul]
  ring

-- η σειρά Taylor έχει άθροισμα f(x) αν και μόνο αν R_n(x) = f(x) - T_n(x) → 0
theorem taylor_series_iff (f : ℝ → ℝ) (s : Set ℝ) (x₀ x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s x₀ x) atTop (𝓝 0) := by
  constructor
  · -- (⇒) αν T_n(x) → f(x), τότε f(x) - T_n(x) → f(x) - f(x) = 0
    intro h
    have h1 := (tendsto_const_nhds (x := f x)).sub h
    rw [sub_self] at h1
    exact h1
  · -- (⇐) αν R_n(x) → 0, τότε T_n(x) = f(x) - R_n(x) → f(x) - 0 = f(x)
    intro h
    have h1 := (tendsto_const_nhds (x := f x)).sub h
    rw [sub_zero] at h1
    have h2 : (fun n => f x - (f x - taylorWithinEval f n s x₀ x)) =
        fun n => taylorWithinEval f n s x₀ x := by
      funext n
      ring
    rw [h2] at h1
    exact h1

-- για x₀ = 0: η σειρά Maclaurin
theorem maclaurin_iff (f : ℝ → ℝ) (s : Set ℝ) (x : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s 0 x) atTop (𝓝 (f x)) ↔
      Tendsto (fun n => f x - taylorWithinEval f n s 0 x) atTop (𝓝 0) :=
  taylor_series_iff f s 0 x

-- υπόλοιπο Lagrange: R_n(x) = f^(n+1)(ξ)/(n+1)! · (x - x₀)^(n+1), με ξ μεταξύ x₀ και x
theorem lagrange_remainder (f : ℝ → ℝ) (n : ℕ) (x₀ x : ℝ) (hx : x₀ ≠ x)
    (hf : ContDiffOn ℝ n f (Set.uIcc x₀ x))
    (hf' : DifferentiableOn ℝ (iteratedDerivWithin n f (Set.uIcc x₀ x)) (Set.uIoo x₀ x)) :
    ∃ ξ ∈ Set.uIoo x₀ x, f x - taylorWithinEval f n (Set.uIcc x₀ x) x₀ x =
      iteratedDerivWithin (n + 1) f (Set.uIcc x₀ x) ξ * (x - x₀) ^ (n + 1) / (n + 1)! :=
  taylor_mean_remainder_lagrange hx hf hf'

-- στο κέντρο x₀ η σειρά Taylor συγκλίνει πάντα στο f(x₀)
theorem taylor_at_center (f : ℝ → ℝ) (s : Set ℝ) (x₀ : ℝ) :
    Tendsto (fun n => taylorWithinEval f n s x₀ x₀) atTop (𝓝 (f x₀)) := by
  simp only [taylorWithinEval_self]
  exact tendsto_const_nhds
