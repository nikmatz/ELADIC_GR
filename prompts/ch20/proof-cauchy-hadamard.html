Τύπος Cauchy–Hadamard (Ακτίνα Σύγκλισης)

Κεφάλαιο 20 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΓια τη σειρά δυνάμεων $\sum_{n=0}^{\infty} c_n (x-x_0)^n$, η ακτίνα σύγκλισης δίνεται από τον τύπο Cauchy–Hadamard $R$${}=\dfrac{1}{\limsup_{n\to\infty}\sqrt[n]{|c_n|}}$, με τις συμβάσεις $\dfrac{1}{0}=+\infty$ και $\dfrac{1}{+\infty}=0$. Η σειρά συγκλίνει απολύτως για $|x-x_0|\lt R$ και αποκλίνει για $|x-x_0|\gt R$ (τα άκρα απαιτούν ξεχωριστή εξέταση). Πρακτική μορφή: αν $c_n\ne 0$ για κάθε αρκετά μεγάλο $n$ και υπάρχει το όριο $\lim_{n\to\infty}\left|\dfrac{c_n}{c_{n+1}}\right|$, τότε αυτό ισούται με το $R$.

Στη Mathlib η σειρά δυνάμεων $\sum c_n y^n$ είναι το FormalMultilinearSeries.ofScalars ℝ c, και η ακτίνα σύγκλισής της, .radius, είναι στοιχείο του $[0,+\infty]$ (ℝ≥0∞). Η Mathlib ορίζει την ακτίνα χωρίς τον τύπο, ως το supremum των $r\ge 0$ για τα οποία η ακολουθία $|c_n|\,r^n$ είναι φραγμένη· γι’ αυτό ο τύπος Cauchy–Hadamard είναι θεώρημα. Στο $[0,+\infty]$ ισχύουν ακριβώς οι συμβάσεις $\dfrac{1}{0}=+\infty$ και $\dfrac{1}{+\infty}=0$ του βιβλίου. Το $|c_n|$ γράφεται ‖c n‖₊, ως μη αρνητικός πραγματικός, και η ρίζα $\sqrt[n]{|c_n|}$ ως δύναμη με εκθέτη $\tfrac1n$. Η σειρά του βιβλίου είναι σε δυνάμεις του $y=x-x_0$, και το $|x-x_0|$ γράφεται ‖x - x₀‖ₑ, ως στοιχείο του $[0,+\infty]$, ώστε να συγκρίνεται με το $R$. Η απόκλιση για $|x-x_0|\gt R$ προκύπτει από την αναγκαία συνθήκη: αν η σειρά συνέκλινε, θα ήταν $c_n(x-x_0)^n\to 0$, και από αυτό έπεται $|x-x_0|\le R$.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • FormalMultilinearSeries.radius_inv_eq_limsup: ο τύπος Cauchy–Hadamard για γενικές σειρές δυνάμεων: $\dfrac{1}{R}$${}=\limsup\sqrt[n]{\|p_n\|}$.
  • FormalMultilinearSeries.ofScalars_norm: για τη σειρά $\sum c_n y^n$ ισχύει $\|p_n\|=|c_n|$.
  • FormalMultilinearSeries.summable_norm_mul_pow: για $r\lt R$ η $\sum|c_n|\,r^n$ συγκλίνει.
  • FormalMultilinearSeries.le_radius_of_tendsto: αν η ακολουθία $|c_n|\,r^n$ έχει όριο, τότε $r\le R$.
  • FormalMultilinearSeries.ofScalars_radius_eq_of_tendsto: η ακτίνα από το όριο του $\left|\dfrac{c_n}{c_{n+1}}\right|$.
  • FormalMultilinearSeries.ofScalars_radius_eq_top_of_tendsto: αν $\left|\dfrac{c_{n+1}}{c_n}\right|\to 0$, τότε $R=+\infty$.
  • FormalMultilinearSeries.ofScalars_radius_eq_zero_of_tendsto: αν $\left|\dfrac{c_{n+1}}{c_n}\right|\to+\infty$, τότε $R=0$.
  • Filter.Tendsto.inv_tendsto_atTop: αν $u_n\to+\infty$, τότε $\dfrac{1}{u_n}\to 0$.
  • tendsto_inv_nhdsGT_zero: αν $u_n\to 0$ με $u_n\gt 0$, τότε $\dfrac{1}{u_n}\to+\infty$.

import Mathlib

namespace Κεφ20.CauchyHadamard
open Filter Topology
open scoped NNReal ENNReal

-- η σειρά δυνάμεων Σ cₙ yⁿ με y = x - x₀, και η ακτίνα σύγκλισής της R στο [0, +∞]
-- τύπος Cauchy–Hadamard: R = 1 / limsup ⁿ√|cₙ|, με 1/0 = +∞ και 1/(+∞) = 0
theorem cauchy_hadamard (c : ℕ → ℝ) :
    (FormalMultilinearSeries.ofScalars ℝ c).radius =
      (limsup (fun n => ((‖c n‖₊ ^ (1 / (n : ℝ)) : ℝ≥0) : ℝ≥0∞)) atTop)⁻¹ := by
  have h := (FormalMultilinearSeries.ofScalars ℝ c).radius_inv_eq_limsup
  have hn : ∀ n, ‖FormalMultilinearSeries.ofScalars ℝ c n‖₊ = ‖c n‖₊ := fun n =>
    NNReal.eq (FormalMultilinearSeries.ofScalars_norm ℝ c n)
  simp only [hn] at h
  rw [← h, inv_inv]

-- για |x - x₀| < R η σειρά συγκλίνει απολύτως
theorem converges_inside (c : ℕ → ℝ) (x₀ x : ℝ)
    (hx : ‖x - x₀‖ₑ < (FormalMultilinearSeries.ofScalars ℝ c).radius) :
    Summable (fun n => |c n * (x - x₀) ^ n|) := by
  have h := (FormalMultilinearSeries.ofScalars ℝ c).summable_norm_mul_pow hx
  simp only [FormalMultilinearSeries.ofScalars_norm, coe_nnNorm, Real.norm_eq_abs] at h
  simpa [abs_mul, abs_pow] using h

-- για |x - x₀| > R τα μερικά αθροίσματα δεν συγκλίνουν
theorem diverges_outside (c : ℕ → ℝ) (x₀ x : ℝ)
    (hx : (FormalMultilinearSeries.ofScalars ℝ c).radius < ‖x - x₀‖ₑ) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, c n * (x - x₀) ^ n) atTop (𝓝 S) := by
  rintro ⟨S, hS⟩
  -- αναγκαία συνθήκη: cₙ (x - x₀)ⁿ → 0
  have h0 : Tendsto (fun n => c n * (x - x₀) ^ n) atTop (𝓝 0) := by
    have h1 := (hS.comp (tendsto_add_atTop_nat 1)).sub hS
    simp only [Function.comp_def, Finset.sum_range_succ, add_sub_cancel_left, sub_self] at h1
    exact h1
  -- τότε |x - x₀| ≤ R, άτοπο
  have h2 : (‖x - x₀‖₊ : ℝ≥0∞) ≤ (FormalMultilinearSeries.ofScalars ℝ c).radius := by
    refine (FormalMultilinearSeries.ofScalars ℝ c).le_radius_of_tendsto (r := ‖x - x₀‖₊) (l := 0) ?_
    simpa [abs_mul, abs_pow] using h0.abs
  exact absurd h2 (not_le.mpr hx)

-- πρακτική μορφή: αν |cₙ / cₙ₊₁| → R με 0 < R < +∞, η ακτίνα είναι R
theorem ratio_formula (c : ℕ → ℝ) (R : ℝ≥0) (hR : R ≠ 0)
    (h : Tendsto (fun n => |c n / c (n + 1)|) atTop (𝓝 (R : ℝ))) :
    (FormalMultilinearSeries.ofScalars ℝ c).radius = R :=
  FormalMultilinearSeries.ofScalars_radius_eq_of_tendsto ℝ c hR (by simpa [abs_div] using h)

-- αν |cₙ / cₙ₊₁| → +∞, η ακτίνα είναι +∞
theorem ratio_formula_top (c : ℕ → ℝ) (hc : ∀ᶠ n in atTop, c n ≠ 0)
    (h : Tendsto (fun n => |c n / c (n + 1)|) atTop atTop) :
    (FormalMultilinearSeries.ofScalars ℝ c).radius = ⊤ := by
  refine FormalMultilinearSeries.ofScalars_radius_eq_top_of_tendsto ℝ c hc ?_
  have h1 := h.inv_tendsto_atTop
  simpa [abs_div, Pi.inv_def] using h1

-- αν |cₙ / cₙ₊₁| → 0, η ακτίνα είναι 0
theorem ratio_formula_zero (c : ℕ → ℝ) (hc : ∀ᶠ n in atTop, c n ≠ 0)
    (h : Tendsto (fun n => |c n / c (n + 1)|) atTop (𝓝 0)) :
    (FormalMultilinearSeries.ofScalars ℝ c).radius = 0 := by
  refine FormalMultilinearSeries.ofScalars_radius_eq_zero_of_tendsto ℝ c ?_
  -- ο λόγος είναι θετικός για μεγάλα n, άρα ο αντίστροφός του τείνει στο +∞
  have hpos : ∀ᶠ n in atTop, 0 < |c n / c (n + 1)| := by
    filter_upwards [hc, (tendsto_add_atTop_nat 1).eventually hc] with n h1 h2
    exact abs_pos.mpr (div_ne_zero h1 h2)
  have h1 : Tendsto (fun n => |c n / c (n + 1)|) atTop (𝓝[>] 0) :=
    tendsto_nhdsWithin_iff.mpr ⟨h, hpos⟩
  have h2 := tendsto_inv_nhdsGT_zero.comp h1
  simpa [Function.comp_def, abs_div] using h2

end Κεφ20.CauchyHadamard
