Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Για φθίνουσα $(b_n)$ με $b_n\to 0$: η $\sum_{n=0}^{\infty}(-1)^n b_n$ συγκλίνει σε κάποιο $I$, και για τα μερικά αθροίσματα $I_N=\sum_{n=0}^{N}(-1)^n b_n$ ισχύει $|I-I_N|\le b_{N+1}$
    theorem alternating_error (b : ℕ → ℝ) (hb : Antitone b) (hb0 : Tendsto b atTop (𝓝 0)) :
    ∃ I, Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), (-1) ^ n * b n) atTop (𝓝 I) ∧
      ∀ N, |I - ∑ n ∈ Finset.range (N + 1), (-1) ^ n * b n| ≤ b (N + 1)

Το μερικό άθροισμα $I_N=\sum_{n=0}^{N}(-1)^n b_n$ έχει $N+1$ όρους, για $n=0,1,\dots,N$, και γράφεται ∑ n ∈ Finset.range (N + 1), (-1) ^ n * b n· ο πρώτος όρος που παραλείπεται είναι ο $(-1)^{N+1}b_{N+1}$. Το $b_n\downarrow 0$ γράφεται με δύο υποθέσεις: η $(b_n)$ είναι φθίνουσα (Antitone b) και $b_n\to 0$. Η απόδειξη δείχνει πρώτα το φράγμα $|I-S_M|\le b_M$ για το άθροισμα $S_M$ των $M$ πρώτων όρων, με δύο περιπτώσεις, $M$ άρτιο ή περιττό, όπως στο κριτήριο Leibniz του Κεφαλαίου 19, και το εφαρμόζει με $M=N+1$.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Antitone.tendsto_alternating_series_of_tendsto_zero: η σειρά συγκλίνει (κριτήριο Leibniz).
  • Antitone.alternating_series_le_tendsto: $S_{2k}\le I$.
  • Antitone.tendsto_le_alternating_series: $I\le S_{2k+1}$.
  • Nat.even_or_odd': κάθε φυσικός είναι της μορφής $2k$ ή $2k+1$.

import Mathlib

namespace Κεφ20.SfalmaEnallassousas
open Filter Topology

-- I = b₀ - b₁ + b₂ - …, και I_N = Σ από n = 0 έως N των (-1)ⁿ bₙ, δηλαδή N + 1 όροι
theorem alternating_error (b : ℕ → ℝ) (hb : Antitone b) (hb0 : Tendsto b atTop (𝓝 0)) :
    ∃ I, Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), (-1) ^ n * b n) atTop (𝓝 I) ∧
      ∀ N, |I - ∑ n ∈ Finset.range (N + 1), (-1) ^ n * b n| ≤ b (N + 1) := by
  obtain ⟨I, hI⟩ := hb.tendsto_alternating_series_of_tendsto_zero hb0
  -- το φράγμα |I - S_M| ≤ b M για το άθροισμα S_M των M πρώτων όρων
  have key : ∀ M, |I - ∑ n ∈ Finset.range M, (-1) ^ n * b n| ≤ b M := by
    intro M
    obtain ⟨k, rfl | rfl⟩ := Nat.even_or_odd' M
    · -- M = 2k: S_{2k} ≤ I ≤ S_{2k+1} = S_{2k} + b(2k)
      have h1 := hb.alternating_series_le_tendsto hI k
      have h2 := hb.tendsto_le_alternating_series hI k
      rw [Finset.sum_range_succ, pow_mul, neg_one_sq, one_pow, one_mul] at h2
      rw [abs_le]
      constructor <;> linarith
    · -- M = 2k + 1: S_{2k+2} = S_{2k+1} - b(2k+1) ≤ I ≤ S_{2k+1}
      have h1 := hb.tendsto_le_alternating_series hI k
      have h2 := hb.alternating_series_le_tendsto hI (k + 1)
      rw [show 2 * (k + 1) = 2 * k + 1 + 1 by ring, Finset.sum_range_succ, pow_succ, pow_mul,
        neg_one_sq, one_pow, one_mul, neg_one_mul] at h2
      rw [abs_le]
      constructor <;> linarith
  -- με M = N + 1 όρους παίρνουμε το φράγμα b(N + 1)
  exact ⟨I, hI.comp (tendsto_add_atTop_nat 1), fun N => key (N + 1)⟩

end Κεφ20.SfalmaEnallassousas
