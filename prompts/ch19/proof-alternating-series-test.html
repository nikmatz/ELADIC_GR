Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν η $(b_n)$ είναι φθίνουσα με $b_n\to 0$, τότε η $b_0-b_1+b_2-\cdots$ συγκλίνει σε κάποιο $S$, και $|S-S_N|\le b_N$, όπου $S_N$ το άθροισμα των $N$ πρώτων όρων
    theorem leibniz_test (b : ℕ → ℝ) (hb : Antitone b) (hb0 : Tendsto b atTop (𝓝 0)) :
    ∃ S, Tendsto (fun N => ∑ i ∈ Finset.range N, (-1) ^ i * b i) atTop (𝓝 S) ∧
      ∀ N, |S - ∑ i ∈ Finset.range N, (-1) ^ i * b i| ≤ b N

Το βιβλίο γράφει τη σειρά $\sum_{n=1}^{\infty}(-1)^{n-1}b_n$${}=b_1-b_2+b_3-\cdots$· εδώ η αρίθμηση ξεκινά από το $0$, δηλαδή η σειρά είναι η $b_0-b_1+b_2-\cdots$, με όρους $(-1)^i b_i$. Το άθροισμα των $N$ πρώτων όρων είναι το ∑ i ∈ Finset.range N, (-1) ^ i * b i, και ο πρώτος όρος που παραλείπεται είναι ο $b_N$, που αντιστοιχεί στο $b_{N+1}$ του βιβλίου. Η φθίνουσα ακολουθία γράφεται Antitone b. Η υπόθεση $b_n\gt 0$ δεν χρειάζεται: από τη μονοτονία και το $b_n\to 0$ προκύπτει ότι $b_n\ge 0$. Για το φράγμα η απόδειξη χωρίζει δύο περιπτώσεις, $N$ άρτιο ή περιττό, και χρησιμοποιεί ότι το $S$ βρίσκεται ανάμεσα σε δύο διαδοχικά μερικά αθροίσματα: $S_{2k}\le S\le S_{2k+1}$.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Antitone.tendsto_alternating_series_of_tendsto_zero: το κριτήριο Leibniz: η σειρά συγκλίνει.
  • Antitone.alternating_series_le_tendsto: $S_{2k}\le S$.
  • Antitone.tendsto_le_alternating_series: $S\le S_{2k+1}$.
  • Nat.even_or_odd': κάθε φυσικός είναι της μορφής $2k$ ή $2k+1$.

import Mathlib

namespace Κεφ19.Enallassousa
open Filter Topology

-- η σειρά b₀ - b₁ + b₂ - …, με b φθίνουσα και b n → 0
theorem leibniz_test (b : ℕ → ℝ) (hb : Antitone b) (hb0 : Tendsto b atTop (𝓝 0)) :
    ∃ S, Tendsto (fun N => ∑ i ∈ Finset.range N, (-1) ^ i * b i) atTop (𝓝 S) ∧
      ∀ N, |S - ∑ i ∈ Finset.range N, (-1) ^ i * b i| ≤ b N := by
  obtain ⟨S, hS⟩ := hb.tendsto_alternating_series_of_tendsto_zero hb0
  refine ⟨S, hS, fun N => ?_⟩
  obtain ⟨k, rfl | rfl⟩ := Nat.even_or_odd' N
  · -- N = 2k: S_{2k} ≤ S ≤ S_{2k+1} = S_{2k} + b(2k)
    have h1 := hb.alternating_series_le_tendsto hS k
    have h2 := hb.tendsto_le_alternating_series hS k
    rw [Finset.sum_range_succ, pow_mul, neg_one_sq, one_pow, one_mul] at h2
    rw [abs_le]
    constructor <;> linarith
  · -- N = 2k + 1: S_{2k+2} = S_{2k+1} - b(2k+1) ≤ S ≤ S_{2k+1}
    have h1 := hb.tendsto_le_alternating_series hS k
    have h2 := hb.alternating_series_le_tendsto hS (k + 1)
    rw [show 2 * (k + 1) = 2 * k + 1 + 1 by ring, Finset.sum_range_succ, pow_succ, pow_mul,
      neg_one_sq, one_pow, one_mul, neg_one_mul] at h2
    rw [abs_le]
    constructor <;> linarith

end Κεφ19.Enallassousa
