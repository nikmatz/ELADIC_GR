Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν η $\sum a_n$ συγκλίνει, τότε $a_n\to 0$
    theorem necessary (a : ℕ → ℝ) (S : ℝ)
    (h : Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)) :
    Tendsto a atTop (𝓝 0)
  • Το αντίστροφο δεν ισχύει: $\dfrac{1}{n}\to 0$, αλλά τα μερικά αθροίσματα της αρμονικής σειράς τείνουν στο $+\infty$
    theorem harmonic :
    Tendsto (fun n : ℕ => 1 / ((n : ℝ) + 1)) atTop (𝓝 0) ∧
      Tendsto (fun N => ∑ n ∈ Finset.range N, 1 / ((n : ℝ) + 1)) atTop atTop
  • Αν δεν ισχύει $a_n\to 0$, η σειρά αποκλίνει
    theorem diverges_of_not_tendsto (a : ℕ → ℝ) (h : ¬ Tendsto a atTop (𝓝 0)) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)

Η σύγκλιση της σειράς γράφεται όπως στο βιβλίο, με τα μερικά αθροίσματα: Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S), όπου $S_N=a_0+\dots+a_{N-1}$. Η αρίθμηση ξεκινά από το $0$· για την αρμονική σειρά γράφουμε τους όρους ως $\dfrac{1}{n+1}$ με $n\ge 0$, που είναι οι $1,\tfrac12,\tfrac13,\dots$ του βιβλίου.

2. Βήμα προς βήμα: Η $\sum a_n$ συγκλίνει $\Rightarrow$ $a_n\to 0$

Η ιδέα, όπως στο βιβλίο: $a_N=S_{N+1}-S_N\to S-S=0$. Ξεκινάμε από τον στόχο:

Ο στόχος
a : ℕ → ℝ
S : ℝ
h : Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)
⊢ Tendsto a atTop (𝓝 0)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- και η ακολουθία S_{N+1} τείνει στο S
have h1 : Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a n) atTop (𝓝 S) :=
  h.comp (tendsto_add_atTop_nat 1)

    Αφού $S_N\to S$, και η μετατοπισμένη ακολουθία $S_{N+1}$ τείνει στο $S$.

    Τι μένει να αποδειχθεί
    h1 : Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a n) atTop (𝓝 S)
⊢ Tendsto a atTop (𝓝 0)
  2. -- a_N = S_{N+1} - S_N
have h2 : (fun N => ∑ n ∈ Finset.range (N + 1), a n - ∑ n ∈ Finset.range N, a n) = a := by
  funext N
  rw [Finset.sum_range_succ]

    Για να συγκρίνουμε τα δύο μερικά αθροίσματα, γράφουμε $S_{N+1}=S_N+a_N$· ο στόχος γίνεται $S_N+a_N-S_N=a_N$.

    Τι μένει να αποδειχθεί
    N : ℕ
⊢ ∑ x ∈ Finset.range N, a x + a N - ∑ n ∈ Finset.range N, a n = a N
  3. ring

    Η ring το επιβεβαιώνει. Έτσι, $S_{N+1}-S_N=a_N$ για κάθε $N$.

    Τι μένει να αποδειχθεί
    h2 : (fun N => ∑ n ∈ Finset.range (N + 1), a n - ∑ n ∈ Finset.range N, a n) = a
⊢ Tendsto a atTop (𝓝 0)
  4. -- άρα a_N → S - S = 0
have h3 := h1.sub h

    Από τις ιδιότητες των ορίων, $S_{N+1}-S_N\to S-S$.

    Τι μένει να αποδειχθεί
    h3 : Tendsto (fun x => ∑ n ∈ Finset.range (x + 1), a n - ∑ n ∈ Finset.range x, a n) atTop (𝓝 (S - S))
⊢ Tendsto a atTop (𝓝 0)
  5. rw [h2, sub_self] at h3

    Αντικαθιστούμε $S_{N+1}-S_N=a_N$ και $S-S=0$: το h3 λέει ότι $a_n\to 0$, που είναι ο στόχος.

    Τι μένει να αποδειχθεί
    h3 : Tendsto a atTop (𝓝 0)
⊢ Tendsto a atTop (𝓝 0)

3. Δοκίμασε εσύ: Κριτήριο απόκλισης

Δείξε ότι αν δεν ισχύει $a_n\to 0$, τότε τα μερικά αθροίσματα δεν συγκλίνουν. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Με απαγωγή σε άτοπο: rintro ⟨S, hS⟩ και μετά exact h (necessary a S hS).

theorem diverges_of_not_tendsto (a : ℕ → ℝ) (h : ¬ Tendsto a atTop (𝓝 0)) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S) := by
  rintro ⟨S, hS⟩
  exact h (necessary a S hS)

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Filter.tendsto_add_atTop_nat: $N+1\to+\infty$ όταν $N\to+\infty$.
  • Filter.Tendsto.comp: σύνθεση ορίων· εδώ δίνει $S_{N+1}\to S$.
  • Finset.sum_range_succ: $S_{N+1}=S_N+a_N$.
  • Filter.Tendsto.sub: το όριο της διαφοράς.
  • tendsto_one_div_add_atTop_nhds_zero_nat: $\dfrac{1}{n+1}\to 0$.
  • Real.tendsto_sum_range_one_div_nat_succ_atTop: τα μερικά αθροίσματα της αρμονικής σειράς τείνουν στο $+\infty$.

import Mathlib

namespace Κεφ19.AnagkaiaSynthiki
open Filter Topology

-- αν τα μερικά αθροίσματα S_N συγκλίνουν, τότε a n → 0
theorem necessary (a : ℕ → ℝ) (S : ℝ)
    (h : Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S)) :
    Tendsto a atTop (𝓝 0) := by
  -- και η ακολουθία S_{N+1} τείνει στο S
  have h1 : Tendsto (fun N => ∑ n ∈ Finset.range (N + 1), a n) atTop (𝓝 S) :=
    h.comp (tendsto_add_atTop_nat 1)
  -- a_N = S_{N+1} - S_N
  have h2 : (fun N => ∑ n ∈ Finset.range (N + 1), a n - ∑ n ∈ Finset.range N, a n) = a := by
    funext N
    rw [Finset.sum_range_succ]
    ring
  -- άρα a_N → S - S = 0
  have h3 := h1.sub h
  rw [h2, sub_self] at h3
  exact h3

-- το αντίστροφο δεν ισχύει: 1/(n+1) → 0, αλλά η αρμονική σειρά αποκλίνει
theorem harmonic :
    Tendsto (fun n : ℕ => 1 / ((n : ℝ) + 1)) atTop (𝓝 0) ∧
      Tendsto (fun N => ∑ n ∈ Finset.range N, 1 / ((n : ℝ) + 1)) atTop atTop :=
  ⟨tendsto_one_div_add_atTop_nhds_zero_nat, Real.tendsto_sum_range_one_div_nat_succ_atTop⟩

theorem diverges_of_not_tendsto (a : ℕ → ℝ) (h : ¬ Tendsto a atTop (𝓝 0)) :
    ¬ ∃ S, Tendsto (fun N => ∑ n ∈ Finset.range N, a n) atTop (𝓝 S) := by
  rintro ⟨S, hS⟩
  exact h (necessary a S hS)
