ΕκφώνησηΑν $\lim a_n=A$, $\lim b_n=B$: $\lim(a_n\pm b_n)=A\pm B$· $\lim(a_n b_n)=AB$· $\lim\dfrac{a_n}{b_n}=\dfrac{A}{B}$ ($B\ne 0$)· $\lim|a_n|=|A|$· $\lim a_n^p=A^p$ για $p\in\mathbb{R}$ (για μη ακέραιο $p$ απαιτείται $a_n\gt 0$ και $A\gt 0$, και για $p\lt 0$ απαιτείται $A\ne 0$). Παρεμβολή: αν $a_n\le c_n\le b_n$ και $\lim a_n=\lim b_n=L$, τότε $\lim c_n=L$.

Το $\lim a_n=A$ γράφεται Tendsto a atTop (𝓝 A): η $a_n$ τείνει στο $A$ καθώς $n\to+\infty$. Το όριο του αθροίσματος αποδεικνύεται με $\varepsilon$-$N$, όπως στο βιβλίο· οι υπόλοιπες ιδιότητες προκύπτουν από τα αντίστοιχα θεωρήματα της Mathlib. Για τις δυνάμεις χωρίζουμε τρεις περιπτώσεις: φυσικό εκθέτη, χωρίς περιορισμό· ακέραιο εκθέτη, με $A\neq 0$, ώστε να ορίζεται το $A^k$ για $k\lt 0$· και πραγματικό εκθέτη, με $A\gt 0$. Στην τελευταία δεν χρειάζεται η υπόθεση $a_n\gt 0$: από το $a_n\to A\gt 0$ προκύπτει ότι $a_n\gt 0$ για μεγάλα $n$.

2. Βήμα προς βήμα: $\lim(a_n+b_n)=A+B$

Η ιδέα, όπως στο βιβλίο: παίρνουμε $\tfrac{\varepsilon}{2}$ για καθεμιά ακολουθία και την τριγωνική ανισότητα. Ξεκινάμε από τον στόχο:

Ο στόχος
a b : ℕ → ℝ
A B : ℝ
ha : Tendsto a atTop (𝓝 A)
hb : Tendsto b atTop (𝓝 B)
⊢ Tendsto (fun n => a n + b n) atTop (𝓝 (A + B))

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [Metric.tendsto_atTop] at ha hb ⊢

    Γράφουμε και τα τρία όρια με τον ορισμό $\varepsilon$-$N$. Η απόσταση dist x y είναι το $|x-y|$.

    Τι μένει να αποδειχθεί
    ha : ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (a n) A < ε
hb : ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (b n) B < ε
⊢ ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (a n + b n) (A + B) < ε
  2. intro ε hε

    Παίρνουμε $\varepsilon\gt 0$.

    Τι μένει να αποδειχθεί
    ε : ℝ
hε : ε > 0
⊢ ∃ N, ∀ n ≥ N, dist (a n + b n) (A + B) < ε
  3. -- N₁ για το ε/2 στην a και N₂ για το ε/2 στη b
obtain ⟨N₁, hN₁⟩ := ha (ε / 2) (by linarith)
obtain ⟨N₂, hN₂⟩ := hb (ε / 2) (by linarith)

    Εφαρμόζουμε τον ορισμό με $\tfrac{\varepsilon}{2}$: για $n\ge N_1$ ισχύει $|a_n-A|\lt\tfrac{\varepsilon}{2}$ και για $n\ge N_2$ ισχύει $|b_n-B|\lt\tfrac{\varepsilon}{2}$.

    Τι μένει να αποδειχθεί
    N₁ : ℕ
hN₁ : ∀ n ≥ N₁, dist (a n) A < ε / 2
N₂ : ℕ
hN₂ : ∀ n ≥ N₂, dist (b n) B < ε / 2
⊢ ∃ N, ∀ n ≥ N, dist (a n + b n) (A + B) < ε
  4. refine ⟨max N₁ N₂, fun n hn => ?_⟩

    Διαλέγουμε $N=\max(N_1,N_2)$ και παίρνουμε $n\ge N$.

    Τι μένει να αποδειχθεί
    n : ℕ
hn : n ≥ max N₁ N₂
⊢ dist (a n + b n) (A + B) < ε
  5. have h1 := hN₁ n (le_of_max_le_left hn)
have h2 := hN₂ n (le_of_max_le_right hn)

    Αφού $n\ge N_1$ και $n\ge N_2$, ισχύουν και οι δύο ανισότητες.

    Τι μένει να αποδειχθεί
    h1 : dist (a n) A < ε / 2
h2 : dist (b n) B < ε / 2
⊢ dist (a n + b n) (A + B) < ε
  6. rw [Real.dist_eq] at h1 h2 ⊢

    Γράφουμε τις αποστάσεις ως απόλυτες τιμές. Η τριγωνική ανισότητα κλείνει την απόδειξη: $|a_n+b_n-(A+B)|\le|a_n-A|$${}+|b_n-B|\lt\tfrac{\varepsilon}{2}$${}+\tfrac{\varepsilon}{2}$${}=\varepsilon$.

    Τι μένει να αποδειχθεί
    h1 : |a n - A| < ε / 2
h2 : |b n - B| < ε / 2
⊢ |a n + b n - (A + B)| < ε

3. Δοκίμασε εσύ: $\lim(a_n-b_n)=A-B$

Δείξε ότι $\lim(a_n-b_n)=A-B$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Γράψε $a_n-b_n=a_n+(-b_n)$ και εφάρμοσε το sum_rule με την $-b_n\to -B$ (hb.neg): have h := sum_rule a (fun n => -b n) A (-B) ha hb.neg, μετά simp only [← sub_eq_add_neg] at h και exact h.

Λύση
theorem diff_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n - b n) atTop (𝓝 (A - B)) := by
  have h := sum_rule a (fun n => -b n) A (-B) ha hb.neg
  simp only [← sub_eq_add_neg] at h
  exact h

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Metric.tendsto_atTop: ο ορισμός $\varepsilon$-$N$ του ορίου.
  • abs_add_le: η τριγωνική ανισότητα $|x+y|\le|x|+|y|$.
  • le_of_max_le_left: αν $\max(N_1,N_2)\le n$, τότε $N_1\le n$.
  • Filter.Tendsto.neg: αν $b_n\to B$, τότε $-b_n\to -B$.
  • Filter.Tendsto.mul: το όριο του γινομένου.
  • Filter.Tendsto.div: το όριο του πηλίκου, όταν το όριο του παρονομαστή δεν είναι $0$.
  • Filter.Tendsto.abs: το όριο της απόλυτης τιμής.
  • Filter.Tendsto.pow: το όριο δύναμης με φυσικό εκθέτη.
  • Filter.Tendsto.zpow₀: το όριο δύναμης με ακέραιο εκθέτη.
  • Filter.Tendsto.rpow_const: το όριο δύναμης με πραγματικό εκθέτη.
  • tendsto_of_tendsto_of_tendsto_of_le_of_le: το θεώρημα της παρεμβολής.

-- όριο αθροίσματος, με ε-N
theorem sum_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n + b n) atTop (𝓝 (A + B)) := by
  rw [Metric.tendsto_atTop] at ha hb ⊢
  intro ε hε
  -- N₁ για το ε/2 στην a και N₂ για το ε/2 στη b
  obtain ⟨N₁, hN₁⟩ := ha (ε / 2) (by linarith)
  obtain ⟨N₂, hN₂⟩ := hb (ε / 2) (by linarith)
  refine ⟨max N₁ N₂, fun n hn => ?_⟩
  have h1 := hN₁ n (le_of_max_le_left hn)
  have h2 := hN₂ n (le_of_max_le_right hn)
  rw [Real.dist_eq] at h1 h2 ⊢
  -- τριγωνική ανισότητα
  calc |a n + b n - (A + B)| = |(a n - A) + (b n - B)| := by congr 1; ring
    _ ≤ |a n - A| + |b n - B| := abs_add_le _ _
    _ < ε / 2 + ε / 2 := by linarith
    _ = ε := by ring

theorem diff_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n - b n) atTop (𝓝 (A - B)) := by
  have h := sum_rule a (fun n => -b n) A (-B) ha hb.neg
  simp only [← sub_eq_add_neg] at h
  exact h

theorem mul_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) : Tendsto (fun n => a n * b n) atTop (𝓝 (A * B)) :=
  ha.mul hb

theorem div_rule (a b : ℕ → ℝ) (A B : ℝ) (ha : Tendsto a atTop (𝓝 A))
    (hb : Tendsto b atTop (𝓝 B)) (hB : B ≠ 0) :
    Tendsto (fun n => a n / b n) atTop (𝓝 (A / B)) :=
  ha.div hb hB

theorem abs_rule (a : ℕ → ℝ) (A : ℝ) (ha : Tendsto a atTop (𝓝 A)) :
    Tendsto (fun n => |a n|) atTop (𝓝 |A|) :=
  ha.abs

theorem npow_rule (a : ℕ → ℝ) (A : ℝ) (k : ℕ) (ha : Tendsto a atTop (𝓝 A)) :
    Tendsto (fun n => a n ^ k) atTop (𝓝 (A ^ k)) :=
  ha.pow k

theorem zpow_rule (a : ℕ → ℝ) (A : ℝ) (k : ℤ) (ha : Tendsto a atTop (𝓝 A)) (hA : A ≠ 0) :
    Tendsto (fun n => a n ^ k) atTop (𝓝 (A ^ k)) :=
  ha.zpow₀ k (Or.inl hA)

theorem pow_rule (a : ℕ → ℝ) (A p : ℝ) (ha : Tendsto a atTop (𝓝 A)) (hA : 0 < A) :
    Tendsto (fun n => a n ^ p) atTop (𝓝 (A ^ p)) :=
  ha.rpow_const (Or.inl hA.ne')

theorem squeeze (a b c : ℕ → ℝ) (L : ℝ) (ha : Tendsto a atTop (𝓝 L))
    (hb : Tendsto b atTop (𝓝 L)) (hac : ∀ n, a n ≤ c n) (hcb : ∀ n, c n ≤ b n) :
    Tendsto c atTop (𝓝 L) :=
  tendsto_of_tendsto_of_tendsto_of_le_of_le ha hb hac hcb
