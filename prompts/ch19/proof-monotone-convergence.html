Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν η $(a_n)$ είναι αύξουσα και $a_n\le M$, τότε $a_n\to\sup\{a_n\}$ και $\sup\{a_n\}\le M$
    theorem monotone_convergence (a : ℕ → ℝ) (M : ℝ) (hmono : Monotone a) (hM : ∀ n, a n ≤ M) :
    Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ (⨆ n, a n) ≤ M
  • Αν η $(a_n)$ είναι φθίνουσα και $a_n\ge m$, τότε $a_n\to\inf\{a_n\}$ και $\inf\{a_n\}\ge m$
    theorem antitone_convergence (a : ℕ → ℝ) (m : ℝ) (hanti : Antitone a) (hm : ∀ n, m ≤ a n) :
    Tendsto a atTop (𝓝 (⨅ n, a n)) ∧ m ≤ ⨅ n, a n

Το $\sup\{a_n\}$ γράφεται ⨆ n, a n και το $\inf\{a_n\}$ γράφεται ⨅ n, a n. Η αύξουσα ακολουθία γράφεται Monotone a και η φθίνουσα Antitone a. Η Mathlib ορίζει το $\sup$ για κάθε σύνολο πραγματικών αριθμών, αλλά οι ιδιότητές του ισχύουν όταν το σύνολο είναι άνω φραγμένο (BddAbove), γι’ αυτό η απόδειξη δείχνει πρώτα το φράγμα. Η σύγκλιση στο $\sup$ αποδεικνύεται με τον ορισμό $\varepsilon$-$N$, όπως στο βιβλίο.

2. Βήμα προς βήμα: Αύξουσα και άνω φραγμένη $\Rightarrow$ $a_n\to\sup\{a_n\}$

Η ιδέα, όπως στο βιβλίο: το $\sup\{a_n\}$ είναι το ελάχιστο άνω φράγμα, άρα από κάποιο $N$ και μετά οι όροι πλησιάζουν το $\sup$ όσο θέλουμε. Ξεκινάμε από τον στόχο:

Ο στόχος
a : ℕ → ℝ
M : ℝ
hmono : Monotone a
hM : ∀ (n : ℕ), a n ≤ M
⊢ Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ ⨆ n, a n ≤ M

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- το σύνολο των όρων είναι άνω φραγμένο
have hbdd : BddAbove (Set.range a) := ⟨M, by
  rintro _ ⟨n, rfl⟩
  exact hM n⟩

    Το σύνολο των όρων $\{a_n\}$ είναι άνω φραγμένο από το $M$, άρα ισχύουν οι ιδιότητες του $\sup\{a_n\}$, που γράφεται ⨆ n, a n.

    Τι μένει να αποδειχθεί
    hbdd : BddAbove (Set.range a)
⊢ Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ ⨆ n, a n ≤ M
  2. refine ⟨?_, ciSup_le hM⟩

    Το δεύτερο μέρος, $\sup\{a_n\}\le M$, ισχύει γιατί το $M$ είναι άνω φράγμα (ciSup_le). Μένει το όριο.

    Τι μένει να αποδειχθεί
    ⊢ Tendsto a atTop (𝓝 (⨆ n, a n))
  3. rw [Metric.tendsto_atTop]

    Γράφουμε το όριο με τον ορισμό: για κάθε $\varepsilon\gt 0$ υπάρχει $N$ ώστε η απόσταση του $a_n$ από το $\sup$ να είναι μικρότερη από $\varepsilon$ για $n\ge N$. Η απόσταση dist x y είναι το $|x-y|$.

    Τι μένει να αποδειχθεί
    ⊢ ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (a n) (⨆ n, a n) < ε
  4. intro ε hε
-- το sup - ε δεν είναι άνω φράγμα: υπάρχει N με a N > sup - ε
obtain ⟨N, hN⟩ := exists_lt_of_lt_ciSup (show (⨆ n, a n) - ε < ⨆ n, a n by linarith)

    Παίρνουμε $\varepsilon\gt 0$. Το $\sup-\varepsilon$ δεν είναι άνω φράγμα, γιατί είναι μικρότερο από το ελάχιστο άνω φράγμα· άρα υπάρχει όρος $a_N\gt\sup-\varepsilon$.

    Τι μένει να αποδειχθεί
    ε : ℝ
hε : ε > 0
N : ℕ
hN : (⨆ n, a n) - ε < a N
⊢ ∃ N, ∀ n ≥ N, dist (a n) (⨆ n, a n) < ε
  5. refine ⟨N, fun n hn => ?_⟩

    Αυτό το $N$ είναι το ζητούμενο. Παίρνουμε $n\ge N$.

    Τι μένει να αποδειχθεί
    n : ℕ
hn : n ≥ N
⊢ dist (a n) (⨆ n, a n) < ε
  6. -- για n ≥ N: sup - ε < a N ≤ a n ≤ sup
have h1 : a N ≤ a n := hmono hn
have h2 : a n ≤ ⨆ n, a n := le_ciSup hbdd n

    Η ακολουθία είναι αύξουσα, άρα $a_N\le a_n$, και κάθε όρος είναι το πολύ ίσος με το $\sup$.

    Τι μένει να αποδειχθεί
    h1 : a N ≤ a n
h2 : a n ≤ ⨆ n, a n
⊢ dist (a n) (⨆ n, a n) < ε
  7. rw [Real.dist_eq, abs_lt]

    Η ανισότητα $|a_n-\sup|\lt\varepsilon$ γράφεται $-\varepsilon\lt a_n-\sup$ και $a_n-\sup\lt\varepsilon$· και οι δύο προκύπτουν γραμμικά από τις προηγούμενες ανισότητες (linarith).

    Τι μένει να αποδειχθεί
    ⊢ -ε < a n - ⨆ n, a n ∧ a n - ⨆ n, a n < ε

3. Δοκίμασε εσύ: Φθίνουσα ακολουθία

Δείξε ότι μια φθίνουσα ακολουθία με $a_n\ge m$ συγκλίνει στο $\inf\{a_n\}$ και ότι $\inf\{a_n\}\ge m$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Η Mathlib έχει έτοιμο το όριο για φθίνουσες ακολουθίες: exact ⟨tendsto_atTop_ciInf hanti ⟨m, by rintro _ ⟨n, rfl⟩; exact hm n⟩, le_ciInf hm⟩. Μπορείς επίσης να μιμηθείς την απόδειξη με $\varepsilon$-$N$.

    exact hm n⟩, le_ciInf hm⟩

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • ciSup_le: αν $a_n\le M$ για κάθε $n$, τότε $\sup\{a_n\}\le M$.
  • le_ciSup: σε άνω φραγμένο σύνολο, κάθε όρος είναι το πολύ ίσος με το $\sup\{a_n\}$.
  • exists_lt_of_lt_ciSup: αν $x\lt\sup\{a_n\}$, υπάρχει όρος $a_N\gt x$.
  • Metric.tendsto_atTop: ο ορισμός $\varepsilon$-$N$ του ορίου.
  • tendsto_atTop_ciInf: φθίνουσα και κάτω φραγμένη ακολουθία συγκλίνει στο $\inf\{a_n\}$.
  • le_ciInf: αν $a_n\ge m$ για κάθε $n$, τότε $\inf\{a_n\}\ge m$.

import Mathlib

namespace Κεφ19.MonotoniSygklisi
open Filter Topology

-- αύξουσα και άνω φραγμένη από M: συγκλίνει στο sup, και sup ≤ M
theorem monotone_convergence (a : ℕ → ℝ) (M : ℝ) (hmono : Monotone a) (hM : ∀ n, a n ≤ M) :
    Tendsto a atTop (𝓝 (⨆ n, a n)) ∧ (⨆ n, a n) ≤ M := by
  -- το σύνολο των όρων είναι άνω φραγμένο
  have hbdd : BddAbove (Set.range a) := ⟨M, by
    rintro _ ⟨n, rfl⟩
    exact hM n⟩
  refine ⟨?_, ciSup_le hM⟩
  rw [Metric.tendsto_atTop]
  intro ε hε
  -- το sup - ε δεν είναι άνω φράγμα: υπάρχει N με a N > sup - ε
  obtain ⟨N, hN⟩ := exists_lt_of_lt_ciSup (show (⨆ n, a n) - ε < ⨆ n, a n by linarith)
  refine ⟨N, fun n hn => ?_⟩
  -- για n ≥ N: sup - ε < a N ≤ a n ≤ sup
  have h1 : a N ≤ a n := hmono hn
  have h2 : a n ≤ ⨆ n, a n := le_ciSup hbdd n
  rw [Real.dist_eq, abs_lt]
  constructor <;> linarith

theorem antitone_convergence (a : ℕ → ℝ) (m : ℝ) (hanti : Antitone a) (hm : ∀ n, m ≤ a n) :
    Tendsto a atTop (𝓝 (⨅ n, a n)) ∧ m ≤ ⨅ n, a n :=
  ⟨tendsto_atTop_ciInf hanti ⟨m, by
    rintro _ ⟨n, rfl⟩
    exact hm n⟩, le_ciInf hm⟩

end Κεφ19.MonotoniSygklisi
