Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $0\le a_n\le b_n$ για κάθε $n$ και η $\sum b_n$ συγκλίνει, τότε συγκλίνει και η $\sum a_n$

    (hb : Summable b) : Summable a
  • Το ίδιο, όταν το $0\le a_n\le b_n$ ισχύει μόνο για $n\ge N$

  • Αν η $\sum a_n$ αποκλίνει, τότε αποκλίνει και η $\sum b_n$
    theorem comparison_diverges (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hdiv : ¬ Summable a) : ¬ Summable b

Η σύγκλιση μιας σειράς γράφεται Summable. Για πραγματικούς αριθμούς αυτή η έννοια της Mathlib σημαίνει απόλυτη σύγκλιση, αλλά για σειρές με μη αρνητικούς όρους, όπως εδώ, είναι ακριβώς η σύγκλιση του βιβλίου· η απόκλιση γράφεται ¬ Summable. Το άθροισμα της σειράς $\sum_{n=0}^{\infty}b_n$ γράφεται ∑' n, b n και η αρίθμηση των όρων ξεκινά από το $0$. Η εκδοχή με $n\ge N$ ανάγεται στην πρώτη μέσω των «ουρών» $a_{n+N}$ και $b_{n+N}$: μια σειρά συγκλίνει ακριβώς όταν συγκλίνει η ουρά της.

2. Βήμα προς βήμα: $0\le a_n\le b_n$ και η $\sum b_n$ συγκλίνει $\Rightarrow$ η $\sum a_n$ συγκλίνει

Η ιδέα: τα μερικά αθροίσματα της $\sum a_n$ αυξάνουν και είναι φραγμένα από το άθροισμα της $\sum b_n$. Ξεκινάμε από τον στόχο:

Ο στόχος
a b : ℕ → ℝ
ha : ∀ (n : ℕ), 0 ≤ a n
hab : ∀ (n : ℕ), a n ≤ b n
hb : Summable b
⊢ Summable a

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. -- τα μερικά αθροίσματα της a είναι φραγμένα από το άθροισμα της b
have hbound : ∀ N, ∑ n ∈ Finset.range N, a n ≤ ∑' n, b n := by
  intro N

    Δείχνουμε πρώτα ότι κάθε μερικό άθροισμα της $a$ είναι το πολύ $\sum_{n=0}^{\infty}b_n$. Παίρνουμε τυχαίο $N$.

    Τι μένει να αποδειχθεί
    N : ℕ
⊢ ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
  2. -- όρο προς όρο: a n ≤ b n
have h1 : ∑ n ∈ Finset.range N, a n ≤ ∑ n ∈ Finset.range N, b n :=
  Finset.sum_le_sum fun n _ => hab n

    Όρο προς όρο $a_n\le b_n$, άρα $a_0+\dots+a_{N-1}\le b_0+\dots+b_{N-1}$.

    Τι μένει να αποδειχθεί
    h1 : ∑ n ∈ Finset.range N, a n ≤ ∑ n ∈ Finset.range N, b n
⊢ ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
  3. -- κάθε μερικό άθροισμα της b είναι ≤ του αθροίσματος της σειράς, γιατί b n ≥ 0
have h2 : ∑ n ∈ Finset.range N, b n ≤ ∑' n, b n :=
  hb.sum_le_tsum (Finset.range N) fun n _ => (ha n).trans (hab n)

    Οι όροι της $b$ είναι μη αρνητικοί, αφού $b_n\ge a_n\ge 0$· άρα κάθε μερικό άθροισμα της $b$ είναι το πολύ ίσο με το άθροισμα όλης της σειράς.

    Τι μένει να αποδειχθεί
    h2 : ∑ n ∈ Finset.range N, b n ≤ ∑' (n : ℕ), b n
⊢ ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
  4. exact h1.trans h2

    Οι δύο ανισότητες δίνουν το φράγμα hbound για κάθε $N$. Μια σειρά με μη αρνητικούς όρους και φραγμένα μερικά αθροίσματα συγκλίνει, γιατί τα μερικά αθροίσματα σχηματίζουν αύξουσα και άνω φραγμένη ακολουθία· αυτό κλείνει την απόδειξη.

    Τι μένει να αποδειχθεί
    hbound : ∀ (N : ℕ), ∑ n ∈ Finset.range N, a n ≤ ∑' (n : ℕ), b n
⊢ Summable a

3. Δοκίμασε εσύ: Η μορφή της απόκλισης

Δείξε ότι αν η $\sum a_n$ αποκλίνει, τότε αποκλίνει και η $\sum b_n$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Υπόδειξη

Με απαγωγή σε άτοπο: αν η $\sum b_n$ συνέκλινε, το κριτήριο θα έδινε ότι συγκλίνει και η $\sum a_n$. exact fun hb => hdiv (comparison a b ha hab hb).

Λύση
theorem comparison_diverges (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hdiv : ¬ Summable a) : ¬ Summable b :=
  fun hb => hdiv (comparison a b ha hab hb)

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • Finset.sum_le_sum: αν $f(i)\le g(i)$ για κάθε $i$, τότε $\sum f(i)\le\sum g(i)$ σε πεπερασμένο άθροισμα.
  • Summable.sum_le_tsum: για σειρά με μη αρνητικούς όρους, κάθε μερικό άθροισμα είναι το πολύ ίσο με το άθροισμα της σειράς.
  • summable_of_sum_range_le: μη αρνητικοί όροι και φραγμένα μερικά αθροίσματα: η σειρά συγκλίνει.
  • summable_nat_add_iff: μια σειρά συγκλίνει ακριβώς όταν συγκλίνει η ουρά της $\sum a_{n+N}$.

theorem comparison (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hb : Summable b) : Summable a := by
  -- τα μερικά αθροίσματα της a είναι φραγμένα από το άθροισμα της b
  have hbound : ∀ N, ∑ n ∈ Finset.range N, a n ≤ ∑' n, b n := by
    intro N
    -- όρο προς όρο: a n ≤ b n
    have h1 : ∑ n ∈ Finset.range N, a n ≤ ∑ n ∈ Finset.range N, b n :=
      Finset.sum_le_sum fun n _ => hab n
    -- κάθε μερικό άθροισμα της b είναι ≤ του αθροίσματος της σειράς, γιατί b n ≥ 0
    have h2 : ∑ n ∈ Finset.range N, b n ≤ ∑' n, b n :=
      hb.sum_le_tsum (Finset.range N) fun n _ => (ha n).trans (hab n)
    exact h1.trans h2
  -- μη αρνητικοί όροι με φραγμένα μερικά αθροίσματα: η σειρά συγκλίνει
  exact summable_of_sum_range_le ha hbound

-- το ίδιο, όταν 0 ≤ a n ≤ b n ισχύει μόνο για n ≥ N
theorem comparison_from (a b : ℕ → ℝ) (N : ℕ) (ha : ∀ n ≥ N, 0 ≤ a n)
    (hab : ∀ n ≥ N, a n ≤ b n) (hb : Summable b) : Summable a := by
  -- εφαρμόζουμε το κριτήριο στις ουρές a (n + N) και b (n + N)
  have h := comparison (fun n => a (n + N)) (fun n => b (n + N))
    (fun n => ha (n + N) (Nat.le_add_left N n)) (fun n => hab (n + N) (Nat.le_add_left N n))
    ((summable_nat_add_iff N).mpr hb)
  exact (summable_nat_add_iff N).mp h

theorem comparison_diverges (a b : ℕ → ℝ) (ha : ∀ n, 0 ≤ a n) (hab : ∀ n, a n ≤ b n)
    (hdiv : ¬ Summable a) : ¬ Summable b :=
  fun hb => hdiv (comparison a b ha hab hb)
