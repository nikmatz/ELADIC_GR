Κλίση Εφαπτομένης Πολικής Καμπύλης

Κεφάλαιο 10 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΓια πολική καμπύλη $r=f(\theta)$ (με $r'=dr/d\theta$): $\dfrac{dy}{dx}$${}=\dfrac{r'\sin\theta+r\cos\theta}{r'\cos\theta-r\sin\theta}$. Η εφαπτομένη είναι οριζόντια αν $r'\sin\theta+r\cos\theta=0$ και $r'\cos\theta-r\sin\theta\ne 0$, και κατακόρυφη αν $r'\cos\theta-r\sin\theta=0$ και $r'\sin\theta+r\cos\theta\ne 0$. Όταν μηδενίζονται και οι δύο (μορφή $0/0$, π.χ. στην ακίδα της καρδιοειδούς) το κριτήριο δεν δίνει συμπέρασμα και χρειάζεται όριο ή ανάπτυγμα ανώτερης τάξης.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Για την καμπύλη $r=r(\theta)$, όταν ο παρονομαστής δεν είναι $0$: $\dfrac{dy}{dx}$${}=\dfrac{r'\sin\theta_0+r\cos\theta_0}{r'\cos\theta_0-r\sin\theta_0}$

    (hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t))
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0) :
    F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  • Βοηθητικό: $(r\cos\theta)'$${}=r'\cos\theta-r\sin\theta$
    theorem x_deriv (r : ℝ → ℝ) (θ r' : ℝ) (hr : HasDerivAt r r' θ) :
    HasDerivAt (fun t => r t * Real.cos t) (r' * Real.cos θ - r θ * Real.sin θ) θ
  • Βοηθητικό: $(r\sin\theta)'$${}=r'\sin\theta+r\cos\theta$
    theorem y_deriv (r : ℝ → ℝ) (θ r' : ℝ) (hr : HasDerivAt r r' θ) :
    HasDerivAt (fun t => r t * Real.sin t) (r' * Real.sin θ + r θ * Real.cos θ) θ
  • Αν $r'\sin\theta_0+r\cos\theta_0=0$ και $r'\cos\theta_0-r\sin\theta_0\neq 0$, η εφαπτομένη είναι οριζόντια: $\dfrac{dy}{dx}=0$
    theorem polar_horizontal (r F : ℝ → ℝ) (θ₀ r' F' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t))
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0)
    (hnum : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ = 0) : F' = 0
  • Αν $r'\cos\theta_0-r\sin\theta_0=0$ και $r'\sin\theta_0+r\cos\theta_0\neq 0$, η εφαπτομένη είναι κατακόρυφη: $\dfrac{dx}{dy}=0$
    theorem polar_vertical (r G : ℝ → ℝ) (θ₀ r' G' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hG : HasDerivAt G G' (r θ₀ * Real.sin θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.cos t = G (r t * Real.sin t))
    (hnum : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ ≠ 0)
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ = 0) : G' = 0

Η καμπύλη $r=r(\theta)$ γράφεται σε καρτεσιανές συντεταγμένες ως $x(\theta)=r(\theta)\cos\theta$, $y(\theta)=r(\theta)\sin\theta$, δηλαδή είναι παραμετρική καμπύλη με παράμετρο $\theta$. Όπως στις παραμετρικές καμπύλες, υποθέτουμε ότι κοντά στο $\theta_0$ η καμπύλη είναι γράφημα $y=F(x)$ (υπόθεση hcurve) και δείχνουμε ότι η κλίση $F'$ είναι $\dfrac{y'(\theta_0)}{x'(\theta_0)}$. Για την κατακόρυφη εφαπτομένη η καμπύλη γράφεται ως $x=G(y)$ και δείχνουμε ότι $\dfrac{dx}{dy}=G'=0$. Το $r'$ είναι η παράγωγος $\dfrac{dr}{d\theta}$ στο $\theta_0$. Όταν μηδενίζονται και οι δύο παραστάσεις, κανένα από τα δύο κριτήρια δεν εφαρμόζεται, όπως λέει και το βιβλίο.

2. Βήμα προς βήμα: η κλίση $\dfrac{dy}{dx}$

Η ιδέα: η πολική καμπύλη είναι παραμετρική, με $x(\theta)=r\cos\theta$ και $y(\theta)=r\sin\theta$, οπότε $\dfrac{dy}{dx}$${}=\dfrac{y'(\theta_0)}{x'(\theta_0)}$. Ξεκινάμε από τον στόχο:

Ο στόχος
r F : ℝ → ℝ
θ₀ r' F' : ℝ
hr : HasDerivAt r r' θ₀
hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀)
hcurve : ∀ᶠ (t : ℝ) in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t)
hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have hx := x_deriv r θ₀ r' hr

    Η $x(\theta)=r(\theta)\cos\theta$ έχει παράγωγο $r'\cos\theta_0-r(\theta_0)\sin\theta_0$ (βοηθητικό x_deriv).

    Τι μένει να αποδειχθεί
    hx : HasDerivAt (fun t => r t * Real.cos t) (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  2. have hy := y_deriv r θ₀ r' hr

    Η $y(\theta)=r(\theta)\sin\theta$ έχει παράγωγο $r'\sin\theta_0+r(\theta_0)\cos\theta_0$ (βοηθητικό y_deriv).

    Τι μένει να αποδειχθεί
    hy : HasDerivAt (fun t => r t * Real.sin t) (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  3. have h1 := hF.comp θ₀ hx

    Κανόνας αλυσίδας: η $\theta\mapsto F(x(\theta))$ έχει παράγωγο $F'\cdot x'(\theta_0)$.

    Τι μένει να αποδειχθεί
    h1 : HasDerivAt (F ∘ fun t => r t * Real.cos t) (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  4. have h2 : HasDerivAt (fun t => r t * Real.sin t)
    (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀ := h1.congr_of_eventuallyEq hcurve

    Κοντά στο $\theta_0$ ισχύει $y(\theta)=F(x(\theta))$, άρα και η $y$ έχει παράγωγο $F'\cdot x'(\theta_0)$.

    Τι μένει να αποδειχθεί
    h2 : HasDerivAt (fun t => r t * Real.sin t) (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  5. have h3 := hy.unique h2

    Η παράγωγος είναι μοναδική: $y'(\theta_0)=F'\cdot x'(\theta_0)$.

    Τι μένει να αποδειχθεί
    h3 : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ = F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
⊢ F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)
  6. rw [h3, mul_div_cancel_right₀ _ hden]

    Επομένως, $F'$${}=\dfrac{y'(\theta_0)}{x'(\theta_0)}$, αφού ο παρονομαστής δεν είναι $0$.

3. Δοκίμασε εσύ: η παράγωγος της $y(\theta)$

Δείξε ότι η $y(\theta)=r(\theta)\sin\theta$ έχει παράγωγο $r'\sin\theta+r(\theta)\cos\theta$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Κανόνας γινομένου, με $(\sin\theta)'=\cos\theta$: exact hr.mul (Real.hasDerivAt_sin θ).

Λύση
theorem y_deriv (r : ℝ → ℝ) (θ r' : ℝ) (hr : HasDerivAt r r' θ) :
    HasDerivAt (fun t => r t * Real.sin t) (r' * Real.sin θ + r θ * Real.cos θ) θ :=
  hr.mul (Real.hasDerivAt_sin θ)

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • HasDerivAt.mul: ο κανόνας του γινομένου.
  • Real.hasDerivAt_sin: $(\sin\theta)'=\cos\theta$.
  • Real.hasDerivAt_cos: $(\cos\theta)'=-\sin\theta$.
  • HasDerivAt.comp: ο κανόνας αλυσίδας.
  • HasDerivAt.congr_of_eventuallyEq: συναρτήσεις ίσες κοντά στο σημείο έχουν την ίδια παράγωγο.
  • HasDerivAt.unique: η παράγωγος είναι μοναδική.
  • mul_div_cancel_right₀: $\dfrac{ab}{b}=a$ όταν $b\neq 0$.
  • HasDerivAt.comp_of_eq: ο κανόνας αλυσίδας, με το σημείο δοσμένο ως ισότητα.
  • mul_eq_zero: $ab=0$ ακριβώς όταν $a=0$ ή $b=0$.

import Mathlib

namespace Κεφ10.Poliki
open Filter Topology

theorem x_deriv (r : ℝ → ℝ) (θ r' : ℝ) (hr : HasDerivAt r r' θ) :
    HasDerivAt (fun t => r t * Real.cos t) (r' * Real.cos θ - r θ * Real.sin θ) θ := by
  have h := hr.mul (Real.hasDerivAt_cos θ)
  rw [show r' * Real.cos θ - r θ * Real.sin θ = r' * Real.cos θ + r θ * -Real.sin θ by ring]
  exact h

theorem y_deriv (r : ℝ → ℝ) (θ r' : ℝ) (hr : HasDerivAt r r' θ) :
    HasDerivAt (fun t => r t * Real.sin t) (r' * Real.sin θ + r θ * Real.cos θ) θ :=
  hr.mul (Real.hasDerivAt_sin θ)

theorem polar_slope (r F : ℝ → ℝ) (θ₀ r' F' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t))
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0) :
    F' = (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀) / (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀) := by
  have hx := x_deriv r θ₀ r' hr
  have hy := y_deriv r θ₀ r' hr
  have h1 := hF.comp θ₀ hx
  have h2 : HasDerivAt (fun t => r t * Real.sin t)
      (F' * (r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀)) θ₀ := h1.congr_of_eventuallyEq hcurve
  have h3 := hy.unique h2
  rw [h3, mul_div_cancel_right₀ _ hden]

-- οριζόντια εφαπτομένη
theorem polar_horizontal (r F : ℝ → ℝ) (θ₀ r' F' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hF : HasDerivAt F F' (r θ₀ * Real.cos θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.sin t = F (r t * Real.cos t))
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ ≠ 0)
    (hnum : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ = 0) : F' = 0 := by
  rw [polar_slope r F θ₀ r' F' hr hF hcurve hden, hnum, zero_div]

-- κατακόρυφη εφαπτομένη: η καμπύλη γράφεται x = G(y) και dx/dy = 0
theorem polar_vertical (r G : ℝ → ℝ) (θ₀ r' G' : ℝ) (hr : HasDerivAt r r' θ₀)
    (hG : HasDerivAt G G' (r θ₀ * Real.sin θ₀))
    (hcurve : ∀ᶠ t in 𝓝 θ₀, r t * Real.cos t = G (r t * Real.sin t))
    (hnum : r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀ ≠ 0)
    (hden : r' * Real.cos θ₀ - r θ₀ * Real.sin θ₀ = 0) : G' = 0 := by
  have hx := x_deriv r θ₀ r' hr
  have hy := y_deriv r θ₀ r' hr
  have h1 := hG.comp_of_eq θ₀ hy rfl
  have h2 : HasDerivAt (fun t => r t * Real.cos t)
      (G' * (r' * Real.sin θ₀ + r θ₀ * Real.cos θ₀)) θ₀ := h1.congr_of_eventuallyEq hcurve
  have h3 := hx.unique h2
  rw [hden] at h3
  exact (mul_eq_zero.mp h3.symm).resolve_right hnum
