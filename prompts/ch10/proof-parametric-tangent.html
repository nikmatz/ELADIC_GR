ΕκφώνησηΓια ομαλή παραμετρική καμπύλη $x=x(t)$, $y=y(t)$ με $x'(t)\ne 0$: $\dfrac{dy}{dx}$${}=\dfrac{y'(t)}{x'(t)}$. Η εφαπτομένη είναι οριζόντια αν $y'(t)=0$ (και $x'(t)\ne 0$), και κατακόρυφη αν $x'(t)=0$ (και $y'(t)\ne 0$). Δεύτερη παράγωγος $\dfrac{d^2 y}{dx^2}$${}=\dfrac{\frac{d}{dt}\!\left(\frac{dy}{dx}\right)}{x'(t)}$.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $x'(t_0)\neq 0$, η κλίση της εφαπτομένης είναι $\dfrac{dy}{dx}$${}=\dfrac{y'(t_0)}{x'(t_0)}$
    theorem slope_parametric (x y F : ℝ → ℝ) (t₀ x' y' F' : ℝ) (hx : HasDerivAt x x' t₀)
    (hy : HasDerivAt y y' t₀) (hF : HasDerivAt F F' (x t₀))
    (hcurve : ∀ᶠ t in 𝓝 t₀, y t = F (x t)) (hx0 : x' ≠ 0) : F' = y' / x'
  • Με $x'(t_0)\neq 0$, η εφαπτομένη είναι οριζόντια ακριβώς όταν $y'(t_0)=0$
    theorem horizontal_iff (x' y' : ℝ) (hx0 : x' ≠ 0) : y' / x' = 0 ↔ y' = 0
  • Αν $x'(t_0)=0$ και $y'(t_0)\neq 0$, η εφαπτομένη είναι κατακόρυφη: $\dfrac{dx}{dy}=0$
    theorem vertical_tangent (x y G : ℝ → ℝ) (t₀ x' y' G' : ℝ) (hx : HasDerivAt x x' t₀)
    (hy : HasDerivAt y y' t₀) (hG : HasDerivAt G G' (y t₀))
    (hcurve : ∀ᶠ t in 𝓝 t₀, x t = G (y t)) (hy0 : y' ≠ 0) (hx0 : x' = 0) : G' = 0
  • Δεύτερη παράγωγος: $\dfrac{d^2y}{dx^2}$${}=\dfrac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{x'(t_0)}$
    theorem second_derivative (x F' : ℝ → ℝ) (t₀ x' F'' d : ℝ) (hx : HasDerivAt x x' t₀)
    (hF' : HasDerivAt F' F'' (x t₀)) (hd : HasDerivAt (fun t => F' (x t)) d t₀)
    (hx0 : x' ≠ 0) : F'' = d / x'

Οι παράγωγοι γράφονται HasDerivAt x x' t₀ και HasDerivAt y y' t₀. Κοντά στο $t_0$ η καμπύλη είναι γράφημα $y=F(x)$ μιας συνάρτησης $F$ με παράγωγο $F'$ στο $x(t_0)$: αυτό λέει η υπόθεση hcurve, $y(t)=F(x(t))$ για $t$ κοντά στο $t_0$ (για ομαλή καμπύλη με $x'(t_0)\neq 0$ ισχύει πάντα, από το θεώρημα αντίστροφης συνάρτησης). Η κλίση της εφαπτομένης είναι το $F'$, δηλαδή το $\dfrac{dy}{dx}$. Για την κατακόρυφη εφαπτομένη η καμπύλη γράφεται αντίστροφα, ως $x=G(y)$, και κατακόρυφη εφαπτομένη σημαίνει $\dfrac{dx}{dy}=G'=0$. Στη δεύτερη παράγωγο η F' είναι η $\dfrac{dy}{dx}$ ως συνάρτηση του $x$, το d είναι η παράγωγος της $t\mapsto F'(x(t))$ στο $t_0$ και το F'' είναι το $\dfrac{d^2y}{dx^2}$: ο τύπος προκύπτει από τον τύπο της κλίσης, εφαρμοσμένο στην $\dfrac{dy}{dx}$. Το F ∘ x είναι η σύνθεση $t\mapsto F(x(t))$.

2. Βήμα προς βήμα: η κλίση $\dfrac{dy}{dx}$

Η ιδέα: από τον κανόνα αλυσίδας η $y=F(x(t))$ έχει παράγωγο $F'\cdot x'(t_0)$· άρα $y'(t_0)=F'\,x'(t_0)$ και διαιρούμε με $x'(t_0)\neq 0$. Ξεκινάμε από τον στόχο:

Ο στόχος
x y F : ℝ → ℝ
t₀ x' y' F' : ℝ
hx : HasDerivAt x x' t₀
hy : HasDerivAt y y' t₀
hF : HasDerivAt F F' (x t₀)
hcurve : ∀ᶠ (t : ℝ) in 𝓝 t₀, y t = F (x t)
hx0 : x' ≠ 0
⊢ F' = y' / x'

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have h1 : HasDerivAt (F ∘ x) (F' * x') t₀ := hF.comp t₀ hx

    Κανόνας αλυσίδας: η $t\mapsto F(x(t))$ έχει παράγωγο $F'\cdot x'$ στο $t_0$.

    Τι μένει να αποδειχθεί
    h1 : HasDerivAt (F ∘ x) (F' * x') t₀
⊢ F' = y' / x'
  2. have h2 : HasDerivAt y (F' * x') t₀ := h1.congr_of_eventuallyEq hcurve

    Κοντά στο $t_0$ ισχύει $y(t)=F(x(t))$, άρα και η $y$ έχει παράγωγο $F'\cdot x'$ στο $t_0$.

    Τι μένει να αποδειχθεί
    h2 : HasDerivAt y (F' * x') t₀
⊢ F' = y' / x'
  3. have h3 : y' = F' * x' := hy.unique h2

    Η παράγωγος είναι μοναδική, οπότε $y'=F'\cdot x'$.

    Τι μένει να αποδειχθεί
    h3 : y' = F' * x'
⊢ F' = y' / x'
  4. rw [h3, mul_div_cancel_right₀ _ hx0]

    Επομένως, $\dfrac{y'}{x'}$${}=\dfrac{F'\,x'}{x'}$${}=F'$, αφού $x'\neq 0$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: οριζόντια εφαπτομένη

Δείξε ότι, όταν $x'\neq 0$, ισχύει $\dfrac{y'}{x'}=0$ ακριβώς όταν $y'=0$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ένα κλάσμα είναι $0$ ακριβώς όταν ο αριθμητής ή ο παρονομαστής είναι $0$, και εδώ ο παρονομαστής δεν είναι: rw [div_eq_zero_iff, or_iff_left hx0].

Λύση
theorem horizontal_iff (x' y' : ℝ) (hx0 : x' ≠ 0) : y' / x' = 0 ↔ y' = 0 := by
  rw [div_eq_zero_iff, or_iff_left hx0]

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • HasDerivAt.comp: ο κανόνας αλυσίδας.
  • HasDerivAt.congr_of_eventuallyEq: συναρτήσεις ίσες κοντά στο σημείο έχουν την ίδια παράγωγο.
  • HasDerivAt.unique: η παράγωγος είναι μοναδική.
  • mul_div_cancel_right₀: $\dfrac{ab}{b}=a$ όταν $b\neq 0$.
  • div_eq_zero_iff: $\dfrac{a}{b}=0$ ακριβώς όταν $a=0$ ή $b=0$.
  • zero_div: $\dfrac{0}{b}=0$.
  • Filter.Eventually.of_forall: ό,τι ισχύει για κάθε $t$ ισχύει και κοντά στο $t_0$.

import Mathlib

namespace Κεφ10.Parametriki
open Filter Topology

theorem slope_parametric (x y F : ℝ → ℝ) (t₀ x' y' F' : ℝ) (hx : HasDerivAt x x' t₀)
    (hy : HasDerivAt y y' t₀) (hF : HasDerivAt F F' (x t₀))
    (hcurve : ∀ᶠ t in 𝓝 t₀, y t = F (x t)) (hx0 : x' ≠ 0) : F' = y' / x' := by
  have h1 : HasDerivAt (F ∘ x) (F' * x') t₀ := hF.comp t₀ hx
  have h2 : HasDerivAt y (F' * x') t₀ := h1.congr_of_eventuallyEq hcurve
  have h3 : y' = F' * x' := hy.unique h2
  rw [h3, mul_div_cancel_right₀ _ hx0]

theorem horizontal_iff (x' y' : ℝ) (hx0 : x' ≠ 0) : y' / x' = 0 ↔ y' = 0 := by
  rw [div_eq_zero_iff, or_iff_left hx0]

-- κατακόρυφη εφαπτομένη: η καμπύλη γράφεται x = G(y) και dx/dy = 0
theorem vertical_tangent (x y G : ℝ → ℝ) (t₀ x' y' G' : ℝ) (hx : HasDerivAt x x' t₀)
    (hy : HasDerivAt y y' t₀) (hG : HasDerivAt G G' (y t₀))
    (hcurve : ∀ᶠ t in 𝓝 t₀, x t = G (y t)) (hy0 : y' ≠ 0) (hx0 : x' = 0) : G' = 0 := by
  rw [slope_parametric y x G t₀ y' x' G' hy hx hG hcurve hy0, hx0, zero_div]

-- δεύτερη παράγωγος: η F' είναι η dy/dx ως συνάρτηση του x και το F'' η d²y/dx²
theorem second_derivative (x F' : ℝ → ℝ) (t₀ x' F'' d : ℝ) (hx : HasDerivAt x x' t₀)
    (hF' : HasDerivAt F' F'' (x t₀)) (hd : HasDerivAt (fun t => F' (x t)) d t₀)
    (hx0 : x' ≠ 0) : F'' = d / x' :=
  slope_parametric x (fun t => F' (x t)) F' t₀ x' d F'' hx hd hF'
    (Eventually.of_forall fun _ => rfl) hx0
