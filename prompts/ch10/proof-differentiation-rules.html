Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $(c)'=0$
    theorem d_const (x c : ℝ) : HasDerivAt (fun _ => c) 0 x
  • $(x^n)'=nx^{n-1}$
    theorem d_pow (x : ℝ) (n : ℕ) : HasDerivAt (fun y => y ^ n) (n * x ^ (n - 1)) x
  • $(e^x)'=e^x$
    theorem d_exp (x : ℝ) : HasDerivAt Real.exp (Real.exp x) x
  • $(\ln x)'=\dfrac{1}{x}$
    theorem d_log (x : ℝ) (hx : x ≠ 0) : HasDerivAt Real.log (1 / x) x
  • $(\sin x)'=\cos x$
    theorem d_sin (x : ℝ) : HasDerivAt Real.sin (Real.cos x) x
  • $(\cos x)'=-\sin x$
    theorem d_cos (x : ℝ) : HasDerivAt Real.cos (-Real.sin x) x
  • $(cf)'=cf'$
    theorem d_const_mul (f : ℝ → ℝ) (x f' c : ℝ) (hf : HasDerivAt f f' x) :
    HasDerivAt (fun y => c * f y) (c * f') x
  • $(f+g)'=f'+g'$
    theorem d_add (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x) :
    HasDerivAt (fun y => f y + g y) (f' + g') x
  • $(f-g)'=f'-g'$
    theorem d_sub (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x) :
    HasDerivAt (fun y => f y - g y) (f' - g') x
  • $(fg)'=f'g+fg'$
    theorem d_mul (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x) :
    HasDerivAt (fun y => f y * g y) (f' * g x + f x * g') x
  • $\left(\dfrac{f}{g}\right)'$${}=\dfrac{f'g-fg'}{g^2}$, για $g\neq 0$
    theorem d_div (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x)
    (hgx : g x ≠ 0) :
    HasDerivAt (fun y => f y / g y) ((f' * g x - f x * g') / g x ^ 2) x

Το HasDerivAt f f' x σημαίνει ότι η $f$ έχει παράγωγο $f'$ στο $x$. Στους κανόνες για τις $f$ και $g$ οι αριθμοί f' και g' είναι οι παράγωγοί τους στο $x$. Ο εκθέτης $n$ στο $x^n$ είναι φυσικός αριθμός. Στον Lean ο λογάριθμος Real.log ορίζεται και για $x\lt 0$, ως $\ln|x|$, οπότε ο τύπος $(\ln x)'=\dfrac{1}{x}$ αποδεικνύεται για κάθε $x\neq 0$· για $x\gt 0$ είναι ο τύπος του βιβλίου.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • hasDerivAt_const: η σταθερή συνάρτηση έχει παράγωγο $0$.
  • hasDerivAt_pow: η παράγωγος της $x^n$.
  • Real.hasDerivAt_exp: η παράγωγος της $e^x$.
  • Real.hasDerivAt_log: η παράγωγος του λογαρίθμου, για $x\neq 0$.
  • Real.hasDerivAt_sin: η παράγωγος του $\sin x$.
  • Real.hasDerivAt_cos: η παράγωγος του $\cos x$.
  • HasDerivAt.const_mul: ο κανόνας για την $c\,f(x)$.
  • HasDerivAt.add: ο κανόνας του αθροίσματος.
  • HasDerivAt.sub: ο κανόνας της διαφοράς.
  • HasDerivAt.mul: ο κανόνας του γινομένου.
  • HasDerivAt.div: ο κανόνας του πηλίκου.

import Mathlib

namespace Κεφ10.KanonesParagogisis

theorem d_const (x c : ℝ) : HasDerivAt (fun _ => c) 0 x := hasDerivAt_const x c

theorem d_pow (x : ℝ) (n : ℕ) : HasDerivAt (fun y => y ^ n) (n * x ^ (n - 1)) x :=
  hasDerivAt_pow n x

theorem d_exp (x : ℝ) : HasDerivAt Real.exp (Real.exp x) x := Real.hasDerivAt_exp x

theorem d_log (x : ℝ) (hx : x ≠ 0) : HasDerivAt Real.log (1 / x) x := by
  rw [one_div]
  exact Real.hasDerivAt_log hx

theorem d_sin (x : ℝ) : HasDerivAt Real.sin (Real.cos x) x := Real.hasDerivAt_sin x

theorem d_cos (x : ℝ) : HasDerivAt Real.cos (-Real.sin x) x := Real.hasDerivAt_cos x

theorem d_const_mul (f : ℝ → ℝ) (x f' c : ℝ) (hf : HasDerivAt f f' x) :
    HasDerivAt (fun y => c * f y) (c * f') x := hf.const_mul c

theorem d_add (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x) :
    HasDerivAt (fun y => f y + g y) (f' + g') x := hf.add hg

theorem d_sub (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x) :
    HasDerivAt (fun y => f y - g y) (f' - g') x := hf.sub hg

theorem d_mul (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x) :
    HasDerivAt (fun y => f y * g y) (f' * g x + f x * g') x := hf.mul hg

theorem d_div (f g : ℝ → ℝ) (x f' g' : ℝ) (hf : HasDerivAt f f' x) (hg : HasDerivAt g g' x)
    (hgx : g x ≠ 0) :
    HasDerivAt (fun y => f y / g y) ((f' * g x - f x * g') / g x ^ 2) x := hf.div hg hgx
