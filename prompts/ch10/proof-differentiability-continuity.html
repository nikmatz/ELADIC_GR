Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν η $f$ είναι παραγωγίσιμη στο $x_0$, τότε είναι συνεχής στο $x_0$
    theorem continuous_of_hasDeriv (f : ℝ → ℝ) (x₀ f' : ℝ) (hf : HasDerivAt f f' x₀) :
    ContinuousAt f x₀
  • Εφαρμογή: αν οι $f$ και $g$ είναι παραγωγίσιμες στο $x_0$, η $f+g$ είναι συνεχής στο $x_0$
    theorem sum_continuous (f g : ℝ → ℝ) (x₀ f' g' : ℝ) (hf : HasDerivAt f f' x₀)
    (hg : HasDerivAt g g' x₀) : ContinuousAt (fun x => f x + g x) x₀
  • Το αντίστροφο δεν ισχύει: η $|x|$ είναι συνεχής στο $0$ αλλά όχι παραγωγίσιμη εκεί
    theorem abs_counterexample :
    ContinuousAt (fun x : ℝ => |x|) 0 ∧ ¬ DifferentiableAt ℝ (fun x : ℝ => |x|) 0

Το HasDerivAt f f' x₀ σημαίνει ότι η $f$ έχει παράγωγο $f'$ στο $x_0$ και το ContinuousAt f x₀ ότι η $f$ είναι συνεχής στο $x_0$. Η Mathlib γράφει τα όρια με την Tendsto: το Tendsto g (𝓝[≠] x₀) (𝓝 L) σημαίνει ότι $g(x)\to L$ όταν $x\to x_0$ με $x\neq x_0$. Η κλίση $\dfrac{f(x)-f(x_0)}{x-x_0}$ γράφεται slope f x₀ x. Η απόδειξη είναι αυτή του βιβλίου: $f(x)-f(x_0)$${}=\dfrac{f(x)-f(x_0)}{x-x_0}\,(x-x_0)\to f'\cdot 0$${}=0$.

2. Βήμα προς βήμα: παραγωγίσιμη $\Rightarrow$ συνεχής

Η ιδέα: γράφουμε τη διαφορά $f(x)-f(x_0)$ ως γινόμενο της κλίσης επί $x-x_0$· η κλίση τείνει στο $f'$ και ο δεύτερος παράγοντας στο $0$. Ξεκινάμε από τον στόχο:

Ο στόχος
f : ℝ → ℝ
x₀ f' : ℝ
hf : HasDerivAt f f' x₀
⊢ ContinuousAt f x₀

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. rw [hasDerivAt_iff_tendsto_slope] at hf

    Γράφουμε την παράγωγο ως όριο: η κλίση slope f x₀ x τείνει στο $f'$ όταν $x\to x_0$ με $x\neq x_0$.

    Τι μένει να αποδειχθεί
    hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
⊢ ContinuousAt f x₀
  2. have h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0) := by

    Ενδιάμεσος ισχυρισμός h1: $x-x_0\to 0$ όταν $x\to x_0$ με $x\neq x_0$.

    Τι μένει να αποδειχθεί
    ⊢ Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0)
  3. have h : Tendsto (fun x => x - x₀) (𝓝 x₀) (𝓝 (x₀ - x₀)) :=
  (continuous_id.sub continuous_const).tendsto x₀
rw [sub_self] at h
exact h.mono_left nhdsWithin_le_nhds

    Η $x\mapsto x-x_0$ είναι συνεχής, άρα τείνει στο $x_0-x_0=0$· το ίδιο ισχύει και όταν κρατάμε μόνο τα $x\neq x_0$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  4. have h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 (f' * 0)) := hf.mul h1

    Όριο γινομένου (h2): η κλίση επί $(x-x_0)$ τείνει στο $f'\cdot 0$.

    Τι μένει να αποδειχθεί
    f : ℝ → ℝ
x₀ f' : ℝ
hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0)
h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 (f' * 0))
⊢ ContinuousAt f x₀
  5. rw [mul_zero] at h2

    Απλοποιούμε: $f'\cdot 0=0$.

    Τι μένει να αποδειχθεί
    h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 0)
⊢ ContinuousAt f x₀
  6. have h3 : Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0) := by

    Ενδιάμεσος ισχυρισμός h3: $f(x)-f(x_0)\to 0$.

    Τι μένει να αποδειχθεί
    ⊢ Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0)
  7. apply h2.congr'

    Αρκεί οι δύο συναρτήσεις να είναι ίσες για $x$ κοντά στο $x_0$ με $x\neq x_0$· τότε έχουν το ίδιο όριο, το $0$ της h2.

    Τι μένει να αποδειχθεί
    ⊢ (fun x => slope f x₀ x * (x - x₀)) =ᶠ[𝓝[≠] x₀] fun x => f x - f x₀
  8. filter_upwards [self_mem_nhdsWithin] with x hx

    Παίρνουμε $x\neq x_0$ (το {x₀}ᶜ είναι το σύνολο των $x\neq x_0$).

    Τι μένει να αποδειχθεί
    x : ℝ
hx : x ∈ {x₀}ᶜ
⊢ slope f x₀ x * (x - x₀) = f x - f x₀
  9. rw [slope_def_field, div_mul_cancel₀ _ (sub_ne_zero.mpr (Set.mem_compl_singleton_iff.mp hx))]

    Αφού $x-x_0\neq 0$: $\dfrac{f(x)-f(x_0)}{x-x_0}\cdot(x-x_0)$${}=f(x)-f(x_0)$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  10. rw [continuousAt_iff_punctured_nhds]

    Συνέχεια στο $x_0$ σημαίνει $f(x)\to f(x_0)$ όταν $x\to x_0$ με $x\neq x_0$.

    Τι μένει να αποδειχθεί
    f : ℝ → ℝ
x₀ f' : ℝ
hf : Tendsto (slope f x₀) (𝓝[≠] x₀) (𝓝 f')
h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0)
h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 0)
h3 : Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0)
⊢ Tendsto f (𝓝[≠] x₀) (𝓝 (f x₀))
  11. have h4 := h3.add_const (f x₀)

    Προσθέτουμε τη σταθερά $f(x_0)$ στο όριο της h3: $f(x)-f(x_0)+f(x_0)\to 0+f(x_0)$.

    Τι μένει να αποδειχθεί
    h4 : Tendsto (fun x => f x - f x₀ + f x₀) (𝓝[≠] x₀) (𝓝 (0 + f x₀))
⊢ Tendsto f (𝓝[≠] x₀) (𝓝 (f x₀))
  12. simpa using h4

    Απλοποιούμε: $f(x)-f(x_0)+f(x_0)=f(x)$ και $0+f(x_0)=f(x_0)$, που είναι ακριβώς ο στόχος.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: άθροισμα παραγωγίσιμων

Αν οι $f$ και $g$ είναι παραγωγίσιμες στο $x_0$, δείξε ότι η $f+g$ είναι συνεχής στο $x_0$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Η $f+g$ έχει παράγωγο $f'+g'$ (hf.add hg). Εφάρμοσε το θεώρημα: exact continuous_of_hasDeriv _ x₀ (f' + g') (hf.add hg).

Λύση
theorem sum_continuous (f g : ℝ → ℝ) (x₀ f' g' : ℝ) (hf : HasDerivAt f f' x₀)
    (hg : HasDerivAt g g' x₀) : ContinuousAt (fun x => f x + g x) x₀ :=
  continuous_of_hasDeriv _ x₀ (f' + g') (hf.add hg)

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • hasDerivAt_iff_tendsto_slope: η παράγωγος ως όριο της κλίσης $\dfrac{f(x)-f(x_0)}{x-x_0}$.
  • Filter.Tendsto.mul: το όριο γινομένου.
  • Filter.Tendsto.congr': συναρτήσεις ίσες κοντά στο σημείο έχουν το ίδιο όριο.
  • Filter.Tendsto.add_const: το όριο αθροίσματος με σταθερά.
  • continuousAt_iff_punctured_nhds: συνέχεια στο $x_0$ σημαίνει $f(x)\to f(x_0)$ όταν $x\to x_0$ με $x\neq x_0$.
  • slope_def_field: ο τύπος της κλίσης, $\dfrac{f(x)-f(x_0)}{x-x_0}$.
  • div_mul_cancel₀: $\dfrac{a}{b}\cdot b=a$ όταν $b\neq 0$.
  • HasDerivAt.add: ο κανόνας του αθροίσματος.
  • not_differentiableAt_abs_zero: η $|x|$ δεν είναι παραγωγίσιμη στο $0$.

import Mathlib

namespace Κεφ10.ParagogisimotitaSynexeia
open Filter Topology

theorem continuous_of_hasDeriv (f : ℝ → ℝ) (x₀ f' : ℝ) (hf : HasDerivAt f f' x₀) :
    ContinuousAt f x₀ := by
  rw [hasDerivAt_iff_tendsto_slope] at hf
  have h1 : Tendsto (fun x => x - x₀) (𝓝[≠] x₀) (𝓝 0) := by
    have h : Tendsto (fun x => x - x₀) (𝓝 x₀) (𝓝 (x₀ - x₀)) :=
      (continuous_id.sub continuous_const).tendsto x₀
    rw [sub_self] at h
    exact h.mono_left nhdsWithin_le_nhds
  have h2 : Tendsto (fun x => slope f x₀ x * (x - x₀)) (𝓝[≠] x₀) (𝓝 (f' * 0)) := hf.mul h1
  rw [mul_zero] at h2
  have h3 : Tendsto (fun x => f x - f x₀) (𝓝[≠] x₀) (𝓝 0) := by
    apply h2.congr'
    filter_upwards [self_mem_nhdsWithin] with x hx
    rw [slope_def_field, div_mul_cancel₀ _ (sub_ne_zero.mpr (Set.mem_compl_singleton_iff.mp hx))]
  rw [continuousAt_iff_punctured_nhds]
  have h4 := h3.add_const (f x₀)
  simpa using h4

theorem sum_continuous (f g : ℝ → ℝ) (x₀ f' g' : ℝ) (hf : HasDerivAt f f' x₀)
    (hg : HasDerivAt g g' x₀) : ContinuousAt (fun x => f x + g x) x₀ :=
  continuous_of_hasDeriv _ x₀ (f' + g') (hf.add hg)

theorem abs_counterexample :
    ContinuousAt (fun x : ℝ => |x|) 0 ∧ ¬ DifferentiableAt ℝ (fun x : ℝ => |x|) 0 :=
  ⟨continuous_abs.continuousAt, not_differentiableAt_abs_zero⟩
