Συμμετρικοί Πίνακες: πάντα ορθογώνια διαγωνιοποιήσιμοι

Κεφάλαιο 6 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΤο βήμα-κλειδί του Φασματικού Θεωρήματος: σε πραγματικό συμμετρικό πίνακα $A=A^{T}$ καμία ιδιοτιμή δεν είναι ελαττωματική, δηλαδή $m_g(\lambda)=m_a(\lambda)$ για κάθε ιδιοτιμή $\lambda$. Από αυτό, μαζί με την ορθογωνιότητα των ιδιοδιανυσμάτων διαφορετικών ιδιοτιμών, προκύπτει η ορθογώνια διαγωνιοποίηση $A=Q\Lambda Q^{T}$. Προσοχή: ο ισχυρισμός $m_g=m_a$ δεν επιτρέπεται να χρησιμοποιηθεί ως βήμα σε απόδειξη της ίδιας της διαγωνιοποιησιμότητας, γιατί είναι ακριβώς το ζητούμενο· η απόδειξη περνά από τη μιγαδική εσωτερική δομή ή από επαγωγή στη διάσταση.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $m_g(\lambda)=m_a(\lambda)$ για κάθε $\lambda$, σε πραγματικό συμμετρικό $A$: καμία ιδιοτιμή δεν είναι ελαττωματική
    theorem geom_eq_alg (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) (μ : ℝ) :
    finrank ℝ (End.eigenspace (toEuclideanLin A) μ) = A.charpoly.rootMultiplicity μ
  • Η ίδια ισότητα για συμμετρικό τελεστή σε χώρο με εσωτερικό γινόμενο
    theorem geom_eq_alg_operator {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E]
    [FiniteDimensional ℝ E] (T : E →ₗ[ℝ] E) (hT : T.IsSymmetric) {m : ℕ}
    (hm : finrank ℝ E = m) (μ : ℝ) :
    finrank ℝ (End.eigenspace T μ) = T.charpoly.rootMultiplicity μ
  • Η ορθογώνια διαγωνιοποίηση $A=Q\Lambda Q^{T}$ με $Q^{T}Q=I$
    theorem orthogonal_diagonalization (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) :
    ∃ Q : Matrix (Fin n) (Fin n) ℝ, Qᵀ * Q = 1 ∧ A = Q * diagonal hA.eigenvalues * Qᵀ
  • Βοηθητικό: ο $A$ και η απεικόνιση $\mathbf{x}\mapsto A\mathbf{x}$ του $\mathbb{R}^n$ έχουν το ίδιο χαρακτηριστικό πολυώνυμο
    theorem charpoly_euclidean (A : Matrix (Fin n) (Fin n) ℝ) :
    (toEuclideanLin A).charpoly = A.charpoly

Ο συμμετρικός πίνακας δίνεται με την υπόθεση hA : A.IsHermitian: για πραγματικούς πίνακες, ερμιτιανός σημαίνει ακριβώς $A^{T}=A$. Η γεωμετρική πολλαπλότητα $m_g(\lambda)$ είναι η διάσταση του ιδιόχωρου End.eigenspace (toEuclideanLin A) μ, όπου toEuclideanLin A είναι η απεικόνιση $\mathbf{x}\mapsto A\mathbf{x}$ του $\mathbb{R}^n$ με το συνηθισμένο εσωτερικό γινόμενο. Η αλγεβρική πολλαπλότητα $m_a(\lambda)$ είναι η A.charpoly.rootMultiplicity μ. Η απόδειξη μετράει: και οι δύο πολλαπλότητες είναι ίσες με το πλήθος των δεικτών $i$ με $\lambda_i=\lambda$. Για τη $m_g$ η Mathlib στηρίζεται σε ορθοκανονική βάση από ιδιοδιανύσματα, την οποία έχει κατασκευάσει πρώτα, χωρίς να χρησιμοποιήσει την $m_g=m_a$. Για τη $m_a$ στηρίζεται στο ότι οι ρίζες του χαρακτηριστικού πολυωνύμου είναι οι $\lambda_1,\dots,\lambda_n$.

2. Πού βρίσκεται στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • LinearMap.IsSymmetric.card_filter_eigenvalues_eq: η διάσταση του ιδιόχωρου της $\lambda$ είναι το πλήθος των $i$ με $\lambda_i=\lambda$.
  • LinearMap.IsSymmetric.roots_charpoly_eq_eigenvalues: οι ρίζες του χαρακτηριστικού πολυωνύμου είναι οι $\lambda_1,\dots,\lambda_n$.
  • Polynomial.count_roots: η πολλαπλότητα μιας ρίζας είναι το πόσες φορές εμφανίζεται στο πολυσύνολο των ριζών.
  • Matrix.isSymmetric_toEuclideanLin_iff: ο $A$ είναι συμμετρικός ακριβώς όταν η $\mathbf{x}\mapsto A\mathbf{x}$ είναι συμμετρικός τελεστής.
  • Matrix.IsHermitian.spectral_theorem: το φασματικό θεώρημα για ερμιτιανούς πίνακες.

import Mathlib

namespace Κεφ6.SymmetrikosDiagonopoiisimos
open Matrix Module

-- η γενική μορφή: συμμετρικός τελεστής σε χώρο με εσωτερικό γινόμενο
theorem geom_eq_alg_operator {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E]
    [FiniteDimensional ℝ E] (T : E →ₗ[ℝ] E) (hT : T.IsSymmetric) {m : ℕ}
    (hm : finrank ℝ E = m) (μ : ℝ) :
    finrank ℝ (End.eigenspace T μ) = T.charpoly.rootMultiplicity μ := by
  rw [← Polynomial.count_roots, hT.roots_charpoly_eq_eigenvalues hm, Multiset.count_map,
    ← hT.card_filter_eigenvalues_eq hm μ, Finset.card_def, Finset.filter_val]
  congr 1
  apply Multiset.filter_congr
  intro i _
  rw [Function.comp_apply, eq_comm]

variable {n : ℕ}

theorem charpoly_euclidean (A : Matrix (Fin n) (Fin n) ℝ) :
    (toEuclideanLin A).charpoly = A.charpoly := by
  rw [toEuclideanLin_eq_toLin_orthonormal, charpoly_toLin]

theorem geom_eq_alg (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) (μ : ℝ) :
    finrank ℝ (End.eigenspace (toEuclideanLin A) μ) = A.charpoly.rootMultiplicity μ := by
  rw [← charpoly_euclidean A]
  exact geom_eq_alg_operator _ (isSymmetric_toEuclideanLin_iff.mpr hA) finrank_euclideanSpace μ

theorem orthogonal_diagonalization (A : Matrix (Fin n) (Fin n) ℝ) (hA : A.IsHermitian) :
    ∃ Q : Matrix (Fin n) (Fin n) ℝ, Qᵀ * Q = 1 ∧ A = Q * diagonal hA.eigenvalues * Qᵀ := by
  refine ⟨hA.eigenvectorUnitary, ?_, ?_⟩
  · rw [← conjTranspose_eq_transpose_of_trivial, ← star_eq_conjTranspose]
    exact Unitary.coe_star_mul_self hA.eigenvectorUnitary
  · conv_lhs => rw [hA.spectral_theorem]
    rw [Unitary.conjStarAlgAut_apply, star_eq_conjTranspose,
      conjTranspose_eq_transpose_of_trivial, RCLike.ofReal_real_eq_id, Function.id_comp]
