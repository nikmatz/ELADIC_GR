Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $T(\mathbf{0})=\mathbf{0}$
    theorem image_zero (T : V →ₗ[ℝ] W) : T 0 = 0
  • $T(-\mathbf{u})=-T(\mathbf{u})$
    theorem image_neg (T : V →ₗ[ℝ] W) (u : V) : T (-u) = -T u
  • $T(c_1\mathbf{u}_1+\dots+c_k\mathbf{u}_k)$${}=c_1T(\mathbf{u}_1)+\dots+c_kT(\mathbf{u}_k)$
    theorem image_lincomb (T : V →ₗ[ℝ] W) (k : ℕ) (c : Fin k → ℝ) (u : Fin k → V) :
    T (∑ i, c i • u i) = ∑ i, c i • T (u i)

Οι $V,W$ είναι οποιοιδήποτε πραγματικοί διανυσματικοί χώροι και ο $T$ γράφεται T : V →ₗ[ℝ] W. Ο γραμμικός συνδυασμός $c_1\mathbf{u}_1+\dots+c_k\mathbf{u}_k$ γράφεται ∑ i, c i • u i, όπου οι συντελεστές c και τα διανύσματα u έχουν δείκτες $i=0,\dots,k-1$. Οι γραμμές inst✝ : … στους στόχους είναι οι υποθέσεις ότι οι $V,W$ είναι διανυσματικοί χώροι.

2. Βήμα προς βήμα: $T(\mathbf{0})=\mathbf{0}$

Η ιδέα: $T(\mathbf{0})$${}=T(\mathbf{0}+\mathbf{0})$${}=T(\mathbf{0})+T(\mathbf{0})$, και διαγράφουμε το $T(\mathbf{0})$ από τα δύο μέλη. Ξεκινάμε από τον στόχο:

Ο στόχος
V : Type u_1
W : Type u_2
inst✝³ : AddCommGroup V
inst✝² : Module ℝ V
inst✝¹ : AddCommGroup W
inst✝ : Module ℝ W
T : V →ₗ[ℝ] W
⊢ T 0 = 0

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. have h : T 0 + T 0 = T 0 + 0 := by

    Ενδιάμεσος ισχυρισμός: $T(\mathbf{0})+T(\mathbf{0})$${}=T(\mathbf{0})+\mathbf{0}$.

    Τι μένει να αποδειχθεί
    ⊢ T 0 + T 0 = T 0 + 0
  2. rw [← map_add]

    Από τη γραμμικότητα, $T(\mathbf{0})+T(\mathbf{0})$${}=T(\mathbf{0}+\mathbf{0})$ (θεώρημα map_add, από δεξιά προς τα αριστερά).

    Τι μένει να αποδειχθεί
    ⊢ T (0 + 0) = T 0 + 0
  3. rw [add_zero, add_zero]

    Επειδή $\mathbf{0}+\mathbf{0}=\mathbf{0}$ και $T(\mathbf{0})+\mathbf{0}$${}=T(\mathbf{0})$, τα δύο μέλη γίνονται ίδια.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  4. rw [add_right_inj] at h

    Διαγράφουμε το $T(\mathbf{0})$ από τα αριστερά: από $a+b=a+c$ έπεται $b=c$. Η h γίνεται $T(\mathbf{0})=\mathbf{0}$.

    Τι μένει να αποδειχθεί
    V : Type u_1
W : Type u_2
inst✝³ : AddCommGroup V
inst✝² : Module ℝ V
inst✝¹ : AddCommGroup W
inst✝ : Module ℝ W
T : V →ₗ[ℝ] W
h : T 0 = 0
⊢ T 0 = 0
  5. exact h

    Αυτό ζητούσαμε.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: $T(-\mathbf{u})=-T(\mathbf{u})$

Δείξε ότι $T(-\mathbf{u})=-T(\mathbf{u})$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Γράψε $-\mathbf{u}=(-1)\,\mathbf{u}$ και βγάλε τον αριθμό έξω από τον $T$: rw [← neg_one_smul ℝ u, map_smul, neg_one_smul].

Λύση
theorem image_neg (T : V →ₗ[ℝ] W) (u : V) : T (-u) = -T u := by
  rw [← neg_one_smul ℝ u, map_smul, neg_one_smul]

4. Στη Mathlib

Οι ίδιες ιδιότητες υπάρχουν έτοιμες στη Mathlib, για κάθε γραμμική απεικόνιση:

  • map_zero: $T(\mathbf{0})=\mathbf{0}$.
  • map_neg: $T(-\mathbf{u})=-T(\mathbf{u})$.
  • map_add: $T(\mathbf{u}+\mathbf{v})$${}=T(\mathbf{u})+T(\mathbf{v})$.
  • map_smul: $T(c\,\mathbf{u})=c\,T(\mathbf{u})$.
  • map_sum: η εικόνα ενός αθροίσματος είναι το άθροισμα των εικόνων.

theorem image_zero (T : V →ₗ[ℝ] W) : T 0 = 0 := by
  have h : T 0 + T 0 = T 0 + 0 := by
    rw [← map_add]
    rw [add_zero, add_zero]
  rw [add_right_inj] at h
  exact h
