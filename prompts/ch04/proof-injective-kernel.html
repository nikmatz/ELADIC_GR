  • Ο $T:\mathbb{R}^n\to\mathbb{R}^m$ είναι ένα-προς-ένα αν και μόνο αν $\ker T=\{\mathbf{0}\}$

  • Η ίδια ισοδυναμία, όπως είναι γραμμένη στη Mathlib
    theorem mathlib_version (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) :
    LinearMap.ker T = ⊥ ↔ Function.Injective T

Ο γραμμικός μετασχηματισμός $T:\mathbb{R}^n\to\mathbb{R}^m$ γράφεται T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ). Το «ένα-προς-ένα» είναι η Function.Injective T: από $T(\mathbf{x})=T(\mathbf{y})$ έπεται $\mathbf{x}=\mathbf{y}$. Ο πυρήνας $\ker T$${}=\{\mathbf{x}: T(\mathbf{x})$${}=\mathbf{0}\}$ γράφεται LinearMap.ker T (στους στόχους εμφανίζεται ως T.ker) και ο μηδενικός υπόχωρος $\{\mathbf{0}\}$ γράφεται ⊥. Το ⇑T στους στόχους είναι απλώς ο $T$ ως συνάρτηση.

2. Βήμα προς βήμα: ένα-προς-ένα $\Leftrightarrow\ker T$${}=\{\mathbf{0}\}$

Η ιδέα: αν ο $T$ είναι ένα-προς-ένα, το μόνο διάνυσμα με εικόνα $\mathbf{0}$ είναι το $\mathbf{0}$, γιατί ήδη $T(\mathbf{0})=\mathbf{0}$. Αντίστροφα, αν $T(\mathbf{x})=T(\mathbf{y})$, τότε $T(\mathbf{x}-\mathbf{y})$${}=\mathbf{0}$, άρα $\mathbf{x}-\mathbf{y}\in\ker T$${}=\{\mathbf{0}\}$. Ξεκινάμε από τον στόχο:

Ο στόχος
m n : ℕ
T : (Fin n → ℝ) →ₗ[ℝ] Fin m → ℝ
⊢ Function.Injective ⇑T ↔ T.ker = ⊥

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. constructor

    Δύο κατευθύνσεις: mp για το $\Rightarrow$ και mpr για το $\Leftarrow$.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος mp
    ⊢ Function.Injective ⇑T → T.ker = ⊥
    σκέλος mpr
    ⊢ T.ker = ⊥ → Function.Injective ⇑T
  2. · intro h

    Κατεύθυνση $\Rightarrow$: υποθέτουμε ότι ο $T$ είναι ένα-προς-ένα (υπόθεση h).

    Τι μένει να αποδειχθεί
    h : Function.Injective ⇑T
⊢ T.ker = ⊥
  3. rw [eq_bot_iff]

    Ο $\{\mathbf{0}\}$ είναι ο μικρότερος υπόχωρος, άρα ένας υπόχωρος είναι ίσος με αυτόν ακριβώς όταν περιέχεται σε αυτόν. Το ≤ ανάμεσα σε υπόχωρους σημαίνει $\subseteq$.

    Τι μένει να αποδειχθεί
    ⊢ T.ker ≤ ⊥
  4. intro x hx

    Παίρνουμε ένα $\mathbf{x}$ του πυρήνα (υπόθεση hx) και θα δείξουμε ότι $\mathbf{x}\in\{\mathbf{0}\}$.

    Τι μένει να αποδειχθεί
    x : Fin n → ℝ
hx : x ∈ T.ker
⊢ x ∈ ⊥
  5. rw [LinearMap.mem_ker] at hx

    $\mathbf{x}\in\ker T$ σημαίνει $T(\mathbf{x})=\mathbf{0}$.

    Τι μένει να αποδειχθεί
    hx : T x = 0
⊢ x ∈ ⊥
  6. rw [Submodule.mem_bot]

    $\mathbf{x}\in\{\mathbf{0}\}$ σημαίνει $\mathbf{x}=\mathbf{0}$.

    Τι μένει να αποδειχθεί
    ⊢ x = 0
  7. apply h

    Επειδή ο $T$ είναι ένα-προς-ένα, για να δείξουμε $\mathbf{x}=\mathbf{0}$ αρκεί να δείξουμε $T(\mathbf{x})=T(\mathbf{0})$.

    Τι μένει να αποδειχθεί
    ⊢ T x = T 0
  8. rw [hx, map_zero]

    Ισχύει, γιατί $T(\mathbf{x})=\mathbf{0}$ και $T(\mathbf{0})=\mathbf{0}$ (θεώρημα map_zero).

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  9. · intro h x y hxy

    Κατεύθυνση $\Leftarrow$: υποθέτουμε $\ker T=\{\mathbf{0}\}$ και παίρνουμε $\mathbf{x},\mathbf{y}$ με $T(\mathbf{x})=T(\mathbf{y})$ (υπόθεση hxy). Θα δείξουμε ότι $\mathbf{x}=\mathbf{y}$.

    Τι μένει να αποδειχθεί
    m n : ℕ
T : (Fin n → ℝ) →ₗ[ℝ] Fin m → ℝ
h : T.ker = ⊥
x y : Fin n → ℝ
hxy : T x = T y
⊢ x = y
  10. have hsub : x - y ∈ LinearMap.ker T := by

    Ενδιάμεσος ισχυρισμός: το $\mathbf{x}-\mathbf{y}$ ανήκει στον πυρήνα.

    Τι μένει να αποδειχθεί
    ⊢ x - y ∈ T.ker
  11. rw [LinearMap.mem_ker, map_sub, hxy, sub_self]

    $T(\mathbf{x}-\mathbf{y})$${}=T(\mathbf{x})-T(\mathbf{y})$${}=T(\mathbf{y})-T(\mathbf{y})$${}=\mathbf{0}$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  12. rw [h, Submodule.mem_bot, sub_eq_zero] at hsub

    Αφού ο πυρήνας είναι ο $\{\mathbf{0}\}$, έχουμε $\mathbf{x}-\mathbf{y}=\mathbf{0}$, δηλαδή $\mathbf{x}=\mathbf{y}$.

    Τι μένει να αποδειχθεί
    m n : ℕ
T : (Fin n → ℝ) →ₗ[ℝ] Fin m → ℝ
h : T.ker = ⊥
x y : Fin n → ℝ
hxy : T x = T y
hsub : x = y
⊢ x = y
  13. exact hsub

    Αυτό ζητούσαμε.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: μόνο το $\mathbf{0}$ πηγαίνει στο $\mathbf{0}$

Αν ο $T$ είναι ένα-προς-ένα και $T(\mathbf{x})=\mathbf{0}$, δείξε ότι $\mathbf{x}=\mathbf{0}$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • LinearMap.mem_ker: $\mathbf{x}\in\ker T\Leftrightarrow T(\mathbf{x})$${}=\mathbf{0}$.
  • Submodule.mem_bot: $\mathbf{x}\in\{\mathbf{0}\}\Leftrightarrow\mathbf{x}$${}=\mathbf{0}$.
  • eq_bot_iff: ένας υπόχωρος είναι ο $\{\mathbf{0}\}$ ακριβώς όταν περιέχεται σε αυτόν.
  • map_zero: $T(\mathbf{0})=\mathbf{0}$.
  • map_sub: $T(\mathbf{x}-\mathbf{y})$${}=T(\mathbf{x})-T(\mathbf{y})$.
  • LinearMap.ker_eq_bot: η ίδια ισοδυναμία στη Mathlib.

variable {m n : ℕ}

theorem injective_iff_ker (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) :
    Function.Injective T ↔ LinearMap.ker T = ⊥ := by
  constructor
  · intro h
    rw [eq_bot_iff]
    intro x hx
    rw [LinearMap.mem_ker] at hx
    rw [Submodule.mem_bot]
    apply h
    rw [hx, map_zero]
  · intro h x y hxy
    have hsub : x - y ∈ LinearMap.ker T := by
      rw [LinearMap.mem_ker, map_sub, hxy, sub_self]
    rw [h, Submodule.mem_bot, sub_eq_zero] at hsub
    exact hsub

theorem zero_of_injective (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) (h : Function.Injective T)
    (x : Fin n → ℝ) (hx : T x = 0) : x = 0 := by
  apply h
  rw [hx, map_zero]

theorem mathlib_version (T : (Fin n → ℝ) →ₗ[ℝ] (Fin m → ℝ)) :
    LinearMap.ker T = ⊥ ↔ Function.Injective T :=
  LinearMap.ker_eq_bot
