Κριτήριο Παρεμβολής (Squeeze Theorem)

Κεφάλαιο 9 · Εξήγηση από Μεγάλο Γλωσσικό Μοντέλο και απόδειξη ελεγμένη από υπολογιστή (Lean)

ΕκφώνησηΑν $h(x)\le f(x)\le g(x)$ σε γειτονιά του $x_0$ (ίσως εκτός του $x_0$) και $\lim_{x\to x_0}h(x)$${}=\lim_{x\to x_0}g(x)$${}=L$, τότε $\lim_{x\to x_0}f(x)=L$.

Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $h\le f\le g$ κοντά στο $x_0$ και $\lim h=\lim g=L$, τότε $\lim f=L$
    theorem squeeze (f g h : ℝ → ℝ) (x₀ L δ₀ : ℝ) (hδ₀ : 0 < δ₀)
    (hle : ∀ x, 0 < |x - x₀| → |x - x₀| < δ₀ → h x ≤ f x ∧ f x ≤ g x)
    (hh : HasLim h x₀ L) (hg : HasLim g x₀ L) : HasLim f x₀ L
  • Το ίδιο θεώρημα με το όριο της Mathlib
    theorem squeeze_mathlib (f g h : ℝ → ℝ) (x₀ L : ℝ) (hh : Tendsto h (𝓝[≠] x₀) (𝓝 L))
    (hg : Tendsto g (𝓝[≠] x₀) (𝓝 L)) (hhf : ∀ᶠ x in 𝓝[≠] x₀, h x ≤ f x)
    (hfg : ∀ᶠ x in 𝓝[≠] x₀, f x ≤ g x) : Tendsto f (𝓝[≠] x₀) (𝓝 L)
  • Εφαρμογή: αν $|f(x)-L|\le|x-x_0|$ για κάθε $x$, τότε $\lim f=L$
    theorem lim_of_bound (f : ℝ → ℝ) (x₀ L : ℝ) (hb : ∀ x, |f x - L| ≤ |x - x₀|) :
    HasLim f x₀ L

Ο ορισμός του βιβλίου γράφεται ως HasLim f x₀ L: για κάθε $\varepsilon\gt 0$ υπάρχει $\delta\gt 0$ ώστε, για κάθε $x$ με $0\lt|x-x_0|\lt\delta$, να ισχύει $|f(x)-L|\lt\varepsilon$. Η «γειτονιά του $x_0$, ίσως εκτός του $x_0$» είναι τα $x$ με $0\lt|x-x_0|\lt\delta_0$ (υπόθεση hle). Στη διατύπωση της Mathlib το «κοντά στο $x_0$, με $x\neq x_0$» γράφεται ∀ᶠ x in 𝓝[≠] x₀.

2. Βήμα προς βήμα: το κριτήριο παρεμβολής

Η ιδέα: για $x$ αρκετά κοντά στο $x_0$ έχουμε $L-\varepsilon\lt h(x)\le f(x)\le g(x)\lt L+\varepsilon$. Ξεκινάμε από τον στόχο:

Ο στόχος
f g h : ℝ → ℝ
x₀ L δ₀ : ℝ
hδ₀ : 0 < δ₀
hle : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₀ → h x ≤ f x ∧ f x ≤ g x
hh : HasLim h x₀ L
hg : HasLim g x₀ L
⊢ HasLim f x₀ L

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. intro ε hε

    Παίρνουμε τυχαίο $\varepsilon\gt 0$.

    Τι μένει να αποδειχθεί
    ε : ℝ
hε : ε > 0
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε
  2. obtain ⟨δ₁, hδ₁, h₁⟩ := hh ε hε

    Από το όριο της $h$ παίρνουμε $\delta_1\gt 0$, με $|h(x)-L|\lt\varepsilon$ όταν $0\lt|x-x_0|\lt\delta_1$.

    Τι μένει να αποδειχθεί
    δ₁ : ℝ
hδ₁ : δ₁ > 0
h₁ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₁ → |h x - L| < ε
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε
  3. obtain ⟨δ₂, hδ₂, h₂⟩ := hg ε hε

    Από το όριο της $g$ παίρνουμε $\delta_2\gt 0$, με $|g(x)-L|\lt\varepsilon$ όταν $0\lt|x-x_0|\lt\delta_2$.

    Τι μένει να αποδειχθεί
    δ₂ : ℝ
hδ₂ : δ₂ > 0
h₂ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₂ → |g x - L| < ε
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε
  4. refine ⟨min δ₀ (min δ₁ δ₂), lt_min hδ₀ (lt_min hδ₁ hδ₂), ?_⟩

    Διαλέγουμε $\delta$${}=\min(\delta_0,\delta_1,\delta_2)$, που είναι θετικό.

    Τι μένει να αποδειχθεί
    ⊢ ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < min δ₀ (min δ₁ δ₂) → |f x - L| < ε
  5. intro x hx hxδ

    Παίρνουμε $x$ με $0\lt|x-x_0|\lt\delta$.

    Τι μένει να αποδειχθεί
    x : ℝ
hx : 0 < |x - x₀|
hxδ : |x - x₀| < min δ₀ (min δ₁ δ₂)
⊢ |f x - L| < ε
  6. have hx₀ : |x - x₀| < δ₀ := lt_of_lt_of_le hxδ (min_le_left _ _)
have hx₁ : |x - x₀| < δ₁ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_left _ _))
have hx₂ : |x - x₀| < δ₂ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_right _ _))

    Επειδή το $\delta$ είναι το μικρότερο, ισχύουν οι $|x-x_0|\lt\delta_0$, $|x-x_0|\lt\delta_1$ και $|x-x_0|\lt\delta_2$.

    Τι μένει να αποδειχθεί
    hx₀ : |x - x₀| < δ₀
hx₁ : |x - x₀| < δ₁
hx₂ : |x - x₀| < δ₂
⊢ |f x - L| < ε
  7. obtain ⟨hhf, hfg⟩ := hle x hx hx₀

    Από την υπόθεση hle: $h(x)\le f(x)$ και $f(x)\le g(x)$.

    Τι μένει να αποδειχθεί
    hhf : h x ≤ f x
hfg : f x ≤ g x
⊢ |f x - L| < ε
  8. have ha := h₁ x hx hx₁
have hb := h₂ x hx hx₂

    Από τα όρια: $|h(x)-L|\lt\varepsilon$ και $|g(x)-L|\lt\varepsilon$.

    Τι μένει να αποδειχθεί
    ha : |h x - L| < ε
hb : |g x - L| < ε
⊢ |f x - L| < ε
  9. rw [abs_sub_lt_iff] at ha hb ⊢

    Γράφουμε κάθε απόλυτη τιμή ως δύο ανισότητες: το $|a-b|\lt\varepsilon$ σημαίνει $a-b\lt\varepsilon$ και $b-a\lt\varepsilon$.

    Τι μένει να αποδειχθεί
    ha : h x - L < ε ∧ L - h x < ε
hb : g x - L < ε ∧ L - g x < ε
⊢ f x - L < ε ∧ L - f x < ε
  10. constructor

    Δύο στόχοι: $f(x)-L\lt\varepsilon$ και $L-f(x)\lt\varepsilon$.

    Τι μένει να αποδειχθεί (2 στόχοι)σκέλος left
    ⊢ f x - L < ε
    σκέλος right
    ⊢ L - f x < ε
  11. · linarith [hb.1]

    $f(x)-L\le g(x)-L\lt\varepsilon$.

    ✓ Αυτό το σκέλος ολοκληρώθηκε.
  12. · linarith [ha.2]

    $L-f(x)\le L-h(x)\lt\varepsilon$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: φράγμα από το $|x-x_0|$

Αν $|f(x)-L|\le|x-x_0|$ για κάθε $x$, δείξε ότι $\lim_{x\to x_0}f(x)=L$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ξεκίνα με intro ε hε και πάρε $\delta=\varepsilon$: refine ⟨ε, hε, ?_⟩. Μετά γράψε intro x _ hxδ και exact lt_of_le_of_lt (hb x) hxδ, γιατί $|f(x)-L|\le|x-x_0|\lt\varepsilon$.

Λύση
theorem lim_of_bound (f : ℝ → ℝ) (x₀ L : ℝ) (hb : ∀ x, |f x - L| ≤ |x - x₀|) :
    HasLim f x₀ L := by
  intro ε hε
  refine ⟨ε, hε, ?_⟩
  intro x _ hxδ
  exact lt_of_le_of_lt (hb x) hxδ

import Mathlib

namespace Κεφ9.Parembolh
open Filter Topology

-- ο ορισμός του βιβλίου: lim_{x→x₀} f(x) = L
def HasLim (f : ℝ → ℝ) (x₀ L : ℝ) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ x, 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε

theorem squeeze (f g h : ℝ → ℝ) (x₀ L δ₀ : ℝ) (hδ₀ : 0 < δ₀)
    (hle : ∀ x, 0 < |x - x₀| → |x - x₀| < δ₀ → h x ≤ f x ∧ f x ≤ g x)
    (hh : HasLim h x₀ L) (hg : HasLim g x₀ L) : HasLim f x₀ L := by
  intro ε hε
  obtain ⟨δ₁, hδ₁, h₁⟩ := hh ε hε
  obtain ⟨δ₂, hδ₂, h₂⟩ := hg ε hε
  refine ⟨min δ₀ (min δ₁ δ₂), lt_min hδ₀ (lt_min hδ₁ hδ₂), ?_⟩
  intro x hx hxδ
  have hx₀ : |x - x₀| < δ₀ := lt_of_lt_of_le hxδ (min_le_left _ _)
  have hx₁ : |x - x₀| < δ₁ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_left _ _))
  have hx₂ : |x - x₀| < δ₂ := lt_of_lt_of_le hxδ ((min_le_right _ _).trans (min_le_right _ _))
  obtain ⟨hhf, hfg⟩ := hle x hx hx₀
  have ha := h₁ x hx hx₁
  have hb := h₂ x hx hx₂
  rw [abs_sub_lt_iff] at ha hb ⊢
  constructor
  · linarith [hb.1]
  · linarith [ha.2]

theorem lim_of_bound (f : ℝ → ℝ) (x₀ L : ℝ) (hb : ∀ x, |f x - L| ≤ |x - x₀|) :
    HasLim f x₀ L := by
  intro ε hε
  refine ⟨ε, hε, ?_⟩
  intro x _ hxδ
  exact lt_of_le_of_lt (hb x) hxδ

theorem squeeze_mathlib (f g h : ℝ → ℝ) (x₀ L : ℝ) (hh : Tendsto h (𝓝[≠] x₀) (𝓝 L))
    (hg : Tendsto g (𝓝[≠] x₀) (𝓝 L)) (hhf : ∀ᶠ x in 𝓝[≠] x₀, h x ≤ f x)
    (hfg : ∀ᶠ x in 𝓝[≠] x₀, f x ≤ g x) : Tendsto f (𝓝[≠] x₀) (𝓝 L) :=
  tendsto_of_tendsto_of_tendsto_of_le_of_le' hh hg hhf hfg

end Κεφ9.Parembolh
