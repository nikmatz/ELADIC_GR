Ο Lean είναι γλώσσα στην οποία γράφουμε μια απόδειξη τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα. Αν ένα βήμα δεν προκύπτει από τα προηγούμενα, ο έλεγχος αποτυγχάνει.

1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • Αν $\lim_{x\to x_0}g(x)=\ell$ και η $f$ είναι συνεχής στο $\ell$, τότε $\lim_{x\to x_0}f(g(x))=f(\ell)$
    theorem lim_comp (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : HasLim g x₀ ℓ) (hf : ContAt f ℓ) :
    HasLim (f ∘ g) x₀ (f ℓ)
  • Το ίδιο θεώρημα με το όριο και τη συνέχεια της Mathlib
    theorem lim_comp_mathlib (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : Tendsto g (𝓝[≠] x₀) (𝓝 ℓ))
    (hf : ContinuousAt f ℓ) : Tendsto (f ∘ g) (𝓝[≠] x₀) (𝓝 (f ℓ))

Το όριο γράφεται ως HasLim g x₀ ℓ, με τον ορισμό $\varepsilon$-$\delta$ του βιβλίου, και η συνέχεια της $f$ στο $\ell$ ως ContAt f ℓ: για κάθε $\varepsilon\gt 0$ υπάρχει $\eta\gt 0$ ώστε $|u-\ell|\lt\eta\Rightarrow|f(u)-f(\ell)|\lt\varepsilon$. Η σύνθεση $x\mapsto f(g(x))$ γράφεται f ∘ g. Στη διατύπωση της Mathlib η συνέχεια είναι η ContinuousAt f ℓ.

2. Βήμα προς βήμα: $\lim f(g(x))=f(\ell)$

Η ιδέα: η συνέχεια της $f$ δίνει ένα $\eta$ για το $\varepsilon$, και το όριο της $g$ δίνει ένα $\delta$ για αυτό το $\eta$. Ξεκινάμε από τον στόχο:

Ο στόχος
f g : ℝ → ℝ
x₀ ℓ : ℝ
hg : HasLim g x₀ ℓ
hf : ContAt f ℓ
⊢ HasLim (f ∘ g) x₀ (f ℓ)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. intro ε hε

    Παίρνουμε τυχαίο $\varepsilon\gt 0$.

    Τι μένει να αποδειχθεί
    ε : ℝ
hε : ε > 0
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  2. obtain ⟨η, hη, h₁⟩ := hf ε hε

    Από τη συνέχεια της $f$ στο $\ell$: υπάρχει $\eta\gt 0$ ώστε $|u-\ell|\lt\eta\Rightarrow|f(u)-f(\ell)|\lt\varepsilon$.

    Τι μένει να αποδειχθεί
    η : ℝ
hη : η > 0
h₁ : ∀ (u : ℝ), |u - ℓ| < η → |f u - f ℓ| < ε
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  3. obtain ⟨δ, hδ, h₂⟩ := hg η hη

    Από το όριο της $g$, με $\eta$ στη θέση του $\varepsilon$: υπάρχει $\delta\gt 0$ ώστε $|g(x)-\ell|\lt\eta$ όταν $0\lt|x-x_0|\lt\delta$.

    Τι μένει να αποδειχθεί
    δ : ℝ
hδ : δ > 0
h₂ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |g x - ℓ| < η
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  4. refine ⟨δ, hδ, ?_⟩

    Διαλέγουμε αυτό το $\delta$.

    Τι μένει να αποδειχθεί
    ⊢ ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f ∘ g) x - f ℓ| < ε
  5. intro x hx hxδ

    Παίρνουμε $x$ με $0\lt|x-x_0|\lt\delta$.

    Τι μένει να αποδειχθεί
    x : ℝ
hx : 0 < |x - x₀|
hxδ : |x - x₀| < δ
⊢ |(f ∘ g) x - f ℓ| < ε
  6. have hgx : |g x - ℓ| < η := h₂ x hx hxδ

    Τότε $|g(x)-\ell|\lt\eta$.

    Τι μένει να αποδειχθεί
    hgx : |g x - ℓ| < η
⊢ |(f ∘ g) x - f ℓ| < ε
  7. exact h₁ (g x) hgx

    Εφαρμόζουμε τη συνέχεια της $f$ με $u=g(x)$ και παίρνουμε $|f(g(x))-f(\ell)|\lt\varepsilon$. Το (f ∘ g) x είναι το $f(g(x))$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: η $u\mapsto u$ είναι συνεχής

Δείξε, με τον ορισμό του $\eta$, ότι η ταυτοτική συνάρτηση $u\mapsto u$ είναι συνεχής σε κάθε $\ell$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ξεκίνα με intro ε hε και πάρε $\eta=\varepsilon$: refine ⟨ε, hε, ?_⟩. Μετά γράψε intro u hu και exact hu, γιατί ο στόχος είναι ακριβώς η υπόθεση $|u-\ell|\lt\varepsilon$.

Λύση
theorem cont_id (ℓ : ℝ) : ContAt (fun u => u) ℓ := by
  intro ε hε
  refine ⟨ε, hε, ?_⟩
  intro u hu
  exact hu

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • ContinuousAt.tendsto: συνέχεια στο $\ell$ σημαίνει ότι $f(u)\to f(\ell)$ όταν $u\to\ell$.
  • Filter.Tendsto.comp: το όριο μιας σύνθεσης.

import Mathlib

namespace Κεφ9.Antikatastasi
open Filter Topology

-- ο ορισμός του βιβλίου: lim_{x→x₀} f(x) = L
def HasLim (f : ℝ → ℝ) (x₀ L : ℝ) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ x, 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε

-- η συνέχεια της f στο ℓ, επίσης με ε και δ
def ContAt (f : ℝ → ℝ) (ℓ : ℝ) : Prop :=
  ∀ ε > 0, ∃ η > 0, ∀ u, |u - ℓ| < η → |f u - f ℓ| < ε

theorem lim_comp (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : HasLim g x₀ ℓ) (hf : ContAt f ℓ) :
    HasLim (f ∘ g) x₀ (f ℓ) := by
  intro ε hε
  obtain ⟨η, hη, h₁⟩ := hf ε hε
  obtain ⟨δ, hδ, h₂⟩ := hg η hη
  refine ⟨δ, hδ, ?_⟩
  intro x hx hxδ
  have hgx : |g x - ℓ| < η := h₂ x hx hxδ
  exact h₁ (g x) hgx

theorem cont_id (ℓ : ℝ) : ContAt (fun u => u) ℓ := by
  intro ε hε
  refine ⟨ε, hε, ?_⟩
  intro u hu
  exact hu

theorem lim_comp_mathlib (f g : ℝ → ℝ) (x₀ ℓ : ℝ) (hg : Tendsto g (𝓝[≠] x₀) (𝓝 ℓ))
    (hf : ContinuousAt f ℓ) : Tendsto (f ∘ g) (𝓝[≠] x₀) (𝓝 (f ℓ)) :=
  hf.tendsto.comp hg

end Κεφ9.Antikatastasi
