1. Τι αποδεικνύεται: η διατύπωση στο βιβλίο και στον Lean

  • $\lim(f+g)=L+M$, με τον ορισμό $\varepsilon$-$\delta$ του βιβλίου
    theorem lim_add (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f + g) x₀ (L + M)
  • $\lim(f-g)=L-M$
    theorem lim_sub (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f - g) x₀ (L - M)
  • $\lim(fg)=LM$
    theorem lim_mul (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f * g) x₀ (L * M)
  • $\lim\dfrac{f}{g}=\dfrac{L}{M}$, όταν $M\ne 0$
    theorem lim_div (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M)
    (hM : M ≠ 0) : HasLim (f / g) x₀ (L / M)
  • $\lim f^n=L^n$
    theorem lim_pow (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (f ^ n) x₀ (L ^ n)
  • $\lim\sqrt{f}=\sqrt{L}$
    theorem lim_sqrt (f : ℝ → ℝ) (x₀ L : ℝ) (hf : HasLim f x₀ L) :
    HasLim (fun x => √(f x)) x₀ (√L)
  • $\lim f^{1/n}=L^{1/n}$, δηλαδή $\lim\sqrt[n]{f}=\sqrt[n]{L}$ όταν οι τιμές είναι $\ge 0$
    theorem lim_root (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (fun x => f x ^ ((1 : ℝ) / n)) x₀ (L ^ ((1 : ℝ) / n))
  • Ο ορισμός $\varepsilon$-$\delta$ του βιβλίου συμφωνεί με το όριο της Mathlib
    theorem hasLim_iff (f : ℝ → ℝ) (x₀ L : ℝ) : HasLim f x₀ L ↔ Tendsto f (𝓝[≠] x₀) (𝓝 L)

Ο ορισμός του βιβλίου γράφεται ως HasLim f x₀ L: για κάθε $\varepsilon\gt 0$ υπάρχει $\delta\gt 0$ ώστε, για κάθε $x$ με $0\lt|x-x_0|\lt\delta$, να ισχύει $|f(x)-L|\lt\varepsilon$. Το άθροισμα $f+g$ είναι η συνάρτηση $x\mapsto f(x)+g(x)$. Ο νόμος του αθροίσματος αποδεικνύεται κατευθείαν από τον ορισμό. Για τους υπόλοιπους δείχνουμε πρώτα ότι ο ορισμός του βιβλίου συμφωνεί με το όριο της Mathlib, Tendsto f (𝓝[≠] x₀) (𝓝 L), όπου το 𝓝[≠] x₀ σημαίνει «$x\to x_0$ με $x\neq x_0$». Έτσι, χρησιμοποιούμε έτοιμα τα θεωρήματα της Mathlib. Στον Lean η τετραγωνική ρίζα ορίζεται για κάθε πραγματικό, με $\sqrt{t}=0$ όταν $t\lt 0$, και η δύναμη $t^{1/n}$ συμπίπτει με την $n$-οστή ρίζα όταν $t\ge 0$. Έτσι, όταν $f\ge 0$ κοντά στο $x_0$ και $L\ge 0$ (οι συνθήκες του βιβλίου για άρτιο $n$), οι δύο τελευταίοι νόμοι λένε ακριβώς ό,τι και το βιβλίο. Η περίπτωση περιττού $n$ με αρνητικές τιμές δεν καλύπτεται εδώ, γιατί για $t\lt 0$ η δύναμη $t^{1/n}$ του Lean δεν είναι η πραγματική ρίζα $\sqrt[n]{t}$.

2. Βήμα προς βήμα: $\lim(f+g)=L+M$

Η ιδέα: κάνουμε τα $|f(x)-L|$ και $|g(x)-M|$ μικρότερα από $\varepsilon/2$ το καθένα και χρησιμοποιούμε την τριγωνική ανισότητα. Ξεκινάμε από τον στόχο:

Ο στόχος
f g : ℝ → ℝ
x₀ L M : ℝ
hf : HasLim f x₀ L
hg : HasLim g x₀ M
⊢ HasLim (f + g) x₀ (L + M)

Πάνω από το ⊢ είναι ό,τι ξέρουμε· μετά το ⊢ είναι ό,τι πρέπει να δείξουμε. Μετά από κάθε βήμα δείχνουμε μόνο ό,τι άλλαξε.

  1. intro ε hε

    Παίρνουμε τυχαίο $\varepsilon\gt 0$. Ο ορισμός ξεδιπλώνεται: πρέπει να βρούμε κατάλληλο $\delta$.

    Τι μένει να αποδειχθεί
    ε : ℝ
hε : ε > 0
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f + g) x - (L + M)| < ε
  2. obtain ⟨δ₁, hδ₁, h₁⟩ := hf (ε / 2) (by linarith)

    Από το όριο της $f$, με $\varepsilon/2$ στη θέση του $\varepsilon$, παίρνουμε $\delta_1\gt 0$. Το by linarith δείχνει ότι $\varepsilon/2\gt 0$.

    Τι μένει να αποδειχθεί
    δ₁ : ℝ
hδ₁ : δ₁ > 0
h₁ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₁ → |f x - L| < ε / 2
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f + g) x - (L + M)| < ε
  3. obtain ⟨δ₂, hδ₂, h₂⟩ := hg (ε / 2) (by linarith)

    Ομοίως, από το όριο της $g$ παίρνουμε $\delta_2\gt 0$.

    Τι μένει να αποδειχθεί
    δ₂ : ℝ
hδ₂ : δ₂ > 0
h₂ : ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ₂ → |g x - M| < ε / 2
⊢ ∃ δ > 0, ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < δ → |(f + g) x - (L + M)| < ε
  4. refine ⟨min δ₁ δ₂, lt_min hδ₁ hδ₂, ?_⟩

    Διαλέγουμε $\delta=\min(\delta_1,\delta_2)$, που είναι θετικό.

    Τι μένει να αποδειχθεί
    ⊢ ∀ (x : ℝ), 0 < |x - x₀| → |x - x₀| < min δ₁ δ₂ → |(f + g) x - (L + M)| < ε
  5. intro x hx hxδ

    Παίρνουμε $x$ με $0\lt|x-x_0|\lt\delta$.

    Τι μένει να αποδειχθεί
    x : ℝ
hx : 0 < |x - x₀|
hxδ : |x - x₀| < min δ₁ δ₂
⊢ |(f + g) x - (L + M)| < ε
  6. have hfx := h₁ x hx (lt_of_lt_of_le hxδ (min_le_left δ₁ δ₂))

    Επειδή $\delta\le\delta_1$, ισχύει $|f(x)-L|\lt\varepsilon/2$.

    Τι μένει να αποδειχθεί
    hfx : |f x - L| < ε / 2
⊢ |(f + g) x - (L + M)| < ε
  7. have hgx := h₂ x hx (lt_of_lt_of_le hxδ (min_le_right δ₁ δ₂))

    Επειδή $\delta\le\delta_2$, ισχύει $|g(x)-M|\lt\varepsilon/2$.

    Τι μένει να αποδειχθεί
    hgx : |g x - M| < ε / 2
⊢ |(f + g) x - (L + M)| < ε
  8. rw [Pi.add_apply]

    Η τιμή της $f+g$ στο $x$ είναι $f(x)+g(x)$.

    Τι μένει να αποδειχθεί
    ⊢ |f x + g x - (L + M)| < ε
  9. calc |f x + g x - (L + M)| = |(f x - L) + (g x - M)| := by congr 1; ring
  _ ≤ |f x - L| + |g x - M| := abs_add_le _ _
  _ < ε / 2 + ε / 2 := add_lt_add hfx hgx
  _ = ε := by ring

    Η αλυσίδα: $|f(x)+g(x)-(L+M)|$${}=|(f(x)-L)+(g(x)-M)|$, που από την τριγωνική ανισότητα είναι $\le|f(x)-L|+|g(x)-M|$, και αυτό είναι $\lt\varepsilon/2+\varepsilon/2$${}=\varepsilon$.

    ✓ Καμία εκκρεμότητα: η απόδειξη ολοκληρώθηκε.

3. Δοκίμασε εσύ: το όριο μιας σταθεράς

Δείξε ότι $\lim_{x\to x_0}c=c$. Για τη σταθερή συνάρτηση κάνει οποιοδήποτε $\delta$. Άνοιξε την άσκηση στον Lean και αντικατάστησε τη λέξη sorry με τα δικά σου βήματα. Όταν η απόδειξη είναι σωστή, το μήνυμα declaration uses sorry φεύγει και δεν εμφανίζεται κανένα κόκκινο σφάλμα.

Άνοιξε την άσκηση στον Lean
Υπόδειξη

Ξεκίνα με intro ε hε και πάρε $\delta=1$: refine ⟨1, one_pos, ?_⟩. Μετά, για τυχαίο $x$ (intro x _ _), μένει $|c-c|\lt\varepsilon$, δηλαδή $0\lt\varepsilon$: simpa using hε.

Λύση
theorem lim_const (c x₀ : ℝ) : HasLim (fun _ => c) x₀ c := by
  intro ε hε
  refine ⟨1, one_pos, ?_⟩
  intro x _ _
  simpa using hε

4. Στη Mathlib

Χρησιμοποιήσαμε τα εξής θεωρήματα:

  • abs_add_le: η τριγωνική ανισότητα $|a+b|\le|a|+|b|$.
  • Metric.tendsto_nhdsWithin_nhds: το όριο της Mathlib γραμμένο με $\varepsilon$ και $\delta$.
  • Filter.Tendsto.sub: το όριο διαφοράς.
  • Filter.Tendsto.mul: το όριο γινομένου.
  • Filter.Tendsto.div: το όριο πηλίκου.
  • Filter.Tendsto.pow: το όριο δύναμης.
  • Filter.Tendsto.sqrt: το όριο τετραγωνικής ρίζας.
  • Filter.Tendsto.rpow_const: το όριο της $f^{p}$ για σταθερό εκθέτη $p\ge 0$.

import Mathlib

namespace Κεφ9.NomoiOrion
open Filter Topology

-- ο ορισμός του βιβλίου: lim_{x→x₀} f(x) = L
def HasLim (f : ℝ → ℝ) (x₀ L : ℝ) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ x, 0 < |x - x₀| → |x - x₀| < δ → |f x - L| < ε

theorem lim_add (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f + g) x₀ (L + M) := by
  intro ε hε
  obtain ⟨δ₁, hδ₁, h₁⟩ := hf (ε / 2) (by linarith)
  obtain ⟨δ₂, hδ₂, h₂⟩ := hg (ε / 2) (by linarith)
  refine ⟨min δ₁ δ₂, lt_min hδ₁ hδ₂, ?_⟩
  intro x hx hxδ
  have hfx := h₁ x hx (lt_of_lt_of_le hxδ (min_le_left δ₁ δ₂))
  have hgx := h₂ x hx (lt_of_lt_of_le hxδ (min_le_right δ₁ δ₂))
  rw [Pi.add_apply]
  calc |f x + g x - (L + M)| = |(f x - L) + (g x - M)| := by congr 1; ring
    _ ≤ |f x - L| + |g x - M| := abs_add_le _ _
    _ < ε / 2 + ε / 2 := add_lt_add hfx hgx
    _ = ε := by ring

theorem lim_const (c x₀ : ℝ) : HasLim (fun _ => c) x₀ c := by
  intro ε hε
  refine ⟨1, one_pos, ?_⟩
  intro x _ _
  simpa using hε

-- ο ορισμός του βιβλίου συμφωνεί με το όριο της Mathlib
theorem hasLim_iff (f : ℝ → ℝ) (x₀ L : ℝ) : HasLim f x₀ L ↔ Tendsto f (𝓝[≠] x₀) (𝓝 L) := by
  rw [Metric.tendsto_nhdsWithin_nhds]
  constructor
  · intro h ε hε
    obtain ⟨δ, hδ, hx⟩ := h ε hε
    refine ⟨δ, hδ, ?_⟩
    intro x hx1 hx2
    rw [Real.dist_eq] at hx2 ⊢
    exact hx x (abs_pos.mpr (sub_ne_zero.mpr (Set.mem_compl_singleton_iff.mp hx1))) hx2
  · intro h ε hε
    obtain ⟨δ, hδ, hx⟩ := h ε hε
    refine ⟨δ, hδ, ?_⟩
    intro x hx1 hx2
    have hne : x ≠ x₀ := sub_ne_zero.mp (abs_pos.mp hx1)
    have h2 := hx (Set.mem_compl_singleton_iff.mpr hne) (by rw [Real.dist_eq]; exact hx2)
    rwa [Real.dist_eq] at h2

theorem lim_sub (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f - g) x₀ (L - M) := by
  rw [hasLim_iff] at hf hg ⊢
  exact hf.sub hg

theorem lim_mul (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M) :
    HasLim (f * g) x₀ (L * M) := by
  rw [hasLim_iff] at hf hg ⊢
  exact hf.mul hg

theorem lim_div (f g : ℝ → ℝ) (x₀ L M : ℝ) (hf : HasLim f x₀ L) (hg : HasLim g x₀ M)
    (hM : M ≠ 0) : HasLim (f / g) x₀ (L / M) := by
  rw [hasLim_iff] at hf hg ⊢
  exact hf.div hg hM

theorem lim_pow (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (f ^ n) x₀ (L ^ n) := by
  rw [hasLim_iff] at hf ⊢
  exact hf.pow n

theorem lim_sqrt (f : ℝ → ℝ) (x₀ L : ℝ) (hf : HasLim f x₀ L) :
    HasLim (fun x => √(f x)) x₀ (√L) := by
  rw [hasLim_iff] at hf ⊢
  exact hf.sqrt

theorem lim_root (f : ℝ → ℝ) (x₀ L : ℝ) (n : ℕ) (hf : HasLim f x₀ L) :
    HasLim (fun x => f x ^ ((1 : ℝ) / n)) x₀ (L ^ ((1 : ℝ) / n)) := by
  rw [hasLim_iff] at hf ⊢
  exact hf.rpow_const (Or.inr (by positivity))
