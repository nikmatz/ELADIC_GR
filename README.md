### Αποδείξεις σε Lean

Το [Lean](https://lean-lang.org/) είναι γλώσσα στην οποία μια απόδειξη γράφεται τόσο αυστηρά, ώστε ο υπολογιστής ελέγχει κάθε βήμα της. Όπου υπάρχει απόδειξη σε Lean, η σελίδα του θεωρήματος έχει δεύτερη καρτέλα, **«Απόδειξη σε Lean»**, με:

- τη διατύπωση του βιβλίου δίπλα στη διατύπωση σε Lean,
- την απόδειξη βήμα προς βήμα, με ό,τι μένει να αποδειχθεί μετά από κάθε βήμα,
- μια άσκηση για τον αναγνώστη, που ανοίγει έτοιμη στον [online editor του Lean](https://live.lean-lang.org/),
- ολόκληρο τον κώδικα, όπως ελέγχθηκε (Lean 4 με τη βιβλιοθήκη Mathlib).

Η καρτέλα με τα Μεγάλα Γλωσσικά Μοντέλα μένει πρώτη, όπως στο βιβλίο. Οι αποδείξεις σε Lean προστίθενται σταδιακά. Πρώτη: [Βασικές Ιδιότητες Γραμμικού Χώρου](https://nikmatz.github.io/ELADIC_GR/prompts/ch01/proof-grammikos-idiotites.html#lean) (Κεφ. 1).
