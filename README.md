# Στοιχεία Γραμμικής Άλγεβρας και Στοιχεία Διαφορικού και Ολοκληρωτικού Λογισμού

### Ψηφιακό Συνοδευτικό Υλικό

Ψηφιακές, διαδραστικές δραστηριότητες που συνοδεύουν το βιβλίο **«Στοιχεία Γραμμικής Άλγεβρας και Στοιχεία Διαφορικού και Ολοκληρωτικού Λογισμού»** του Ν. Ματζάκου. Η πρόσβαση γίνεται μέσω **QR codes** από το έντυπο βιβλίο ή απευθείας online.

🔗 **https://nikmatz.github.io/ELADIC_GR/**

### Περιεχόμενα

| Φάκελος | Περιγραφή |
|---------|-----------|
| `quizzes/` | Διαδραστικά κουίζ αυτοαξιολόγησης — 20 κουίζ (`ch00`–`ch19`, ένα ανά κεφάλαιο) + `vol2_diaf_ex`, ~212 ερωτήσεις. Τυχαιοποίηση ερωτήσεων/επιλογών, υποδείξεις ανά ερώτηση, ανατροφοδότηση ανά θέμα, «ξαναπροσπάθησε τα λάθος» και αποθήκευση καλύτερου σκορ. |
| `code/` | Δραστηριότητες CAS (`ch00`–`ch19`, ένα ανά κεφάλαιο, + `vol2_diaf_ex`): κώδικας **Maxima** και κώδικας **Python που τρέχει μέσα στη σελίδα** (Pyodide — NumPy/SciPy/SymPy/Matplotlib, χωρίς εγκατάσταση). |
| `prompts/` | Σελίδες αποδείξεων: κάθε θεώρημα ανοίγει με έτοιμο ερώτημα σε Μεγάλο Γλωσσικό Μοντέλο (ChatGPT / Claude / Grok / Perplexity), με βιβλιογραφικές πηγές για ανεξάρτητη επαλήθευση. |
| `hist_prompts/` | Ιστορικά σημειώματα με τη βοήθεια Μεγάλων Γλωσσικών Μοντέλων. |
| `animations/` | Διαδραστικές οπτικοποιήσεις εννοιών (`ch00_ypovathro` … `ch19_seires`, + `vol2_diaf_ex`). |
| `appendices/` | Online οδηγοί Maxima & Python. |
| `catalog.json` | Ευρετήριο όλου του υλικού (path/url/κεφάλαιο) για τη δημιουργία QR codes. |
| `quizzes/`, `_shared/` | Κοινά στυλ (book.css) και υλικό. |

### Αρίθμηση κεφαλαίων

Οι φάκελοι `chNN` **ακολουθούν την αρίθμηση των κεφαλαίων του βιβλίου (0–19)**:

| # | Κεφάλαιο | | # | Κεφάλαιο |
|---|----------|---|---|----------|
| 0 | Μαθηματικό Υπόβαθρο | | 10 | Παράγωγος Συνάρτησης |
| 1 | Γραμμικοί Διανυσματικοί Χώροι | | 11 | Μονοτονία, Κυρτότητα και Ακρότατα |
| 2 | Άλγεβρα Πινάκων | | 12 | Εφαρμογές Παραγώγου |
| 3 | Γραμμικά Συστήματα | | 13 | Αόριστο Ολοκλήρωμα |
| 4 | Γραμμικοί Μετασχηματισμοί | | 14 | Ορισμένο Ολοκλήρωμα |
| 5 | Ιδιοτιμές και Ιδιοδιανύσματα | | 15 | Θεμελιώδες Θεώρημα Λογισμού |
| 6 | Διαγωνοποίηση Πινάκων | | 16 | Τεχνικές Ολοκλήρωσης |
| 7 | Δυναμικά Συστήματα και Αλυσίδες Markov | | 17 | Εφαρμογές Ολοκληρωτικού Λογισμού |
| 8 | Συναρτήσεις Πραγματικής Μεταβλητής | | 18 | Γενικευμένα Ολοκληρώματα |
| 9 | Όρια και Συνέχεια | | 19 | Ακολουθίες και Σειρές |

Ο φάκελος **`vol2_diaf_ex`** (σε `code/`, `quizzes/`, `animations/`) περιέχει υλικό για τις **Διαφορικές Εξισώσεις**, το οποίο **δεν ανήκει στον παρόντα τόμο** αλλά προορίζεται για τον **2ο τόμο**.
