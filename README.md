# Στοιχεία Γραμμικής Άλγεβρας, Διαφορικού & Ολοκληρωτικού Λογισμού

### Ψηφιακό Συνοδευτικό Υλικό

Ψηφιακές, διαδραστικές δραστηριότητες που συνοδεύουν το βιβλίο **«Στοιχεία Γραμμικής Άλγεβρας, Διαφορικού & Ολοκληρωτικού Λογισμού»** του Ν. Ματζάκου. Η πρόσβαση γίνεται μέσω **QR codes** από το έντυπο βιβλίο ή απευθείας online.

🔗 **https://nikmatz.github.io/ELADIC_GR/**

### Περιεχόμενα

| Φάκελος | Περιγραφή |
|---------|-----------|
| `quizzes/` | Διαδραστικά κουίζ αυτοαξιολόγησης — 21 κουίζ (`ch00`–`ch20`, ένα ανά κεφάλαιο), 212 ερωτήσεις. Τυχαιοποίηση ερωτήσεων/επιλογών, υποδείξεις ανά ερώτηση, ανατροφοδότηση ανά θέμα, «ξαναπροσπάθησε τα λάθος» και αποθήκευση καλύτερου σκορ. |
| `code/` | Δραστηριότητες CAS (`ch00`–`ch20`, ένα ανά κεφάλαιο): κώδικας **Maxima** και κώδικας **Python που τρέχει μέσα στη σελίδα** (Pyodide — NumPy/SciPy/SymPy/Matplotlib, χωρίς εγκατάσταση). |
| `prompts/` | 178 σελίδες αποδείξεων: κάθε θεώρημα ανοίγει με έτοιμο ερώτημα σε Μεγάλο Γλωσσικό Μοντέλο (ChatGPT / Claude / Grok / Perplexity), με βιβλιογραφικές πηγές για ανεξάρτητη επαλήθευση. |
| `hist_prompts/` | 39 ιστορικά σημειώματα με τη βοήθεια Μεγάλων Γλωσσικών Μοντέλων. |
| `askiseis/` | Επιπλέον ασκήσεις ανά κεφάλαιο (`ch00`–`ch20`), 1.251 εκφωνήσεις με υποδείξεις. |
| `animations/` | 46 διαδραστικές οπτικοποιήσεις εννοιών (`ch00_ypovathro` … `ch20_dynamoseires`). |
| `appendices/` | Online οδηγοί Maxima & Python. |
| `catalog.json` | Ευρετήριο όλου του υλικού (328 εγγραφές: path/url/κεφάλαιο) για τη δημιουργία QR codes. |
| `_shared/` | Κοινά στυλ (`book.css`). |
