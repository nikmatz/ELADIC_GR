📋 Περιεχόμενα Δραστηριοτήτων

Αντικείμενο: ολοκλήρωμα σε άπειρο διάστημα, ιδιαίτερο σημείο, p-κριτήριο, εκθετικό ολοκλήρωμα

Επιλέξτε γλώσσα από τις καρτέλες. Τον κώδικα Python μπορείτε να τον τρέξετε εδώ μέσα στη σελίδα (κουμπί «▶ Τρέξε») — μπορείτε και να τον επεξεργαστείτε. Ο κώδικας Maxima εκτελείται στο wxMaxima.

;; Ματζάκος, Ν. (2026). Στοιχεία Γραμμικής Άλγεβρας, Διαφορικού & Ολοκληρωτικού Λογισμού. NewTech Publications.

/* 1. Ολοκλήρωμα σε άπειρο διάστημα */
print("1. integrate(1/x^2, x, 1, inf) =",
      integrate(1/x^2, x, 1, inf));
print("2. integrate(1/x,   x, 1, inf) =",
      integrate(1/x,   x, 1, inf));

/* 2. Ολοκλήρωμα με ιδιαίτερο σημείο */
print("3. integrate(1/sqrt(x), x, 0, 1) =",
      integrate(1/sqrt(x), x, 0, 1));
print("4. integrate(1/x, x, 0, 1) =",
      integrate(1/x, x, 0, 1));

/* 3. p-κριτήριο */
for p: [1/2, 3/2, 2, 3] do (
  val: integrate(1/x^p, x, 1, inf),
  print("p =", p, "->", val)
)$

/* 4. Εκθετικά */
print("∫e^(-x) dx από 0 ως ∞ =",
      integrate(exp(-x), x, 0, inf));
print("∫x·e^(-x) dx από 0 ως ∞ =",
      integrate(x*exp(-x), x, 0, inf));
print("∫x²·e^(-x) dx από 0 ως ∞ =",
      integrate(x^2*exp(-x), x, 0, inf));

/* 5. Γράφημα σύγκρισης */
plot2d([1/x^2, 1/x], [x, 1, 10],
       [legend, "1/x² (σύγκλ.)", "1/x (αποκλ.)"],
       [title, "Σύγκριση 1/x και 1/x²"])$
